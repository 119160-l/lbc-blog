# 第4章 随机变量及其分布 · 公式推导

## 1. 随机变量的定义

**为什么要引入随机变量？**

样本空间 $\Omega$ 中的事件是集合，无法直接进行加减乘除运算。将样本点映射为实数，就能引入微积分工具。

> **定义**：随机变量 $X$ 是从样本空间 $\Omega$ 到实数集 $\mathbb{R}$ 的映射
> $$X: \Omega \to \mathbb{R}$$
> 即对每个样本点 $\omega \in \Omega$，$X(\omega)$ 是一个实数。

这相当于给每个随机结果"贴上一个数字标签"，使得我们能够用数学公式描述随机现象。

---

## 2. 离散型随机变量与概率质量函数（PMF）

**定义**：若随机变量 $X$ 的取值集合为有限集或可数无限集，则称 $X$ 为离散型随机变量。

**概率质量函数**（Probability Mass Function, PMF）：
$$p(x) = P(X = x)$$

**性质**：
1. 非负性：$p(x) \ge 0$
2. 归一性：$\displaystyle\sum_{x} p(x) = 1$

**推导说明**：由于离散型随机变量的取值是可数的，概率分配就是给每个可能取值赋一个非负概率值，且总和为 1，这是概率公理的直接推论。

---

## 3. 连续型随机变量与概率密度函数（PDF）

### 从直方图到密度函数

对于连续型随机变量，单点概率为 0（因为取值有无穷多个），我们需要用"单位长度的概率"来描述。

考虑区间 $[x, x+\Delta x)$ 上的概率：
$$P(x \le X < x+\Delta x)$$

定义平均密度为 $\dfrac{P(x \le X < x+\Delta x)}{\Delta x}$，令 $\Delta x \to 0$，得到**概率密度函数**：

$$f(x) = \lim_{\Delta x \to 0} \frac{P(x \le X < x+\Delta x)}{\Delta x}$$

### 正式定义

若存在非负函数 $f(x)$，使得对任意 $a \le b$ 有：
$$P(a \le X \le b) = \int_a^b f(x)\,dx$$

则称 $X$ 为连续型随机变量，$f(x)$ 为概率密度函数。

**性质**：
1. 非负性：$f(x) \ge 0$
2. 归一性：$\displaystyle\int_{-\infty}^{\infty} f(x)\,dx = 1$

**重要结论**：连续型随机变量单点概率为 0
$$P(X = a) = \int_a^a f(x)\,dx = 0$$

## 4. 累积分布函数（CDF）

### 定义

$$F(x) = P(X \le x)$$

累积分布函数适用于所有随机变量（离散、连续、混合型）。

![离散vs连续CDF](./figures/02_离散vs连续CDF.png)

*图：左图为离散型 Binomial(10, 0.5) 的 PMF（杆状图）和 CDF（阶梯状、右连续）；右图为连续型 Normal(0,1) 的 CDF（光滑曲线、处处连续）*

### 离散型 CDF

$$F(x) = \sum_{t \le x} p(t)$$

其中 $p(t)$ 是 PMF。

### 连续型 CDF

$$F(x) = \int_{-\infty}^x f(t)\,dt$$

其中 $f(t)$ 是 PDF。

### CDF 的性质

1. **单调不减**：若 $x_1 < x_2$，则 $F(x_1) \le F(x_2)$
2. **极限性质**：
   $$F(-\infty) = \lim_{x \to -\infty} F(x) = 0$$
   $$F(\infty) = \lim_{x \to \infty} F(x) = 1$$
3. **右连续性**：$F(x) = \lim_{t \to x^+} F(t)$

### PDF 与 CDF 的关系（连续型）

由微积分基本定理：
$$f(x) = F'(x)$$

即密度函数是分布函数的导数。

![PDF与CDF关系](./figures/01_PDF与CDF关系.png)

*图：正态分布 N(0,1) 的 PDF（左）与 CDF（右）。PDF 曲线下的面积 = 概率；CDF 的高度 = P(X ≤ x)；两者通过微积分基本定理互逆。阴影面积为 P(-1 ≤ X ≤ 1) ≈ 0.683*

### 区间概率计算

$$P(a < X \le b) = F(b) - F(a)$$

**推导**：
$$P(a < X \le b) = P(X \le b) - P(X \le a) = F(b) - F(a)$$

## 5. 随机变量函数的分布

### 5.1 离散情况

若 $Y = g(X)$，则：
$$\boxed{p_Y(y) = \sum_{x: g(x) = y} p_X(x)}$$

**推导**：$P(Y = y) = P(g(X) = y) = P(\{x: g(x) = y\}) = \sum_{x: g(x)=y} p_X(x)$

### 5.2 连续情况：CDF 法（通用方法）

**步骤**：
1. 写出 $Y$ 的 CDF：$F_Y(y) = P(Y \le y) = P(g(X) \le y)$
2. 将不等式转化为关于 $X$ 的形式
3. 用 $F_X$ 表示
4. 对 $y$ 求导得到 $f_Y(y)$

$$\boxed{F_Y(y) = P(g(X) \le y), \quad f_Y(y) = \frac{d}{dy}F_Y(y)}$$

### 5.3 线性变换 $Y = aX + b$

**$a > 0$ 时**：
$$F_Y(y) = P(aX + b \le y) = P\left(X \le \frac{y-b}{a}\right) = F_X\left(\frac{y-b}{a}\right)$$
$$f_Y(y) = \frac{d}{dy}F_Y(y) = f_X\left(\frac{y-b}{a}\right) \cdot \frac{1}{a}$$

**$a < 0$ 时**：
$$F_Y(y) = P(aX + b \le y) = P\left(X \ge \frac{y-b}{a}\right) = 1 - F_X\left(\frac{y-b}{a}\right)$$
$$f_Y(y) = -f_X\left(\frac{y-b}{a}\right) \cdot \frac{1}{a} = f_X\left(\frac{y-b}{a}\right) \cdot \frac{1}{|a|}$$

**统一公式**：
$$\boxed{f_Y(y) = \frac{1}{|a|} f_X\left(\frac{y-b}{a}\right)}$$

### 5.4 单调变换法

若 $g$ 是单调函数，且 $g^{-1}$ 可导，则：
$$\boxed{f_Y(y) = f_X\left(g^{-1}(y)\right) \cdot \left|\frac{d}{dy} g^{-1}(y)\right|}$$

**推导**：
- 若 $g$ 单调递增：$F_Y(y) = P(g(X) \le y) = P(X \le g^{-1}(y)) = F_X(g^{-1}(y))$
  $$f_Y(y) = f_X(g^{-1}(y)) \cdot \frac{d}{dy} g^{-1}(y)$$
- 若 $g$ 单调递减：$F_Y(y) = P(g(X) \le y) = P(X \ge g^{-1}(y)) = 1 - F_X(g^{-1}(y))$
  $$f_Y(y) = -f_X(g^{-1}(y)) \cdot \frac{d}{dy} g^{-1}(y) = f_X(g^{-1}(y)) \cdot \left(-\frac{d}{dy} g^{-1}(y)\right)$$
- 合并两种情况，取绝对值。

## 6. 分位数函数

**定义**：分位数函数是 CDF 的广义逆函数：
$$\boxed{Q(p) = F^{-1}(p) = \inf\{x: F(x) \ge p\}, \quad 0 < p < 1}$$

**中位数**：$p = 0.5$ 对应的分位数。

**解释**：$Q(p)$ 表示使得 $P(X \le x) \ge p$ 成立的最小 $x$ 值。当 $F$ 严格递增且连续时，$Q(p)$ 就是普通的反函数。

## 一、为什么需要条件概率？

### 一个经典问题：癌症筛查

假设有一种癌症，在人群中的患病率为 $0.1\%$。有一种检测方法：
- 如果一个人确实患病，检测结果为阳性的概率是 $99\%$（灵敏度）
- 如果一个人没有患病，检测结果为阴性的概率是 $98\%$（特异度）

现在你去做检测，结果呈阳性——你觉得自己患病的概率是多少？

很多人直觉地回答"约 $99\%$"，但这是错误的。正确答案是大约 **$4.7\%$**。

这个反直觉的结果告诉我们一个深刻的事实：**检测阳性 ≠ 患病**。我们需要一种数学工具来正确更新我们的信念——这就是**条件概率**和**贝叶斯公式**。

> 条件概率是统计推断的基石，它让我们能够从观测数据中逆向推断原因。

## 二、条件概率的本质——信息更新

### 从先验到后验

条件概率的核心思想是**信息更新**：

- **先验概率** $P(A)$：在获得任何额外信息之前，对事件 $A$ 发生的信念
- **后验概率** $P(A|B)$：在观察到事件 $B$ 发生后，更新后的信念

$$
\underbrace{P(A)}_{\text{先验}} \quad \xrightarrow{\text{观察到 }B} \quad \underbrace{P(A|B)}_{\text{后验}}
$$

**贝叶斯公式就是信念更新的规则**：它告诉我们如何根据新的证据来修正旧有的判断。

### 直观理解

条件概率 $P(A|B)$ 可以理解为"在 $B$ 成立的缩小版世界中，$A$ 发生的比例"。当我们知道 $B$ 发生了，样本空间就从 $\Omega$ 缩小到了 $B$，原来不可能的事件仍然不可能，但可能的事件概率需要重新按比例分配。

![条件概率缩小样本空间](./figures/01_条件概率缩小样本空间.png)

*知道 $B$ 发生后，样本空间从 $\Omega$ 缩小为 $B$，条件概率正是在缩小后的空间中重新计算比例。*

## 三、全概率公式的思维模型——分情况讨论

### 核心思想：加权平均

全概率公式的思维模型可以用一句话概括：

> **如果一个问题可以分解为若干互斥的情况，那么总概率就是各情况概率的加权平均。**

$$
P(B) = \sum_{i=1}^n P(A_i) \cdot P(B|A_i)
$$

其中 $P(A_i)$ 是权重，$P(B|A_i)$ 是在各情况下的条件概率。

### 生活中的例子

假设你要计算"明天迟到的概率"：
- 晴天（概率 $0.7$），迟到概率 $0.05$
- 雨天（概率 $0.3$），迟到概率 $0.2$

那么总迟到概率 = $0.7 \times 0.05 + 0.3 \times 0.2 = 0.095$（$9.5\%$）。

这就是全概率公式——**分情况讨论，加权求和**。

![全概率公式分割](./figures/02_全概率公式分割.png)

*划分将样本空间分成互斥的若干块，$B$ 的总概率是各块中 $B$ 概率的加权和。*

## 四、贝叶斯公式的思维模型——逆向推理

### 核心思想：由果溯因

贝叶斯公式解决的是**逆向概率**问题：

> 已知结果，反推原因的概率。

$$
\boxed{P(\text{原因}|\text{结果}) = \frac{P(\text{原因}) \times P(\text{结果}|\text{原因})}{P(\text{结果})}}
$$

### 三要素

| 名称   | 符号        | 含义             |                   |
| ---- | --------- | -------------- | ----------------- |
| 先验概率 | $P(A_k)$  | 看到结果前，对原因的初始判断 |                   |
| 似然   | $P(BA_k)$ |                | 如果该原因成立，出现该结果的可能性 |
| 后验概率 | $P(A_kB)$ |                | 看到结果后，对该原因的修正判断   |

### 直观口诀

> **后验概率 = 先验概率 × 似然 / 全概率**

分母（全概率）是归一化因子，确保所有后验概率之和为 $1$。

![贝叶斯公式树状图](./figures/03_贝叶斯公式树状图.png)

*树状图直观展示逆向推理：由各原因的先验概率与似然出发，经全概率归一化反推后验概率（如癌症筛查中阳性结果对应的真实患病概率）。*

## 五、独立性——事件之间没有信息传递

### 核心思想

如果两个事件独立，那么**知道其中一个是否发生，不会改变另一个发生的概率**。

$$
P(A|B) = P(A) \quad \text{或等价地} \quad P(A \cap B) = P(A) P(B)
$$

### 典型例子

抛两次均匀硬币：
- $A$ = 第一次正面
- $B$ = 第二次正面

显然 $P(A|B) = P(A) = 1/2$，两次抛掷互不影响——这就是独立。

### 独立性的直觉

独立性意味着**信息传递为零**。如果 $A$ 和 $B$ 独立，那么：
- 知道 $B$ 发生，对 $A$ 的概率判断**没有任何影响**
- 知道 $A$ 发生，对 $B$ 的概率判断也**没有任何影响**

## 六、互斥 vs 独立——对比表格

初学者最容易混淆的概念就是"互斥"和"独立"，它们本质上是相反的。

| 对比维度 | 互斥 (Mutually Exclusive) | 独立 (Independent) |
|---------|--------------------------|-------------------|
| **定义** | $A \cap B = \varnothing$ | $P(A \cap B) = P(A)P(B)$ |
| **同时发生** | 不可能 | 可能 |
| **知道 $B$ 发生对 $A$ 的影响** | $P(A|B)=0$，$B$ 发生意味着 $A$ 一定不发生 | $P(A|B)=P(A)$，$B$ 发生不影响 $A$ |
| **概率含义** | 两个事件没有重叠 | 一个事件的信息不包含另一个事件的信息 |
| **关系** | 若 $P(A)>0$ 且 $P(B)>0$，则互斥**一定不独立** | 独立事件通常不互斥 |

### 为什么互斥且概率大于 0 就一定不独立？

$$
\begin{aligned}
\text{互斥} &\Rightarrow A \cap B = \varnothing \Rightarrow P(A \cap B) = 0 \\
P(A) > 0,\; P(B) > 0 &\Rightarrow P(A) P(B) > 0 \\
\therefore\; P(A \cap B) &\neq P(A) P(B)
\end{aligned}
$$

所以互斥且概率为正的事件**一定不独立**。

## 七、知识地图

```
条件概率
    ├── 乘法公式 ──→ 计算交事件的概率
    ├── 全概率公式 ──→ 分情况讨论，加权求和
    ├── 贝叶斯公式 ──→ 由果推因，信念更新
    └── 独立性
        ├── 两两独立 ──→ 信息不传递
        ├── 相互独立 ──→ 更强的条件
        └── 条件独立 ──→ 控制变量后的独立性
```

**学习路径建议**：
1. 先理解条件概率的含义（样本空间缩小）
2. 掌握乘法公式（串联条件概率）
3. 理解全概率公式（分情况讨论的数学化）
4. 掌握贝叶斯公式（逆向推理，统计推断的核心）
5. 理解独立性（信息不传递的特殊情况）

# 综合冲刺 · 典型题型与解题套路

> 冲刺阶段第三站：考试不是"背公式"，是"识别题型 → 套套路 → 算对数字"。本文把 12 章的高频题型整理成**可照做的分步套路**，并附常见陷阱与跨章节综合模式。
> 使用方式：每类套路先看"识别标志"（一句话判断该用哪个套路），再按步骤演练；最后做综合模式题检验串联能力。

---

## 套路总览（先记住这张图）

```
概率计算类：计数 → 事件概率 → 条件/贝叶斯 → 分布
随机变量类：分布 → 函数分布 → 联合/边缘/条件 → 和的分布
数字特征类：期望/方差/协方差 → 条件期望 → 矩
极限类：大数定律 → CLT 近似（含连续性修正）
统计推断类：抽样分布 → 点估计 → 区间估计 → 假设检验 → 回归/ANOVA
```

**拿到任何题先问三个问题**：
1. 题目问的是**概率**、**分布**、**期望/方差**，还是**推断结论**？（决定用哪一类套路）
2. 涉及**几个随机变量**？独立吗？（决定用单变量还是多维套路）
3. 是**已知分布求量**，还是**未知参数用样本估**？（决定用概率论还是统计推断套路）

## 一、概率计算类（第1-3章）

### 套路 1.1 古典概型计数

**识别标志**："随机取""等可能""不放回/有放回"，事件是有限集合。

**步骤**：
1. 确定样本空间 $\Omega$ 的计数方式（排列 or 组合）
2. 数出 $|A|$（分子计数与分母必须**同一种计数规则**）
3. $P(A)=|A|/|\Omega|$

**示例**（经典）：袋中 5 红 3 白，不放回取 3 个，恰 2 红的概率。
- 分母：$C_8^3$（组合，无序）
- 分子：$C_5^2C_3^1$（2 红 1 白）
- $P=\dfrac{C_5^2C_3^1}{C_8^3}=\dfrac{10\times3}{56}=\dfrac{15}{28}$

**陷阱**：分子分母计数规则必须一致（都有序或都无序）；"至少 1 个"优先用 $1-P(\text{无})$。

### 套路 1.2 "至少/至多"类

**识别标志**："至少一个""至多一个""都没有"。

**步骤**：
1. 找补事件（"至少 1 个"的补是"0 个"）
2. 算补事件概率（通常更简单）
3. 答案 $=1-P(\text{补})$

**示例**：生日问题——$n$ 人生日全不同的概率 $=\dfrac{365!}{(365-n)!\,365^n}$，至少两人同日的概率 $=1-$ 上式。

### 套路 1.3 全概率 / 贝叶斯

**识别标志**：
- 全概率："先发生某件事，再发生目标事件"（分层结构）→ 求目标事件总概率
- 贝叶斯："已经看到结果，反推是哪条路径产生的" → 求条件概率

**步骤（全概率）**：
1. 找"分层的划分" $\{A_i\}$（互斥且并集为全空间）
2. 每个 $A_i$ 下目标事件的概率 $P(B|A_i)$
3. $P(B)=\sum_i P(A_i)P(B|A_i)$

**步骤（贝叶斯）**：在全概率基础上加一步
4. $P(A_k|B)=\dfrac{P(A_k)P(B|A_k)}{\sum_j P(A_j)P(B|A_j)}$

**示例**：一车间有两台机器，甲产量占 60%（次品率 2%），乙占 40%（次品率 4%）。
- 抽一件是次品的概率：$0.6\times0.02+0.4\times0.04=0.028$
- 已知抽到次品，来自甲的概率：$\dfrac{0.6\times0.02}{0.028}=\dfrac{3}{7}$

**陷阱**：贝叶斯分母忘写全概率公式；把 $P(B|A)$ 与 $P(A|B)$ 混用。

### 套路 1.4 独立性判定与使用

**识别标志**：出现"独立"二字，或需判断是否独立。

**步骤**：
1. 验证 $P(AB)=P(A)P(B)$（两事件）
2. 多事件：任意子集的乘积等式都成立才算相互独立
3. 独立时，"都发生"=概率相乘；"至少一个"用 $1-\prod(1-P_i)$

## 二、随机变量类（第4-6章）

### 套路 2.1 已知分布求概率

**识别标志**：给出分布类型/参数，求 $P(a\le X\le b)$。

**步骤**：
1. 离散：把区间内所有 $k$ 的分布律相加（注意端点）
2. 连续：$P(a\le X\le b)=F(b)-F(a)=\int_a^b f(x)dx$
3. 正态：标准化 $Z=(X-\mu)/\sigma$ 后查 $\Phi$ 表

**示例**：$X\sim N(60,100)$，求 $P(X\ge 75)$。
- $P(X\ge75)=P(Z\ge\frac{75-60}{10})=P(Z\ge1.5)=1-\Phi(1.5)=1-0.9332=0.0668$

**陷阱**：$P(X\ge a)$ 用 $1-F(a)$ 而非 $F(a)$；标准化方向"先减后除"。

### 套路 2.2 求 $Y=g(X)$ 的分布（函数分布）

**识别标志**："设 $Y=X^2$（或 $aX+b$ 等），求 $Y$ 的分布"。

**步骤**：
1. 判断 $g$ 是否严格单调可导
   - 单调 → **变换法**：$f_Y(y)=f_X(g^{-1}(y))\cdot\left|\dfrac{d}{dy}g^{-1}(y)\right|$（注意写出 $y$ 的取值范围）
   - 非单调（如 $Y=X^2$）→ **CDF 法**：
2. CDF 法：先求 $F_Y(y)=P(g(X)\le y)$，把不等式反解成 $X$ 的区间，用 $F_X$ 表达，再求导得 $f_Y$

**示例**：$X\sim U(0,1)$，$Y=X^2$。对 $0<y<1$：
- $F_Y(y)=P(X\le\sqrt y)=\sqrt y$，故 $f_Y(y)=\dfrac{1}{2\sqrt y}$，$0<y<1$

**陷阱**：忘记写 $Y$ 的取值范围（变换后定义域变了）；非单调时直接套单调公式。

### 套路 2.3 联合分布 → 边缘 / 条件

**识别标志**：给联合密度/分布律，求 $f_X$、$f_{Y|X}$、判断独立。

**步骤**：
1. 边缘：$f_X(x)=\int_{-\infty}^{\infty}f(x,y)dy$（离散则求和），**注意积分范围由联合密度的定义域决定**
2. 条件：$f_{Y|X}(y|x)=\dfrac{f(x,y)}{f_X(x)}$，$x$ 固定时看 $y$
3. 独立：$f(x,y)=f_X(x)f_Y(y)$ 对所有 $(x,y)$ 成立

**陷阱**：积分时把 $y$ 的范围写错（$y$ 的范围可能依赖 $x$）；条件分布的分母 $f_X(x)=0$ 处无定义。

### 套路 2.4 独立随机变量的和（卷积）

**识别标志**：$X,Y$ 独立，求 $Z=X+Y$ 的分布。

**步骤**：
1. 写卷积：$f_Z(z)=\int f_X(x)f_Y(z-x)dx$
2. **关键：确定积分范围**——由 $f_X(x)\ne0$ 与 $f_Y(z-x)\ne0$ 联立解出 $x$ 的范围（范围通常依赖 $z$，分段讨论）
3. 逐段积分

**示例**：$X,Y\sim U(0,1)$ 独立，$Z=X+Y$。
- $f_Z(z)=\int_0^1 1\cdot I\{0<z-x<1\}dx$
- $0<z<1$：$f_Z(z)=\int_0^z dx=z$
- $1\le z<2$：$f_Z(z)=\int_{z-1}^{1}dx=2-z$（三角形分布）

**陷阱**：积分上下限写错（最常见丢分点）；$z$ 的分段区间没写全。

### 套路 2.5 $\max$ / $\min$ 的分布

**识别标志**：$X_1,\dots,X_n$ i.i.d.，求 $M=\max$ 或 $m=\min$ 的分布。

**步骤**：
1. $\max$：$F_M(z)=P(\text{都}\le z)=\prod F_{X_i}(z)=[F(z)]^n$
2. $\min$：$F_m(z)=1-P(\text{都}>z)=1-[1-F(z)]^n$
3. 求导得密度

**陷阱**：$\min$ 忘记用补集；$\max$ 与 $\min$ 的公式记反。

## 三、数字特征类（第7章）

### 套路 3.1 求期望 / 方差

**识别标志**："求 $E[X]$""$\text{Var}(X)$""$E[X^2]$"。

**步骤**：
1. 先想能否套已知分布的公式（$B(n,p)$ → $E=np$，$\text{Var}=npq$ 等）
2. 否则按定义：离散 $\sum x\,p(x)$；连续 $\int xf(x)dx$
3. $E[g(X)]$ 用 LOTUS：$\int g(x)f(x)dx$（不要先求 $g(X)$ 的分布）
4. 方差：$\text{Var}(X)=E[X^2]-(E[X])^2$

**示例**：$X\sim U(a,b)$，$E[X^2]=\int_a^b\frac{x^2}{b-a}dx=\frac{b^2+ab+a^2}{3}$，故 $\text{Var}(X)=\frac{b^2+ab+a^2}{3}-(\frac{a+b}{2})^2=\frac{(b-a)^2}{12}$。

**陷阱**：$E[X^2]\ne(E[X])^2$；指数分布期望 $1/\lambda$ 别写成 $\lambda$。

### 套路 3.2 和的期望方差 / 协方差

**识别标志**："$X,Y$ 独立，求 $E[aX+bY]$""$\text{Var}(X+Y)$""$\text{Cov}$"。

**步骤**：
1. $E[aX+bY]=aE[X]+bE[Y]$（**恒成立，不需独立**）
2. $\text{Var}(X\pm Y)=\text{Var}(X)+\text{Var}(Y)\pm2\text{Cov}(X,Y)$（独立时交叉项为 0）
3. $\text{Cov}(X,Y)=E[XY]-E[X]E[Y]$；$E[XY]$ 用 $\iint xy\,f(x,y)dxdy$

**陷阱**：$X,Y$ 不独立却直接用方差相加公式；系数忘平方。

### 套路 3.3 条件期望与全期望/全方差

**识别标志**："$E[X|Y]$""随机个随机变量之和"（如"抛骰子，每点再抛一次硬币，总正面数"）。

**步骤**：
1. 先求内层：$E[X|Y=y]$ 是关于 $y$ 的函数
2. 全期望：$E[X]=E[E[X|Y]]$
3. 全方差：$\text{Var}(X)=E[\text{Var}(X|Y)]+\text{Var}(E[X|Y])$（**组内平均 + 组间波动**，两部分都非负）

**示例**：$N$ 次试验，每次成功概率 $p$，$N\sim\text{Poisson}(\lambda)$ 独立。
- $E[X]=E[E[X|N]]=E[Np]=p\lambda$
- $\text{Var}(X)=E[\text{Var}(X|N)]+\text{Var}(E[X|N])=E[Npq]+\text{Var}(Np)=\lambda pq+p^2\lambda=\lambda p$（$X\sim\text{Poisson}(\lambda p)$）

## 四、极限类（第8章）

### 套路 4.1 切比雪夫不等式求概率上界

**识别标志**："只给均值方差，求 $P(|X-\mu|\ge\varepsilon)$ 的上界"。

**步骤**：
1. 写出 $P(|X-\mu|\ge\varepsilon)\le\dfrac{\sigma^2}{\varepsilon^2}$
2. 若给 $k$ 倍标准差：$P(|X-\mu|\ge k\sigma)\le\dfrac1{k^2}$

**陷阱**：$\varepsilon$ 的单位与 $\sigma$ 一致；方向是 $\le$ 上界。

### 套路 4.2 中心极限定理近似求和

**识别标志**："$n$ 很大（$n\ge30$）""求和超过某值""近似计算"。

**步骤**：
1. 识别每个 $X_i$ 的 $E=\mu$、$\text{Var}=\sigma^2$（或 $S_n$ 直接近似 $N(n\mu,n\sigma^2)$）
2. 标准化：$Z=\dfrac{S_n-n\mu}{\sigma\sqrt n}$
3. 目标概率 $=P(Z\le \text{标准化后的值})\approx\Phi(\cdot)$

**示例**：1000 个顾客，每人消费均值 100 元、标准差 30 元，求总收入超 102000 元的概率。
- $Z=\dfrac{102000-100000}{30\sqrt{1000}}=\dfrac{2000}{948.7}\approx2.11$
- $P\approx1-\Phi(2.11)\approx0.0174$

### 套路 4.3 二项分布正态近似（含连续性修正）⭐⭐⭐

**识别标志**：$X\sim B(n,p)$，$np\ge5$ 且 $nq\ge5$，求 $P(X\ge k)$ 等。

**步骤**：
1. 记 $\mu=np$，$\sigma=\sqrt{npq}$
2. **离散→连续加 0.5 修正**：
   - $P(X\ge k)\approx P(Z\ge\dfrac{k-0.5-\mu}{\sigma})$
   - $P(X\le k)\approx P(Z\le\dfrac{k+0.5-\mu}{\sigma})$
   - $P(X=k)\approx P(\dfrac{k-0.5-\mu}{\sigma}\le Z\le\dfrac{k+0.5-\mu}{\sigma})$
3. 查 $\Phi$ 表

**陷阱**：漏掉 0.5 修正；$\ge k$ 用 $k-0.5$、$\le k$ 用 $k+0.5$（方向别记反——"半开区间扩大"）。

## 五、统计推断类（第9-12章）

### 套路 5.1 点估计：矩估计 & MLE

**识别标志**："用样本估计参数""求 $\theta$ 的矩估计/极大似然估计"。

**步骤（矩估计）**：
1. 列方程：$E[X]=\bar X$（一个参数）；两个参数时再加 $E[X^2]=\frac1n\sum X_i^2$
2. 解出 $\hat\theta$

**步骤（MLE）** ⭐⭐⭐：
1. 写似然函数 $L(\theta)=\prod_{i=1}^n f(x_i;\theta)$（连续）或 $\prod p(x_i;\theta)$（离散）
2. 取对数 $\ell(\theta)=\ln L(\theta)$
3. 求导解 $\ell'(\theta)=0$
4. **先检查：$\theta$ 的定义域是否有边界？** 若 $L$ 在边界取最大（如 $U(0,\theta)$ 的 $\theta\ge x_{(n)}$），MLE 是 $\hat\theta=X_{(n)}$，不能求导！
5. 求 $g(\theta)$ 的 MLE：$\widehat{g(\theta)}=g(\hat\theta)$（不变性）

**示例**：$X\sim U(0,\theta)$，$L(\theta)=\prod\frac1\theta=\theta^{-n}$，要求 $\theta\ge x_{(n)}$，$\theta^{-n}$ 关于 $\theta$ 递减 → $\hat\theta=X_{(n)}$。

**陷阱**：均匀分布用求导法；MLE 忘检查边界；似然函数忘乘 $\prod$。

### 套路 5.2 置信区间

**识别标志**："求 $\mu$（或 $\sigma^2$）的 $1-\alpha$ 置信区间"。

**步骤（先选对枢轴量）**：

| 目标 | 条件 | 枢轴量 | 区间 |
|------|------|--------|------|
| $\mu$ | $\sigma^2$ 已知 | $\dfrac{\bar X-\mu}{\sigma/\sqrt n}\sim N(0,1)$ | $\bar X\pm z_{\alpha/2}\dfrac{\sigma}{\sqrt n}$ |
| $\mu$ | $\sigma^2$ 未知 | $\dfrac{\bar X-\mu}{S/\sqrt n}\sim t(n-1)$ | $\bar X\pm t_{\alpha/2}(n-1)\dfrac{S}{\sqrt n}$ |
| $\sigma^2$ | $\mu$ 未知 | $\dfrac{(n-1)S^2}{\sigma^2}\sim\chi^2(n-1)$ | $\left(\dfrac{(n-1)S^2}{\chi^2_{\alpha/2}(n-1)},\ \dfrac{(n-1)S^2}{\chi^2_{1-\alpha/2}(n-1)}\right)$ |

1. 判断 $\sigma$ 已知/未知 → 选 z 或 t
2. 查对应分位点（$\chi^2$ 用右侧表，注意方向）
3. 代入数据算区间

**陷阱**：$\sigma$ 未知却用 $z$；$\chi^2$ 两个分位点放反；忘除 $\sqrt n$。

### 套路 5.3 假设检验（完整五步）

**识别标志**："是否有充分证据认为……""检验 $H_0$""p 值"。

**步骤**：
1. **写假设**：$H_0$（含等号）vs $H_1$（研究目标；单侧/双侧看问题，**先定再算**）
2. **选统计量**（与置信区间同一张表）：
   - $\sigma$ 已知：$Z=\dfrac{\bar X-\mu_0}{\sigma/\sqrt n}$
   - $\sigma$ 未知：$T=\dfrac{\bar X-\mu_0}{S/\sqrt n}\sim t(n-1)$
   - 方差：$\chi^2=\dfrac{(n-1)S^2}{\sigma_0^2}\sim\chi^2(n-1)$
   - 两均值：$T=\dfrac{\bar X-\bar Y}{S_p\sqrt{1/m+1/n}}\sim t(m+n-2)$
   - 两方差：$F=\dfrac{S_1^2}{S_2^2}\sim F(m-1,n-1)$
3. **定拒绝域**：双侧 $|z|\ge z_{\alpha/2}$；单侧 $z\ge z_\alpha$ 等
4. **计算**统计量数值
5. **决策**：落入拒绝域（或 $p<\alpha$）→ 拒绝 $H_0$；否则不拒绝
6. **结论用自然语言**："在 $\alpha=0.05$ 水平下，有充分证据认为……"（拒绝时）；"没有充分证据认为……"（不拒绝时）

**陷阱**：$H_0$ 与 $H_1$ 写反（$H_0$ 必须含等号）；结论说"接受 $H_0$"；拒绝域方向（F 检验是右单侧）。

### 套路 5.4 p 值计算

**识别标志**："求 p 值""用 p 值判断"。

**步骤**：
1. 算统计量值 $z_0$（或 $t_0$）
2. 双侧：$p=2P(Z\ge|z_0|)$；右侧：$p=P(Z\ge z_0)$；左侧：$p=P(Z\le z_0)$
3. $p<\alpha$ → 拒绝 $H_0$

**陷阱**：双侧忘乘 2；单侧方向取反（右侧却算 $P(Z\le z_0)$）。

### 套路 5.5 一元线性回归

**识别标志**："拟合直线""$\hat\beta_1$""$R^2$""回归系数显著性"。

**步骤**：
1. 算中间量：$\bar X,\bar Y$，$S_{XX}=\sum(X_i-\bar X)^2$，$S_{XY}=\sum(X_i-\bar X)(Y_i-\bar Y)$
2. $\hat\beta_1=S_{XY}/S_{XX}$；$\hat\beta_0=\bar Y-\hat\beta_1\bar X$
3. $SSE=SST-\hat\beta_1S_{XY}$（其中 $SST=\sum(Y_i-\bar Y)^2$）；$s^2=SSE/(n-2)$
4. $R^2=\hat\beta_1 S_{XY}/SST$（= 相关系数平方）
5. 显著性检验：$T=\dfrac{\hat\beta_1\sqrt{S_{XX}}}{s}\sim t(n-2)$，$|T|\ge t_{\alpha/2}(n-2)$ 则斜率显著

**陷阱**：$S_{XY}$ 与 $S_{XX}$ 位置写反；自由度 $n-2$ 写成 $n-1$。

### 套路 5.6 单因素方差分析

**识别标志**："比较 $r$ 组的均值是否相同""ANOVA""方差分析表"。

**步骤**：
1. 计算：
   - $SST=\sum_{i,j}(Y_{ij}-\bar Y_{\cdot\cdot})^2$（df $N-1$）
   - $SSA=\sum_i n_i(\bar Y_{i\cdot}-\bar Y_{\cdot\cdot})^2$（df $r-1$）
   - $SSE=SST-SSA$（df $N-r$）
2. $F=\dfrac{SSA/(r-1)}{SSE/(N-r)}\sim F(r-1,N-r)$
3. 右单侧：$F\ge F_\alpha(r-1,N-r)$ → 拒绝 $H_0$（至少一组不同）
4. 填方差分析表（来源/SS/df/MS/F 五行三列）

**陷阱**：$F$ 用双侧拒绝域；$SSA$ 的组数权重 $n_i$ 忘乘；结论说"所有组两两不同"。

## 六、综合组合模式（跨章节串联）

> 考试大题常把多个套路串起来。以下是 6 种最常见的"组合拳"，先识别模式再逐段拆解。

### 模式 A：分布 + 期望 + 极限 三连问

**特征**：第 1 问求分布/参数，第 2 问求期望方差，第 3 问大样本近似。

**示例型结构**：$X_i$ 是某分布的 i.i.d. 样本，问 $E[\bar X]$、$\text{Var}(\bar X)$，再问 $P(\bar X>a)$。
- 第 1 步：单变量期望（套路 3.1）
- 第 2 步：$\bar X$ 的均值=$\mu$，方差=$\sigma^2/n$（样本均值定理）
- 第 3 步：CLT（套路 4.2），$\bar X\approx N(\mu,\sigma^2/n)$

### 模式 B：联合分布 + 边缘 + 独立性 + 和的分布

**特征**：给联合密度，依次问边缘、是否独立、$X+Y$ 的分布。
- 第 1 步：边缘积分（套路 2.3）——积分范围依赖另一个变量
- 第 2 步：验证 $f=f_Xf_Y$ 判断独立
- 第 3 步：若独立，卷积（套路 2.4）；若不独立，先求联合再积分 $\iint_{x+y\le z}f(x,y)dxdy$

### 模式 C：估计 + 区间 + 检验 三连问

**特征**：同一份样本数据，先点估计、再区间估计、再假设检验。
- 第 1 步：MLE/矩估计（套路 5.1）
- 第 2 步：置信区间（套路 5.2）——注意与检验的对偶性
- 第 3 步：假设检验（套路 5.3）——"$\mu_0$ 是否落在区间内"可快速判断双侧检验结论

**对偶性速用**：双侧检验 $H_0:\mu=\mu_0$ 在水平 $\alpha$ 下不拒绝 ⟺ $\mu_0$ 在 $1-\alpha$ 置信区间内。区间不含 $\mu_0$ → 拒绝。

### 模式 D：全概率 + 二项/泊松 + 期望 三连问

**特征**：分层随机 + "问总概率" + "问期望/方差"。
- 第 1 步：全概率公式（套路 1.3）
- 第 2 步：识别结果层分布（每层是 Bernoulli/计数）
- 第 3 步：全期望/全方差（套路 3.3）——"随机个随机变量之和"

### 模式 E：正态总体抽样 + 区间/检验（统计推断主线）

**特征**：$X_1,\dots,X_n\sim N(\mu,\sigma^2)$，$\mu,\sigma$ 未知，问推断。
- 第 1 步：识别抽样分布定理：$\dfrac{\bar X-\mu}{S/\sqrt n}\sim t(n-1)$，$\dfrac{(n-1)S^2}{\sigma^2}\sim\chi^2(n-1)$
- 第 2 步：区间/检验都用对应枢轴量（套路 5.2/5.3）
- 第 3 步：$\sigma$ 未知一律 t 与 $\chi^2$，不要用 $z$

### 模式 F：回归 + ANOVA 统一题

**特征**：连续预测 → 回归；分类分组 → ANOVA；或问"两者关系"。
- 第 1 步：识别自变量类型（连续/分类）
- 第 2 步：回归走套路 5.5；ANOVA 走套路 5.6
- 第 3 步：共同语言——都是"总变异 = 可解释 + 随机"，都用信号/噪声比做检验

## 七、考试答题检查清单

> 每道大题做完后，花 30 秒过一遍：

- [ ] **概率**：答案在 $[0,1]$ 吗？分布律/密度归一了吗？
- [ ] **期望**：$E[X]$ 符号和量级合理吗？（$U(a,b)$ 的期望在 $[a,b]$ 内）
- [ ] **方差**：非负吗？系数平方了吗？
- [ ] **标准化**：$Z=(X-\mu)/\sigma$，先减后除？
- [ ] **统计量**：分母有 $\sqrt n$ 吗？自由度对吗（$n-1$/$n-2$/$m+n-2$）？
- [ ] **结论**：写的是"拒绝/不拒绝 $H_0$"，不是"接受 $H_0$"吗？用了自然语言解释吗？
- [ ] **单位/端点**：离散型的 $\le$ vs $<$；连续性修正 0.5 加了吗？
- [ ] **参数定义**：指数分布是 $\lambda e^{-\lambda x}$ 还是 $\frac1\theta e^{-x/\theta}$？与题目一致吗？

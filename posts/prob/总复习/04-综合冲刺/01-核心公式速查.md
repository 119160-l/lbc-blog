# 综合冲刺 · 核心公式速查

> 冲刺阶段第一站：把 12 章的核心公式浓缩在一处，随时查、反复背。

## 一、概率论基础（第1-5章）

### 组合分析
- [ ] $P_n^k = \dfrac{n!}{(n-k)!}$，$C_n^k = \dfrac{n!}{k!(n-k)!}$
- [ ] 二项式定理：$(a+b)^n = \sum_{k=0}^n C_n^k a^{n-k}b^k$

### 概率公理与性质
- [ ] $P(A\cup B) = P(A)+P(B)-P(AB)$
- [ ] $P(\bar A) = 1 - P(A)$

### 条件概率与独立性
- [ ] $P(A|B) = \dfrac{P(AB)}{P(B)}$
- [ ] 全概率：$P(B) = \sum_i P(A_i)P(B|A_i)$
- [ ] 贝叶斯：$P(A_i|B) = \dfrac{P(A_i)P(B|A_i)}{\sum_j P(A_j)P(B|A_j)}$
- [ ] 独立：$P(AB) = P(A)P(B)$

### 随机变量
- [ ] $F(x) = P(X\leq x)$，$f(x) = F'(x)$
- [ ] $P(a<X\leq b) = F(b)-F(a)$

### 常见分布（务必全部默写）

| 分布 | 参数 | 期望 | 方差 |
|------|------|------|------|
| Bernoulli | $p$ | $p$ | $p(1-p)$ |
| Binomial | $n,p$ | $np$ | $np(1-p)$ |
| Poisson | $\lambda$ | $\lambda$ | $\lambda$ |
| Geometric（首次成功） | $p$ | $1/p$ | $(1-p)/p^2$ |
| Negative Binomial | $r,p$ | $r/p$ | $r(1-p)/p^2$ |
| Uniform | $a,b$ | $(a+b)/2$ | $(b-a)^2/12$ |
| Exponential | $\lambda$ | $1/\lambda$ | $1/\lambda^2$ |
| Normal | $\mu,\sigma^2$ | $\mu$ | $\sigma^2$ |
| Gamma | $\alpha,\lambda$ | $\alpha/\lambda$ | $\alpha/\lambda^2$ |
| Beta | $\alpha,\beta$ | $\alpha/(\alpha+\beta)$ | $\dfrac{\alpha\beta}{(\alpha+\beta)^2(\alpha+\beta+1)}$ |

> **分布关系谱系**：Bernoulli → Binomial（$n$ 次独立）→ Poisson（$n\to\infty,np\to\lambda$）；Exponential = Gamma($\alpha=1$)；$\chi^2(k)$ = Gamma($\alpha=k/2,\lambda=1/2$)；$\dfrac{X-\mu}{\sigma}\sim N(0,1)$（标准化）。

## 二、多维随机变量与极限理论（第6-8章）

- [ ] 联合 → 边缘：$f_X(x) = \int f(x,y)dy$（离散求和）
- [ ] 条件分布：$f_{Y|X}(y|x) = \dfrac{f(x,y)}{f_X(x)}$
- [ ] 独立：$f(x,y)=f_X(x)f_Y(y)$（对所有 $x,y$）
- [ ] 和的分布（卷积）：$f_Z(z)=\int f_X(x)f_Y(z-x)dx$（$X,Y$ 独立）
- [ ] $\max$：$F_{\max}(z)=[F(z)]^n$；$\min$：$F_{\min}(z)=1-[1-F(z)]^n$
- [ ] $\text{Var}(X) = E[X^2] - (E[X])^2$
- [ ] $\text{Cov}(X,Y) = E[XY]-E[X]E[Y]$，$\rho = \dfrac{\text{Cov}(X,Y)}{\sigma_X\sigma_Y}$
- [ ] $\text{Var}(X+Y)=\text{Var}(X)+\text{Var}(Y)+2\text{Cov}(X,Y)$
- [ ] 独立 ⟹ 不相关；不相关 ⇏ 独立
- [ ] 全期望：$E[Y] = E[E[Y|X]]$；全方差：$\text{Var}(Y)=E[\text{Var}(Y|X)]+\text{Var}(E[Y|X])$
- [ ] Chebyshev：$P(|X-\mu|\geq\varepsilon) \leq \sigma^2/\varepsilon^2$（切比雪夫不等式）
- [ ] 大数定律：$\bar X_n \xrightarrow{P} \mu$（依概率收敛）
- [ ] CLT：$\dfrac{\sum X_i - n\mu}{\sigma\sqrt{n}} \xrightarrow{d} N(0,1)$
- [ ] 二项正态近似：$B(n,p) \approx N(np, npq)$（$np\geq5, nq\geq5$，用连续性修正）

## 三、数理统计（第9-12章）

### 抽样分布（正态总体四大定理）
- [ ] $\bar X \sim N(\mu, \sigma^2/n)$，$\dfrac{\bar X - \mu}{\sigma/\sqrt{n}} \sim N(0,1)$
- [ ] $\dfrac{(n-1)S^2}{\sigma^2} \sim \chi^2(n-1)$
- [ ] $\dfrac{\bar X - \mu}{S/\sqrt{n}} \sim t(n-1)$
- [ ] $F = \dfrac{S_1^2/\sigma_1^2}{S_2^2/\sigma_2^2} \sim F(n_1-1, n_2-1)$
- [ ] $\bar X$ 与 $S^2$ 独立（正态总体特有）
- [ ] 三大分布互推：$t^2(k) \sim F(1,k)$；$Z^2 \sim \chi^2(1)$

### 参数估计
- [ ] 矩估计：样本矩 = 总体矩，解方程得 $\hat\theta$
- [ ] MLE：$L(\theta)=\prod f(x_i;\theta)$，$\hat\theta=\arg\max\ln L(\theta)$
- [ ] 无偏性 $E[\hat\theta]=\theta$；有效性：方差越小越好；一致性：$n\to\infty$ 收敛
- [ ] 置信区间（$\sigma$ 已知）：$\bar X \pm z_{\alpha/2}\dfrac{\sigma}{\sqrt{n}}$
- [ ] 置信区间（$\sigma$ 未知）：$\bar X \pm t_{\alpha/2}(n-1)\dfrac{S}{\sqrt{n}}$
- [ ] 方差置信区间：$\left(\dfrac{(n-1)S^2}{\chi^2_{\alpha/2}(n-1)},\ \dfrac{(n-1)S^2}{\chi^2_{1-\alpha/2}(n-1)}\right)$

### 假设检验（统计量速查）
- [ ] z 检验：$z = \dfrac{\bar X - \mu_0}{\sigma/\sqrt{n}}$（$\sigma$ 已知）
- [ ] t 检验：$t = \dfrac{\bar X - \mu_0}{S/\sqrt{n}} \sim t(n-1)$（$\sigma$ 未知）
- [ ] $\chi^2$ 检验：$\chi^2 = \dfrac{(n-1)S^2}{\sigma_0^2} \sim \chi^2(n-1)$（方差）
- [ ] $F$ 检验：$F = \dfrac{S_1^2}{S_2^2} \sim F(n_1-1,n_2-1)$（两方差）
- [ ] 决策：$|T| \geq$ 临界值 或 $p < \alpha$ → 拒绝 $H_0$
- [ ] 常用临界值：$z_{0.025}=1.96$，$z_{0.05}=1.645$

### 回归与方差分析
- [ ] 模型：$Y_i = \beta_0 + \beta_1 X_i + \varepsilon_i$，$\varepsilon_i \sim N(0,\sigma^2)$ 独立
- [ ] $\hat\beta_1 = \dfrac{S_{XY}}{S_{XX}} = \dfrac{\sum (X_i-\bar X)(Y_i-\bar Y)}{\sum (X_i-\bar X)^2}$，$\hat\beta_0 = \bar Y - \hat\beta_1\bar X$
- [ ] $\text{Var}(\hat\beta_1)=\dfrac{\sigma^2}{S_{XX}}$；$\hat\sigma^2 = s^2 = \dfrac{SSE}{n-2}$（无偏）
- [ ] 斜率检验：$T = \dfrac{\hat\beta_1\sqrt{S_{XX}}}{s} \sim t(n-2)$
- [ ] $R^2 = \dfrac{SSR}{SST} = 1 - \dfrac{SSE}{SST}$；$SST = SSR + SSE$
- [ ] 一元回归：$R^2 = r^2$（$r$ 为相关系数）
- [ ] ANOVA 模型：$Y_{ij}=\mu+\alpha_i+\varepsilon_{ij}$，$\sum\alpha_i=0$
- [ ] 分解：$SST=SSA+SSE$；$MSA=\dfrac{SSA}{r-1}$，$MSE=\dfrac{SSE}{N-r}$
- [ ] $F = \dfrac{MSA}{MSE} \sim F(r-1, N-r)$（右侧拒绝域）

# 综合冲刺 · 高频易错点

> 冲刺阶段第二站：把 12 章里最容易丢分的坑集中起来。分三类——**概念混淆**（理解错）、**公式误用**（用错）、**细节陷阱**（看漏），每一类按章节编排。
> 使用方式：先通读一遍，在"易错指数"⭐⭐⭐的条目上重点标记；做题出错后回来对照，找到自己踩的是哪个坑。

---

## 一、概念混淆（理解错）

> 这类错误最隐蔽——不是不会算，而是理解偏了，算出结果也白搭。

### 第1章 组合分析

- [ ] **排列 vs 组合分不清** ⭐⭐⭐：题目问"排成一排"（有序）→ 排列 $P_n^k$；问"选出一组"（无序）→ 组合 $C_n^k$。关键词："次序有关/无关"。
- [ ] **"至少 1 个" vs "恰好 1 个"**：$\ge1$ 用补集 $1-P(\text{无})$；恰好 1 个要单独数。
- [ ] **隔板法的使用条件**：只适用于**相同物品**分配（有重复组合）。如果物品互不相同，直接用乘法原理 $n^r$。

### 第2章 概率公理

- [ ] **$P(A\cup B)$ 与 $P(A)+P(B)$**：只有 $A,B$ 互斥（不相交）时才能直接相加。相交时必须减 $P(AB)$。
- [ ] **"互斥" vs "独立"** ⭐⭐⭐：互斥是"不能同时发生"（$AB=\emptyset$）；独立是"一个发生不影响另一个的概率"（$P(AB)=P(A)P(B)$）。互斥且都有正概率的事件**不可能独立**。
- [ ] **事件的对偶律（De Morgan）**：$\overline{A\cup B}=\bar A\cap\bar B$，"至少一个发生"的补是"都没发生"，别取反出错。

### 第3章 条件概率与独立性

- [ ] **$P(A|B)$ 与 $P(B|A)$ 混为一谈** ⭐⭐⭐：条件概率不满足交换律！"吸烟者中患肺癌的概率"≠"肺癌患者中吸烟的概率"。要用贝叶斯公式转化。
- [ ] **两两独立 ≠ 相互独立** ⭐⭐⭐：经典反例——抛两枚硬币，$A$=第一枚正面，$B$=第二枚正面，$C$=两枚相同。$A,B,C$ 两两独立但三者不独立（$P(ABC)=0\ne\frac18$）。
- [ ] **$P(A|B)=P(A)$ ⟺ 独立**：容易只记正向，忘记反向也是判断独立的方法。

### 第4章 随机变量及其分布

- [ ] **离散 vs 连续**：离散型 $P(X=x)$ 可以非零；连续型 $P(X=x)=0$（单点概率为零）！连续型只能问区间概率。
- [ ] **PDF 不是概率** ⭐⭐⭐：$f(x)$ 是密度不是概率，可以大于 1。要算概率必须积分：$P(a\le X\le b)=\int_a^b f(x)dx$。
- [ ] **CDF 与 PDF 方向**：$F(x)=P(X\le x)$（左端点闭合）；$P(X>x)=1-F(x)$。连续型下 $\le$ 与 $<$ 无区别，离散型有区别。
- [ ] **$P(a<X\le b)=F(b)-F(a)$**：对离散型，若 $X$ 可能恰取 $a$，则 $P(a\le X\le b)=F(b)-F(a-)$，注意端点是否包含。

### 第5章 常见分布族

- [ ] **Binomial 的 $k$ 从 0 开始，Geometric 的 $k$ 从 1 开始** ⭐⭐⭐：二项分布 $k=0,1,\dots,n$；几何分布 $k=1,2,\dots$（首次成功的次数，不可能为 0）。
- [ ] **Poisson 均值=方差**：$\lambda$ 既是均值也是方差。而 Binomial 均值 $np$ ≠ 方差 $npq$（除非 $q=1$）。看到"方差等于均值"要立刻想到 Poisson。
- [ ] **指数分布的无记忆性** ⭐⭐⭐：$P(X>s+t|X>s)=P(X>t)$，与 $s$ 无关。"用了 100 小时还能再撑 10 小时的概率"=$P(X>10)$，不是条件概率计算式。
- [ ] **Normal 的标准化方向**：$Z=\frac{X-\mu}{\sigma}$ 是"减均值、除标准差"，别写成加或乘。
- [ ] **$P(X>a)$ 与 $P(X<a)$ 对称性**：标准正态 $\Phi(-z)=1-\Phi(z)$。

### 第6章 多维随机向量

- [ ] **边缘分布 vs 条件分布**：边缘分布把另一个变量"积掉/加掉"；条件分布是"固定一个看另一个"。$f_{X|Y}(x|y)\ne f_X(x)$（除非独立）。
- [ ] **独立 ⟹ 不相关，不相关 ⇏ 独立** ⭐⭐⭐：例 $X\sim U(-1,1)$，$Y=X^2$，则 $\text{Cov}(X,Y)=0$（不相关）但显然不独立。
- [ ] **联合分布 ≠ 两个边缘分布的简单组合**：知道 $f_X$ 和 $f_Y$ 不能推出 $f(x,y)$，除非已知独立。

### 第7章 数学期望与矩

- [ ] **$E[X^2]\ne(E[X])^2$** ⭐⭐⭐：$\text{Var}(X)=E[X^2]-\mu^2\ge0$，所以 $E[X^2]\ge\mu^2$。别在算方差时把 $E[X^2]$ 写成 $\bar x^2$。
- [ ] **$E[1/X]\ne 1/E[X]$**：期望不是对任何函数可交换的。$E[g(X)]$ 必须用 LOTUS 算。
- [ ] **$\text{Var}(X+Y)=\text{Var}(X)+\text{Var}(Y)$ 的适用条件**：**只有 $X,Y$ 不相关（特别是独立）时成立**。否则要加 $2\text{Cov}(X,Y)$。
- [ ] **$\text{Var}(aX)=a^2\text{Var}(X)$**：系数要**平方**。而 $E[aX]=aE[X]$ 不平方。常考陷阱。
- [ ] **不相关/独立的区别在"线性"**：不相关只说明"没有线性关系"，非线性关系照样存在。

### 第8章 极限定理

- [ ] **大数定律 vs CLT 的结论方向**：大数定律说 $\bar X_n$ **收敛到** $\mu$（一个确定值）；CLT 说 $S_n$ 的**标准化**近似 $N(0,1)$（一个分布）。别搞混"收敛到常数"和"收敛到分布"。
- [ ] **CLT 中的标准化**：$\frac{S_n-n\mu}{\sigma\sqrt n}$，分母是 $\sigma\sqrt n$ 不是 $\sqrt n$ 也不是 $\sigma n$。
- [ ] **$\xrightarrow{P}$（依概率）vs $\xrightarrow{d}$（依分布）**：依分布收敛弱于依概率收敛；依概率收敛到常数 ⟹ 依分布收敛到该常数。

### 第9章 抽样分布

- [ ] **$\bar X$ 的分布 vs $X_i$ 的分布**：$\bar X\sim N(\mu,\sigma^2/n)$，方差除以 $n$，标准差除以 $\sqrt n$。$\bar X$ 比单个 $X_i$ 波动小。
- [ ] **$S^2$ 的分母是 $n-1$ 不是 $n$** ⭐⭐⭐：$\frac{1}{n-1}\sum(X_i-\bar X)^2$ 才无偏。$\frac1n$ 版本低估方差（除非已知 $\mu$）。
- [ ] **$t$ 分布、$\chi^2$、$F$ 分布的构造记混** ⭐⭐⭐：
  - $\chi^2(k)$：$k$ 个 $N(0,1)$ 平方和
  - $t(k)$：$\frac{Z}{\sqrt{V/k}}$（标准正态 ÷ 卡方/自由度 的根）
  - $F(m,n)$：$\frac{U/m}{V/n}$（两个卡方各自除以自由度之比）
  - 记法：$t$ 是"1 个正态 + 1 个卡方"；$F$ 是"2 个卡方"。
- [ ] **$\chi^2$ 分布不对称**：左分位点 $\chi^2_{1-\alpha/2}$ 和右分位点 $\chi^2_{\alpha/2}$ 不能互换（不像正态的 $\pm z_{\alpha/2}$ 对称）。

### 第10章 参数估计

- [ ] **MLE 的无偏性**：MLE 一般只是**渐近无偏**，小样本可能偏。例如 $\hat\sigma^2_{MLE}=\frac1n\sum(X_i-\bar X)^2$ 是有偏的（少算 $\frac{n-1}{n}$ 倍），$\frac1{n-1}$ 版本才无偏。
- [ ] **估计量 vs 估计值**：估计量是随机变量（用大写 $X$ 表示），估计值是具体数（用小写 $x$ 表示）。问"求 $\hat\theta$ 的分布"回答的是估计量的分布。
- [ ] **置信区间的含义** ⭐⭐⭐：95% 置信区间不是说"$\mu$ 有 95% 概率落在区间内"（$\mu$ 是固定常数，不是随机变量）！正确说法：**反复抽样**构造区间，约 95% 的区间覆盖 $\mu$。
- [ ] **矩估计 vs MLE 的选择**：矩估计只要求矩存在，好算；MLE 需要知道完整分布。题目给分布形式优先 MLE。

### 第11章 假设检验

- [ ] **"不拒绝 $H_0$" ≠ "接受 $H_0$"** ⭐⭐⭐：证据不足，只能说"没有足够证据拒绝"，不能说"$H_0$ 为真"。
- [ ] **p 值 ≠ $P(H_0)$ 真** ⭐⭐⭐：p 值是"$H_0$ 成立时观察到当前或更极端结果的概率"，不是"$H_0$ 为真的概率"。
- [ ] **两类错误的表述**：$\alpha$ = 弃真（$H_0$ 真但拒绝）；$\beta$ = 纳伪（$H_0$ 假但未拒绝）。容易记反。
- [ ] **单侧 vs 双侧** ⭐⭐⭐：$\alpha=0.05$ 双侧临界值 $z=1.96$（两侧各 0.025）；单侧 $z=1.645$。看数据前先定方向，看数据后改单侧 = 数据操纵（p-hacking）。
- [ ] **显著性 ≠ 实际重要性**：大样本下微小差异也能 p<0.05。

### 第12章 回归与方差分析

- [ ] **相关 ≠ 因果** ⭐⭐⭐：回归只能说明关联，不能证明因果（第三变量问题：冰淇淋销量 vs 溺水）。
- [ ] **$R^2$ 高 ≠ 模型好**：增加自变量 $R^2$ 只增不减，可能过拟合。多元要看调整 $R^2$。
- [ ] **ANOVA $F$ 显著 ≠ 所有组两两不同**：只说"至少一组不同"，具体哪组不同要多重比较。
- [ ] **回归是预测，不是解释因果**：预测区间 vs 置信区间的区别（见第三类）。

## 二、公式误用（用错）

> 这类错误是"用了对的公式但用错了场景"——参数、条件、字母没对上。

### 概率论部分（第1-5章）

- [ ] **加法公式漏减 $P(AB)$**：$P(A\cup B)=P(A)+P(B)-P(AB)$。三个事件版本：加三个、减三个两两交、加一个三交集。
- [ ] **乘法公式方向错**：$P(AB)=P(A)P(B|A)=P(B)P(A|B)$，条件概率里的条件事件必须和"先发生"的一致。
- [ ] **贝叶斯公式分母用错**：分母是全概率 $\sum_j P(A_j)P(B|A_j)$，不是 $P(B|A_k)$ 或别的单项。
- [ ] **几何分布两种定义** ⭐⭐⭐：有的教材用 $P(X=k)=(1-p)^{k-1}p$（$k$=第 1 次成功），有的用 $P(X=k)=(1-p)^k p$（$k$=失败次数）。题目用哪种先确认！期望分别是 $1/p$ 和 $(1-p)/p$。
- [ ] **均匀分布区间含端点**：$U(a,b)$ 密度 $1/(b-a)$，方差 $\frac{(b-a)^2}{12}$——分母 12 别记成 6 或 2。
- [ ] **指数分布参数混淆** ⭐⭐⭐：$f(x)=\lambda e^{-\lambda x}$ 时 $E[X]=1/\lambda$；有些书用 $f(x)=\frac1\theta e^{-x/\theta}$ 时 $E[X]=\theta$。做题先看密度写法！
- [ ] **Gamma 分布的参数**：$\text{Gamma}(\alpha,\lambda)$ 期望 $\alpha/\lambda$。若用 $\text{Gamma}(\alpha,\beta)$ 表示（$\beta$ 为尺度参数），期望是 $\alpha\beta$。同样要先看定义。
- [ ] **正态查表方向**：$P(X\le a)=\Phi(\frac{a-\mu}{\sigma})$，$P(X>a)=1-\Phi(\cdot)$。$\Phi$ 表给的是 $\le$ 的概率。

### 多维与期望部分（第6-8章）

- [ ] **卷积公式忘标积分变量范围**：$f_Z(z)=\int f_X(x)f_Y(z-x)dx$，积分限由 $f_Y$ 的定义域决定（比如 $Y$ 只在正半轴有密度，则 $z-x>0$）。忘写范围是丢分重灾区。
- [ ] **$\max/\min$ 分布记反**：$F_{\max}(z)=[F(z)]^n$（都 $\le z$）；$F_{\min}(z)=1-[1-F(z)]^n$（至少一个 $\le z$）。求 $\min$ 用补集！
- [ ] **LOTUS 里 $g$ 套错**：$E[g(X)]=\int g(x)f(x)dx$，直接把 $g$ 作用在期望上（$g(E[X])$）是错的。
- [ ] **协方差公式 $\text{Cov}(X,Y)=E[XY]-E[X]E[Y]$**：忘记展开中间步骤，直接写 $\text{Cov}(X,Y)=E[XY]$（那是 $X,Y$ 均值都为零时才成立）。
- [ ] **独立和的方差**：$\text{Var}(\sum X_i)=\sum\text{Var}(X_i)$ 只对独立（或不相关）成立；$\text{Var}(\sum a_iX_i)=\sum a_i^2\text{Var}(X_i)$ 系数平方。
- [ ] **CLT 连续性修正** ⭐⭐⭐：二项分布 $B(n,p)$ 用正态近似时，$P(X=k)$ 用 $P(k-0.5<X<k+0.5)$ 修正；$P(X\ge k)$ 用 $P(X\ge k-0.5)$。漏了修正答案会偏。
- [ ] **切比雪夫方向**：$P(|X-\mu|\ge\varepsilon)\le\sigma^2/\varepsilon^2$。反过来 $P(|X-\mu|<\varepsilon)\ge1-\sigma^2/\varepsilon^2$ 用的是补事件。

### 统计部分（第9-12章）

- [ ] **$\bar X$ 的标准误用成 $\sigma$**：$\bar X$ 的标准差是 $\sigma/\sqrt n$。检验统计量分母必须是 $\sigma/\sqrt n$（z 检验）或 $S/\sqrt n$（t 检验）。
- [ ] **自由度写错** ⭐⭐⭐：
  - 单样本均值 t 检验：$t(n-1)$
  - 两独立样本 t 检验（方差相等合并）：$t(m+n-2)$
  - 回归斜率检验：$t(n-2)$
  - ANOVA $F$：$F(r-1,\ N-r)$
  - 记法：估计了几个参数就减几个。回归减 2（$\beta_0,\beta_1$），ANOVA 组内减 $r$（$r$ 个组均值）。
- [ ] **置信区间公式选错**：$\sigma$ 已知用 $z$，未知用 $t$。样本量多大都一样——$\sigma$ 未知就该用 $t$（$n\ge30$ 时才近似可用 $z$）。
- [ ] **$\chi^2$ 置信区间的分位点**：区间 $(\frac{(n-1)S^2}{\chi^2_{\alpha/2}},\ \frac{(n-1)S^2}{\chi^2_{1-\alpha/2}})$——注意**分子在 $\chi^2$ 大的那边除以小分位点**，别写成同向。
- [ ] **$F$ 检验拒绝域方向** ⭐⭐⭐：ANOVA 和方差比检验 $F$ 都是**右侧单侧拒绝域**（$F\ge F_\alpha$）。只有双侧检验方差比时才两边。
- [ ] **$F$ 分布下侧分位数**：$F_{1-p}(m,n)=1/F_p(n,m)$——分子分母自由度要交换。表里没有的小分位点用它算。
- [ ] **回归 $\hat\beta_1$ 公式**：分子是 $\sum(X_i-\bar X)(Y_i-\bar Y)$（协方差），分母是 $\sum(X_i-\bar X)^2$（方差）。别把 $X,Y$ 位置写反。
- [ ] **$SST=SSR+SSE$ 与 $SST=SSA+SSE$**：回归里是 $SSR$（回归平方和），ANOVA 里是 $SSA$（组间平方和），符号别串。

## 三、细节陷阱（看漏）

> 这类错误不是不懂，是"没看见"——题目里的隐藏条件、端点、单位、符号。

### 题目阅读类

- [ ] **"不放回" vs "有放回"**：抽球/抽样问题先确认。不放回且分组 → 超几何，不放回有序 → 排列，有放回 → 独立重复。
- [ ] **"独立"这个词**：题目说"相互独立"才可以用独立公式；没说就不行。
- [ ] **$X$ 与 $Y$ 的记号**：题目问 $P(X>Y)$ 时，是联合概率 $\iint_{x>y}f(x,y)dxdy$，不是边缘分布相减。
- [ ] **参数的单位**：$np$ 与 $npq$ 都可能是"次数"，连续性修正的 0.5 用的是**次数单位**。若 $p$ 是概率、$n$ 是次数，先统一单位。
- [ ] **区间端点开闭**：连续型无影响；离散型 $P(X\le k)$ vs $P(X<k)=P(X\le k-1)$ 必须区分。

### 计算类

- [ ] **$E[X^2]$ 算成 $(E[X])^2$**：算方差 $\text{Var}(X)=E[X^2]-\mu^2$ 时，$E[X^2]$ 是二阶矩，用 LOTUS 算，别偷懒。
- [ ] **正态分布的对称分位点**：$z_{0.025}=1.96$（双侧 95%），$z_{0.05}=1.645$（单侧 95% 或双侧 90%）。查表时注意 $\alpha/2$ vs $\alpha$。
- [ ] **$\Phi$ 表给的是 $\le z$**：$P(Z>1.96)=0.025$，$P(Z<-1.96)=0.025$，别把符号弄反。
- [ ] **$\chi^2$ 表的方向**：$\chi^2$ 表列的是**右侧概率**。$\chi^2_{0.05}(k)$ 是"右侧面积 0.05"，即 $P(\chi^2>\chi^2_{0.05})=0.05$。与 $z$ 表（左侧面积）方向相反！
- [ ] **除零与边界**：$U(0,\theta)$ 的 MLE 是 $\hat\theta=X_{(n)}$（最大值），不是 $\bar X$ 或似然方程解。极值点在边界时直接求导会得到错的答案。
- [ ] **$P(B)>0$ 条件**：$P(A|B)$ 定义要求 $P(B)>0$。$P(B)=0$ 时条件概率无定义。
- [ ] **样本量影响**：$n$ 大时 $t$ 分布接近正态，但**小样本**（$n<30$）$t$ 与 $z$ 差距明显，临界值差很多（$n=5$ 时 $t_{0.025}(4)=2.776$ vs $1.96$）。
- [ ] **重复抽样表述**：置信区间说"重复抽样 100 次约 95 次覆盖真值"——是**区间**覆盖 $\mu$，不是 $\mu$ 在区间内概率。

### 分布/分布律类

- [ ] **分布律的合法性检查**：写完分布律/密度立刻验证：所有概率和为 1、密度积分为 1。这能抓回一半计算错误。
- [ ] **$k$ 的取值集合**：几何分布 $k=1,2,\dots$（没有 0）；负二项 $k=r,r+1,\dots$；Poisson $k=0,1,\dots$。写分布律先写取值范围。
- [ ] **标准化的方向**：$Z=\frac{X-\mu}{\sigma}$ 里是"先减后除"。$\frac{X-\mu}{\sigma}$ 和 $\frac{\mu-X}{\sigma}$ 分布相同（对称），但期望别写反。
- [ ] **$S^2$ 与 $\hat\sigma^2_{MLE}$**：题目问"样本方差"默认 $S^2=\frac1{n-1}\sum(X_i-\bar X)^2$；若题目定义 $\hat\sigma^2=\frac1n\sum(X_i-\bar X)^2$ 则不同。看题目给的定义！
- [ ] **条件期望的嵌套**：$E[E[X|Y]]=E[X]$（全期望公式），但 $E[X|Y]$ 本身是 $Y$ 的函数（随机变量），不是常数。

## 易错点自测（每题 10 秒判断对错）

1. 若 $P(A)=0.5$，$P(B)=0.5$，$P(AB)=0$，则 $A,B$ 独立。 → **错**（互斥且正概率不可能独立）
2. $X\sim N(\mu,\sigma^2)$，则 $P(X=\mu)=1/\sqrt{2\pi}$。 → **错**（连续型单点概率为 0）
3. $E[X^2]\ge(E[X])^2$ 恒成立。 → **对**（方差非负）
4. $\text{Var}(2X)=2\text{Var}(X)$。 → **错**（应为 $4\text{Var}(X)$）
5. $X,Y$ 不相关 ⟹ $X,Y$ 独立。 → **错**（方向反了：独立 ⟹ 不相关）
6. 95% 置信区间意味着 $\mu$ 以 95% 概率落在区间内。 → **错**（$\mu$ 是常数，正确说法是区间以 95% 概率覆盖 $\mu$）
7. p 值大于 0.05 说明 $H_0$ 为真。 → **错**（只能说证据不足，不能接受 $H_0$）
8. $t$ 分布在小样本时比正态分布尾部更厚。 → **对**
9. 两两独立的事件必然相互独立。 → **错**（经典反例：两枚硬币三事件）
10. $P(X\le a)$ 对连续型等于 $P(X<a)$。 → **对**（连续型端点概率为 0）

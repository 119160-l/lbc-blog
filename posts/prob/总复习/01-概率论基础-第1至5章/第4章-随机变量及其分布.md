# 第4章 随机变量及其分布 · 总复习

> 复习目标：掌握随机变量的量化描述（PMF/PDF/CDF）及其运算。
> 一句话：**随机变量 = 给随机结果贴上数字标签，从而引入微积分工具。**

---

## 一、本章核心概念（复习时逐条回忆）

- [ ] 随机变量 $X: \Omega \to \mathbb{R}$（离散 / 连续）
- [ ] 概率质量函数 PMF：$p(x) = P(X=x)$（离散）
- [ ] 概率密度函数 PDF：$f(x)$（连续，"密度"不是概率）
- [ ] 累积分布函数 CDF：$F(x) = P(X\le x)$（万能语言）
- [ ] PMF/PDF/CDF 的互推关系（求和/积分 vs 跳跃/求导）
- [ ] 随机变量函数 $Y=g(X)$ 的分布（CDF 法 / 单调变换法）
- [ ] CDF 三大性质：单调不减、$F(-\infty)=0,\ F(+\infty)=1$、右连续

## 二、核心公式速记

| 公式 | 适用场景 |
|------|---------|
| $F(x) = P(X \leq x)$ | CDF 定义（离散/连续通用） |
| $P(X = x_k) = p_k$ | 离散 PMF（且 $\sum_k p_k = 1$） |
| $F(x) = \sum_{t \le x} p(t)$ | 离散 CDF 由 PMF 累加 |
| $F(x) = \int_{-\infty}^x f(t)\,dt$ | 连续 CDF 由 PDF 积分 |
| $f(x) = F'(x)$ | 连续：PDF 由 CDF 求导（$f$ 连续点处） |
| $p(x_k) = F(x_k) - F(x_k^-)$ | 离散：PMF 由 CDF 的跳跃高度 |
| $P(a < X \leq b) = F(b) - F(a)$ | 区间概率 |
| $p_Y(y) = \sum_{x:\, g(x)=y} p_X(x)$ | 离散 $Y=g(X)$ 的分布（合并同值概率） |
| $f_Y(y) = \dfrac{1}{|a|}\,f_X\!\left(\dfrac{y-b}{a}\right)$ | 连续线性变换 $Y = aX + b$ |
| $f_Y(y) = f_X(g^{-1}(y))\cdot\left|\dfrac{d}{dy}g^{-1}(y)\right|$ | 单调变换法（$g$ 严格单调可导） |

## 三、重点推导

### 推导：CDF 与 PDF/PMF 的互推关系（含离散/连续对比）

**（1）连续型：由 CDF 求 PDF**

CDF 与 PDF 的联系：
$$
F(x) = P(X\le x) = \int_{-\infty}^{x} f(t)\,dt
$$

由**微积分基本定理**，在 $f$ 的连续点处对 $F$ 求导即得：
$$
f(x) = F'(x)
$$

即**密度函数是分布函数的导数**。反过来，PDF 积分还原为 CDF——两者互为"求导 / 积分"关系。

**（2）离散型：由 CDF 求 PMF**

离散型 CDF 是**阶梯函数**：
$$
F(x) = \sum_{t\le x} p(t)
$$

在每个取值点 $x_k$ 处，CDF 产生一个跳跃，**跳跃的高度就是该点的概率**：
$$
p(x_k) = P(X = x_k) = F(x_k) - F(x_k^-)
$$
其中 $F(x_k^-)$ 表示从左侧趋近 $x_k$ 的极限值（跳跃前的台阶高度）。

**（3）离散 vs 连续对比**

| 对比项 | 离散型 | 连续型 |
|--------|--------|--------|
| 核心函数 | PMF $p(x)$ | PDF $f(x)$ |
| 非负性 | $p(x) \ge 0$ | $f(x) \ge 0$ |
| 归一化 | $\sum_x p(x) = 1$ | $\int_{-\infty}^{\infty} f(x)\,dx = 1$ |
| CDF | $F(x)=\sum_{t\le x}p(t)$（阶梯） | $F(x)=\int_{-\infty}^{x}f(t)\,dt$（连续） |
| 由 CDF 反推 | $p(x_k)=F(x_k)-F(x_k^-)$（跳跃高度） | $f(x)=F'(x)$（求导） |
| 单点概率 | $P(X=x_k)=p_k$，可为正 | $P(X=a)=0$ |

核心思想：**离散的求和 $\sum$ 对应连续的积分 $\int$**，两者是同一概念在不同框架下的表现。

**（4）附带：区间概率公式推导**

因为 $\{X\le a\} \subseteq \{X\le b\}$，由概率的单调性：
$$
P(a < X \le b) = P(X\le b) - P(X\le a) = F(b) - F(a)
$$

## 四、易错点

- 离散与连续分布函数的区别——离散 CDF 是**阶梯函数**（跳跃点对应 PMF 的非零值），连续 CDF 是**连续函数**（可导处导数即 PDF）。
- $P(X=a)=0$ 只对连续变量成立——离散变量单点概率可为正，写"$X\ge x$"这类区间时要区分端点开闭。
- CDF 的三条性质——右连续、单调不减、取值 $[0,1]$（极限 $0$ 和 $1$）；验证一个函数是否为合法 CDF 时逐条核对。
- $f(x)$ 是**密度不是概率**——$f(x)$ 可以大于 1，$f(x)\,\Delta x \approx P(x \le X < x+\Delta x)$ 才是近似概率，概率是曲线下的**面积**。
- 随机变量函数 $Y=g(X)$ 的分布求法混淆——离散型用"合并相同 $y$ 值的概率"；连续型且 $g$ 严格单调用单调变换法（最快）；$g$ 非单调（如 $Y=X^2$）用 CDF 法分段处理（永远不会错）。

## 五、典型题型

- [ ] 由 PMF/PDF 求 CDF——**要点**：离散逐点累加、连续分段积分；注意 CDF 定义用"$\le x$"，分段点处取右连续约定。
- [ ] 由 CDF 求 PMF/PDF 及概率——**要点**：连续型分段求导得 PDF，离散型取跳跃高度得 PMF；区间概率一律用 $F(b)-F(a)$。
- [ ] 验证一个函数是否是合法的 PMF/PDF——**要点**：两个条件——非负 + 归一化（$\sum p(x)=1$ 或 $\int f\,dx=1$）；含未知常数时先用归一化反解常数。
- [ ] 求 $Y=g(X)$ 的分布（CDF法 / 变换法）——**要点**：先判断 $g$ 是否单调；不确定就用 CDF 法四步：写 $F_Y(y) = P(g(X)\le y)$ → 解不等式 → 用 $F_X$ 表示 → 对 $y$ 求导。

## 二、核心公式速记

| 公式 | 适用场景 |
|------|---------|
| $P_n^k = \dfrac{n!}{(n-k)!}$ | 不放回、有序选取 |
| $C_n^k = \dfrac{n!}{k!(n-k)!}$ | 不放回、无序选取 |
| $C_n^k = C_n^{n-k}$ | 对称性：选 $k$ 个保留 = 选 $n-k$ 个舍弃 |
| $C(n,r) = C(n-1,r-1) + C(n-1,r)$ | Pascal 恒等式（每个数是上方两数之和） |
| 隔板法：$C_{n-1}^{m-1}$ | n 个相同物分给 m 组（每组≥1） |
| 有重复组合：$C(r+n-1,\ n-1)$ | n 种元素有放回取 r 个（无序），即非负整数解个数 |
| 有重复排列：$n^r$ | n 种元素有放回取 r 个（有序） |
| 二项式定理 $(x+y)^n = \sum_{k=0}^n C_n^k x^k y^{n-k}$ | 展开求指定项系数 |
| 多项式系数 $\dfrac{n!}{n_1!\,n_2!\cdots n_r!}$ | 把 n 个不同元素分成 r 组（第 i 组大小 $n_i$） |

## 三、重点推导

### 推导1：二项式定理（组合计数推导）

**定理**：
$$
(x+y)^n = \sum_{k=0}^{n} C(n,k)\, x^k y^{n-k}
$$

**证明**：将 $(x+y)^n$ 展开为 $n$ 个 $(x+y)$ 因子的乘积：
$$
(x+y)^n = \underbrace{(x+y)(x+y)\cdots(x+y)}_{n\text{个括号}}
$$

展开时，每个括号要么选 $x$，要么选 $y$，展开后的每一项都是 $x^k y^{n-k}$ 的形式，其中 $k$ 是选取 $x$ 的括号个数。

要得到 $x^k y^{n-k}$ 这一项，需要**从 $n$ 个括号中选出 $k$ 个取 $x$**（其余 $n-k$ 个自然取 $y$），选择方式数为 $C(n,k)$。

因此 $x^k y^{n-k}$ 的系数为 $C(n,k)$，对所有 $k = 0,1,\dots,n$ 求和即得：
$$
(x+y)^n = \sum_{k=0}^{n} C(n,k)\, x^k y^{n-k}
$$

**两个直接推论**（与概率论的联系）：
- 令 $x = p$、$y = 1-p$，即得二项分布 $P(X=k) = C(n,k)\,p^k(1-p)^{n-k}$，且 $\sum_k P(X=k) = 1$；
- 令 $x = y = 1$，得 $\sum_{k=0}^{n} C(n,k) = 2^n$，即 Pascal 三角形每行之和。

### 推导2：隔板法（有重复组合公式）

**问题**：求 $x_1 + x_2 + \cdots + x_n = r$ 的**非负整数解**个数（等价于：从 $n$ 种元素中有放回取 $r$ 个、不考虑顺序的组合数）。

**第一步——化为正整数解**：令 $y_i = x_i + 1$，则 $y_i$ 为正整数，且：
$$
y_1 + y_2 + \cdots + y_n = (x_1+1) + \cdots + (x_n+1) = r + n
$$
问题转化为：求 $y_1 + \cdots + y_n = r+n$ 的**正整数解**个数。

**第二步——隔板**：把 $r+n$ 个 $1$ 排成一排，它们之间有 $r+n-1$ 个空隙（相邻两个 $1$ 之间）。在这 $r+n-1$ 个空隙中**插入 $n-1$ 个隔板**，把 $r+n$ 个 $1$ 分成 $n$ 组，每组对应一个 $y_i$。

**第三步——计数**：隔板互不区分，且每个空隙最多放一个隔板，选法数为：
$$
C(r+n-1,\ n-1)
$$

因此原方程的非负整数解个数（即"有放回、无序"的组合数）为 $C(r+n-1,\ n-1)$。

**特例**：n 个相同物分给 m 组且每组至少 1 个，等价于正整数解 $z_1+\cdots+z_m = n$，个数为 $C(n-1,\ m-1)$；允许空组则等价于非负整数解，个数为 $C(n+m-1,\ m-1)$。

## 四、易错点

- 什么时候用排列、什么时候用组合？——只看**顺序是否重要**：选完还要排序（送人、排岗位）用排列 $P_n^k$；只选不排（进小组、捐书）用组合 $C_n^k$。
- "至少/至多"问题需要分类讨论还是补集法？——若补集更好数（如"至少两个相同"的补集是"全部不同"），优先用补集：$P(\text{至少一个}) = 1 - P(\text{一个都没有})$。
- 隔板法的变形：允许空组时如何处理？——允许空组 = 非负整数解 = $C(r+n-1,\ n-1)$；要求每组≥1 则用 $C(n-1,\ m-1)$。
- 乘法原理要求步骤**缺一不可**（"且"关系），加法原理要求类别**互斥**（"或"关系）："先…再…"用乘，"要么…要么…"用加。

## 五、典型题型

- [ ] 数字/字母排列问题——**要点**：先判断是否允许重复、顺序是否重要，再决定用 $P_n^k$（不放回有序）、$n^r$（有放回有序）还是 $C_n^k$。
- [ ] 分组分配问题——**要点**：用多项式系数 $\dfrac{n!}{n_1!\cdots n_r!}$，先确认各组大小满足 $\sum n_i = n$。
- [ ] 隔板法应用——**要点**：识别"相同物 + 分组"结构，先处理"每组≥1"的约束（必要时先补虚拟物）。
- [ ] 古典概型计数——**要点**：先确定样本空间 $\Omega$ 及其等可能假设，分子分母分别用计数工具数清楚。

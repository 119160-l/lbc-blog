## 二、核心公式速记

| 公式                                                                                                          | 适用场景         |     |        |     |         |
| ----------------------------------------------------------------------------------------------------------- | ------------ | --- | ------ | --- | ------- |
| $P(A \cup B) = P(A) + P(B) - P(AB)$                                                                         | 两事件并的概率      |     |        |     |         |

## 三、重点推导

### 推导1：加法公式 $P(A\cup B) = P(A) + P(B) - P(AB)$ 的证明

**证明**：将 $A \cup B$ 分解为三个互不相容的部分：
$$
A \cup B = (A\setminus B) \cup (A\cap B) \cup (B\setminus A)
$$

其中 $A\setminus B = A\cap B^c$，$B\setminus A = B\cap A^c$，三者两两互不相交。由**有限可加性**：
$$
P(A\cup B) = P(A\setminus B) + P(A\cap B) + P(B\setminus A) \tag{1}
$$

又因为 $A = (A\setminus B) \cup (A\cap B)$，由有限可加性：
$$
P(A) = P(A\setminus B) + P(A\cap B) \quad\Rightarrow\quad P(A\setminus B) = P(A) - P(A\cap B) \tag{2}
$$

同理：
$$
P(B\setminus A) = P(B) - P(A\cap B) \tag{3}
$$

将 (2)(3) 代入 (1)：
$$
\begin{aligned}
P(A\cup B) &= \big[P(A) - P(A\cap B)\big] + P(A\cap B) + \big[P(B) - P(A\cap B)\big] \\
&= P(A) + P(B) - P(A\cap B)
\end{aligned}
$$

**关键工具**：有限可加性——它本身由公理 3（可列可加性）结合 $P(\emptyset)=0$ 推出，是本书所有概率运算的"发动机"。

### 推导2：容斥原理（三事件与一般情形）

**三事件加法公式**：
$$
P(A\cup B\cup C) = P(A)+P(B)+P(C) - P(AB) - P(AC) - P(BC) + P(ABC)
$$

**证明**：令 $D = A \cup B$，对 $D \cup C$ 反复应用两事件加法公式：
$$
P(A\cup B\cup C) = P(D\cup C) = P(D) + P(C) - P(D\cap C) \tag{1}
$$

其中：
$$
P(D) = P(A\cup B) = P(A) + P(B) - P(AB) \tag{2}
$$

而
$$
D\cap C = (A\cup B)\cap C = (A\cap C)\cup(B\cap C)
$$
$$
P(D\cap C) = P(AC) + P(BC) - P(ABC) \tag{3}
$$

将 (2)(3) 代入 (1) 并合并同类项，即得三事件加法公式。

**直观记忆**：**"单事件项加、两两交项减、三三交项加"**——符号按交集个数奇偶交替。

**一般容斥原理**（$n$ 个事件，由数学归纳法 + 两事件加法公式逐层推出）：
$$
P\left(\bigcup_{i=1}^n A_i\right) = \sum_{i}P(A_i) - \sum_{i<j}P(A_iA_j) + \sum_{i<j<k}P(A_iA_jA_k) - \cdots + (-1)^{n+1}P(A_1A_2\cdots A_n)
$$

## 四、易错点

- 容斥原理漏项或多算——按"奇加偶减"逐层核对：先加单事件、减两两交、加三三交……最后一项符号与 $n$ 的奇偶一致。
- "至少有一个"用对立事件转换：$P(\bigcup A_i) = 1 - P(\bigcap A_i^c)$，当"一个都没有"好算时（如生日问题）优先用补集。
- 古典概型的"等可能"条件是否满足——等可能需由对称性判断（均匀硬币、洗好的牌 ✅；不均匀硬币 ❌），不是自动成立的假设。
- 事件不互斥时误用加法公式——$P(A\cup B) = P(A)+P(B)$ 仅在 $A\cap B = \emptyset$ 时成立，否则必须减去 $P(AB)$。
- 几何概型是古典概型的连续推广：结果无限多个时不能用 $\dfrac{|A|}{|\Omega|}$，改用它需要先明确"均匀"（等可能）体现在长度/面积/体积上。

## 五、典型题型

- [ ] 用集合运算表示复杂事件——**要点**：先把"且/或/非"翻译成 $\cap / \cup / ^c$，画韦恩图辅助，再套用对应概率公式。
- [ ] 利用概率性质反解未知概率——**要点**：由 $P(A\cup B)$、$P(\bar A)$ 等已知量出发，用加法公式与补事件公式联立，解出 $P(AB)$ 等未知量。
- [ ] 古典概型计算（搭配第1章计数）——**要点**：先确认"有限 + 等可能"，分子分母分别用排列组合数清楚，常用补集化简"至少"类问题。
- [ ] 几何概型求概率——**要点**：画出样本空间与有利区域的图形，将概率化为长度/面积/体积之比，注意端点处测度为零不影响结果。

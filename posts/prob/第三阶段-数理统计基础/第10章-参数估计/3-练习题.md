## 基础题

### 10.1 $X \sim \operatorname{Exp}(\lambda)$ 的矩估计与 MLE

设总体 $X$ 服从参数为 $\lambda$ 的指数分布，概率密度函数为：

$$
f(x;\lambda) = \lambda e^{-\lambda x}, \quad x > 0, \; \lambda > 0
$$

从该总体中抽取简单随机样本 $X_1, X_2, \dots, X_n$。

**（1）** 求 $\lambda$ 的矩估计量 $\hat{\lambda}_{\text{MoM}}$。  
**（2）** 求 $\lambda$ 的极大似然估计量 $\hat{\lambda}_{\text{MLE}}$。  
**（3）** 验证 $\hat{\lambda}_{\text{MLE}}$ 是否是无偏估计？若否，给出偏差表达式。

**答案**

（1）矩估计：指数分布 $E[X] = \frac{1}{\lambda}$。令 $\frac{1}{\lambda} = \bar{X}$，得 $\boxed{\hat{\lambda}_{\text{MoM}} = \frac{1}{\bar{X}}}$。

（2）MLE：似然函数 $L(\lambda) = \lambda^n e^{-\lambda\sum x_i}$，对数似然 $\ell(\lambda) = n\ln\lambda - \lambda\sum x_i$，求导得 $\hat{\lambda}_{\text{MLE}} = \frac{1}{\bar{X}}$，两者相同。

（3）无偏性：$E[\hat{\lambda}_{\text{MLE}}] = \frac{n}{n-1}\lambda \neq \lambda$，有偏，偏差为 $\frac{\lambda}{n-1}$，渐近无偏。

### 10.2 $X \sim U(0, \theta)$ 的矩估计与 MLE

设总体 $X$ 服从区间 $(0, \theta)$ 上的均匀分布，概率密度函数为：

$$
f(x;\theta) = \frac{1}{\theta}, \quad 0 < x < \theta, \; \theta > 0
$$

从该总体中抽取简单随机样本 $X_1, X_2, \dots, X_n$。

**（1）** 求 $\theta$ 的矩估计量 $\hat{\theta}_{\text{MoM}}$。  
**（2）** 求 $\theta$ 的极大似然估计量 $\hat{\theta}_{\text{MLE}}$（提示：注意似然函数的单调性，不能通过解似然方程得到）。  
**（3）** 比较 $\hat{\theta}_{\text{MoM}}$ 和 $\hat{\theta}_{\text{MLE}}$ 哪个更合理？并说明理由。

**答案**

（1）矩估计：$E[X] = \frac{\theta}{2}$，令 $\frac{\theta}{2} = \bar{X}$，得 $\boxed{\hat{\theta}_{\text{MoM}} = 2\bar{X}}$。

（2）MLE：$L(\theta) = 1/\theta^n$ 是 $\theta$ 的递减函数，$\theta$ 最小为 $\max X_i$，得 $\boxed{\hat{\theta}_{\text{MLE}} = \max\{X_1,\dots,X_n\}}$。

（3）比较：$\hat{\theta}_{\text{MoM}}$ 无偏但方差大，可能 $\hat{\theta} < \max X_i$ 不合理；$\hat{\theta}_{\text{MLE}}$ 有偏但总是合理，可修正为 $\frac{n+1}{n}\max X_i$。

### 10.3 正态总体均值的置信区间

某工厂生产一批零件，其直径 $X \sim N(\mu, \sigma^2)$。现随机抽取 $n = 25$ 个零件，测得样本均值 $\bar{x} = 10.2$ mm，样本标准差 $s = 1.5$ mm。

**（1）** 求 $\mu$ 的 95% 置信区间（$\sigma$ 未知）。  
**（2）** 若已知 $\sigma = 1.5$ mm，求 $\mu$ 的 95% 置信区间，并与（1）的结果比较。  
**（3）** 若要求置信区间宽度不超过 1 mm（在 $\sigma$ 已知且 $\sigma = 1.5$ 的情况下），至少需要多大的样本量？

**答案**

（1）$\sigma$ 未知：$t_{0.025}(24)=2.064$，$\bar{x} \pm 2.064 \times \frac{1.5}{5} = 10.2 \pm 0.6192$，得 $\boxed{(9.5808, 10.8192)}$。

（2）$\sigma$ 已知：$z_{0.025}=1.96$，$10.2 \pm 1.96 \times \frac{1.5}{5} = 10.2 \pm 0.588$，得 $\boxed{(9.612, 10.788)}$。已知时区间略窄。

（3）样本量：$2 \times 1.96 \times \frac{1.5}{\sqrt{n}} = 1$，解得 $n \approx 34.57$，至少需要 $\boxed{n=35}$。

### 10.4 样本方差的无偏性证明

设 $X_1, X_2, \dots, X_n$ 是来自总体 $X$ 的简单随机样本，$E[X] = \mu$，$\operatorname{Var}(X) = \sigma^2$。定义：

$$
S^2 = \frac{1}{n-1}\sum_{i=1}^{n} (X_i - \bar{X})^2, \quad \hat{\sigma}^2 = \frac{1}{n}\sum_{i=1}^{n} (X_i - \bar{X})^2
$$

**（1）** 证明 $E[S^2] = \sigma^2$，即 $S^2$ 是 $\sigma^2$ 的无偏估计。  
**（2）** 证明 $E[\hat{\sigma}^2] = \frac{n-1}{n}\sigma^2$，并计算 $\hat{\sigma}^2$ 的偏差。  
**（3）** 当 $n = 5$ 时，$\hat{\sigma}^2$ 的偏差是 $\sigma^2$ 的百分之多少？$n = 50$ 时呢？

**答案**

（1）$E[\sum (X_i-\bar{X})^2] = (n-1)\sigma^2$，故 $E[S^2] = \sigma^2$。

（2）$E[\hat{\sigma}^2] = \frac{n-1}{n}\sigma^2$，偏差为 $-\frac{\sigma^2}{n}$。

（3）$n=5$ 时低估 20%，$n=50$ 时低估 2%。

## 提高题

### 10.5 估计量的有效性比较

设 $X_1, X_2, X_3$ 是来自总体 $X$ 的简单随机样本，$E[X] = \mu$，$\operatorname{Var}(X) = \sigma^2$。考虑以下三个 $\mu$ 的估计量：

$$
\hat{\mu}_1 = \frac{X_1 + X_2 + X_3}{3}, \quad
\hat{\mu}_2 = \frac{X_1 + 2X_2 + X_3}{4}, \quad
\hat{\mu}_3 = \frac{X_1 + X_2}{2}
$$

**（1）** 判断这三个估计量是否都是 $\mu$ 的无偏估计。  
**（2）** 计算每个估计量的方差。  
**（3）** 哪个估计量最有效？哪个最差？  
**（4）** 构造一个比 $\hat{\mu}_1$ 更有效的无偏估计量（提示：考虑加权平均，权重和为 1）。

**答案**

（1）三个估计量都是无偏的。

（2）$\operatorname{Var}(\hat{\mu}_1)=\frac{\sigma^2}{3}$，$\operatorname{Var}(\hat{\mu}_2)=\frac{3\sigma^2}{8}$，$\operatorname{Var}(\hat{\mu}_3)=\frac{\sigma^2}{2}$。

（3）$\hat{\mu}_1$ 最有效，$\hat{\mu}_3$ 最差。

（4）等权平均 $\hat{\mu}_1=\bar{X}$ 在所有线性无偏估计中方差最小。

### 10.6 正态总体方差的置信区间

某食品厂生产袋装薯片，每袋净重 $X \sim N(\mu, \sigma^2)$。从一批产品中随机抽取 $n = 16$ 袋，测得样本标准差 $s = 3.2$ g。

**（1）** 求 $\sigma^2$ 的 95% 置信区间。  
**（2）** 求 $\sigma$ 的 95% 置信区间。  
**（3）** 若要求 $\sigma$ 的置信上限不超过 5 g，是否需要增大样本量？（提示：计算当前置信上限并与 5 g 比较）

**答案**

（1）$\sigma^2$ 的 95% CI：$\left(\frac{15\times 3.2^2}{27.49}, \frac{15\times 3.2^2}{6.262}\right) = \boxed{(5.586, 24.527)}$。

（2）$\sigma$ 的 95% CI：$\boxed{(2.363, 4.953)}$。

（3）上限 4.953 < 5，不需要增大样本量。

### 10.7 Poisson 分布的参数估计

设 $X \sim P(\lambda)$（Poisson 分布），分布列为：

$$
P(X = k) = \frac{\lambda^k e^{-\lambda}}{k!}, \quad k = 0, 1, 2, \dots, \; \lambda > 0
$$

从该总体中抽取简单随机样本 $X_1, X_2, \dots, X_n$。

**（1）** 求 $\lambda$ 的矩估计量。  
**（2）** 求 $\lambda$ 的极大似然估计量。  
**（3）** 验证该 MLE 是无偏的。  
**（4）** 利用不变性，求 $P(X = 0) = e^{-\lambda}$ 的 MLE。

**答案**

（1）矩估计：$\hat{\lambda}_{\text{MoM}} = \bar{X}$。

（2）MLE：$\hat{\lambda}_{\text{MLE}} = \bar{X}$。

（3）$E[\hat{\lambda}_{\text{MLE}}] = \lambda$，是无偏估计。

（4）$\widehat{e^{-\lambda}} = e^{-\bar{X}}$。

### 10.8 指数分布均值的置信区间

设 $X_1, X_2, \dots, X_n$ 是来自指数分布 $\operatorname{Exp}(\lambda)$ 的简单随机样本，其概率密度为 $f(x;\lambda) = \lambda e^{-\lambda x}$（$x > 0$）。

已知 $\bar{X}$ 是 $\frac{1}{\lambda}$ 的 MLE，且 $2n\lambda\bar{X} \sim \chi^2(2n)$。

**（1）** 利用枢轴量法，构造 $\frac{1}{\lambda}$（即总体均值）的置信水平为 $1-\alpha$ 的置信区间。  
**（2）** 若 $n = 10$，$\bar{x} = 5.2$，求 $\frac{1}{\lambda}$ 的 95% 置信区间。  
（已知 $\chi^2_{0.025}(20) = 34.17$，$\chi^2_{0.975}(20) = 9.591$）

**答案**

（1）$\frac{1}{\lambda}$ 的 $1-\alpha$ 置信区间：$\boxed{\left(\frac{2n\bar{X}}{\chi^2_{\alpha/2}(2n)}, \frac{2n\bar{X}}{\chi^2_{1-\alpha/2}(2n)}\right)}$。

（2）$n=10,\bar{x}=5.2$，$2n\bar{x}=104$，$\chi^2_{0.025}(20)=34.17$，$\chi^2_{0.975}(20)=9.591$，得 $\boxed{(3.044, 10.843)}$。

## 拓展题

### 10.9 均匀分布 $U(-\theta, \theta)$ 的参数估计

设总体 $X \sim U(-\theta, \theta)$，其中 $\theta > 0$ 为未知参数，概率密度函数为：

$$
f(x;\theta) = \frac{1}{2\theta}, \quad -\theta < x < \theta
$$

从该总体中抽取简单随机样本 $X_1, X_2, \dots, X_n$。

**（1）** 求 $\theta$ 的矩估计量 $\hat{\theta}_{\text{MoM}}$。  
**（2）** 求 $\theta$ 的极大似然估计量 $\hat{\theta}_{\text{MLE}}$。  
**（3）** 判断 $\hat{\theta}_{\text{MoM}}$ 和 $\hat{\theta}_{\text{MLE}}$ 是否是无偏的。若否，能否修正？  
**（4）** 在 $n \to \infty$ 时，这两个估计量是否都具有一致性？

**答案**

（1）矩估计：$\hat{\theta}_{\text{MoM}} = \sqrt{\frac{3}{n}\sum X_i^2}$。

（2）MLE：$\hat{\theta}_{\text{MLE}} = \max\{|X_1|,\dots,|X_n|\}$。

（3）两者均有偏，$\hat{\theta}_{\text{MLE}}$ 可修正为 $\frac{n+1}{n}\max|X_i|$。

（4）两者均具有一致性。

### 10.10 双参数估计的综合问题

设总体 $X$ 的概率密度为：

$$
f(x;\alpha, \beta) = \frac{\alpha}{\beta^\alpha} x^{\alpha-1}, \quad 0 < x < \beta, \; \alpha > 0, \; \beta > 0
$$

（这是 Pareto 分布的一种特殊形式）

从该总体中抽取简单随机样本 $X_1, X_2, \dots, X_n$。

**（1）** 求 $\alpha$ 和 $\beta$ 的矩估计量（提示：先计算 $E[X]$ 和 $E[X^2]$）。  
**（2）** 求 $\beta$ 的 MLE（提示：考虑似然函数关于 $\beta$ 的单调性）。  
**（3）** 在 $\beta$ 已知的情况下，求 $\alpha$ 的 MLE。

**答案**

（1）矩估计：解 $\frac{\alpha(\alpha+2)}{(\alpha+1)^2} = \frac{\bar{X}^2}{\frac{1}{n}\sum X_i^2}$ 得 $\hat{\alpha}$，$\hat{\beta} = \frac{\hat{\alpha}+1}{\hat{\alpha}}\bar{X}$。

（2）$\hat{\beta}_{\text{MLE}} = \max\{X_1,\dots,X_n\}$。

（3）$\beta$ 已知时，$\hat{\alpha}_{\text{MLE}} = \frac{n}{n\ln\beta - \sum \ln X_i}$。

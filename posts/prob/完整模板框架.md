# 三大阶段知识内容——完整模板框架

> 可直接复制使用。占位符用 `{...}` 表示，替换为实际内容即可。

---

## 一、目录结构

```
第{章节编号}章-{章节名称}/
├── 1-公式推导.md      ← 全部公式推导，从定义出发逐步展开
├── 2-知识讲解.md      ← 直观理解 + 为什么→怎么做→是什么
├── 3-练习题.md        ← 基础题 + 提高题 + 拓展题（题目后紧跟答案）
└── figures/            ← 该章的示意图（可选）
```

---

```markdown

---

### 1.1 定义

$$
\boxed{核心公式}
$$

**说明**：对公式中每个符号的解释，1-2句。

### 1.2 推导过程

$$
\begin{aligned}
\text{第1步} & = \text{理由} \\
\text{第2步} & = \text{利用性质X} \\
\vdots
\end{aligned}
$$

**关键思路**：点明核心技巧（1-2句）。

---

## 2. {下一个概念}

### 2.1 定义

$$
\boxed{公式}
$$

### 2.2 推导

---

## 3. {重要性质/定理}

### 3.1 {性质名称}

**陈述**：

$$
公式
$$

**证明**：

---

## 【可选】总结表

| 概念 | 公式 | 条件 |
|------|------|------|
| {概念A} | $...$ | ... |
| {概念B} | $...$ | ... |
```

### 公式推导 格式要点

| 规则 | 说明 |
|------|------|
| **标题层级** | `# 章节名` → `## 序号.概念` → `### 序号.子概念` |
| **核心公式** | 用 `\boxed{...}` 包裹突出显示 |
| **推导过程** | 用 `\begin{aligned}...\end{aligned}`，每一步一行，末尾 `\\` |
| **关键思路** | 推导结束后，用 **加粗** 写"关键思路"：点明技巧 |
| **图片插入** | `![描述](./figures/文件名.png)` 独立段落，下一行 `*说明文字*` |
| **分隔符** | 小节之间用 `---` 分隔 |
| **公式风格** | 行内 `$...$`，独立 `$$...$$` |

```markdown
## 【可选】对比表格

| 概念A | 概念B | 概念C |
|-------|-------|-------|
| 特征1 | 特征1 | 特征1 |
| 特征2 | 特征2 | 特征2 |

---

## 总结：知识体系图

{用文字或流程图梳理本章核心脉络}

### 核心脉络

1. 起点 → 步骤1 → 步骤2 → 终点
2. 关键思想：1句话总结

---

## 本章应掌握的内容

- [ ] 能写出核心公式
- [ ] 能解释概念{XX}的本质
- [ ] 能区分概念A和概念B
- [ ] 能完成典型计算题
```

### 知识讲解 格式要点

| 规则 | 说明 |
|------|------|
| **开头三件套** | `本章内容`(引用块目录) + `承上启下`(2-3句) + `问题导向`(3个问题) |
| **每节三段式** | **为什么？**（动机）→ **怎么做？**（操作）→ **是什么？**（定义） |
| **类比优先** | 抽象概念先用生活类比，再给公式 |
| **重要公式** | 用 `\boxed{...}` 包裹 |
| **图片嵌入** | 放在对应概念解释之后，`![描述](./figures/文件名.png)` + `*说明文字*` |
| **对比表格** | 涉及多个概念对比时，一定用表格 |
| **结尾** | `总结：知识体系图` + `本章应掌握的内容`（清单） |
| **强调** | 关键结论用 `**加粗**`，不要用 `>` 引用块标记普通文字 |

## 七、核心套路（一句话总结）

> **公式推导**：`定义 → 推导 → 关键思路 → 图片 → 分隔`
> 
> **知识讲解**：`本章目录 → 承上启下 → 问题导向 → (为什么→怎么做→是什么)ⁿ → 总结表 → 应掌握内容`
> 
> **每节三段式**：`为什么（动机）→ 怎么做（操作）→ 是什么（定义）`
>
> **练习题**：`基础题 → 提高题 → 拓展题`，每道题**题目后紧跟答案**，答案包含思路说明
>
> **总复习**：`核心概念 → 公式速记 → 重点推导 → 易错点 → 典型题型 → 自检清单`

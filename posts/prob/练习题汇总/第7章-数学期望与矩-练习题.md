# 练习题

## 基础题

### 7.1 指数分布的期望与方差

设 $X \sim \text{Exp}(\lambda)$，概率密度函数为 $f(x) = \lambda e^{-\lambda x}$，$x \geq 0$（$\lambda > 0$）。

(1) 求 $E[X]$
(2) 求 $E[X^2]$
(3) 求 $\operatorname{Var}(X)$

**要求**：使用分部积分法，逐步推导。

---

### 7.2 二项分布的期望与方差（MGF 法）

设 $X \sim B(n, p)$，即 $X$ 服从参数为 $n$（试验次数）和 $p$（成功概率）的二项分布。

(1) 求 $X$ 的 MGF $M_X(t)$
(2) 利用 MGF 求 $E[X]$ 和 $\operatorname{Var}(X)$

---

### 7.3 联合分布的协方差与相关系数

设 $(X, Y)$ 的联合概率密度函数为：

$$
f(x, y) = 
\begin{cases}
2, & 0 < x < y < 1 \\
0, & \text{其他}
\end{cases}
$$

(1) 求边缘密度 $f_X(x)$ 和 $f_Y(y)$
(2) 求 $E[X]$，$E[Y]$，$E[XY]$
(3) 求 $\operatorname{Cov}(X, Y)$
(4) 求 $\rho(X, Y)$

---

### 7.4 独立性与协方差的关系

(1) 证明：若 $X$ 与 $Y$ 独立，则 $\operatorname{Cov}(X, Y) = 0$。

(2) 构造一个反例：$\operatorname{Cov}(X, Y) = 0$ 但 $X$ 与 $Y$ 不独立。

**要求**：反例需给出具体的分布和计算过程。

---

## 提高题

### 7.5 正态分布的 MGF 与特征函数

设 $X \sim N(\mu, \sigma^2)$，概率密度函数为：

$$
f(x) = \frac{1}{\sqrt{2\pi}\sigma} e^{-\frac{(x-\mu)^2}{2\sigma^2}}
$$

(1) 求 $X$ 的 MGF $M_X(t)$
(2) 利用 MGF 求 $E[X]$ 和 $\operatorname{Var}(X)$
(3) 求 $X$ 的特征函数 $\varphi_X(t)$

---

### 7.6 条件期望与全期望公式

设 $(X, Y)$ 的联合概率密度函数为：

$$
f(x, y) = 
\begin{cases}
\frac{3}{2}x^2 + y, & 0 \leq x \leq 1, \; 0 \leq y \leq 1 \\
0, & \text{其他}
\end{cases}
$$

(1) 求边缘密度 $f_X(x)$ 和 $f_Y(y)$
(2) 求条件密度 $f_{X|Y}(x|y)$
(3) 求条件期望 $E[X \mid Y = y]$
(4) 利用全期望公式 $E[X] = E[E[X \mid Y]]$ 验证(3)的结果

---

### 7.7 全方差公式的应用

设 $X$ 和 $Y$ 是随机变量，且已知：

$$E[X \mid Y] = 2Y + 1, \quad \operatorname{Var}(X \mid Y) = 3Y^2 + 1, \quad E[Y] = 2, \quad \operatorname{Var}(Y) = 4$$

(1) 求 $E[X]$
(2) 求 $\operatorname{Var}(X)$

---

### 7.8 Gamma 分布与 MGF

设 $X \sim \text{Gamma}(\alpha, \beta)$，概率密度函数为：

$$
f(x) = \frac{\beta^\alpha}{\Gamma(\alpha)} x^{\alpha-1} e^{-\beta x}, \quad x > 0
$$

其中 $\alpha > 0$（形状参数），$\beta > 0$（速率参数），$\Gamma(\alpha) = \int_0^\infty t^{\alpha-1} e^{-t} \, dt$ 是 Gamma 函数。

(1) 求 $X$ 的 MGF $M_X(t)$，并指出 $t$ 的取值范围
(2) 利用 MGF 求 $E[X]$ 和 $\operatorname{Var}(X)$
(3) 特别地，当 $\alpha = 1$ 时，Gamma 分布退化为指数分布。验证此时 $E[X]$ 和 $\operatorname{Var}(X)$ 与指数分布的结果一致

---

## 拓展题

### 7.9 联合正态分布的协方差矩阵

设 $(X, Y)$ 服从二维正态分布，联合密度函数为：

$$
f(x, y) = \frac{1}{2\pi\sigma_X\sigma_Y\sqrt{1-\rho^2}} \exp\left\{ -\frac{1}{2(1-\rho^2)} \left[ \frac{(x-\mu_X)^2}{\sigma_X^2} - \frac{2\rho(x-\mu_X)(y-\mu_Y)}{\sigma_X\sigma_Y} + \frac{(y-\mu_Y)^2}{\sigma_Y^2} \right] \right\}
$$

(1) 求 $X$ 和 $Y$ 的边缘分布
(2) 求 $\operatorname{Cov}(X, Y)$ 和 $\rho(X, Y)$，验证 $\rho$ 就是相关系数参数
(3) 求条件分布 $X \mid Y = y$，并求条件期望 $E[X \mid Y = y]$ 和条件方差 $\operatorname{Var}(X \mid Y = y)$
(4) 验证全期望公式和全方差公式

---

### 7.10 随机游走的期望与方差

设 $S_n = \sum_{i=1}^n X_i$ 是一个简单随机游走，其中 $X_i$ 独立同分布，且：

$$
P(X_i = 1) = p, \quad P(X_i = -1) = 1-p = q
$$

(1) 求 $E[S_n]$ 和 $\operatorname{Var}(S_n)$
(2) 设 $T = \min\{n \geq 1 : S_n = 0\}$ 是首次回到原点的步数。已知 $S_0 = 0$，且 $p = q = 1/2$（对称随机游走）。利用全期望公式证明 $E[T] = \infty$（即对称随机游走返回原点的时间期望无限大）

---

## 答案提示

### 基础题

**7.1** 

(1) $E[X] = \frac{1}{\lambda}$

(2) $E[X^2] = \frac{2}{\lambda^2}$

(3) $\operatorname{Var}(X) = \frac{1}{\lambda^2}$

**7.2**

(1) $M_X(t) = (pe^t + 1-p)^n$

(2) $E[X] = np$，$\operatorname{Var}(X) = np(1-p)$

**7.3**

(1) $f_X(x) = 2(1-x), \; 0 < x < 1$；$f_Y(y) = 2y, \; 0 < y < 1$

(2) $E[X] = \frac{1}{3}$，$E[Y] = \frac{2}{3}$，$E[XY] = \frac{1}{4}$

(3) $\operatorname{Cov}(X, Y) = \frac{1}{36}$

(4) $\rho(X, Y) = \frac{1}{2}$

**7.4**

(1) 独立性 $\Rightarrow$ $E[XY]=E[X]E[Y]$ $\Rightarrow$ $\operatorname{Cov}(X,Y)=0$

(2) 反例：$X \sim U(-1,1)$，$Y = X^2$，则 $\operatorname{Cov}(X,Y)=0$ 但 $X$ 与 $Y$ 不独立。

### 提高题

**7.5**

(1) $M_X(t) = e^{\mu t + \frac{\sigma^2 t^2}{2}}$

(2) $E[X] = \mu$，$\operatorname{Var}(X) = \sigma^2$

(3) $\varphi_X(t) = e^{i\mu t - \frac{\sigma^2 t^2}{2}}$

**7.6**

(1) $f_X(x) = \frac{3}{2}x^2 + \frac{1}{2}, \; 0 \leq x \leq 1$；$f_Y(y) = \frac{1}{2} + y, \; 0 \leq y \leq 1$

(2) $f_{X|Y}(x|y) = \frac{\frac{3}{2}x^2 + y}{\frac{1}{2} + y}, \; 0 \leq x \leq 1$

(3) $E[X \mid Y = y] = \frac{3 + 4y}{4(1 + 2y)}$

(4) $E[E[X \mid Y]] = \frac{5}{8} = E[X]$，验证成立。

**7.7**

(1) $E[X] = 5$

(2) $\operatorname{Var}(X) = 41$

**7.8**

(1) $M_X(t) = \left( \frac{\beta}{\beta - t} \right)^\alpha$，$t < \beta$

(2) $E[X] = \frac{\alpha}{\beta}$，$\operatorname{Var}(X) = \frac{\alpha}{\beta^2}$

(3) $\alpha=1$ 时 $E[X]=\frac{1}{\beta}$，$\operatorname{Var}(X)=\frac{1}{\beta^2}$，与指数分布一致。

### 拓展题

**7.9**

(1) $X \sim N(\mu_X, \sigma_X^2)$，$Y \sim N(\mu_Y, \sigma_Y^2)$

(2) $\operatorname{Cov}(X, Y) = \rho \sigma_X \sigma_Y$，$\rho(X, Y) = \rho$

(3) $X \mid Y = y \sim N\left( \mu_X + \rho \frac{\sigma_X}{\sigma_Y} (y - \mu_Y), \; \sigma_X^2 (1 - \rho^2) \right)$

(4) 全期望和全方差公式均成立。

**7.10**

(1) $E[S_n] = n(2p-1)$，$\operatorname{Var}(S_n) = 4npq$

(2) 由全期望公式推出矛盾方程，故 $E[T] = \infty$。

# 第4章 随机变量及其分布 · 练习题

---

## 基础题

### 4.1 离散型 PMF 验证

已知随机变量 $X$ 的 PMF 为 $p(x) = \dfrac{x}{6}$，$x = 1, 2, 3$。

**(a)** 验证这是合法的 PMF。
**(b)** 求 $P(X \ge 2)$。
**(c)** 求 $F(2)$。

---

### 4.2 连续型 PDF 求常数

已知随机变量 $X$ 的 PDF 为 $f(x) = cx^2$，$0 \le x \le 2$。

**(a)** 求常数 $c$ 的值。
**(b)** 求 $P(1 \le X \le 2)$。

---

### 4.3 CDF 求区间概率

已知随机变量 $X$ 的 CDF 为 $F(x) = x^2$，$0 \le x \le 1$（当 $x < 0$ 时 $F(x)=0$，当 $x > 1$ 时 $F(x)=1$）。

**(a)** 求 $P(0.2 < X \le 0.6)$。
**(b)** 求 PDF $f(x)$。

---

## 提高题

### 4.4 随机变量函数的分布

设 $X$ 的 PDF 为 $f_X(x) = e^{-x}$，$x > 0$，求 $Y = X^2$ 的 PDF $f_Y(y)$。

---

### 4.5 概率积分变换

设 $X$ 是连续型随机变量，CDF 为 $F(x)$，且 $F$ 严格单调递增。证明 $Y = F(X)$ 服从 $[0,1]$ 上的均匀分布 $U(0,1)$。

---

### 4.6 Cauchy 分布的自反性

设分布 $X$ 服从 Cauchy ，PDF 为 $f_X(x) = \dfrac{1}{\pi(1 + x^2)}$，$x \in \mathbb{R}$。求 $Y = \dfrac{1}{X}$ 的 PDF，并说明结论。

---

## 拓展题

### 4.7 指数分布变换

设 $X$ 的 PDF 为 $f_X(x) = 2x$，$0 \le x \le 1$，求 $Y = -2\ln X$ 的 PDF，并指出 $Y$ 服从什么分布。

---

### 4.8 证明概率积分变换定理

设 $X$ 是连续型随机变量，CDF 为 $F(x)$。证明：
$$Y = F(X) \sim U(0,1)$$

并说明该定理在随机数生成中的应用。

---

## 答案提示

### 基础题

**4.1** **(a)** 验证 PMF 的合法性需满足两个条件：所有概率值非负，且总和为 1。计算得 $p(1) = \frac{1}{6}$，$p(2) = \frac{2}{6} = \frac{1}{3}$，$p(3) = \frac{3}{6} = \frac{1}{2}$，三者均非负且 $\sum p(x) = \frac{1}{6} + \frac{1}{3} + \frac{1}{2} = 1$，因此是合法的 PMF。

**(b)** $P(X \ge 2)$ 即 $X$ 取值为 2 或 3 的概率之和：
$$P(X \ge 2) = p(2) + p(3) = \frac{1}{3} + \frac{1}{2} = \frac{5}{6}$$

**(c)** CDF $F(2)$ 是 $X \le 2$ 的所有概率之和：
$$F(2) = \sum_{x \le 2} p(x) = p(1) + p(2) = \frac{1}{6} + \frac{1}{3} = \frac{1}{2}$$

**4.2** **(a)** 利用 PDF 的归一化条件：PDF 在整个定义域上的积分为 1。
$$\int_0^2 cx^2\,dx = c \cdot \left[\frac{x^3}{3}\right]_0^2 = c \cdot \frac{8}{3} = 1 \Rightarrow \boxed{c = \frac{3}{8}}$$

**(b)** 求出 $c$ 后，代入 PDF 计算区间概率：
$$P(1 \le X \le 2) = \int_1^2 \frac{3}{8}x^2\,dx = \frac{3}{8} \cdot \left[\frac{x^3}{3}\right]_1^2 = \frac{1}{8}(8 - 1) = \frac{7}{8}$$

**4.3** **(a)** 利用 CDF 的性质：区间概率等于 CDF 在端点处的差值。
$$P(0.2 < X \le 0.6) = F(0.6) - F(0.2) = 0.6^2 - 0.2^2 = 0.36 - 0.04 = \boxed{0.32}$$

**(b)** PDF 是 CDF 的导数（在 CDF 可导处）：
$$f(x) = F'(x) = 2x,\quad 0 \le x \le 1$$
其余区间为 0。

### 提高题

**4.4** 用 CDF 法求解。由于 $Y = X^2$ 是 $X$ 的单调递增函数（$X > 0$），可先求 $Y$ 的 CDF，再求导得 PDF。

对 $y > 0$：
$$F_Y(y) = P(Y \le y) = P(X^2 \le y) = P(X \le \sqrt{y}) = \int_0^{\sqrt{y}} e^{-x}\,dx = 1 - e^{-\sqrt{y}}$$

对 $F_Y(y)$ 求导（链式法则）：
$$f_Y(y) = \frac{d}{dy}F_Y(y) = e^{-\sqrt{y}} \cdot \frac{1}{2\sqrt{y}} = \boxed{\frac{e^{-\sqrt{y}}}{2\sqrt{y}}},\quad y > 0$$

**4.5** **证明思路**：要证明 $Y \sim U(0,1)$，只需证明 $Y$ 的 CDF 等于 $U(0,1)$ 的 CDF。

由于 $F$ 严格单调递增，存在反函数 $F^{-1}$。对 $y \in [0,1]$：
$$F_Y(y) = P(Y \le y) = P(F(X) \le y) = P(X \le F^{-1}(y)) = F(F^{-1}(y)) = y$$

当 $y < 0$ 时，$F_Y(y) = 0$；当 $y > 1$ 时，$F_Y(y) = 1$。这正是 $U(0,1)$ 的 CDF，故 $Y = F(X) \sim U(0,1)$。

**4.6** 用单调变换法。$Y = g(X) = \frac{1}{X}$ 在 $X \neq 0$ 时单调递减，反函数为 $g^{-1}(y) = \frac{1}{y}$，导数为 $\frac{d}{dy}g^{-1}(y) = -\frac{1}{y^2}$。

由随机变量函数变换的公式 $f_Y(y) = f_X(g^{-1}(y)) \cdot \left|\frac{d}{dy}g^{-1}(y)\right|$：
$$f_Y(y) = f_X\left(\frac{1}{y}\right) \cdot \left|-\frac{1}{y^2}\right| = \frac{1}{\pi(1 + (1/y)^2)} \cdot \frac{1}{y^2} = \frac{1}{\pi(y^2 + 1)}$$

结论：$Y$ 也服从 Cauchy 分布，即 Cauchy 分布在倒数变换下具有**自反性**。

### 拓展题

**4.7** 用单调变换法。$g(x) = -2\ln x$ 在 $(0,1]$ 上单调递减，反函数为 $g^{-1}(y) = e^{-y/2}$，导数为 $\frac{d}{dy}g^{-1}(y) = -\frac{1}{2}e^{-y/2}$。

代入变换公式：
$$f_Y(y) = f_X(e^{-y/2}) \cdot \left|-\frac{1}{2}e^{-y/2}\right| = 2e^{-y/2} \cdot \frac{1}{2}e^{-y/2} = e^{-y},\quad y > 0$$

$Y$ 服从参数为 1 的**指数分布** $\text{Exp}(1)$。

**4.8** **证明**：设 $Y = F(X)$，$Y$ 的值域为 $[0,1]$。对任意 $y \in [0,1]$：
$$F_Y(y) = P(F(X) \le y) = P(X \le F^{-1}(y)) = F(F^{-1}(y)) = y$$
当 $y < 0$ 时，$F_Y(y) = 0$；当 $y > 1$ 时，$F_Y(y) = 1$。因此 $Y \sim U(0,1)$。

**应用**：该定理是逆变换抽样法的基础——要生成服从分布 $F$ 的随机数，只需生成 $U \sim U(0,1)$，然后令 $X = F^{-1}(U)$ 即可。

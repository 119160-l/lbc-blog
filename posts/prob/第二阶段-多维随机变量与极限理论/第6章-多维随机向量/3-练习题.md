# 第6章 多维随机向量——练习题

---

## 基础题

### 6.1

设二维随机向量 $(X,Y)$ 的联合PDF为：

$$
f(x,y) = \begin{cases}
c\,x\,y, & 0 < x < 1,\; 0 < y < x \\
0, & \text{其他}
\end{cases}
$$

试求：

(1) 常数 $c$ 的值；
(2) 边缘PDF $f_X(x)$ 和 $f_Y(y)$；
(3) 条件PDF $f_{Y|X}(y|x)$ 和 $f_{X|Y}(x|y)$；
(4) $P\left(X+Y > \frac{1}{2}\right)$。

**答案**

(1) 利用联合PDF的归一化条件：在定义域 $\{0 < x < 1, 0 < y < x\}$ 上积分为1。

$$
\int_0^1\int_0^x c\,x\,y\,dy\,dx = c\int_0^1 x\left[\frac{y^2}{2}\right]_0^x dx = \frac{c}{2}\int_0^1 x^3\,dx = \frac{c}{2} \cdot \frac{1}{4} = \frac{c}{8} = 1
$$

解得 $\boxed{c = 8}$。

(2) 边缘PDF通过对联合PDF关于另一个变量积分得到。

当 $0 < x < 1$ 时：
$$
f_X(x) = \int_0^x 8xy\,dy = 8x\cdot\frac{x^2}{2} = 4x^3
$$

当 $0 < y < 1$ 时，注意 $y < x < 1$，所以 $x$ 从 $y$ 积到 $1$：
$$
f_Y(y) = \int_y^1 8xy\,dx = 8y\int_y^1 x\,dx = 8y\cdot\frac{1-y^2}{2} = 4y(1-y^2)
$$

(3) 条件PDF由公式 $f_{Y|X}(y|x) = \frac{f(x,y)}{f_X(x)}$ 和 $f_{X|Y}(x|y) = \frac{f(x,y)}{f_Y(y)}$ 得到。

当 $0 < y < x < 1$ 时：
$$
f_{Y|X}(y|x) = \frac{8xy}{4x^3} = \frac{2y}{x^2},\quad 0 < y < x
$$

当 $0 < x < 1$ 且固定 $y$（$y < x < 1$）时：
$$
f_{X|Y}(x|y) = \frac{8xy}{4y(1-y^2)} = \frac{2x}{1-y^2},\quad y < x < 1
$$

(4) $P(X+Y > 1/2) = 1 - P(X+Y \le 1/2)$。积分区域为 $0 < x < 1, 0 < y < x, x+y \le 1/2$，即 $0 < x < 1/2, 0 < y < \min(x, 1/2-x)$。由于 $x < 1/2$ 时 $x < 1/2-x$ 当且仅当 $x < 1/4$，需分两段积分：

$$
P(X+Y \le 1/2) = \int_0^{1/4}\int_0^x 8xy\,dy\,dx + \int_{1/4}^{1/2}\int_0^{1/2-x} 8xy\,dy\,dx = \frac{1}{32} + \frac{1}{96} = \frac{1}{24}
$$

因此 $P(X+Y > 1/2) = 1 - 1/24 = \boxed{23/24}$。

### 6.2

设二维离散型随机向量 $(X,Y)$ 的联合PMF由下表给出：

| $X \backslash Y$ | 0 | 1 | 2 |
|:---:|:---:|:---:|:---:|
| 0 | $a$ | $b$ | $0.1$ |
| 1 | $0.1$ | $0.2$ | $c$ |
| 2 | $0$ | $0.1$ | $0.1$ |

已知 $X$ 与 $Y$ 独立。

(1) 求常数 $a, b, c$；
(2) 求条件分布 $p_{Y|X}(y|1)$；
(3) 求 $P(X+Y \ge 2)$。

**答案**

(1) 由独立性，$p(x,y) = p_X(x)p_Y(y)$。先计算边缘PMF的表达式：

$p_X(0) = a+b+0.1$，$p_X(1) = 0.1+0.2+c = 0.3+c$，$p_X(2) = 0+0.1+0.1 = 0.2$

$p_Y(0) = a+0.1+0 = a+0.1$，$p_Y(1) = b+0.2+0.1 = b+0.3$，$p_Y(2) = 0.1+c+0.1 = 0.2+c$

由归一化：$(a+b+0.1)+(0.3+c)+0.2 = 1$，即 $a+b+c = 0.4$。

由独立性 $p(1,0) = p_X(1)p_Y(0)$：$0.1 = (0.3+c)(a+0.1)$
由独立性 $p(2,1) = p_X(2)p_Y(1)$：$0.1 = 0.2(b+0.3)$，得 $b+0.3 = 0.5$，$b = 0.2$
由独立性 $p(0,2) = p_X(0)p_Y(2)$：$0.1 = (a+0.2+0.1)(0.2+c) = (a+0.3)(0.2+c)$

由 $a+b+c=0.4$ 和 $b=0.2$ 得 $a+c=0.2$。

代入 $0.1 = (0.3+c)(a+0.1)$ 和 $0.1 = (a+0.3)(0.2+c)$，结合 $a+c=0.2$，解得 $\boxed{a=0.1,\; b=0.2,\; c=0.1}$。

(2) 条件分布 $p_{Y|X}(y|1) = \frac{p(1,y)}{p_X(1)}$，$p_X(1) = 0.3+0.1 = 0.4$

$p_{Y|X}(0|1) = 0.1/0.4 = 0.25$
$p_{Y|X}(1|1) = 0.2/0.4 = 0.5$
$p_{Y|X}(2|1) = 0.1/0.4 = 0.25$

(3) $P(X+Y \ge 2)$ 即所有满足 $x+y \ge 2$ 的联合概率之和：

$P(X+Y \ge 2) = p(0,2) + p(1,1) + p(1,2) + p(2,0) + p(2,1) + p(2,2)$
$= 0.1 + 0.2 + 0.1 + 0 + 0.1 + 0.1 = \boxed{0.6}$

### 6.3

设随机变量 $X$ 和 $Y$ 独立，$X \sim U(0,1)$（均匀分布），$Y \sim U(0,2)$（均匀分布）。

(1) 求 $(X,Y)$ 的联合PDF；
(2) 求 $Z = X+Y$ 的PDF；
(3) 求 $P(|X-Y| \le 1)$。

**答案**

(1) $X$ 与 $Y$ 独立，故联合PDF为边缘PDF的乘积：
$$
f(x,y) = f_X(x)f_Y(y) = 1 \cdot \frac{1}{2} = \frac{1}{2},\quad 0 < x < 1,\; 0 < y < 2
$$

(2) 用卷积公式求 $Z = X+Y$ 的PDF。$f_X(x)=1, 0<x<1$，$f_Y(y)=1/2, 0<y<2$。

$Z = X+Y$ 的取值范围为 $(0,3)$。分情况讨论：

当 $0 < z < 1$ 时：$x$ 从 $0$ 到 $z$，$z-x$ 在 $(0,2)$ 内自动满足：
$$
f_Z(z) = \int_0^z 1\cdot\frac{1}{2}\,dx = \frac{z}{2}
$$

当 $1 \le z < 2$ 时：$x$ 从 $0$ 到 $1$，$z-x$ 在 $(0,2)$ 内自动满足（因为 $z-1 \ge 0$，且 $z \le 2$ 保证 $z-x \le 2$）：
$$
f_Z(z) = \int_0^1 \frac{1}{2}\,dx = \frac{1}{2}
$$

当 $2 \le z < 3$ 时：要求 $z-x < 2$，即 $x > z-2$，同时 $x < 1$：
$$
f_Z(z) = \int_{z-2}^1 \frac{1}{2}\,dx = \frac{1}{2}(3-z)
$$

因此：
$$
f_Z(z) = \begin{cases}
\dfrac{z}{2}, & 0 < z < 1 \\[6pt]
\dfrac{1}{2}, & 1 \le z < 2 \\[6pt]
\dfrac{3-z}{2}, & 2 \le z < 3 \\[6pt]
0, & \text{其他}
\end{cases}
$$

此即三角形分布（Simpson分布）。

(3) 区域 $|X-Y| \le 1$ 即 $-1 \le X-Y \le 1$，等价于 $X-1 \le Y \le X+1$。在矩形 $[0,1]\times[0,2]$ 上求面积：

$$
P(|X-Y| \le 1) = \iint_{|x-y|\le 1} \frac{1}{2}\,dx\,dy = \frac{1}{2} \times (\text{矩形中满足条件的面积})
$$

矩形面积 $S=2$，不满足条件的区域是 $Y < X-1$（不可能，因为 $Y\ge 0$ 且 $X\le 1$）和 $Y > X+1$（即 $Y > X+1$，在 $X\in[0,1], Y\in[0,2]$ 下，这是 $Y > X+1$ 且 $Y \le 2$，也即 $X < Y-1$）。

不满足条件的面积 $= \int_1^2\int_0^{y-1} 1\,dx\,dy = \int_1^2 (y-1)\,dy = \frac{1}{2}$。

因此满足条件的面积 $= 2 - 1/2 = 3/2$，$P(|X-Y| \le 1) = \frac{1}{2} \times \frac{3}{2} = \boxed{\frac{3}{4}}$。

### 6.4

设 $(X,Y)$ 的联合PDF为：

$$
f(x,y) = \begin{cases}
\frac{1}{x}, & 0 < y < x < 1 \\
0, & \text{其他}
\end{cases}
$$

(1) 判断 $X$ 与 $Y$ 是否独立；
(2) 求 $f_X(x)$ 和 $f_Y(y)$；
(3) 求 $P\left(X > \frac{1}{2} \,\middle|\, Y = \frac{1}{4}\right)$。

**答案**

(1) 先求边缘PDF，再判断独立性。

当 $0 < x < 1$ 时：
$$
f_X(x) = \int_0^x \frac{1}{x}\,dy = 1,\quad 0 < x < 1
$$

当 $0 < y < 1$ 时：
$$
f_Y(y) = \int_y^1 \frac{1}{x}\,dx = [\ln x]_y^1 = -\ln y
$$

检查 $f(x,y) \stackrel{?}{=} f_X(x)f_Y(y)$：

$f_X(x)f_Y(y) = 1 \cdot (-\ln y) = -\ln y$，而 $f(x,y) = 1/x$，两者不相等，故 $X$ 与 $Y$ **不独立**。

(2) 已求得：
$$
f_X(x) = \begin{cases}
1, & 0 < x < 1 \\
0, & \text{其他}
\end{cases},\qquad
f_Y(y) = \begin{cases}
-\ln y, & 0 < y < 1 \\
0, & \text{其他}
\end{cases}
$$

(3) $P\left(X > \frac{1}{2} \,\middle|\, Y = \frac{1}{4}\right) = \int_{1/2}^{1} f_{X|Y}(x|1/4)\,dx$。

先求条件PDF $f_{X|Y}(x|y)$：
$$
f_{X|Y}(x|y) = \frac{f(x,y)}{f_Y(y)} = \frac{1/x}{-\ln y} = \frac{1}{-x\ln y},\quad y < x < 1
$$

代入 $y = 1/4$：
$$
f_{X|Y}(x|1/4) = \frac{1}{-x\ln(1/4)} = \frac{1}{x\ln 4},\quad \frac{1}{4} < x < 1
$$

因此：
$$
P\left(X > \frac{1}{2} \,\middle|\, Y = \frac{1}{4}\right) = \int_{1/2}^{1} \frac{1}{x\ln 4}\,dx = \frac{1}{\ln 4}[\ln x]_{1/2}^{1} = \frac{\ln 2}{\ln 4} = \frac{\ln 2}{2\ln 2} = \boxed{\frac{1}{2}}
$$

## 提高题

### 6.5

设 $X$ 和 $Y$ 相互独立，且都服从参数为 $\lambda$ 的指数分布 $\text{Exp}(\lambda)$，即：

$$
f_X(x) = \lambda e^{-\lambda x},\; x > 0,\qquad f_Y(y) = \lambda e^{-\lambda y},\; y > 0
$$

(1) 求 $Z = \min(X,Y)$ 的分布，并指出它服从什么分布；
(2) 求 $W = \max(X,Y)$ 的分布，并求 $E(W)$；
(3) 求 $U = X + Y$ 的分布；
(4) 求 $V = \frac{X}{X+Y}$ 的分布，并判断 $V$ 与 $U$ 是否独立。

**答案**

(1) $Z = \min(X,Y)$。由独立指数分布的性质，最小值分布仍然是指数分布，参数为两参数之和。
$$
F_Z(z) = 1 - [1-F_X(z)][1-F_Y(z)] = 1 - e^{-\lambda z} \cdot e^{-\lambda z} = 1 - e^{-2\lambda z},\quad z > 0
$$
因此 $Z \sim \text{Exp}(2\lambda)$，即参数为 $2\lambda$ 的指数分布。

(2) $W = \max(X,Y)$ 的CDF为两独立CDF的乘积：
$$
F_W(w) = F_X(w)F_Y(w) = (1-e^{-\lambda w})^2,\quad w > 0
$$
求导得PDF：
$$
f_W(w) = 2\lambda e^{-\lambda w}(1-e^{-\lambda w}) = 2\lambda(e^{-\lambda w} - e^{-2\lambda w}),\quad w > 0
$$
期望：
$$
E(W) = \int_0^\infty w\cdot 2\lambda(e^{-\lambda w} - e^{-2\lambda w})\,dw = 2\lambda\left(\frac{1}{\lambda^2} - \frac{1}{4\lambda^2}\right) = \frac{3}{2\lambda}
$$

(3) $U = X+Y$。用卷积公式，两个独立指数分布之和服从Gamma分布：
$$
f_U(u) = \int_0^u \lambda e^{-\lambda x} \cdot \lambda e^{-\lambda(u-x)}\,dx = \lambda^2 e^{-\lambda u}\int_0^u dx = \lambda^2 u e^{-\lambda u},\quad u > 0
$$
因此 $U \sim \Gamma(2, \lambda)$（Gamma分布，形状参数2，速率参数$\lambda$）。

(4) $V = X/(X+Y)$。用变量变换法，设 $U = X+Y$，$V = X/(X+Y)$，则反变换为 $X = UV$，$Y = U(1-V)$。

Jacobian：
$$
J = \det\begin{pmatrix}
\frac{\partial x}{\partial u} & \frac{\partial x}{\partial v} \\
\frac{\partial y}{\partial u} & \frac{\partial y}{\partial v}
\end{pmatrix}
= \det\begin{pmatrix}
v & u \\
1-v & -u
\end{pmatrix}
= -uv - u(1-v) = -u
$$
因此 $|J| = u$。

联合PDF：
$$
f_{U,V}(u,v) = f_{X,Y}(uv, u(1-v)) \cdot u = \lambda e^{-\lambda uv} \cdot \lambda e^{-\lambda u(1-v)} \cdot u = \lambda^2 u e^{-\lambda u},\quad u>0, 0<v<1
$$

分解为 $f_{U,V}(u,v) = (\lambda^2 u e^{-\lambda u}) \cdot 1$，其中 $u>0, 0<v<1$。

因此 $U$ 与 $V$ **独立**，$U \sim \Gamma(2,\lambda)$，$V \sim U(0,1)$（均匀分布）。

### 6.6

设 $X$ 和 $Y$ 相互独立，且 $X \sim N(0,1)$（标准正态分布），$Y \sim N(0,1)$。

(1) 用变量变换法求 $Z = \frac{X}{Y}$ 的PDF（Cauchy分布）；
(2) 判断 $E(Z)$ 是否存在，并说明理由；
(3) 求 $W = X^2 + Y^2$ 的分布。

**答案**

(1) $f_X(x) = \frac{1}{\sqrt{2\pi}}e^{-x^2/2}$，$f_Y(y) = \frac{1}{\sqrt{2\pi}}e^{-y^2/2}$。

由 $Z = X/Y$ 的公式（比值分布）：
$$
f_Z(z) = \int_{-\infty}^{\infty} |y| f_X(zy) f_Y(y)\,dy = \int_{-\infty}^{\infty} |y| \cdot \frac{1}{\sqrt{2\pi}}e^{-(zy)^2/2} \cdot \frac{1}{\sqrt{2\pi}}e^{-y^2/2}\,dy
$$
$$
= \frac{1}{2\pi}\int_{-\infty}^{\infty} |y| e^{-(z^2+1)y^2/2}\,dy = \frac{1}{\pi}\int_0^{\infty} y e^{-(z^2+1)y^2/2}\,dy
$$

令 $t = y^2$，$dt = 2y\,dy$：
$$
f_Z(z) = \frac{1}{\pi}\int_0^{\infty} \frac{1}{2} e^{-(z^2+1)t/2}\,dt = \frac{1}{2\pi}\cdot\frac{2}{z^2+1} = \frac{1}{\pi(z^2+1)},\quad -\infty < z < \infty
$$
此即**Cauchy分布**的标准形式。

(2) $E(Z)$ 不存在，因为：
$$
\int_{-\infty}^{\infty} \frac{|z|}{\pi(z^2+1)}\,dz = \frac{2}{\pi}\int_0^{\infty} \frac{z}{z^2+1}\,dz = \infty
$$
Cauchy分布是厚尾分布，期望不存在（积分发散）。

(3) $W = X^2 + Y^2$。用变量变换法，设 $X = \sqrt{W}\cos\Theta$，$Y = \sqrt{W}\sin\Theta$，Jacobian $|J| = 1/2$（极坐标变换的Jacobian为 $r$，但这里变换略有不同，实际上 $|J| = 1/2$）。

$$
f_{W,\Theta}(w,\theta) = f_{X,Y}(\sqrt{w}\cos\theta, \sqrt{w}\sin\theta) \cdot \frac{1}{2}
$$
$$
= \frac{1}{2\pi}e^{-w/2} \cdot \frac{1}{2} = \frac{1}{4\pi}e^{-w/2},\quad w>0, 0\le\theta<2\pi
$$

对 $\theta$ 积分：
$$
f_W(w) = \int_0^{2\pi} \frac{1}{4\pi}e^{-w/2}\,d\theta = \frac{1}{2}e^{-w/2},\quad w>0
$$

因此 $W \sim \text{Exp}(1/2)$，即参数为 $1/2$ 的指数分布。等价地，$W \sim \chi^2(2)$（自由度为2的卡方分布）。

### 6.7

设 $(X,Y)$ 的联合PDF为：

$$
f(x,y) = \begin{cases}
2e^{-(x+y)}, & 0 < x < y < \infty \\
0, & \text{其他}
\end{cases}
$$

(1) 求边缘PDF $f_X(x)$ 和 $f_Y(y)$；
(2) 求条件PDF $f_{Y|X}(y|x)$ 和 $f_{X|Y}(x|y)$；
(3) 求 $Z = Y - X$ 的分布；
(4) 判断 $X$ 与 $Z$ 是否独立。

**答案**

(1) 边缘PDF通过对联合PDF积分得到。

当 $x > 0$ 时（$y$ 从 $x$ 到 $\infty$）：
$$
f_X(x) = \int_x^{\infty} 2e^{-(x+y)}\,dy = 2e^{-x}\int_x^{\infty} e^{-y}\,dy = 2e^{-x}\cdot e^{-x} = 2e^{-2x},\quad x > 0
$$

当 $y > 0$ 时（$x$ 从 $0$ 到 $y$）：
$$
f_Y(y) = \int_0^y 2e^{-(x+y)}\,dx = 2e^{-y}\int_0^y e^{-x}\,dx = 2e^{-y}(1-e^{-y}),\quad y > 0
$$

(2) 条件PDF：

当 $0 < x < y$ 时：
$$
f_{Y|X}(y|x) = \frac{2e^{-(x+y)}}{2e^{-2x}} = e^{-(y-x)},\quad y > x
$$

当 $0 < x < y$ 时：
$$
f_{X|Y}(x|y) = \frac{2e^{-(x+y)}}{2e^{-y}(1-e^{-y})} = \frac{e^{-x}}{1-e^{-y}},\quad 0 < x < y
$$

(3) $Z = Y - X$。用变量变换法，设 $Z = Y-X$，$W = X$（辅助变量），则反变换 $X = W$，$Y = Z+W$。

Jacobian $J = \det\begin{pmatrix} 1 & 0 \\ 0 & 1 \end{pmatrix} = 1$。

联合PDF：
$$
f_{W,Z}(w,z) = f_{X,Y}(w, z+w) = 2e^{-(w+z+w)} = 2e^{-(2w+z)},\quad w>0, z>0
$$

对 $w$ 积分得 $Z$ 的边缘PDF：
$$
f_Z(z) = \int_0^{\infty} 2e^{-(2w+z)}\,dw = 2e^{-z}\int_0^{\infty} e^{-2w}\,dw = 2e^{-z}\cdot\frac{1}{2} = e^{-z},\quad z > 0
$$
因此 $Z \sim \text{Exp}(1)$。

(4) 判断 $X$ 与 $Z$ 是否独立。

$f_{X,Z}(x,z) = 2e^{-(2x+z)}$，$x>0, z>0$

$f_X(x) = 2e^{-2x}$，$f_Z(z) = e^{-z}$

$f_{X,Z}(x,z) = 2e^{-2x}e^{-z} = f_X(x)f_Z(z)$，因此 $X$ 与 $Z$ **独立**。

### 6.8

设随机变量 $X$ 和 $Y$ 独立，$X \sim \Gamma(\alpha, \lambda)$（Gamma分布，形状参数 $\alpha$，速率参数 $\lambda$），$Y \sim \Gamma(\beta, \lambda)$。

(1) 用变量变换法求 $U = X+Y$ 和 $V = \frac{X}{X+Y}$ 的联合PDF；
(2) 证明 $U$ 与 $V$ 独立，并分别指出 $U$ 和 $V$ 的分布；
(3) 利用上述结果求 $E\left(\frac{X}{X+Y}\right)$。

**答案**

(1) $X$ 和 $Y$ 独立，$f_X(x) = \frac{\lambda^\alpha}{\Gamma(\alpha)}x^{\alpha-1}e^{-\lambda x}$，$f_Y(y) = \frac{\lambda^\beta}{\Gamma(\beta)}y^{\beta-1}e^{-\lambda y}$，$x,y>0$。

设 $U = X+Y$，$V = X/(X+Y)$，反变换 $X = UV$，$Y = U(1-V)$。

Jacobian $|J| = u$（同6.5题的计算）。

联合PDF：
$$
f_{U,V}(u,v) = f_{X,Y}(uv, u(1-v)) \cdot u
$$
$$
= \frac{\lambda^\alpha}{\Gamma(\alpha)}(uv)^{\alpha-1}e^{-\lambda uv} \cdot \frac{\lambda^\beta}{\Gamma(\beta)}(u(1-v))^{\beta-1}e^{-\lambda u(1-v)} \cdot u
$$
$$
= \frac{\lambda^{\alpha+\beta}}{\Gamma(\alpha)\Gamma(\beta)} u^{\alpha+\beta-1} e^{-\lambda u} \cdot v^{\alpha-1}(1-v)^{\beta-1}
$$

(2) 将联合PDF分解为两个独立部分的乘积：
$$
f_{U,V}(u,v) = \underbrace{\frac{\lambda^{\alpha+\beta}}{\Gamma(\alpha+\beta)} u^{\alpha+\beta-1} e^{-\lambda u}}_{\text{Gamma}(\alpha+\beta,\lambda)} \cdot \underbrace{\frac{\Gamma(\alpha+\beta)}{\Gamma(\alpha)\Gamma(\beta)} v^{\alpha-1}(1-v)^{\beta-1}}_{\text{Beta}(\alpha,\beta)}
$$

因此 $U$ 与 $V$ **独立**，$U \sim \Gamma(\alpha+\beta, \lambda)$，$V \sim \text{Beta}(\alpha, \beta)$。

(3) $E\left(\frac{X}{X+Y}\right) = E(V) = \frac{\alpha}{\alpha+\beta}$（Beta分布的期望公式）。

## 拓展题

### 6.9

设 $(X,Y)$ 服从单位圆内的均匀分布，即联合PDF为：

$$
f(x,y) = \begin{cases}
\frac{1}{\pi}, & x^2 + y^2 \le 1 \\
0, & \text{其他}
\end{cases}
$$

(1) 求边缘PDF $f_X(x)$，并说明它是否服从均匀分布；
(2) 求条件PDF $f_{Y|X}(y|x)$，并说明 $Y$ 在给定 $X=x$ 时的分布特点；
(3) 判断 $X$ 与 $Y$ 是否独立（直观解释和数学证明）；
(4) 用变量变换法求 $R = \sqrt{X^2+Y^2}$ 和 $\Theta = \arctan(Y/X)$ 的联合PDF，并证明 $R$ 与 $\Theta$ 独立。

**答案**

(1) 边缘PDF：当 $|x| < 1$ 时，$y$ 的范围为 $-\sqrt{1-x^2} \le y \le \sqrt{1-x^2}$：
$$
f_X(x) = \int_{-\sqrt{1-x^2}}^{\sqrt{1-x^2}} \frac{1}{\pi}\,dy = \frac{2}{\pi}\sqrt{1-x^2},\quad |x| < 1
$$
$X$ **不服从均匀分布**——它更集中在0附近。

(2) 条件PDF：当 $|x| < 1$ 且 $|y| < \sqrt{1-x^2}$ 时：
$$
f_{Y|X}(y|x) = \frac{1/\pi}{2\sqrt{1-x^2}/\pi} = \frac{1}{2\sqrt{1-x^2}},\quad |y| < \sqrt{1-x^2}
$$
给定 $X=x$ 时，$Y$ 在 $[-\sqrt{1-x^2}, \sqrt{1-x^2}]$ 上服从**均匀分布**。

(3) $X$ 与 $Y$ **不独立**。直观上，知道 $|X|$ 较大意味着 $|Y|$ 较小（因为 $X^2+Y^2 \le 1$）。数学上，$f_X(x)f_Y(y) \neq f(x,y)$，因为 $f_Y(y)$ 的形式与 $f_X(x)$ 类似（对称），且 $f_X(x)f_Y(y)$ 是乘积形式，不会在圆外为零。

(4) 极坐标变换 $X = R\cos\Theta$，$Y = R\sin\Theta$，$R \ge 0$，$0 \le \Theta < 2\pi$。

Jacobian $|J| = r$。

联合PDF：
$$
f_{R,\Theta}(r,\theta) = f_{X,Y}(r\cos\theta, r\sin\theta) \cdot r = \frac{1}{\pi} \cdot r,\quad 0 \le r \le 1,\; 0 \le \theta < 2\pi
$$

分解为：
$$
f_{R,\Theta}(r,\theta) = \underbrace{2r}_{f_R(r)} \cdot \underbrace{\frac{1}{2\pi}}_{f_\Theta(\theta)},\quad 0 \le r \le 1,\; 0 \le \theta < 2\pi
$$

因此 $R$ 与 $\Theta$ **独立**，$f_R(r) = 2r$（$0\le r\le 1$），$f_\Theta(\theta) = 1/(2\pi)$（$0\le\theta<2\pi$）。

### 6.10

设 $X_1, X_2, \ldots, X_n$ 独立同分布，服从 $U(0,1)$（均匀分布）。记：

$$
X_{(1)} = \min\{X_1, \ldots, X_n\},\quad X_{(n)} = \max\{X_1, \ldots, X_n\}
$$

(1) 求 $X_{(1)}$ 和 $X_{(n)}$ 的CDF和PDF；
(2) 求 $X_{(n)} - X_{(1)}$ 的分布；
(3) 当 $n=2$ 时，求 $X_{(1)}$ 和 $X_{(2)}$ 的联合PDF，并判断它们是否独立。

**答案**

(1) $X_i \sim U(0,1)$，$F(x)=x$，$f(x)=1$，$0<x<1$。

$X_{(1)} = \min$ 的CDF：至少一个变量 $\le x$ 的概率
$$
F_{(1)}(x) = 1 - [1-F(x)]^n = 1 - (1-x)^n,\quad 0<x<1
$$
求导得PDF：
$$
f_{(1)}(x) = n(1-x)^{n-1},\quad 0<x<1
$$

$X_{(n)} = \max$ 的CDF：所有变量都 $\le x$ 的概率
$$
F_{(n)}(x) = [F(x)]^n = x^n,\quad 0<x<1
$$
求导得PDF：
$$
f_{(n)}(x) = nx^{n-1},\quad 0<x<1
$$

(2) 先求 $(X_{(1)}, X_{(n)})$ 的联合PDF。对任意 $0 < s < t < 1$，有：
$$
f_{(1),(n)}(s,t) = n(n-1)(t-s)^{n-2},\quad 0 < s < t < 1
$$
**推导思路：** 选两个变量作为最小值和最大值（$n(n-1)$ 种方式），其余 $n-2$ 个变量必须落在 $(s,t)$ 内，概率密度为 $(t-s)^{n-2}$。

令 $R = X_{(n)} - X_{(1)}$。用变量变换法，设 $R = T-S$，$W = S$（辅助变量），则 $S = W$，$T = W+R$。

Jacobian $J = 1$。
$$
f_{W,R}(w,r) = n(n-1)r^{n-2},\quad 0 < w < w+r < 1,\; r>0
$$
即 $0 < w < 1-r$，$0 < r < 1$。

对 $w$ 积分：
$$
f_R(r) = \int_0^{1-r} n(n-1)r^{n-2}\,dw = n(n-1)r^{n-2}(1-r),\quad 0 < r < 1
$$
因此 $R$ 的PDF为 $f_R(r) = n(n-1)r^{n-2}(1-r)$，$0<r<1$。这等价于 $\text{Beta}(n-1, 2)$ 分布。

(3) 当 $n=2$ 时：
$$
f_{(1),(2)}(s,t) = 2,\quad 0 < s < t < 1
$$
$f_{(1)}(s) = 2(1-s)$，$0<s<1$；$f_{(2)}(t) = 2t$，$0<t<1$。

$f_{(1),(2)}(s,t) = 2 \neq f_{(1)}(s)f_{(2)}(t) = 4t(1-s)$，因此 $X_{(1)}$ 与 $X_{(2)}$ **不独立**。

直观上，$X_{(2)} \ge X_{(1)}$ 必然成立，所以它们一定不独立。

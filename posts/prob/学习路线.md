# 概率论与数理统计 · 学习路线

> 背景：已掌握高等数学（微积分、级数、极限）和复变函数基础
> 目标：系统掌握概率论与数理统计

---

## 总体学习路线

```
组合分析 → 概率公理 → 条件概率 → 随机变量
→ 常见分布族 → 多维随机向量 → 数学期望与矩
→ 大数定律与CLT → 抽样分布 → 参数估计
→ 假设检验 → 线性回归与方差分析
```

## 第一阶段：概率论基础

| 章节 | 内容 | 核心知识点 |
|------|------|-----------|
| 第1章 组合分析 | 计数原理、排列组合、二项式系数 | 乘法/加法原理、排列、组合、Pascal恒等式、二项式定理 |
| 第2章 概率公理与基本性质 | 公理化定义、概率性质、容斥原理 | Kolmogorov公理、有限可加性、加法公式、古典概型 |
| 第3章 条件概率与独立性 | 条件概率、贝叶斯公式、独立事件 | 全概率公式、贝叶斯公式、乘法公式、独立性判定 |
| 第4章 随机变量及其分布 | 离散/连续型、PMF/PDF/CDF、函数分布 | 概率质量函数、概率密度函数、累积分布函数、变量变换 |
| 第5章 常见分布族 | 常用离散/连续分布及其关系 | Bernoulli、Binomial、Poisson、Exponential、Normal、Gamma等 |

## 学习建议

1. **按顺序学习**：每一章都是下一章的基础，不要跳步
2. **动手推导**：所有公式自己推导一遍，不要只看
3. **多做练习**：每章学完至少完成所有练习题
4. **联系对比**：与高等数学中的微积分和级数知识对比学习
5. **可视化辅助**：建议配合 Python 可视化理解分布形态和极限定理

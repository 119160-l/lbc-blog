### 2. 知识主线（一定要先记住这张图）

```
第1章  建立语言：线性空间（能加能数乘）→ 基与坐标 → 线性变换及其矩阵 → 内积空间
  ↓  （"矩阵"从此 = 线性变换在一组基下的坐标表示）
第2章  引入度量：向量范数 → 矩阵范数 → 谱半径、非奇异性、摄动、条件数
  ↓  （有了"长度"，才能谈收敛、误差、稳定）
第3章  把分析搬过来：矩阵序列 → 矩阵级数 → 矩阵函数（e^At 等）→ 微分积分 → 解微分方程组
  ↓  （核心技术：相似变换 / Jordan 标准形，把复杂运算变简单）
第4章  把矩阵拆开：LU → QR → 满秩分解 → 奇异值分解（SVD）
  ↓  （分解出来的"简单因子"，正是第3、6章计算的抓手）
  ├─→ 第5章 特征值估计：圆盘定理、Rayleigh 商极值、直积与矩阵方程
  └─→ 第6章 广义逆：A⁻、A⁺ → 方程组通解 / 最小范数解 / 最小二乘解
第7章  特殊矩阵类：正定、对角占优、非负、M 矩阵、Toeplitz（选学）
```

**关键认知**：全书只有一条主线——**"换一组好基，让矩阵变简单"**。
- 第 1 章的相似、对角化、Jordan 标准形，是"换基"的方法；
- 第 4 章的 QR、SVD 用的是**正交（酉）变换**，是"最不破坏结构"的换基；
- 第 6 章的广义逆，本质上也是靠第 4 章的分解算出来的。

**抓住这条线，全书就不再是七堆互不相干的公式。**

## 三、分章详解

### 第 1 章 线性空间与线性变换

#### 为什么学这章

这是整门课的"入口地图"。它要完成一次观念升级：**矩阵不是"数的表格"，而是"线性变换在一组基下的坐标表示"。** 一旦接受这个观念，后面的所有问题都变成同一句话——"能不能换一组基，让这个变换的矩阵变简单？"

本章要建立的三个基础概念：
1. **线性空间**——什么样的集合可以像向量一样加减、数乘（多项式、矩阵、连续函数都是）；
2. **基与坐标**——如何用一组"最小的"向量表示空间中的一切，以及换基时坐标怎么变；
3. **线性变换**——空间的"拉伸、旋转、投影"，以及它与矩阵的一一对应。

**为什么它是地基**：第 3 章求矩阵函数、第 4 章做分解、第 6 章求广义逆，全部依赖"相似变换"这个动作，而相似变换就是本章 1.2 的核心。

#### 小节导航

| 小节 | 内容 | 速成标记 |
|---|---|---|
| 1.1 线性空间 | 一、集合与映射；二、线性空间及其性质；三、线性空间的基与坐标；四、基变换与坐标变换；五、线性子空间；六、子空间的交与和 | **精读**，"基变换与坐标变换""子空间的交与和"必会 |
| 1.2 线性变换及其矩阵 | 一、线性变换及其运算；二、线性变换的矩阵表示；三、特征值与特征向量；四、对角矩阵；五、不变子空间；六、Jordan 标准形介绍 | **精读**，全章重点，尤其"矩阵表示"与"Jordan 标准形介绍" |
| 1.3 两个特殊的线性空间 | 一、Euclid 空间的定义与性质；二、正交性；三、正交变换与正交矩阵；四、对称变换与对称矩阵；五、酉空间介绍 | 前四部分**精读**；酉空间**略读**（知道概念即可，第 4 章 SVD 会用到） |

#### 预习问题（带着读，答案在教材里）

1. 为什么"向量"可以不指箭头？多项式、矩阵、连续函数为什么也算向量？
2. 一个线性变换在不同基下的矩阵是相似的——这句话到底在说什么？为什么必然相似？
3. 一个矩阵能否对角化，本质取决于什么？（提示：几何重数与代数重数的关系）
4. 内积给我们额外带来了什么能力（长度、夹角、正交）？为什么"正交基"用起来特别方便？
5. 子空间的"交"与"和"的维数满足什么关系式？"直和"比"和"多了什么条件？

#### 达标标准

能验证一个给定集合是否为线性空间；能求基变换的过渡矩阵并做坐标变换；能写出线性变换在指定基下的矩阵；能判断矩阵能否对角化并求 Jordan 标准形。

#### 本章自测题

**1.** 判断 V = { (x₁, x₂)ᵀ ∈ ℝ² | x₁ + x₂ = 0 } 是否构成 ℝ² 的线性子空间；若是，求其维数与一组基。

**2.** 在 ℝ³ 中取基 α₁ = (1,0,0)ᵀ, α₂ = (1,1,0)ᵀ, α₃ = (1,1,1)ᵀ。求从 ℝ³ 的标准基 e₁,e₂,e₃ 到该基的过渡矩阵，并求向量 β = (3,2,1)ᵀ 在该基下的坐标。

**3.** 设 P₂ 为次数不超过 2 的多项式构成的线性空间，定义变换 D(p) = p′(x)（求导）。验证 D 是线性变换，并求它在基 {1, x, x²} 下的矩阵。

**4.** 判断 A = [2 1 0; 0 2 0; 0 0 3] 能否对角化？若不能，写出它的 Jordan 标准形。

**5.** 在 ℝ³ 中用 Schmidt 正交化方法，把 α₁ = (1,1,0)ᵀ, α₂ = (1,0,1)ᵀ, α₃ = (0,1,1)ᵀ 化为标准正交基。

---

#### 本章自测题答案

**1.** **是线性子空间**。V 就是齐次线性方程组 x₁ + x₂ = 0 的解集，解集对加法与数乘封闭（齐次方程组的解空间定理）。

V = { (x, −x)ᵀ } = span{ (1, −1)ᵀ }，故 **维数 dim V = 1**，一组基为 {(1, −1)ᵀ}。

**2.** 按定义，(α₁, α₂, α₃) = (e₁, e₂, e₃)·P，取 α 在标准基下的坐标作为列，得过渡矩阵

```
P = [1 1 1; 0 1 1; 0 0 1]
```

设 β = x₁α₁ + x₂α₂ + x₃α₃，则

(3, 2, 1)ᵀ = (x₁ + x₂ + x₃, x₂ + x₃, x₃)ᵀ

由第三分量得 x₃ = 1；由第二分量 x₂ + x₃ = 2 得 x₂ = 1；由第一分量 x₁ + x₂ + x₃ = 3 得 x₁ = 1。

故坐标为 **(1, 1, 1)ᵀ**。（可验算：α₁ + α₂ + α₃ = (3,2,1)ᵀ ✓）

**3.** **线性性**：对任意 p, q ∈ P₂ 及常数 a, b，
D(ap + bq) = (ap + bq)′ = a p′ + b q′ = a D(p) + b D(q)，故 D 是线性变换。

求矩阵：分别计算基向量的像，再把像写成基 {1, x, x²} 的坐标（作为列）：

- D(1) = 0 → 坐标 (0, 0, 0)ᵀ
- D(x) = 1 → 坐标 (1, 0, 0)ᵀ
- D(x²) = 2x → 坐标 (0, 2, 0)ᵀ

故矩阵为

```
D = [0 1 0; 0 0 2; 0 0 0]
```

（说明：这是一个幂零矩阵，D³ = 0，与"三次多项式求导三次为零"一致。）

**4.** **不能对角化**。特征值为 λ = 2（代数重数 2）与 λ = 3（代数重数 1）。

对 λ = 2：

```
A − 2E = [0 1 0; 0 0 0; 0 0 1]，秩 = 2
```

故几何重数 = 3 − 2 = 1 < 代数重数 2，故 A 不可对角化。

Jordan 标准形为

```
J = [2 1 0; 0 2 0; 0 0 3]
```

即一个 2 阶 Jordan 块 J₂(2) 加一个 1 阶块 J₁(3)。（本题中 A 本身已是 Jordan 形。）

**5.** 记 ‖·‖ 为欧氏范数。

第一步：u₁ = α₁ = (1, 1, 0)ᵀ，‖u₁‖² = 2。

第二步：u₂ = α₂ − (α₂·u₁ / ‖u₁‖²)·u₁

α₂·u₁ = 1×1 + 0×1 + 1×0 = 1，故 u₂ = (1,0,1)ᵀ − (1/2)(1,1,0)ᵀ = (1/2, −1/2, 1)ᵀ，‖u₂‖² = 1/4 + 1/4 + 1 = 3/2。

第三步：u₃ = α₃ − (α₃·u₁/‖u₁‖²)u₁ − (α₃·u₂/‖u₂‖²)u₂

α₃·u₁ = 0 + 1 + 0 = 1；α₃·u₂ = 0×1/2 + 1×(−1/2) + 1×1 = 1/2。
故 u₃ = (0,1,1)ᵀ − (1/2)(1,1,0)ᵀ − (1/3)(1/2, −1/2, 1)ᵀ = (−2/3, 2/3, 2/3)ᵀ，‖u₃‖ = 2/√3。

单位化后得标准正交基：

```
q₁ = (1/√2, 1/√2, 0)
q₂ = (1/√6, −1/√6, 2/√6)
q₃ = (−1/√3, 1/√3, 1/√3)
```

（验算：q₁·q₂ = 1/(2√3) − 1/(2√3) + 0 = 0 ✓；q₁·q₃ = −1/√6 + 1/√6 = 0 ✓。）

### 第 2 章 范数理论及其应用

#### 为什么学这章

第 1 章给了空间的"结构"，但没给"大小"。没有大小，就谈不了**收敛、误差、稳定性**这三件工程上的大事。范数就是给向量和矩阵规定"长度"的规则。

本章直接服务于三件事：
1. **判断收敛**：矩阵幂 A^k → 0 吗？（离散系统的稳定性就看这个）
2. **估计误差**：解的相对误差与矩阵的"条件数"是什么关系？（病态方程的识别）
3. **提供判据**：第 3 章矩阵级数收敛要靠 ‖A‖ < 1 或 ρ(A) < 1。

**一句话**：本章是第 3 章的前置工具，也是整门课里唯一"纯计算但极高频"的一章。

#### 小节导航

| 小节 | 内容 | 速成标记 |
|---|---|---|
| 2.1 向量范数及其性质 | 一、向量范数的概念及 Lp 范数；二、线性空间 Vₙ 上的向量范数的等价性 | **精读**，三类常用范数必背 |
| 2.2 矩阵的范数 | 一、矩阵范数的定义与性质；二、几种常用的矩阵范数 | **精读**，尤其由向量范数诱导的算子范数 |
| 2.3 范数的一些应用 | 一、矩阵的非奇异性条件；二、近似逆矩阵的误差——逆矩阵的摄动；三、矩阵的谱半径及其性质 | **精读**，谱半径与收敛性是高频考点 |

#### 本章自测题答案

**1.** ‖x‖₁ = |1| + |−2| + |2| = **5**；
‖x‖₂ = √(1 + 4 + 4) = **3**；
‖x‖∞ = max{1, 2, 2} = **2**。

**2.** ‖A‖₁ = 各列元素绝对值之和的最大值 = max{1+3, 2+4} = max{4, 6} = **6**；
‖A‖∞ = 各行元素绝对值之和的最大值 = max{1+2, 3+4} = max{3, 7} = **7**；
‖A‖_F = √(1² + 2² + 3² + 4²) = √30 ≈ **5.477**。

**3.** A 是上三角矩阵，特征值就是对角元 0.6、0.6，故 **ρ(A) = 0.6**。

（更精细地，由于 A 含 2 阶 Jordan 块，
A^k = [0.6^k, k·0.6^(k−1); 0, 0.6^k]，虽然出现因子 k，但 k·0.6^(k−1) → 0，故仍趋于零。这说明"ρ<1 就能保证 A^k→0"，与 Jordan 块无关。）

(E − A)S = S(E − A) = lim (E − A)(E + A + … + Aᵏ) = lim (E − A^(k+1)) = E

故 **E − A 可逆**，且 (E − A)⁻¹ = Σ Aᵏ。

上界：‖(E − A)⁻¹‖ ≤ Σ‖A‖ᵏ = **1 / (1 − ‖A‖)**。

AᵀA = [1 3; 2 4]·[1 2; 3 4] = [10 14; 14 20]

λ = (30 ± √(900 − 16))/2 = 15 ± √221 ≈ 29.87 与 0.13。

故 σ₁ = √29.87 ≈ 5.465，σ₂ = √0.13 ≈ 0.366，于是

**cond₂(A) = σ₁/σ₂ ≈ 14.9**

#### 本章自测题答案

**1.** A 为上三角矩阵，特征值均为 1/2，故 **ρ(A) = 1/2 < 1**。

由 3.1 的充要条件，**A^k 收敛于零矩阵**。

具体地，A = (1/2)E + N（N = [0 1; 0 0]，N² = 0），故

```
A^k = (1/2)^k E + k(1/2)^(k−1) N = [ (1/2)^k, k(1/2)^(k−1); 0, (1/2)^k ]
```

其中 k(1/2)^(k−1) → 0，故 A^k → 0。

**2.** 因为 ρ(A) = 0.3 < 1，级数收敛，且

Σ_{k=0}^{∞} A^k = (E − A)⁻¹

计算 E − A = [0.7, −0.2; 0, 0.7]，对上三角阵 [a b; 0 a] 有逆 [1/a, −b/a²; 0, 1/a]，取 a = 0.7, b = −0.2：

```
Σ A^k = (E − A)⁻¹ = [10/7, 20/49; 0, 10/7]
```

**3.** 注意 A² = [0 1; −1 0]·[0 1; −1 0] = [−1 0; 0 −1] = −E。

于是由幂级数定义，
e^(At) = Σ (At)ᵏ/k! = (Σ (−1)ᵐ t^(2m)/(2m)!)E + (Σ (−1)ᵐ t^(2m+1)/(2m+1)!)A

即

```
e^(At) = (cos t)·E + (sin t)·A = [ cos t,  sin t;  −sin t, cos t ]
```

（这正是一个旋转矩阵，A 是"旋转 90° 的生成元"。）

**4.** 记 x = (x₁, x₂)ᵀ，则 ẋ = Ax，A = [0 1; −1 0]，由第 3 题

x(t) = e^(At)·x(0) = [cos t, sin t; −sin t, cos t]·(1, 0)ᵀ = **(cos t, −sin t)ᵀ**

即 x₁(t) = cos t，x₂(t) = −sin t。

验算：ẋ₁ = −sin t = x₂ ✓；ẋ₂ = −cos t = −x₁ ✓；x(0) = (1, 0)ᵀ ✓。

**5.** 令 N = [0 1; 0 0]，则 A = E + N，且 **N² = 0**（幂零）。

于是 e^A = e^(E+N) = e^E·e^N = e·(E + N)（因为 N² = 0，e^N 的级数被截断为两项）

```
e^A = e·[1 1; 0 1] = [e, e; 0, e]
```

（**解题要点**：遇到"对角元相同"的矩阵，先拆成 E + 幂零矩阵，再用 e^(E+N) = e^E·e^N，可秒算。）

#### 本章自测题答案

**1.** 用 Gauss 消去：第二行减去第一行的 2 倍（消去 a₂₁ = 4）。

消元所用的**乘子** m₂₁ = a₂₁/a₁₁ = 4/2 = 2，把它直接填进 L 的下三角位置：

```
L = [1 0; 2 1]
```

消元后得到的上三角矩阵为 U = [2 1; 0 3−2] = [2 1; 0 1]（第二行 = 4 − 2×2 = 0，3 − 2×1 = 1）。

即

```
A = L·U = [1 0; 2 1]·[2 1; 0 1]
```

验算：L·U 第一行 = (2, 1) ✓；第二行 = 2×(2,1) + 1×(0,1) = (4, 3) ✓，与 A 一致。

**答案：A = [2 1; 4 3] = [1 0; 2 1]·[2 1; 0 1]**，即 L = [1 0; 2 1]，U = [2 1; 0 1]。

（要点记牢：**L 的下三角元素就是消元乘子，直接填，不取逆**。这里 a₁₁ = 2 ≠ 0，故不用行交换，LU 分解（Doolittle 形式，L 为单位下三角）存在且唯一。）

**2.** 记 A 的两列为 a₁ = (1,1)ᵀ，a₂ = (1,0)ᵀ。

正交化：q₁ = a₁/‖a₁‖ = (1/√2, 1/√2)ᵀ，R₁₁ = ‖a₁‖ = √2。

a₂ 在 q₁ 上的投影系数 R₁₂ = a₂·q₁ = 1·(1/√2) + 0 = 1/√2。

剩余部分 u₂ = a₂ − R₁₂ q₁ = (1,0)ᵀ − (1/2)(1,1)ᵀ = (1/2, −1/2)ᵀ，‖u₂‖ = 1/√2 = R₂₂。

q₂ = u₂/‖u₂‖ = (1/√2, −1/√2)ᵀ。

故

```
Q = [1/√2  1/√2; 1/√2  −1/√2],   R = [√2  1/√2; 0  1/√2]
```

验算 QR：第一列 = Q 乘 R 第一列 = √2·q₁ = (1,1)ᵀ ✓；第二列 = R₁₂q₁ + R₂₂q₂ = (1/2)(1,1)ᵀ + (1/2)(1,−1)ᵀ = (1,0)ᵀ ✓。

**3.** A 为 2×3 矩阵，rank(A) = 2。取 A 的前两列（线性无关）构成列满秩矩阵 F：

```
F = [1 1; 0 1]，F⁻¹ = [1 −1; 0 1]
```

令 G = F⁻¹A = [1 −1; 0 1]·[1 1 0; 0 1 1] = [1, 0, −1; 0, 1, 1]（行满秩）。

于是满秩分解为

```
A = F·G = [1 1; 0 1]·[1 0 −1; 0 1 1]
```

验算：第 1 行 = 1·(1,0,−1) + 1·(0,1,1) = (1,1,0) ✓；第 2 行 = 0 + 1·(0,1,1) = (0,1,1) ✓。

**4.** A = [1 2; 2 1] 对称，AᵀA = A² = [5 4; 4 5]。

其特征值为 λ = 9 与 λ = 1，故奇异值为 σ₁ = √9 = 3，σ₂ = √1 = 1。

对应 λ = 9 的单位特征向量 v₁ = (1,1)ᵀ/√2，对应 λ = 1 的单位特征向量 v₂ = (1,−1)ᵀ/√2。

计算左奇异向量：u₁ = Av₁/σ₁ = 3·(1,1)ᵀ/√2 ÷ 3 = (1,1)ᵀ/√2；
u₂ = Av₂/σ₂ = (1,−1)ᵀ/√2 ÷ 1 = (1,−1)ᵀ/√2。

故

```
U = [1/√2  −1/√2; 1/√2  1/√2],   Σ = [3 0; 0 1],   V = [1/√2  1/√2; 1/√2  −1/√2]
```

即 A = UΣVᵀ。（验算见草稿：UΣVᵀ 的第一行第一列为 3/2 − 1/2 = 1 ✓，第一行第二列为 3/2 + 1/2 = 2 ✓。）

**5.** 设 σ₁ ≥ σ₂ ≥ … ≥ σ_r > 0 为非零奇异值，r = rank(A)，则

- **A⁺ = V·Σ⁺·Uᵀ**，其中 Σ⁺ = diag(1/σ₁, …, 1/σ_r, 0, …, 0)（把非零奇异值取倒数、零保持不变，再转置）
- **rank(A) = r**（非零奇异值的个数）
- **cond₂(A) = σ₁ / σ_r**（最大奇异值除以最小**非零**奇异值）

**2.** 证明：对任意矩阵 A 的任一特征值 λ，都有 |λ| ≤ ‖A‖。

**3.** 设 A = [2 1; 1 2]，用 Rayleigh 商求它的最大、最小特征值。

**4.** 设 A 为对称矩阵、B 为正定矩阵，说明如何把广义特征值问题 Ax = λBx 化为普通特征值问题。

**5.** 用直积写出矩阵方程 AX + XB = C 的等价线性方程组形式，并说明何时有唯一解。

---

#### 本章自测题答案

**1.** 第 i 个 Gerschgorin 圆盘以 a_ii 为圆心、以该行非对角元绝对值之和为半径：

- 第 1 行：圆心 4，半径 |1| + |0| = 1 → 圆盘 D₁: [3, 5]
- 第 2 行：圆心 4，半径 1 + 1 = 2 → 圆盘 D₂: [2, 6]
- 第 3 行：圆心 4，半径 |1| + |0| = 1 → 圆盘 D₃: [3, 5]

三圆盘的并集 ⊂ [2, 6]，**不包含原点 0**。

由圆盘定理（特征值必落在圆盘并集内），所有特征值实部为正，**A 可逆**（0 不是特征值）。

（实际特征值为 4+√2 ≈ 5.414、4、4−√2 ≈ 2.586，均落在 [2,6] 内 ✓。）

**2.** 设 λ 为 A 的特征值，x ≠ 0 为对应特征向量，则 Ax = λx。

两边取范数：‖Ax‖ = ‖λx‖ = |λ|·‖x‖。

又由相容性 ‖Ax‖ ≤ ‖A‖·‖x‖，得 |λ|·‖x‖ ≤ ‖A‖·‖x‖。

因 ‖x‖ > 0，两边约去得 **|λ| ≤ ‖A‖**。∎

**3.** A = [2 1; 1 2] 的特征值为 λ = 3（特征向量 (1,1)ᵀ）与 λ = 1（特征向量 (1,−1)ᵀ）。

Rayleigh 商 R(x) = xᵀAx / xᵀx，对对称矩阵有 λ_min ≤ R(x) ≤ λ_max：

- 取 x = (1,1)ᵀ：xᵀAx = (1,1)[2 1; 1 2](1,1)ᵀ = 6，xᵀx = 2，R = 3 = **最大特征值**
- 取 x = (1,−1)ᵀ：xᵀAx = 2，xᵀx = 2，R = 1 = **最小特征值**

**4.** 因 B 正定，存在唯一的正定平方根 B^(1/2)（且可逆）。令 y = B^(1/2)x，则

Ax = λBx ⟺ B^(−1/2)AB^(−1/2)·y = λy

即化为对称矩阵 **C = B^(−1/2)A B^(−1/2)** 的普通特征值问题 Cy = λy（A 对称时 C 对称，特征值全为实数，对应特征向量可按 B 正交）。

**5.** 记 vec(X) 为把矩阵按列拉直得到的列向量。由恒等式

vec(AX) = (E ⊗ A)·vec(X)，  vec(XB) = (Bᵀ ⊗ E)·vec(X)

（⊗ 为 Kronecker 积，直积的乘法次序约定以教材为准）

得

```
(E ⊗ A + Bᵀ ⊗ E)·vec(X) = vec(C)
```

**有唯一解的充要条件是系数矩阵可逆**，等价于 **A 与 −B 没有公共特征值**，即对一切 i, j 有 λ_i(A) + λ_j(B) ≠ 0。

（这正是 Lyapunov 方程 AᵀP + PA = −Q 可解性的理论依据：当 A 的特征值实部全为负时，A 与 −A 无公共特征值，P 唯一。）

### 第 6 章 广义逆矩阵

#### 为什么学这章

普通逆矩阵有三个"门槛"：必须是**方阵**、必须**满秩**。但工程中的矩阵经常不满足——传感器数量 ≠ 状态数量（长方阵）、数据冗余（行大于列）、秩亏损。**广义逆就是"给不可逆的矩阵也定义一种逆"**，从而统一地处理：

- 相容方程组（有解）的**通解**；
- 相容方程组的**极小范数解**；
- 矛盾方程组（无解）的**最小二乘解**；
- 以及二者的结合——**极小最小二乘解**（由 A⁺ 给出）。

**对控制专业**：A⁺ 直接对应最小二乘参数估计，是卡尔曼滤波、系统辨识的理论基础。**本章是本次学习中对自动化专业最"立竿见影"的一章。**

| 6.2 广义逆矩阵与线性方程组的求解 | 相容方程组通解、极小范数解、最小二乘解、极小最小二乘解 | **精读**，四类解的情形要能区分 |

#### 本章自测题

**1.** 设 A = [1 0; 0 0]，求 A 的一个减号逆 A⁻（{1}-逆）。

**4.** 求解矛盾方程组：x₁ = 1，x₁ = 2（即 A = [1; 1]，b = (1,2)ᵀ），求其最小二乘解。

**5.** 设 A = [3 0; 0 −2]，用 SVD 观点求 A⁺。

---

#### 本章自测题答案

**1.** 定义方程：G 为 A 的 {1}-逆 ⟺ **A G A = A**。

A = [1 0; 0 0]，试取 G = [1 0; 0 0]（即 A 本身）：
AGA = A·A·A = A ✓（因为 A² = A，A 是幂等矩阵）。

故 **A⁻ = [1 0; 0 0] 就是一个 {1}-逆**（事实上 A 的 {1}-逆有无穷多个，比如 G = [1 a; b c] 对任意 a, b, c 都满足 AGA = A）。

**2.** M-P 逆 A⁺ 是满足下述四个 Penrose 方程的**唯一**矩阵 G：

① AGA = A；② GAG = G；③ (AG)ᵀ = AG；④ (GA)ᵀ = GA。

对 A = [1 0; 0 0]，可验证 A 本身满足全部四条（A 对称、A² = A）：

AGA = A ✓；GAG = A ✓；AG = A = Aᵀ ✓；GA = A = Aᵀ ✓。

故 **A⁺ = [1 0; 0 0]**。

**3.** 计算 A⁻A = [1; 0]·[1 1] = [1 1; 0 0]；E − A⁻A = [0 −1; 0 1]。

A⁻b = [1; 0]·2 = [2; 0]。

故通解为

```
x = A⁻b + (E − A⁻A)y = [2; 0] + [0 −1; 0 1]·[y₁; y₂] = [2 − y₂; y₂]
```

即 **x = (2 − y₂, y₂)ᵀ，y₂ 任意**。

验算：x₁ + x₂ = 2 ✓，与原方程 x₁ + x₂ = 2 一致（通解正确，且 x₂ 为自由参数）。

**4.** 方程组无解（矛盾），最小二乘解为 **x = A⁺b**。

A = [1; 1]，Aᵀ A = [2]（1×1），故 A⁺ = (AᵀA)⁻¹Aᵀ = (1/2)·[1 1]。

于是 x = (1/2)·[1 1]·(1, 2)ᵀ = (1/2)(1 + 2) = **3/2**。

（意义：残差平方 (x − 1)² + (x − 2)² 在 x = 3/2 处取最小，即取两次观测的平均——这正是"最小二乘 = 取平均"的直观。）

**5.** A = diag(3, −2) 本身是"对角形式"，奇异值为 3 与 2。

其 SVD 中 U = V = E（或带符号矩阵），Σ = diag(3, −2)。按 A⁺ = VΣ⁺Uᵀ、非零奇异值取倒数：

**A⁺ = diag(1/3, −1/2)**

验算 Penrose 方程：A A⁺ = diag(1, 1) 对称 ✓；A⁺A = diag(1,1) 对称 ✓；A A⁺ A = A ✓；A⁺ A A⁺ = A⁺ ✓。全部满足。

**3.** 判断 B = [2 −1; −1 2] 是否为 M 矩阵。

**4.** 写出一个 3×3 的 Toeplitz 矩阵，并说明它由多少个独立元素决定。

**5.** 简述非负矩阵的 Perron 根与其余特征值的大小关系（Perron-Frobenius 定理要点）。

#### 本章自测题答案

**1.** 逐行检查 |a_ii| 是否大于该行其余元素绝对值之和：

- 第 1 行：|4| = 4 > |1| + |0| = 1 ✓
- 第 2 行：|3| = 3 > |1| + |1| = 2 ✓
- 第 3 行：|2| = 2 > |1| + |0| = 1 ✓

三行全部满足，故 **A 是严格对角占优矩阵**（从而 A 可逆）。

**2.** 用顺序主子式判定（Sylvester 判据）：

- 一阶主子式：2 > 0 ✓
- 二阶主子式：det C = 2×2 − (−1)×(−1) = 4 − 1 = 3 > 0 ✓

故 **C 正定**（特征值为 1 与 3，均为正，可验证）。

**3.** **是 M 矩阵**。判定要点：

- 对角元为正：2 > 0 ✓
- 非对角元非正：−1 ≤ 0 ✓
- 且可写成 B = sE − N，其中 s = 2 > ρ(N)，N = [0 1; 1 0] 的谱半径 ρ(N) = 1（因其特征值为 ±1），2 > 1 ✓

等价判据：B 可逆且 **B⁻¹ ≥ 0**（元素全非负）。这里 B⁻¹ = (1/3)[2 1; 1 2]，元素全正 ✓。

**4.** Toeplitz 矩阵的定义：**每条对角线上的元素相同**（沿主对角线方向平移不变）。例如

```
T = [1 2 3; 0 1 2; 4 0 1]
```

其中主对角线全为 1，上方第一条对角线全为 2，上方第二条为 3，下方第一条为 0，下方第二条为 4。

它由**第一行与第一列**决定，独立元素个数为 **2n − 1 = 5**（n = 3），远少于一般 3×3 矩阵的 9 个。这正是它存储与计算高效的原因。

**5.** Perron-Frobenius 定理要点（不可约非负矩阵）：

- 存在一个**正实数**特征值 r = ρ(A)（称为 Perron 根），它是 A 的**最大**特征值；
- 对应存在**正**特征向量（各分量严格大于 0）；
- A 的**其余所有特征值的模都 ≤ r**；
- 若 A 还为本原（非负且某个幂为正）矩阵，则其余特征值的模**严格小于** r。

| **相似变换 / Jordan 标准形** | 第 1 章 | 求过渡矩阵、判可对角化、求 Jordan 形各 8 题，直到闭眼能写 |

| **广义逆** | 第 6 章 | 求 A⁻、A⁺ 及四类方程组解，各 5 题 |

**时间分配建议**：这三项占你总学习时间的 **70%**。

### 2. 一条贯穿全书的"万能套路"：把矩阵化简单

任何矩阵问题，先问自己一句：**"能不能换一组基，让它变简单？"**

- 求 A^k、e^(At)、f(A) → 先做**相似对角化 / Jordan 标准形**（第 1、3 章）
- 求最小二乘、伪逆 → 先做 **SVD 或满秩分解**（第 4、6 章）
- 求特征值范围 → 先**用圆盘定理框定**（第 5 章）
- 解矩阵方程 AX + XB = C → 先**用直积拉直成普通方程组**（第 5 章）

**这就是本书唯一的"通用算法"，其余的都在细节上。**

### 3. 高频易错点清单（考前必看）

- **矩阵范数的算子范数**：‖A‖₁ 是"列的绝对值之和的最大值"，‖A‖∞ 是"行的绝对值之和的最大值"——**别记反**（向量范数里 1 和 ∞ 的规则正好相反）
- **相容性要求**：‖AB‖ ≤ ‖A‖‖B‖ 只有**相容范数**才满足；Frobenius 范数满足，但不是算子范数
- **ρ(A) ≤ ‖A‖**：谱半径不超过任意相容范数，但**不是等于**；只有 A 正规时 ρ(A) = ‖A‖₂
- **A^k → 0 的判据**：充要条件是 ρ(A) < 1，不是 ‖A‖ < 1（后者只是充分条件）
- **e^(A+B) ≠ e^A·e^B**：只有当 AB = BA 时等号成立；e^(E+N) = e^E·e^N 之所以成立，正是因为 E 与 N 可交换
- **Jordan 标准形求矩阵函数**：注意 Jordan 块的"上三角项"含 k·λ^(k−1)，别漏掉
- **减号逆 vs 加号逆**：A⁻ 一般**不唯一**，A⁺ **唯一**；只有 A⁺ 能同时给出最小二乘解与极小范数解
- **A⁻b 不是一般方程组的解**：只有当方程组**相容**时，A⁻b 才是解
- **圆盘定理是充分条件**：圆盘全落在某区域内 ⇒ 特征值必在该区域内；但圆盘越界不代表特征值越界
- **广义特征值问题**：Ax = λBx 要求 B 正定（或可逆）才能化成普通特征值问题；B 奇异时需另行处理

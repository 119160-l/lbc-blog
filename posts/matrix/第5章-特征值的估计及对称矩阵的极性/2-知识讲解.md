## 一、为什么要"估计"特征值？

### 为什么？

工程师最关心的稳定性问题，本质上是一个**特征值位置问题**：

- 连续系统 $\dot x=Ax$ 稳定 $\Longleftrightarrow$ $\operatorname{Re}\lambda_i(A)<0$（全部特征值在左半平面）；
- 离散系统 $x_{k+1}=Ax_k$ 稳定 $\Longleftrightarrow$ $|\lambda_i(A)|<1$（全部特征值在单位圆内）；
- 系统响应快慢、振荡频率，由**特征值的实部与虚部**决定。

问题是：真实系统的 $A$ 可能有几十上百阶，而且**参数本身就有误差**。这时精确求解既不可行也没必要——我们只需要知道"**特征值大概在哪个区域**"。本章提供的正是这类"区域估计"工具。

### 怎么做？（三类工具）

```
① 界的工具：用范数、迹、行列式给出 ρ(A) 的上下界 —— 一个数
② 区域的工具：Gerschgorin 圆盘定理 —— 一堆圆盘
③ 敏感性的工具：Bauer-Fike / Weyl 不等式 —— 误差会被放大几倍
```

### 是什么？

> **特征值估计**：不精确求出特征值，而是给出它**必落的范围**（界、圆盘、区间）和**必满足的敏感性关系**（扰动界），从而支持稳定性、可逆性、正定性等工程判断。

### 生活类比

想知道一个陌生人身高，"**拿尺子量**"是精确求解；"**看他比门框高还是矮**"就是估计。工程里绝大多数时候，能判断"他比门框高"就足够做决策了——**估计的价值不在精度，而在"够用且便宜"**。

## 二、特征值的界：一把快尺

### 为什么？

有时我们连"圆盘"都不需要，只要一个数：**谱半径有多大？** 例如判稳时，若 $\|A\|_\infty<1$（离散系统），立刻可断定 $|\lambda_i|<1$，系统稳定——**一行非对角元求和，判完。**

### 怎么做？（三条主公式）

```
① 范数上界：|λ| ≤ ‖A‖，于是 ρ(A) ≤ min{‖A‖₁, ‖A‖∞, ‖A‖₂, ‖A‖F}
② 迹下界：  ρ(A) ≥ |tr A| / n
③ 平方和上界：Σ|λᵢ|² ≤ ‖A‖F²（等号 ⟺ A 正规）
```

配合使用就得到"夹逼"：

$$
\frac{|\operatorname{tr}A|}{n}\ \le\ \rho(A)\ \le\ \|A\|
$$

### 是什么？

> **特征值的界**：由相容范数给出 $|\lambda|\le\|A\|$（上界），由迹给出 $\rho(A)\ge|\operatorname{tr}A|/n$（下界），由 Schur 不等式给出 $\sum|\lambda_i|^2\le\|A\|_F^2$（整体尺度）。它们都**只需 $O(n^2)$ 次四则运算**，性价比极高。

### 生活类比

范数界像"**称最大件行李的重量**"：不必把每件行李都称一遍，把所有行李摞一起看总重量就够了。迹下界像"**平均体重**"：知道总重和人数，就能估计最重的人至少有多重。**一个管住上限，一个兜住下限。**

### 补充：实部与虚部也有界

任何矩阵都能拆成 **Hermite 部分 + 反 Hermite 部分**：

$$
A=H+\mathrm{i}S,\qquad H=\frac{A+A^H}{2},\quad S=\frac{A-A^H}{2\mathrm{i}}
$$

$$
\operatorname{Re}\lambda\in[\lambda_{\min}(H),\lambda_{\max}(H)],\qquad
\operatorname{Im}\lambda\in[\lambda_{\min}(S),\lambda_{\max}(S)]
$$

> **控制视角**：判连续系统稳定性只看实部，所以**只看 $H=(A+A^T)/2$ 就够**。$H$ 是对称矩阵，它的极值特征值可以用 Rayleigh 商（见第六节）快速估出来——**"判稳"这件事就被压缩成"求一个对称矩阵的极值"。**

## 三、Gerschgorin 圆盘定理：把特征值圈起来

### 为什么？

范数界只给一个数，太粗。**圆盘定理给的是"每个特征值分别落在哪个圆盘里"**——它把对角元当作圆心，把同一行的非对角元之和当作半径。对角元通常很大（比如系统矩阵的主对角线），而非对角元较小，所以圆盘往往很小、很准。

### 怎么做？（读题三步）

```
① 定圆心：第 i 个圆盘圆心 = aᵢᵢ
② 定半径：Rᵢ = Σⱼ≠ᵢ |aᵢⱼ|（行）或 Cᵢ = Σⱼ≠ᵢ |aⱼᵢ|（列），两者都能用
③ 读结论：
   - 若 0 ∉ 所有圆盘 → A 可逆
   - 若 A 对称且 aᵢᵢ > Rᵢ（圆心为正、圆盘全在右半轴）→ A 正定
   - 若 m 个圆盘连通成一块、与其他不交 → 这一块恰含 m 个特征值
```

**证明的关键只有一步**：设 $x_k$ 是特征向量中**绝对值最大**的分量，把第 $k$ 行方程移项、取模，就能一致地用 $|x_k|$ 控制所有 $|x_j|$，从而得到 $|\lambda-a_{kk}|\le R_k$。

### 是什么？

> **Gerschgorin 圆盘定理**：$A$ 的任一特征值必落在某个圆盘 $D_i=\{z:|z-a_{ii}|\le\sum_{j\ne i}|a_{ij}|\}$ 之中。进一步地，圆盘的每个"连通部分"所含特征值个数，恰等于该部分包含的圆盘个数。

### 生活类比

把每个圆盘想成"**一间屋子的范围**"：圆心是屋子地址（对角元），半径是屋子的活动范围（这一行与别人耦合的强度）。定理说的是"**人一定在自己屋子里**"；连通部分定理说的是"**几间连在一起的屋子里一共有几个人**"——虽然不知道具体在哪间，但人数是确定的。

### 控制视角：判稳的"第一秒快筛"

| 系统类型 | 稳定性要求 | 圆盘判据（充分条件） |
|----------|------------|----------------------|
| 连续系统 | $\operatorname{Re}\lambda<0$ | $a_{ii}+R_i<0$ 对一切 $i$ |
| 离散系统 | $\vert\lambda\vert<1$ | $\lvert a_{ii}\rvert+R_i<1$ 对一切 $i$ |
| 可逆性 | $0$ 不是特征值 | $0\notin\bigcup_iD_i$，即 $\lvert a_{ii}\rvert>R_i$ |
| 正定（对称） | $\lambda_i>0$ | $a_{ii}>R_i$ 对一切 $i$ |

**注意逻辑方向**：圆盘条件是**充分的**——满足就一定稳/可逆/正定；不满足**不代表**不稳定，只是"这一招没判出来"，需要进一步精算。这就是它被称为"快筛"的原因：**代价极低，通过即定论，不通过才补做精算。**

> **一句话对比**：范数界回答"**特征值最大多大**"，圆盘定理回答"**每个特征值大概在哪**"。前者粗但快，后者稍细且仍然便宜。

## 四、扰动理论：特征值有多"敏感"？

### 为什么？

前面所有估计都建立在"矩阵 $A$ 已知且精确"的前提下。但**真实系统的参数总有误差**：建模时忽略的高阶动态、辨识得到的参数误差、工作点漂移。问题来了：**参数差一点，特征值会不会差很多？**

### 怎么做？（两步）

```
① 算谱条件数 κ(P) = ‖P‖·‖P⁻¹‖（P 为特征向量矩阵）
② 用 Bauer-Fike：扰动后特征值 μ 满足 min|μ-λᵢ| ≤ κ(P)·‖E‖
```

对**正规矩阵**（对称、反对称、酉），可取 $P$ 为酉矩阵，$\kappa_2(P)=1$，于是

$$
\min_i|\mu-\lambda_i|\le\|E\|_2
$$

扰动多大，特征值就最多动多大——**极其可靠**。

### 是什么？

> **Bauer–Fike 定理**：设 $A=P\Lambda P^{-1}$ 可对角化，则 $A+E$ 的任一特征值 $\mu$ 满足 $\min_i|\mu-\lambda_i|\le\kappa_p(P)\|E\|_p$。其中 $\kappa(P)=\|P\|\|P^{-1}\|$ 是**谱条件数**，度量特征值问题的病态程度。

### 生活类比

$\kappa(P)$ 像"**话筒的放大倍数**"。正规系统的 $\kappa=1$，说话多大声听众就听到多大声（保真）；非正规系统的 $\kappa$ 可能高达几百，**细小的杂音被放大成刺耳噪声**。靠近亏损矩阵（大 Jordan 块）的系统就是"高增益话筒"——参数差 $1\%$，极点可能漂移百分之几十。

### Hermite 情形：更强的结论

对 Hermite 矩阵，有比 Bauer–Fike 更细的 **Weyl 不等式**：

$$
\lambda_i(A)+\lambda_{\min}(E)\ \le\ \lambda_i(A+E)\ \le\ \lambda_i(A)+\lambda_{\max}(E)
$$

以及整体的 **Hoffman–Wielandt 不等式**：

$$
\Big(\sum_i\big(\lambda_i(A+E)-\lambda_i(A)\big)^2\Big)^{1/2}\le\|E\|_F
$$

> **控制视角**：这一节是"**鲁棒性分析**"的数学基础。它告诉我们：**对称、正规的系统天然鲁棒**（$\kappa=1$），而**高度非正规的系统是"玻璃做的"**。工程上若发现状态矩阵接近于"多个特征值挤在一起"，就要警惕——此时极点对参数极度敏感，实际系统可能比设计模型脆得多。

## 五、广义特征值问题：换个"尺子"量特征值

### 为什么？

工程很多问题的自然形式不是 $Ax=\lambda x$，而是

$$
Ax=\lambda Bx
$$

- **结构动力学**：$Kx=\omega^2Mx$（刚度 $K$、质量 $M$，$M$ 正定）；
- **约束优化**：在 $x^HBx=1$ 约束下极小化 $x^HAx$；
- **广义奇异值/判别分析**：分母必须用 $B$-度量。

$B$ 起到了"**加权尺子**"的作用。

### 怎么做？（化归三步）

```
① B 可逆时最简单：Ax = λBx  ⟺  B⁻¹Ax = λx
   （缺点：B⁻¹A 一般不对称，谱可能为复数）

② A、B 都 Hermite、B 正定：用"对称化"的技巧
   令 y = B^{1/2}x，则 Ax = λBx ⟺ Cy = λy，C = B^{-1/2}AB^{-1/2}
   C 是 Hermite 的 → 广义特征值全为实数 ✓

③ 特征向量的正交性：改按 B 正交（见下）
```

**为什么 $C$ 一定 Hermite？** 因为 $B^{1/2}$ 正定、$A$ 对称，把两边"夹住"后对称性保持：

$$
C^H=(B^{-1/2}AB^{-1/2})^H=B^{-1/2}AB^{-1/2}=C
$$

### 是什么？

> **广义特征值问题**：$Ax=\lambda Bx$。当 $B$ 可逆时等价于 $B^{-1}Ax=\lambda x$；当 $A$、$B$ Hermite 且 $B$ 正定时，还可化为**对称**矩阵 $C=B^{-1/2}AB^{-1/2}$ 的普通特征值问题，此时特征值全为实数、特征向量按 $B$ 正交。

### 生活类比

普通特征值问题用"**标准尺**"量长度（$B=I$）；广义问题里的自然尺子是 $B$——**因为它就是"能量/代价"的度量**。就像衡量"这段路值不值得走"不能只看距离，还要看路况（$B$）：$B$ 正定意味着"路况处处为正",所以"距离"（特征值）一定是实的。

### 关键结论：按 B 正交

设 $A$、$B$ Hermite，$B$ 正定，$x_1,x_2$ 对应互异特征值 $\lambda_1\ne\lambda_2$，则

$$
\boxed{x_1^HBx_2=0,\qquad x_1^HAx_2=0}
$$

**证明只有两行**：由 $Ax_1=\lambda_1Bx_1$、$Ax_2=\lambda_2Bx_2$，分别左乘 $x_2^H$、$x_1^H$，再取共轭后相减，得 $(\lambda_1-\lambda_2)x_1^HBx_2=0$。

把 $n$ 个特征向量按 $\|x_i\|_B=1$ 标准化，就得到"**按 $B$ 标准正交基**"，并实现**同时对角化**：

$$
X^HBX=I,\qquad X^HAX=\Lambda
$$

> **优化视角**：$B$-正交意味着"**在新几何里的直角**"。约束 $x^HBx=1$ 是椭球约束，$B$-正交基恰好是这个椭球的主轴方向——这正是为什么广义问题可以"化归为普通问题"的几何解释。

## 六、对称矩阵的极性：Rayleigh 商与极小极大原理

### 为什么？

前几节都在"估计范围"，本节给出**精确刻画**：对称矩阵的最大、最小特征值，可以用一个**优化问题**准确表达：

$$
\lambda_{\max}=\max_{x\ne0}\frac{x^TAx}{x^Tx},\qquad
\lambda_{\min}=\min_{x\ne0}\frac{x^TAx}{x^Tx}
$$

这个比值就是 **Rayleigh 商** $R(x)$。它的意义非同小可：**求特征值 = 求二次型极值**。

### 怎么做？（三个层次）

```
① 一维刻画（最常用的 Rayleigh 商）：
   λ_min ≤ R(x) ≤ λ_max，且极值在对应特征向量处取到

② 变分刻画（驻点即特征向量）：
   在 xᵀx=1 下求 R 的驻点，Lagrange 乘子直接给出 Ax = μx

③ k 维刻画（Courant–Fischer 极小极大原理）：
   λ_k = min_{dim S=k} max_{x∈S} R(x)
      = max_{dim T=n-k+1} min_{x∈T} R(x)
```

### 是什么？

> **Rayleigh 商** $R(x)=\dfrac{x^TAx}{x^Tx}$：对实对称矩阵 $A$，它在单位球上的最大/最小值恰为最大/最小特征值，且极值点就是对应该特征值的特征向量。等价地，**Rayleigh 商的驻点恰好是 $A$ 的全部特征向量**。

**证明的核心只有一步**：把 $x$ 按标准正交特征基展开 $x=\sum c_iu_i$，则

$$
R(x)=\frac{\sum\lambda_ic_i^2}{\sum c_i^2}
$$

这是特征值的**加权平均**（权重 $c_i^2/\sum c_j^2\ge0$，和为 1），自然落在 $\lambda_{\min}$ 与 $\lambda_{\max}$ 之间。

### 生活类比

把 $A$ 想象成"**不同方向的坡**"：沿各特征方向，坡的陡峭程度分别是各特征值。$R(x)$ 就是"**沿 $x$ 方向的平均坡度**"。**最陡的方向就是最大特征向量，最缓的方向就是最小特征向量**——爬山找最陡处，就找到了 $\lambda_{\max}$。

### 延伸一：广义 Rayleigh 商

对 $A$ Hermite、$B$ 正定，

$$
R_B(x)=\frac{x^HAx}{x^HBx},\qquad \lambda_{\min}\le R_B(x)\le\lambda_{\max}
$$

这正是第五节 $B$-正交与本节极性的自然合流——**第五节讲"正交"，本节讲"极值"，两者是同一套 $B$-几何的两面。**

### 延伸二：Courant–Fischer 极小极大原理

$$
\lambda_k=\min_{\dim S=k}\max_{x\in S}R(x)=\max_{\dim T=n-k+1}\min_{x\in T}R(x)
$$

**证明思路（记这两句话就够了）**：
1. **上界**：取 $S=\operatorname{span}\{u_1,\dots,u_k\}$，其中 $x$ 只含 $\lambda_1,\dots,\lambda_k$ 的分量，故 $R(x)\le\lambda_k$，取最大恰为 $\lambda_k$；
2. **下界**：任一 $k$ 维 $S$ 与 $\operatorname{span}\{u_k,\dots,u_n\}$ 的交维数 $\ge k+(n-k+1)-n=1>0$，必存在非零向量落在交中，其 $R\ge\lambda_k$。

**为什么这个定理重要？** 它把 $\lambda_k$ 刻画成"**与特征向量无关、只与子空间维数有关**"的量——这就是**扰动理论、Weyl 不等式、特征值优化**的共同源头。

### 延伸三：奇异值的极小极大性质

奇异值定义：$\sigma_i=\sqrt{\lambda_i(A^HA)}$。于是对 $A^HA$ 用 Courant–Fischer，立即得到

$$
\sigma_j=\min_{\dim S=n-j+1}\max_{0\ne x\in S}\frac{\|Ax\|}{\|x\|}
=\max_{\dim T=j}\min_{0\ne x\in T}\frac{\|Ax\|}{\|x\|}
$$

两个最重要的特例：

$$
\sigma_1=\|A\|_2=\max_{x\ne0}\frac{\|Ax\|}{\|x\|},\qquad
\sigma_n=\min_{x\ne0}\frac{\|Ax\|}{\|x\|},\qquad
\kappa_2(A)=\frac{\sigma_1}{\sigma_n}
$$

其中 $\kappa_2(A)$ 就是"解 $Ax=b$ 时输入误差的放大倍数"（条件数）。

> **数值计算视角**：**奇异值为什么比特征值'好用'？** 因为 $\sigma_i$ 是 Hermite 半正定矩阵 $A^HA$ 的特征值平方根，由 Weyl 不等式立刻有 $|\sigma_i(A+E)-\sigma_i(A)|\le\|E\|_2$——**永远 Lipschitz 稳定、永远是实数、永远非负**。而特征值可能因非正规而"乱漂"。这就是数值线性代数偏爱 SVD 的根本原因。

## 七、直积与线性矩阵方程：把 $AX+XB=C$ "压平"

### 为什么？

控制里经常要解**未知量是矩阵**的方程，最经典的就是 Lyapunov 方程

$$
A^TP+PA=-Q
$$

未知量 $P$ 是 $n\times n$ 矩阵。看起来"不是线性方程组"，但**它其实完全等价于一个 $n^2\times n^2$ 的线性方程组**——只要把矩阵"拉直"成向量。实现这一点的工具就是**直积（Kronecker 积）**。

### 怎么做？（拉直三步）

```
① 直积的定义：A ⊗ B = [aᵢⱼ B]（把每个元素换成"该元素 × 整个 B"这一块）
② 两个拉直恒等式（核心！）：
   vec(AX)  = (I ⊗ A)·vec(X)
   vec(XB)  = (Bᵀ ⊗ I)·vec(X)
   一般地  vec(AXB) = (Bᵀ ⊗ A)·vec(X)
③ 拉直原方程：
   AX + XB = C  ⟺  (I ⊗ A + Bᵀ ⊗ I)·vec(X) = vec(C)
```

其中 $\operatorname{vec}(X)$ 是把 $X$ 按列堆叠成的长向量。

### 是什么？

> **直积（Kronecker 积）** $A\otimes B=[a_{ij}B]$：把两个矩阵"拼"成一个更大的分块矩阵。它最重要的性质是**混合乘积法则** $(A\otimes B)(C\otimes D)=(AC)\otimes(BD)$，以及**特征值相乘** $\lambda(A\otimes B)=\{\lambda_i(A)\mu_j(B)\}$。

**必背性质清单**：

| 性质 | 表达式 |
|------|--------|
| 混合乘积 | $(A\otimes B)(C\otimes D)=(AC)\otimes(BD)$ |
| 转置/共轭 | $(A\otimes B)^T=A^T\otimes B^T$，$(A\otimes B)^H=A^H\otimes B^H$ |
| 迹 | $\operatorname{tr}(A\otimes B)=\operatorname{tr}A\cdot\operatorname{tr}B$ |
| 特征值 | $\lambda(A\otimes B)=\{\lambda_i(A)\mu_j(B)\}$ |
| 行列式 | $\det(A\otimes B)=(\det A)^m(\det B)^n$ |
| 逆 | $(A\otimes B)^{-1}=A^{-1}\otimes B^{-1}$ |
| 秩 | $\operatorname{rank}(A\otimes B)=\operatorname{rank}A\cdot\operatorname{rank}B$ |
| 范数 | $\|A\otimes B\|_2=\|A\|_2\|B\|_2$ |

### 怎么判"有没有唯一解"？

拉直后系数矩阵是

$$
K=I_m\otimes A+B^T\otimes I_n
$$

它的两个加项**可交换**，因此可同时上三角化，特征值直接相加：

$$
\lambda(K)=\{\lambda_i(A)+\mu_j(B)\}
$$

于是（这是本节最有用的一句话）：

$$
\boxed{AX+XB=C\ \text{有唯一解}\ \Longleftrightarrow\ \lambda_i(A)+\mu_j(B)\ne0\ \ (\forall i,j)}
$$

### 生活类比

$\operatorname{vec}$ 像"**把一叠纸摊平**"：本来是"矩阵对矩阵"的操作（翻页式），摊平成一长条后就变成"数对数"的普通运算。直积 $K$ 则是"**摊平后那根长条上的操作符**"。**降维不是目的，把未知的问题塞进已有工具箱才是目的。**

### 控制视角（本章点睛）：这就是 Lyapunov 方程

把符号对号入座，$A^TP+PA=-Q$ 就是 $AX+XB=C$ 的形式（取 $A\rightsquigarrow A^T$、$B\rightsquigarrow A$、$C\rightsquigarrow -Q$）。可解性条件变成

$$
\lambda_i(A^T)+\lambda_j(A)\ne0\ \Longleftrightarrow\ \lambda_i(A)+\lambda_j(A)\ne0
$$

若 $A$ **稳定**（$\operatorname{Re}\lambda_i(A)<0$），则每个 $\lambda_i(A)+\lambda_j(A)$ 的实部都小于 0，必然非零，于是

$$
\boxed{\text{$A$ 稳定}\ \Longrightarrow\ \text{Lyapunov 方程对任意 $Q$ 有唯一解}}
$$

并且当 $Q$ 正定时，解 $P$ 也**正定**——这正是 **Lyapunov 稳定性定理**的代数形式。

**它在控制里出现的三处高频场景**：

```
① 判稳：找正定 P 使 AᵀP + PA = -Q（Q 正定）⟺ A 渐近稳定
② 算指标：二次型性能指标 J = ∫xᵀQx dt = x₀ᵀPx₀
③ 设计：观测器、最优控制的 Riccati 迭代中反复解 Lyapunov 方程
```

> **一句话总结本章与控制的关系**：**圆盘定理让你"一眼判稳"，Rayleigh 商让你"把特征值变成优化问题"，而直积把 Lyapunov 方程"翻译成普通线性方程组"。** 这三件事，正是从"矩阵论"通往"线性系统理论"的三道门。

## 总结：知识体系图

```
第5章 特征值的估计及对称矩阵的极性
   │
   ├─ 5.1 特征值的估计（不求解，只定位）
   │    ├─ ① 界：|λ| ≤ ‖A‖（上界）
   │    │        ρ(A) ≥ |tr A|/n（下界）
   │    │        Σ|λᵢ|² ≤ ‖A‖F²（Schur）
   │    │        Re λ ∈ [λmin(H), λmax(H)]，H=(A+Aᵀ)/2
   │    ├─ ② 包含区域：Gerschgorin 圆盘 Dᵢ = {|z-aᵢᵢ| ≤ Σ|aᵢⱼ|}
   │    │        └─ 推论：可逆（0∉∪Dᵢ）、正定（对称且 aᵢᵢ>Rᵢ）
   │    │                  连通部分含特征值个数 = 圆盘个数
   │    └─ ③ 扰动：Bauer–Fike  min|μ-λᵢ| ≤ κ(P)·‖E‖
   │             正规/对称时 κ=1；Hermite 有 Weyl 不等式
   │
   ├─ 5.2 广义特征值问题 Ax = λBx
   │    ├─ ① 等价形式：B 可逆 → B⁻¹Ax = λx
   │    │            A、B Hermite 且 B>0 → C = B^{-1/2}AB^{-1/2} 对称
   │    └─ ② 正交性：xᵢᴴBxⱼ = δᵢⱼ（按 B 正交）；XᴴBX=I, XᴴAX=Λ
   │
   ├─ 5.3 对称矩阵特征值的极性
   │    ├─ ① Rayleigh 商：λmin ≤ R(x) ≤ λmax；驻点 = 特征向量
   │    ├─ ② Courant–Fischer：λₖ = min_{dimS=k} max_{x∈S} R(x)
   │    └─ ③ 奇异值：σⱼ = min_{dimS=n-j+1} max ‖Ax‖/‖x‖；σᵢ=√λᵢ(AᴴA)
   │         └─ σ₁=‖A‖₂，κ₂=σ₁/σₙ（条件数）
   │
   └─ 5.4 直积及其应用
        ├─ ① 直积 A⊗B=[aᵢⱼB]：(A⊗B)(C⊗D)=(AC)⊗(BD)
        │         λ(A⊗B)={λᵢμⱼ}, det=(detA)ᵐ(detB)ⁿ
        └─ ② 矩阵方程：vec(AX+XB) = (I⊗A + Bᵀ⊗I)vec(X)
                 唯一解 ⟺ λᵢ(A)+μⱼ(B) ≠ 0
                 └─ 特例 Lyapunov：AᵀP+PA=-Q，A 稳定 → 唯一解 P
```

### 核心脉络

1. **一条主线**：从"求解特征值"转向"**估计特征值**"——界的工具（§5.1）、化归的工具（§5.2）、极值的工具（§5.3）、拉直的工具（§5.4）；
2. **两个视角互换**：**代数视角**（特征值、特征向量）与**分析视角**（极值、范数、扰动）在本章反复切换——Rayleigh 商是二者的桥，Courant–Fischer 是二者的总纲；

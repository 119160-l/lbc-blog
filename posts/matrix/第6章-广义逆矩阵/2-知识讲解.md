### 承上启下

第3章解 $Ax=b$ 时留了两个"悬案"：**方程组无解怎么办？解有无穷多个怎么办？**当时只能用"高斯消元 + 自由未知量"硬算，一旦 $A$ 不是方阵或不满秩，就没了统一说法。本章补上这把"万能钥匙"——**广义逆**。

同时，前面几章攒下的家底在这里集中兑现：第1章的**等价标准形**给出 $A^-$ 的存在性证明（$PAQ=J$）；第2、4章的**满秩分解**与**SVD**给出 $A^+$ 的两种算法；第5章的**正交投影与奇异值**则直接解释了 $A^+$ 的几何意义。**本章不是新起炉灶，而是把前五章的"零件"组装成一台机器**。学完本章，你将拥有处理一切线性方程组（相容/矛盾、满秩/秩亏、方阵/长方阵）的统一工具。

### 问题导向

带着以下问题学习本章，你会更有方向感：

1. **方程 $AGA=A$ 的解为什么"到处都是"？要加什么条件才能让"逆"从一族收敛到唯一一个？**
2. **为什么 $A^+$ 用 SVD 求特别方便？"非零奇异值取倒数、零保持不变"这句话背后的道理是什么？**
3. **相容方程组的"极小范数解"和矛盾方程组的"极小最小二乘解"为什么都是 $A^+b$？它俩到底在优化什么？**

## 一、为什么要广义逆？

### 为什么？

第3章里，$Ax=b$ 的求解被两个"例外"打断：

- $A$ 不是方阵（$m\neq n$）——比如 3 个传感器测 2 个状态，$A$ 是 $3\times2$，逆没定义；
- $A$ 是方阵但不满秩（$\det A=0$）——数据有共线性，逆不存在。

这两件事在工程里是**常态而非例外**：系统辨识的回归矩阵、卡尔曼滤波的量测矩阵、冗余传感器的数据矩阵，几乎都不是可逆方阵。若没有一个统一工具，每个问题都要"打补丁"。**广义逆就是把所有补丁合成一条定理**。

更关键的是：$A^{-1}$ 只在"恰好可逆"这个针尖上活着，而工程数据永远有噪声、永远有冗余。**我们需要的不是"能不能求逆"，而是"在不能求逆时，什么意义下最优"**——广义逆正是回答这个问题的语言。

### 怎么做？（三步走）

```
① 先问"有没有解"：b 是否落在 R(A) 里？——相容 / 矛盾
② 再问"要哪个解"：解多 → 取范数最小；无解 → 取残差最小
③ 用一个矩阵统管：A⁻ 管通解，A⁺ 管最优解
```

### 是什么？

> **广义逆**：把普通逆矩阵唯一该干的事——"抵消"（$A^{-1}A=AA^{-1}=E$）——抽象成矩阵方程，在 $A$ 不可逆时求它的解。按方程加码的多少，得到一族不同强度的"逆"：$A^-\supset A^-_r\supset A^+$（集合关系是"由宽到窄"，$A^+$ 唯一）。

### 生活类比

普通求逆像"**要求考试每道题都对**"——只有满分（可逆）才算过关，及格线定得极高，绝大多数人（矩阵）都过不了。

广义逆像"**允许多种及格标准**"：{1}-逆是"只要总分对得上"（门槛最低，很多人及格）；$A^+$ 是"既要总分对、又要没偏科"（门槛高，只有一个最优解）。**标准越高，合格者越少，直到唯一**——这就是全章的"加码"逻辑。

> **代数视角**：从 $A^{-1}$ 到 $A^+$，本质是**把"存在性要求"换成了"最优性要求"**。可逆要求"精确抵消 + 唯一"，这在数学上是个"硬条件"；$A^+$ 改为要求"最接近的抵消（最小二乘）+ 最短的答案（最小范数）"，把一个可能无解的问题变回有唯一解的问题——**这才是广义逆能在工程里活下来的原因**。

## 二、{1}-逆：门槛最低的"逆"

### 为什么？

第3章解方程时，我们其实只需要 $G$ 满足一件事：**用它去"抵消" $A$，把 $b$ 还原出来**。至于 $G$ 是不是方阵、唯不唯一，统统不重要。把这件事写成方程，就是

$$
AGA=A
$$

这样定义的 $G$ 就是 {1}-逆。**它存在的理由是"够用"**：证明存在性只要一行（等价标准形），构造它只要一次初等变换。

### 怎么做？（找与用）

```
找：作初等变换把 A 化为标准形 PAQ = [Er 0; 0 0]，取 G = Q[Er 0; 0 0]P
    （更省事：满秩分解 A=FG 后取任意一个 {1}-逆，甚至 G0=QJP）
用：x = A⁻b + (E − A⁻A)y  —— 相容方程组的通解（见第七节）
```

### 是什么？

> **{1}-逆（减号逆）$A^-$**：满足 $AGA=A$ 的矩阵 $G$（$G$ 的形状自动是 $n\times m$，与 $A$ 转置同形）。$A$ 的所有 {1}-逆记为 $A\{1\}$。**特征**：§永远存在；§一般不唯一（$A$ 可逆时才退化为 $A^{-1}$）。

**它的三条"硬事实"**：
1. **一定存在**：$G_0=QJP$ 就是一个（$PAQ=J$）。
2. **一般无穷多**：$A=\begin{bmatrix}1&0\\0&0\end{bmatrix}$ 时 $\begin{bmatrix}1&a\\b&c\end{bmatrix}$ 对任意 $a,b,c$ 都合格。
3. **秩不缩水**：$\operatorname{rank}(AA^-)=\operatorname{rank}A$，且 $AA^-$、$A^-A$ 都是幂等投影。

### 生活类比

{1}-逆像一个"**万能钥匙坯子**"：能开锁（抵消 $A$）就行，齿形（具体数值）有很多种都行。便宜、好配，但不精确——配多了会"划伤锁芯"（破坏自反性），这是下一节要修的毛病。

> **警示**：{1}-逆**不能随便约分**。$A^-A\neq E$、$A^-b$ 未必是解（当 $b\notin\mathcal R(A)$ 时）。凡是拿 $A^-$ 当普通逆用的地方，几乎都错。

## 三、自反广义逆与 M-P 逆：加码加出唯一

### 为什么？

{1}-逆虽然"到处都有"，但太松：它会在 $A$ 的零空间里"乱动"，导致 $A$ 未必是它的逆（不自反）。于是**每加一条方程，就收紧一次**：

```
{1}：AGA=A          → 能抵消，但乱
{1,2}：+ GAG=G      → 去掉零空间乱动（自反）
{1,2,3,4}：+ 两个对称 → 投影变正交，唯一！
```

### 怎么做？（两个关键构造）

**构造 1：从任一 {1}-逆造自反逆**（几乎零成本）

$$
G\ \text{是 {1}-逆}\;\Longrightarrow\; X=GAG\ \text{是 {1,2}-逆}
$$

**构造 2：$A^+$ 的求法**（下一节详述）——满秩分解或 SVD。

**验证 $A^+$ 只需四行**：对一个候选 $G$，逐条代入 (1)(2)(3)(4)，全对则它就是 $A^+$（唯一性保证"验过即完事"，不必再算）。

### 是什么？

> **自反广义逆 $A^-_r$**：满足 $AGA=A$ 且 $GAG=G$。两方程关于 $A,G$ 对称，故"互为广义逆"——关系可逆，故名"自反"。它等价于"秩最小的 {1}-逆"（$\operatorname{rank}G=\operatorname{rank}A$）。

> **Moore–Penrose 逆 $A^+$**：满足四个 Penrose 方程
> $$AGA=A,\quad GAG=G,\quad (AG)^{\mathrm T}=AG,\quad (GA)^{\mathrm T}=GA$$
> 的**唯一**矩阵。前两条管"量"（抵消），后两条管"质"（正交）。

**唯一性一句话证明**（记住这条推理链）：$AX$ 是对 $\mathcal R(A)$ 的正交投影 $\Rightarrow AX=AY$；同理 $XA=YA$；于是

$$
X=XAX=X(AX)=X(AY)=(XA)Y=(YA)Y=YAY=Y
$$

**$A^+$ 的性质速记**：$(A^+)^+=A$；$(A^{\mathrm T})^+=(A^+)^{\mathrm T}$；$\operatorname{rank}A^+=\operatorname{rank}A$；$A$ 可逆时 $A^+=A^{-1}$；**列满秩** $A^+=(A^{\mathrm T}A)^{-1}A^{\mathrm T}$（左逆），**行满秩** $A^+=A^{\mathrm T}(AA^{\mathrm T})^{-1}$（右逆）。

### 生活类比

{1}-逆是"**能开锁的钥匙**"，{1,2}-逆是"**不会划伤锁芯的钥匙**"（不会在零空间乱动），$A^+$ 是"**唯一那把原配钥匙**"（还要求投影正交）。**加码 = 加限定条件 = 减少候选 = 逼近唯一**。

> **控制视角（核心）**：$A^+$ 在自动化专业里就是 **最小二乘参数估计**。给定数据矩阵 $H$ 与量测 $y$，参数的最小二乘估计是 $\hat\theta=H^+y$。当数据充足且无共线性（$H$ 列满秩），它退化为 $\hat\theta=(H^{\mathrm T}H)^{-1}H^{\mathrm T}y$；当数据冗余、有共线性（$H$ 秩亏）时，普通求逆失效，只有 $H^+$ 能给出唯一答案。**这就是卡尔曼滤波、系统辨识、自适应控制的共同地基**——$A^+$ 是这门课里最"立竿见影"的一章。

## 四、投影与 Moore 逆：$A^+$ 为什么"最漂亮"

### 为什么？

$A^+$ 的四条方程看起来抽象，但它的几何图像极其干净：**$A^+$ 就是"两次正交投影"的组合**。1920 年 Moore 正是这样定义伪逆的——比 Penrose 的方程形式还早 30 年。理解投影，才算真正理解 $A^+$。

### 怎么做？（记住一张流程图）

```
        b ∈ Cᵐ
         │  ① 向列空间 R(A) 正交投影（丢掉模型解释不了的部分）
         ▼
      AA⁺b ∈ R(A)          ← 最小二乘：最接近 b 的可达输出
         │  ② 在行空间 R(Aᵀ) 中取唯一原像（垂直分量取零）
         ▼
      x̂ = A⁺b ∈ R(Aᵀ)      ← 极小范数：所有原像中最短的那个
```

### 是什么？

> **Moore 定义**：$A^+$ 是唯一满足 $AA^+=P_{\mathcal R(A)}$、$A^+A=P_{\mathcal R(A^{\mathrm T})}$ 的矩阵。这与 Penrose 四方程**等价**。

**三条必记的投影关系**：

$$
AA^+=P_{\mathcal R(A)},\qquad A^+A=P_{\mathcal R(A^{\mathrm T})}=P_{\mathcal N(A)^\perp},\qquad E-A^+A=P_{\mathcal N(A)}
$$

**{1}-逆与 $A^+$ 的几何差别**：{1}-逆给出的 $AA^-$ 是**斜投影**（幂等但不对称），$A^+$ 给出的 $AA^+$ 是**正交投影**（幂等且对称）。**"对称"两个字，就是从"斜"到"正"的那一刀。**

### 生活类比

拍照时，三维世界（$\mathbb{C}^m$）投影到二维照片（$\mathcal R(A)$）上，一定丢信息（垂直于画面的分量）。$A^+$ 干的活是：**先把景物投到画面上（最小二乘），再穿过画面上这一点、沿垂直方向找回一个"最短"的三维原像（最小范数）**。正交投影 = "垂直地投"，斜投影 = "斜着投"——斜面会把画面拉歪，这就是 {1}-逆不够用的原因。

> **数据视角**：$A^+$ 是"**去噪 + 去冗余**"的双重算子。$E-AA^+$ 削掉的 $\mathcal N(A^{\mathrm T})$ 分量是噪声/失配（模型解释不了）；$E-A^+A$ 削掉的 $\mathcal N(A)$ 分量是冗余自由度（不影响输出）。**一次 $A^+$，同时做完两件事**，所以它给出的解既"贴合数据"又"没有多余"。

## 五、广义逆怎么算？

### 为什么？

理论与算例之间隔着一个"怎么算"。工程软件（MATLAB `pinv`、NumPy `pinv`）默认用 SVD；手算小矩阵则用满秩分解或初等变换。**三条路线对应三种需求**：稳定、可推、好算。

### 怎么做？（三法对照）

| 方法 | 一句话原理 | 适用 |
|---|---|---|
| **满秩分解法** | $A=FG\Rightarrow A^+=G^{\mathrm T}(F^{\mathrm T}AG^{\mathrm T})^{-1}F^{\mathrm T}$ | 手算 / 理论推导 |
| **SVD 法** | $A=U\Sigma V^{\mathrm T}\Rightarrow A^+=V\Sigma^+U^{\mathrm T}$（非零奇异值取倒数） | 通用 / 数值最稳 |
| **初等变换法** | 化 $PAQ=J$ 得满秩分解，再套满秩分解法 | 手算小矩阵 |

**三个特例（考试高频）**：

$$
A\ \text{列满秩}:\ A^+=(A^{\mathrm T}A)^{-1}A^{\mathrm T};\qquad
A\ \text{行满秩}:\ A^+=A^{\mathrm T}(AA^{\mathrm T})^{-1};\qquad
A\ \text{对角}:\ A^+=\operatorname{diag}(d_1^+,\dots)
$$

### 是什么？

> **满秩分解**：把秩 $r$ 的 $A$ 写成 $A=FG$，其中 $F$（$m\times r$，列满秩）收集 $A$ 的"列方向"，$G$（$r\times n$，行满秩）收集"行方向"。**它是 $A^+$ 最自然的出发点**——因为 $F^{\mathrm T}F$、$GG^{\mathrm T}$ 都是 $r$ 阶可逆方阵，可放心求逆。

> **SVD 求伪逆口诀**：**"非零奇异值取倒数，零奇异值保持零，$U$ 与 $V$ 互换位置"**。即 $\sigma_i\mapsto 1/\sigma_i$、$\sigma_i=0\mapsto 0$。

**为什么 SVD 法最稳？** 因为 $\sigma_i$ 直接反映 $A$ 在各个方向上的"伸缩倍数"。$A^+$ 只对**不伸不缩为零的方向**（$\sigma_i>0$）求逆，对**被压扁的方向**（$\sigma_i=0$）置零——这正是"沿着可逆方向求逆、沿着奇异方向放弃"的精确表达。

### 生活类比

$A$ 是一个"**有些方向被压扁了的橡皮图章**"。$A^+$ 想把印章还原：**没被压扁的方向，原样拉回来（取倒数）；被压扁成零的方向，认输不还原（保持零）**。SVD 就是给这个图章按"伸缩倍数"排好序的坐标系——所以它求伪逆最直观、最稳定。

> **数值视角**：$A^{\mathrm T}A$ 的条件数是 $A$ 的平方（$\operatorname{cond}(A^{\mathrm T}A)=\operatorname{cond}(A)^2$），手算用 $(A^{\mathrm T}A)^{-1}A^{\mathrm T}$ 也许简单，但**实际软件绝不这样算**——它会把误差放大一倍量级。这就是 `pinv` 用 SVD 的原因：**理论看满秩分解，工程看 SVD**。

## 六、三种"定制版"逆：加权、约束、Drazin

### 为什么？

标准 $A^+$ 假设"所有观测同等可信、所有参数同等重要、矩阵方向可以随便丢"。但工程里这些假设常常不成立：不同传感器精度不同（要**加权**）、未知量必须落在某个子空间内（要**约束**）、要处理有零特征值的方阵且希望逆与 $A$ 可交换（要 **Drazin**）。**三种定制版逆，就是给标准 $A^+$ 装上三个"调节旋钮"**。

### 怎么做？（三种场景对照）

```
① 观测有轻重 → 加权 M-P 逆 A⁺_{M,N}（M 给观测加权，N 给未知量加权）
② 解必须落在某子空间 → 约束广义逆 A⁻c = C(AC)⁺（只在 R(C) 内找最优）
③ 方阵有零特征值、且要求"逆"与 A 可交换 → Drazin 逆 A^D（丢掉零谱部分）
```

### 是什么？

> **加权 M-P 逆 $A^+_{M,N}$**：$M,N$ 正定，把四个 Penrose 方程里的对称条件换成"$MAX$、$NXA$ 对称"。它解加权最小二乘：先 $\min(Ax-b)^{\mathrm T}M(Ax-b)$，再在其中 $\min x^{\mathrm T}Nx$。**$M$ 管"哪条方程更可信"，$N$ 管"哪个未知量更该小"**。

> **约束广义逆 $A^-_c=C(AC)^+$**：把最小二乘限制在子空间 $\mathcal R(C)$ 内求解；推广即带等式约束 $Bx=d$ 的最小二乘问题（Lagrange 乘子法）。

> **Drazin 广义逆 $A^D$**：方阵专属。设 $k=\operatorname{ind}A$，满足 $A^{k+1}X=A^k$、$XAX=X$、$AX=XA$。谱刻画：**$A$ 的 Jordan 形里非零块取逆、零特征值块置零**。$k=1$ 时称群逆 $A^{\#}$。

**关键对照**：

| | $A^+$ | $A^D$ |
|---|---|---|
| 对"不可逆方向"的处理 | 沿奇异方向置零（投影） | 整个零谱部分置零 |
| 与 $A$ 可交换？ | 一般**不可** | **可以**（$AX=XA$） |
| 求解目标 | 最小二乘 + 最小范数 | 沿动力系统求逆、保持交换性 |
| 适用 | 任意长方阵 | 方阵 |

### 生活类比

- 加权逆 = "**考试按学分算总分**"：重要科目（大权）说了算；
- 约束逆 = "**只能在候选名单里挑人**"：再优秀但不在名单内也不用；
- Drazin 逆 = "**只保留可逆的部分**"：把系统里"退化掉的那半"直接删掉，让剩下的部分能像普通逆一样与 $A$ 交换。

> **控制视角**：$A^D$ 在**离散系统与马尔可夫链**里是主角——例如马尔可夫链平稳分布的计算要用 $(E-P)^{\#}$；而 $A^+$ 是**估计与投影**的主角。**要"投影 + 最小范数"用 $A^+$；要"沿动力方向求逆、保持可交换"用 $A^D$**——这就是选用哪把钥匙的判据。

## 七、四类方程组解：一张表打天下

### 为什么？

有了广义逆，第3章那两个"悬案"终于能一次性解决。所有线性方程组 $Ax=b$ 的情形，只由"**$b$ 是否落在 $\mathcal R(A)$ 里**"和"**解是否要求最短**"两问决定，共四种组合。**记住这张表，等于掌握了本章的全部应用**。

### 怎么做？（四类解）

| 情形 | 条件 | 解 | 公式 |
|---|---|---|---|
| ① 相容通解 | $b\in\mathcal R(A)$ | 全部解 | $x=A^-b+(E-A^-A)y$ |
| ② 相容极小范数解 | $b\in\mathcal R(A)$ | 最短的解 | $x=A^+b$ |
| ③ 矛盾最小二乘解 | $b\notin\mathcal R(A)$ | 残差最小的解（通解） | 解 $A^{\mathrm T}Ax=A^{\mathrm T}b$；通解 $x=A^-_{(1,3)}b+(E-A^-_{(1,3)}A)y$ |
| ④ 极小最小二乘解 | 任意 $b$ | 又准又短 | $x=A^+b$ |

**推导锚点（两条，必须会）**：
- 通解 = **特解 + 齐次通解**：$A^-b$ 是特解，$(E-A^-A)y$ 跑遍 $\mathcal N(A)$；
- 最小二乘 = **法方程**：$\nabla\|Ax-b\|^2=0\Rightarrow A^{\mathrm T}Ax=A^{\mathrm T}b$，几何上即"残差 $\perp\mathcal R(A)$"。

### 是什么？

> **极小范数解**：相容时可取无穷多解，其中落在行空间 $\mathcal R(A^{\mathrm T})$ 里、与 $\mathcal N(A)$ 正交的那个最短——它就是 $A^+b$。
>
> **极小最小二乘解**：矛盾时先让残差最小（最小二乘），再在其中让范数最小——它也是 $A^+b$。

**一句话总结**：**不管 $Ax=b$ 有没有解，$A^+b$ 都是那个"又准又短"的标准答案**——有解时退化为极小范数解，无解时成为极小最小二乘解。

### 生活类比

方程组像"**用几条已知信息去猜一个未知量**"：
- 信息一致且够用（相容）→ 但仍可能"猜法"无穷多（如一条方程两个未知数）→ 选最"朴素"的那个（**极小范数**）；
- 信息之间有矛盾（矛盾）→ 不能全信 → 找"总误差最小"的折中（**最小二乘**）；
- 折中也有一堆 → 再选最朴素的（**极小最小二乘**）。
**$A^+$ 就是那位"既会折中、又不啰嗦"的裁判。**

> **数据视角（点睛）**：这张四类解表就是**系统辨识与状态估计的完整剧本**。量测足够且相容 → 通解；方程冗余但相容 → 极小范数解（去冗余）；量测有噪声导致矛盾 → 最小二乘解（$\hat\theta=H^+y$，即最小二乘辨识）；$H$ 秩亏（共线性 / 传感器不足）→ 极小最小二乘解（$A^+$ 保证唯一）。**卡尔曼滤波的测量更新 $\hat x=\hat x^-+K(y-H\hat x^-)$ 中的增益 $K$，正是 $H^+$ 思想的递推形式**——不懂 $A^+$，就看不懂"最优估计"为什么最优。

## 总结：知识体系图

```
广义逆矩阵（给不可逆矩阵定义"逆"）
   │
   ├─ 核心方程：AGA = A（"抵消"）
   │
   ├─ 加码链：方程越多 → 逆越唯一
   │    ├─ {1}-逆 A⁻ ：AGA=A            存在、一般不唯一、斜投影
   │    │     └─ 通式 A{1} = G₀ + (E−G₀A)U + V(E−AG₀)
   │    ├─ 自反逆 A⁻ᵣ ：+ GAG=G          X = GAG 即可构造
   │    ├─ M-P 逆 A⁺ ：+ (AG)ᵀ=AG, (GA)ᵀ=GA   唯一！正交投影 + 最小范数
   │    │     ├─ 性质：列满秩 → 左逆；行满秩 → 右逆
   │    │     ├─ 几何：AA⁺=P_{R(A)}, A⁺A=P_{R(Aᵀ)}（Moore 1920）
   │    │     └─ 算法：满秩分解 / SVD / 初等变换
   │    ├─ 加权逆 A⁺_{M,N}：M,N 加权 → 加权最小二乘
   │    ├─ 约束逆 A⁻c = C(AC)⁺：限制在子空间内
   │    └─ Drazin 逆 A^D：A^{k+1}X=A^k, XAX=X, AX=XA → 丢掉零谱部分
   │
   └─ 应用：线性方程组四类解
        ├─ 相容 → 通解 x=A⁻b+(E−A⁻A)y
        ├─ 相容 + 最短 → 极小范数解 x=A⁺b
        ├─ 矛盾 → 法方程 AᵀAx=Aᵀb（最小二乘通解）
        └─ 任意 + 又准又短 → 极小最小二乘解 x=A⁺b
```

### 核心脉络

1. **一条主线**：普通逆 $\to$ {1}-逆（只保"抵消"）$\to$ 自反逆（去零空间乱动）$\to$ $A^+$（加正交性，唯一）$\to$ 加权/约束/Drazin（按场景定制）。**方程加码 = 候选收敛 = 逼近唯一**。
2. **一个引擎**：满秩分解（理论）与 SVD（数值）是算 $A^+$ 的两条腿；$A^+$ 的核心性质 $(A^{\mathrm T}A)^+A^{\mathrm T}=A^+$ 是所有最小二乘公式的源头。
3. **一张表**：四类方程组解（通解 / 极小范数解 / 最小二乘解 / 极小最小二乘解）统一在本章框架下。
4. **一个出口**：$A^+$ = 最小二乘参数估计 = 卡尔曼滤波与系统辨识的地基——**本章是自动化专业最"立竿见影"的一章**。

> 广义逆是"手算 + 直觉"双修的章节，实践任务是**把每个定义方程亲手验一遍**。

1. **验四方程**：取 $A=\begin{bmatrix}1&2\\2&4\end{bmatrix}$，先算 $A^+=\frac1{25}\begin{bmatrix}1&2\\2&4\end{bmatrix}$，再逐条验 $AGA=A$、$GAG=G$、$AG$ 对称、$GA$ 对称——**亲手确认"验过四条即唯一"的手感**。

3. **四类解对照**：用同一个 $A$、两个不同的 $b$（一个相容、一个矛盾），写出四种解，画出"$b$ 的投影分解图"，看清 $AA^+b$ 与 $(E-AA^+)b$ 各是什么。

5. **控制连接（选做）**：构造一个简单的线性回归数据 $(H,y)$，用 $H^+y$ 做最小二乘参数估计，再人为制造共线性（让 $H$ 秩亏），观察普通 $(H^{\mathrm T}H)^{-1}$ 失效而 $H^+$ 仍能给出唯一解——**亲手触摸"卡尔曼滤波的地基"**。

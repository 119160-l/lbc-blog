## 一、正定矩阵与正稳定矩阵

### 为什么？

工程里两类问题反复出现：

- **二次型恒正**（能量、最小二乘、广义特征值 $Ax=\lambda Bx$ 要求 $B$ 正定）：需要一个矩阵"处处为正"；
- **动态系统稳定**（$\dot x=Ax$ 渐近稳定）：需要全部特征值落在左半开平面。

这两件事看似无关，实则是本章的起点：**正定管"形"，正稳定管"位"**。有了它们，判定问题就能从"算特征值"降级为"查行列式"或"解一个矩阵方程"。

### 怎么做？

```
① 判正定：先看是否 Hermite；再用 Sylvester 判据（顺序主子式全正）
② 判正稳定：解 Lyapunov 方程 A^H P + P A = -Q，找正定解 P
③ 二者联系：A 正稳定 ⟺ 存在正定 P、Q 满足 Lyapunov 方程
④ 计算实现：正定 ⟺ Cholesky 分解能顺利进行（主元全正）
```

### 是什么？

> **正定矩阵**：Hermite 矩阵 $A$ 若对一切 $x\ne0$ 都有 $x^HAx>0$，称正定。等价于"全部特征值为正"，等价于"各阶顺序主子式为正"（Sylvester 判据）。
>
> **正稳定矩阵**：若 $A$ 的全部特征值实部都小于零，称正稳定。等价于"存在正定矩阵 $P$ 使 $A^HP+PA<0$"。

### 生活类比

正定像"**处处向上的碗**"——不管球放在哪里，势能 $x^HAx$ 都为正，系统有唯一的稳定最低点（最小二乘、凸优化都靠它）。正稳定像"**带阻尼的弹簧**"——不管初始扰动多大，位移都随时间衰减到零（特征值实部为负 = 能量一直在耗散）。

> **数值视角**：Sylvester 判据把"验证无穷多个不等式的二次型"变成"计算有限个行列式"；而计算这些行列式的过程恰好就是 Cholesky 分解。所以数值软件判断正定，底层就是"试着做 Cholesky，主元全正就算通过"。

## 二、对角占优矩阵

### 为什么？

大规模线性方程组 $Ax=b$ 是工程计算的主角。我们最想知道的不是精确解，而是三件事：**$A$ 可不可逆（解是否存在且唯一）？用不用选主元（算法稳不稳）？迭代法收不收敛？** 对角占优矩阵用一个"看元素就能查"的条件，把这三件事一次答完。

### 怎么做？

```
① 逐行求和比较：|a_ii| 是否 > 同行其他元素绝对值之和？
② 是 → 立即得到：A 可逆；Gauss 消去不用选主元；Jacobi/G-S 迭代收敛
③ 检查 Jacobi 迭代矩阵：‖B_J‖∞ = max_i Σ_{j≠i}|a_ij|/|a_ii| < 1
④ 迁移到谱：Gershgorin 圆盘把特征值圈住，0 不在圆盘内 ⇒ 可逆
```

### 是什么？

> **严格对角占优矩阵**：若 $|a_{ii}|>\sum_{j\ne i}|a_{ij}|$ 对每行成立，称严格对角占优。它是**可逆性、Gauss 消去稳定性、迭代法收敛性**的一个统一充分条件。

### 生活类比

对角占优像"**班里的主心骨**"：每一行里，对角线元素（班长）说话的分量，比这一行其他人加起来还重。正因为"主心骨压得住阵"，整个系统不会乱——矩阵不会奇异，消元不会中断，迭代不会发散。

> **控制视角**：判可逆时不必算特征值——只要每行"对角元压得住整行"，$0$ 就一定不是特征值（Gershgorin 圆盘不包含原点），矩阵必然可逆。这是"用一行加法代替一次特征值求解"的经典便宜买卖。

## 三、非负矩阵与 Perron–Frobenius 定理

### 为什么？

很多实际矩阵的元素天然非负：**概率转移矩阵**（马尔可夫链）、**投入产出矩阵**（经济学）、**网页链接矩阵**（PageRank）、**种群模型**。非负性带来了一个普通矩阵没有的奇迹：**最大模特征值一定是正的、一定存在正的（Perron）特征向量**。有了它，网络的"长期稳态"就有了保证。

### 怎么做？

```
① 判非负/正：元素是否全 ≥0 / >0？
② 判不可约：把 A 看成有向图，是否强连通？
③ 求 Perron 根：ρ(A)，它必是 A 的特征值，对应正特征向量
④ 判素（本原）：是否存在 k 使 A^k > 0？等价于 ρ(A) 唯一的等模特征值
⑤ 用幂迭代求稳态：x ← Ax / 归一化，反复迭代即收敛到 Perron 向量
```

### 是什么？

> **Perron–Frobenius 定理（不可约非负矩阵）**：存在正实数特征值 $\rho(A)$（Perron 根），它对应一个**正**特征向量（Perron 向量），且 $\rho(A)$ 是**单**特征值，其余特征值模都不超过它。若 $A$ 还是素矩阵（某次幂为正），则其余特征值模**严格**小于 $\rho(A)$。

### 生活类比

非负矩阵像"**只进不退的投票网络**"：每个网页把票投给别的网页，票数只能累加不能变负。Perron 根就是"整个网络票数总量的最大增长率"，Perron 向量就是"长期稳定后各网页的票数占比"——这正是 PageRank 排名。

> **网络视角**：PageRank 的整个算法就一句话——把网页链接矩阵做成非负（且正）的 Google 矩阵 $G=\alpha P+\frac{1-\alpha}{n}E$，由 Perron–Frobenius 保证存在唯一平稳分布 $\pi>0$，再用幂迭代求出 $\pi$。**非负矩阵的正性，换来了排名的存在性与唯一性。**

## 四、M 矩阵与广义 M 矩阵

### 为什么？

数值计算里还有一类矩阵特别常见：**对角元为正、非对角元非正**（称 Z 矩阵）。离散化的微分方程、电路网络、投入产出模型都是这个形状。M 矩阵就是这类矩阵里"最好的一族"——它们的逆矩阵元素全非负，从而**自动保证正稳定与迭代收敛**。

### 怎么做？

```
① 确认是 Z 矩阵：非对角元是否 ≤0？
② 试找形式 A = sI - B（B≥0, s>ρ(B)）
③ 或直接查更省事的条件：
   - A^{-1} 是否 ≥0？          （逆非负）
   - 是否存在 x>0 使 Ax>0？    （正向量条件）
   - 各阶顺序主子式是否全正？    （行列式条件）
   - 是否严格对角占优且对角元正？（对角占优充分条件）
④ 对称 M 矩阵 ⇒ 正定；M 矩阵 ⇒ 正稳定
```

### 是什么？

> **M 矩阵**：Z 矩阵 $A$ 若可写成 $A=sI-B$（$B\ge0$，$s>\rho(B)$），称非奇异 M 矩阵。等价刻画很多，最常用的是"$A^{-1}\ge0$"。**广义 M 矩阵**放宽为 $s\ge\rho(B)$（允许奇异）。

### 生活类比

M 矩阵像"**友好的负相关系统**"：变量之间是互相"抵消"的关系（非对角元 $\le0$），但对角（自身）足够强。这样的系统扰动后会自然回到平衡，逆矩阵全非负意味着"你推它一下，它朝所有方向都给出正向响应"——稳定、单调、可预测。

> **数值视角**：M 矩阵的三条判据各有便宜之处——"逆非负"最直观、"正向量条件"最好验算、"对角占优"最省事。判迭代法收敛时，先看对角占优；判稳定性时，看 $A^{-1}\ge0$ 或特征值实部；判正定时（对称情形）直接上 Sylvester。**一族矩阵，多把钥匙。**

## 五、Toeplitz 矩阵及其有关矩阵

### 为什么？

信号处理的每一次滤波、每一次卷积，背后都是一个 Toeplitz 矩阵。它的元素"沿对角线相同"——这种**平移不变结构**意味着：$n\times n$ 的矩阵只需存 $2n-1$ 个数，乘法可以用 FFT 在 $O(n\log n)$ 完成，而不是 $O(n^2)$。**结构换来的，是存储和速度的双重红利。**

### 怎么做？

```
① 认结构：是否每条对角线元素相同（a_ij = t_{j-i}）？
② 数参数：独立参数为 2n-1 个（第一行 + 第一列去掉公共元）
③ 做乘法：Tx 就是与核 r_p = t_{-p} 的卷积
④ 循环情形：C = circulant ⇒ C = FΛF^H，乘法用 FFT（O(n log n)）
⑤ 联系 Hessenberg/Hankel：翻转或降阶可互相转化
```

### 是什么？

> **Toeplitz 矩阵**：满足 $a_{ij}=t_{j-i}$ 的矩阵，沿每条对角线元素相同，由第一行与第一列（共 $2n-1$ 个独立参数）决定。**矩阵—向量乘法等价于卷积**：$Tx=r*x$。

### 生活类比

Toeplitz 矩阵像"**印花的滑窗**"：同一块花纹（冲激响应）在信号上从左滑到右，每次叠加出一点输出——这正是卷积，也正是滤波器的工作方式。循环矩阵则像"**绕圈跑道**"：跑到尽头自动接回起点，于是能用 Fourier 分解把它彻底"解开"。

> **信号视角**：数字滤波器对信号的作用就是 $y=h*x$；写成矩阵正是 $y=\mathcal{T}(h)x$。**FIR 滤波 = Toeplitz 乘法 = 卷积**。而 Toeplitz 线性方程组（如谱估计、反卷积）能用 Levinson 递推快速求解，$O(n^2)$ 代替 $O(n^3)$——这就是结构的力量。

## 六、其他特殊矩阵

### 为什么？

还有一些"小而美"的结构，各自对应一类运算：**Hankel**（反对角线相同，系统辨识）、**Hessenberg**（近似三角，特征值算法）、**循环矩阵**（Fourier 对角化）、**幂等**（投影）、**幂零**（Jordan 形）。它们让抽象的矩阵理论落到具体算法上。

### 怎么做？

```
① Hankel：反对角线元素相同，2n-1 个参数；翻转列即得 Toeplitz
② Hessenberg：i>j+1 全零（上）；QR 算法先化到 Hessenberg 形再迭代
③ 循环矩阵：每行循环右移；用 Fourier 矩阵对角化，特征值为 p(ω^k)
④ 幂等 A²=A：特征值 ∈{0,1}，可对角化，rank = tr A
⑤ 幂零 A^k=0：特征值全为 0，迹、行列式均为 0，幂零指数 ≤ n
```

### 是什么？

> **幂等矩阵**：$A^2=A$，特征值只能为 $0$ 或 $1$，相似于 $\operatorname{diag}(I_r,0)$，$\operatorname{rank}A=\operatorname{tr}A$。
>
> **幂零矩阵**：存在 $k$ 使 $A^k=0$，特征值全为 $0$，$\operatorname{tr}A=\det A=0$。

### 生活类比

幂等像"**投影的影子**"：把物体投到墙上，再投一次位置不变（$A^2=A$）——特征值 $1$ 表示"留在平面内"，$0$ 表示"被压掉"。幂零像"**逐级消失的台阶**"：每乘一次 $N$ 就"下坠一级"，有限步后彻底归零。

## 总结：知识体系图

```
特殊矩阵（结构带来结论）
   │
   ├─ 正定矩阵 ── 二次型恒正
   │    └─ Sylvester 判据 Δk>0 ⇔ 特征值全正 ⇔ Cholesky 可做
   │
   ├─ 正稳定矩阵 ── 特征值实部全负
   │    └─ Lyapunov：A^H P + P A = −Q 有正定解
   │
   ├─ 对角占优矩阵 ── |a_ii| > Σ|a_ij|
   │    └─ 可逆 · Gauss 不选主元 · Jacobi/G-S 收敛 · Gershgorin
   │
   ├─ 非负矩阵 ── 元素全 ≥0
   │    ├─ 不可约 ⇒ 强连通
   │    └─ Perron–Frobenius：Perron 根 ρ(A) + 正 Perron 向量
   │         └─ 马尔可夫链 · PageRank · 投入产出
   │
   ├─ M 矩阵 ── A = sI − B (B≥0, s>ρ(B))
   │    └─ A^{-1}≥0 ⇔ 正稳定 ⇔ 顺序主子式正 ⇔ ∃x>0, Ax>0
   │         └─ 对称 M 矩阵 ⇒ 正定；迭代收敛 · 稳定性判定
   │
   ├─ Toeplitz 矩阵 ── a_ij = t_{j−i}，2n−1 个参数
   │    ├─ 乘法 = 卷积（Tx = r*x）
   │    └─ 循环矩阵 = FΛF^H ⇒ FFT (O(n log n))
   │         └─ 信号处理 · 滤波器设计 · 快速卷积
   │
   └─ 其他：Hankel · Hessenberg · 循环 · 幂等 · 幂零
```

### 核心脉络

1. **结构换结论**：正定换"行列式判据"，对角占优换"可逆与收敛"，非负换"Perron 根存在"，M 矩阵换"逆非负、正稳定"，Toeplitz 换"$2n-1$ 参数 + 卷积"；
2. **一条暗线串起全章**：**稳定性**与**非负性**。M 矩阵把"非负逆矩阵"和"特征值实部为正"画上等号，正稳定把"Lyapunov 正定解"和"左半平面"画上等号，Perron 把"非负性"和"最大特征值"画上等号；
3. **三条工程出口**：非负矩阵 → 马尔可夫链与 PageRank；M 矩阵/对角占优 → 迭代法收敛与稳定性；Toeplitz → 信号处理与滤波器设计。

## 动手实践（本章任务）

> 本章是选学章，实践任务的目标是"**把这些结构亲手验一遍**"，不涉及复杂编程。

1. **判据互验**：对同一个 $3\times3$ 矩阵 $A=\begin{bmatrix}2&-1&0\\-1&2&-1\\0&-1&2\end{bmatrix}$，分别用"顺序主子式""$A^{-1}\ge0$""存在 $x>0$ 使 $Ax>0$""严格对角占优"四条路径判定它是不是 M 矩阵，体会"多把钥匙开一把锁"。
2. **Perron 根实验**：对非负矩阵 $A=\begin{bmatrix}0&1&1\\1&0&1\\1&1&0\end{bmatrix}$ 做幂迭代（任取正向量 $x_0$，反复算 $x_{k+1}=Ax_k/\|Ax_k\|$），观察 $x_k$ 是否收敛到 $(1,1,1)/\sqrt3$、比值是否收敛到 $2=\rho(A)$。
3. **卷积即乘法**：自选一个冲激响应核 $h$，构造对应 Toeplitz 矩阵 $\mathcal{T}(h)$，用手算验证 $\mathcal{T}(h)x$ 与卷积 $h*x$ 完全一致（可参考公式推导算例 7）。

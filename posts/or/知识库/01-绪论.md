# 第1章 绪论

> 教材章节：第1章　｜　难度：★　｜　题型：概念题、简答题为主

## 一、本章定位

第1章是纯概念章，考试通常出**填空、选择、简答**，分值不高但**几乎必考**。核心就三件事：运筹学是什么、怎么工作、用在哪。

---

## 二、运筹学的产生与发展

### 2.1 名称的由来

- **起源时间**：20 世纪 30 年代末
- **背景**：英美为对付德国空袭，研发了雷达防空系统，但实际运用效果不理想，于是科学家开始研究**如何合理运用雷达系统**
- **命名**：因为研究的问题不同于一般技术问题（研究的是"运用"而非"制造"），故称 **operational research**（运作研究），后改用 **operations research**，缩写 **OR**

### 2.2 二战期间的经典军事研究（易考举例）

| 研究问题 | 成果 |
|---|---|
| 护航舰队的编队问题 | 船队遭受敌方潜艇攻击时，如何使损失减到最少 |
| 反潜深水炸弹的合理爆炸深度 | 使敌方潜艇被摧毁数量**增加 400%** |
| 船只在受敌机攻击时的规避方法 | 使船只中弹率由 **47% 降到较低水平** |

### 2.3 战后的发展

- 除军事外，运筹学与系统分析（SA）在工业、农业、经济和社会问题各领域应用，常合称 **SA/OR**
- **运筹数学飞速发展**，形成众多分支：数学规划（线性规划、非线性规划、整数规划、目标规划、动态规划、随机规划等）、图论与网络、排队论、存储论、对策论、决策论、维修更新理论、搜索论、可靠性和质量管理等

### 2.4 推动运筹学战后迅速发展的三个因素 ★（简答高频）

1. **经济社会需求**：战后很多国家在经济发展和企业经营管理方面对运筹学研究和方法产生了需求，大量科学家进入该领域
2. **运筹数学的突破**：1947 年 **Dantzig 提出线性规划与单纯形法**，为运筹学应用提供了坚实的数学理论
3. **计算机的出现与普及**：电子计算机快速发展、运筹学算法软件包出现；进入 21 世纪后 Excel 等电子表格软件已能求解多种运筹学问题，使方法迅速普及

> 记忆点：**线性规划是运筹学最重要的分支**——可以说正是线性规划的提出和成功应用，才成就了运筹学辉煌的今天。

### 2.5 软运筹学的崛起（20 世纪 80 年代末，主要发源地英国）

1989 年英国运筹学学会开会，后由 **Rosenhead** 主编论文集（被称为软运筹学的"圣经"），代表方法：

| 缩写 | 全称 |
|---|---|
| SSM | 软系统方法论 |
| SAST | 战略假设表面化与检验 |
| SC | 战略选择 |
| PSM | 问题结构法 |
| Hypergame | 超对策 |
| Metagame | 亚对策 |
| SODA | 战略选择发展与分析 |
| VSM | 生存系统模型 |
| IP | 对话式计划 |
| CSH | 批判式系统启发 |

另一趋势是**软计算**：不追求严格最优，具启发式思路，借用来自生物学、物理学等的思想。

## 三、运筹学的定义与特点

### 3.1 定义

**运筹学**：对生产、管理等活动中出现的优化问题加以提炼，然后利用数学方法进行解决的学科。它利用统计学、数学模型和算法等方法，寻找在一定条件下满足某种最优性质的解，常用于改善或优化现有系统的效率。

### 3.2 三个特点 ★

| 特点 | 内涵 |
|---|---|
| **科学方法** | 建立数学模型，假设从模型得到的结论（解）对实际问题有效；通过实验检验假设是否适当并修改（**模型验证**） |
| **整体视角** | 把组织视为一个整体，研究如何以**对整个组织最有利**的方式解决各部分之间的利益冲突；寻求与整个组织一致的目标，而非局部最优 |
| **寻求最优** | 从数学模型中搜索"一个最优解"（注意：是**一个**最优解，不是唯一最优解，因为可能存在多个最优解）；目的不是简单改善现状，而是帮助管理者决策 |

### 3.3 最优解 vs 满意解 ★（易考简答）

- 已故管理学家 **赫伯特·西蒙**指出："在实践中，**满意解比最优解更为普遍**。"
- 西蒙认为管理者具有寻求"**足够好**"的解决方案的倾向：可根据过去绩效水平或竞争对手成绩设定目标，确定各领域的最低满意绩效水平
- 英国先驱者 **塞缪尔·艾伦**："**最优是终极的科学，满意是可行的艺术。**"
- 结论：运筹学研究的目标应该是**追求最优**，同时还应考虑研究实施的可行性

## 四、运筹学的工作步骤 ★（必背）

| 步骤 | 关键内容 |
|---|---|
| **① 明确问题与目标** | 首先必须确定**管理层的成员都有谁、谁将作出决策**；从一开始就应让决策者参与，这对结果能否得到最终决策者支持至关重要。确定目标时应关注**整个组织**的利益而非某一部分 |
| **② 收集数据** | 可能需要大量数据；研究初期数据常无法获得（从未保存过，或过时/格式错误）；可能需要建立新的**以计算机为基础的管理信息系统**持续收集数据。大数据时代的问题往往是**数据太多**而非太少 |
| **③ 建立数学模型** | 数学模型最显著的优点：更简洁地描述问题、有助于理解整体结构、揭示重要因果关系、搭建利用数学技术和计算机分析问题的桥梁 |
| **④ 模型验证** | 模型是现实问题的抽象化与理想化，必然含近似与简化假设（如线性假设、正态分布假设）；必须确保假设下模型仍是研究对象的**有效表示**。方法是收集额外数据检验 |
| **⑤ 求解** | 用适当算法求出模型的最优解；同时进行**敏感性分析**——当参数发生变化时，从模型中求出的解会如何变化 |
| **⑥ 方案实施与反馈** | 向运营管理层详细解释新系统；共同制定运行所需程序；对相关人员进行培训并启动新方案；**初始阶段应进行监控，获得经验**，确定将来可能的修改 |

### 建模的陷阱（易考）

- 由于数学模型是现实问题的抽象化和理想化，通常会进行必要的**近似或简化假设**（线性假设、正态分布假设等）
- **必须确保作出这些假设时，模型仍然是对所要研究对象的有效表示**
- 判断模型有效性的关键：模型是否经过了描述和测试，若通过了，则得到的解应是实际问题理想方案的良好近似

### 模型验证的方法

1. **重新审视整个模型**：检查是否存在明显错误或疏忽；审查时最好在小组中包括**至少一名没有参与模型设计的人**（避免"只见树木不见森林"）
2. **改变参数/决策变量的值**，检查模型输出是否合理
3. **回顾性测试**：使用历史数据"重现过去"，比较模型输出与实际情况

### 可复制性

一项研究到达终点时，运筹学小组应**清楚、准确地将全部过程特别是方法用文档记录**，使其工作具有可复制性。**可复制性应该是运筹学研究人员职业道德规范的重要组成部分**，在从事可能引发争议的公共政策问题研究时尤为关键。

## 五、运筹学的应用（10 个领域）

1. **生产计划与库存管理**：生产计划的编制、库存水平的确定
2. **运输与配送**：运输路线、车辆调度
3. **人员分配**：各类**指派问题**
4. **人员的合理利用**
5. **人才评价**：如何测定一个人对组织、社会的贡献
6. **工资和津贴的确定**
7. **设备维修、更新和可靠性，项目选择和评价**
8. **工程的优化设计**：建筑、电子、光学、机械、化工等领域
9. **计算机和信息系统**：内存分配、不同排队规则对磁盘工作性能的影响；用整数规划寻找满足一组需求文件的寻找次序；用图论、数学规划研究计算机信息系统自动设计
10. **城市管理**：紧急服务系统（救火站、救护车、警车）分布点的设立；城市垃圾清扫、搬运和处理；城市供水和污水处理系统

> 案例记忆点：美国曾用**排队论**方法确定纽约市紧急电话站的值班人数；加拿大曾研究一座城市警车的配置与负责范围、出事故后警车应走的路线。

### 中国的应用历程

- 1965 年起，**统筹法**应用于建筑业、大型设备维修计划
- 1970 年起，全国大部分省市推广**优选法**：配方和配比选择、生产工艺条件选择、工艺参数确定、工程设计参数选择、仪器仪表调试
- 20 世纪 70 年代中期，**最优化方法**在工程设计界受重视：光学设计、船舶设计、飞机设计、变压器设计、电子线路设计、建筑结构设计、化工过程设计
- 70 年代中期起，**排队论**应用于矿山、港口、电信和计算机设计；**图论**用于线路布置、计算机设计、化学物品存放；**存储论**于 70 年代末在汽车工业等部门取得成功
- 近年趋势：研究规模大而复杂的问题（部门计划、区域经济规划），**已与系统工程难以分解**

## 七、本章考点提示

- **必背**：OR 缩写与由来、三个推动因素、三个特点、六步工作步骤
- **易考简答**："最优解与满意解"（记住西蒙和艾伦两句话）
- **易考举例**：二战军事研究的具体成果（400%、47%）、软运筹学方法缩写（SSM、SAST、SODA、VSM 等）

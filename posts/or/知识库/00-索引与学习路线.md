## 二、本书的知识骨架（先建立全局观）

运筹学这 14 章不是并列的，它们之间有清晰的**逻辑依赖**：

```
                    ┌─────────────────────────────┐
                    │   第2章 线性规划（地基）      │
                    │   单纯形法 = 一切的基础       │
                    └──────────┬──────────────────┘
                               │
              ┌────────────────┼────────────────┐
              ▼                ▼                ▼
      ┌──────────────┐  ┌──────────────┐  ┌──────────────┐
      │ 第3章 对偶理论 │  │ 第4章 运输问题 │  │ 第6章 整数规划 │
      │ 影子价格/灵敏度│  │ 表上作业法    │  │ 分支定界/匈牙利│
      └──────┬───────┘  └──────────────┘  └──────────────┘
             │
             ▼
      ┌──────────────┐
      │ 第5章 目标规划 │  ← 多目标版 LP
      └──────────────┘

      ┌──────────────┐  ┌──────────────┐
      │第7章 非线性规划│  │第8章 动态规划 │  ← 「非线性 / 分阶段」两条独立主线
      └──────────────┘  └──────────────┘

      ┌───────────────────────────────────────┐
      │  第9章 图与网络 → 第10章 网络计划        │  ← 图论主线（物流核心）
      └───────────────────────────────────────┘

      ┌──────────┬──────────┬──────────┬──────────┐
      │11章 排队论│12章 存储论│13章 对策论│14章 决策论│  ← 随机/不确定场景四章
      └──────────┴──────────┴──────────┴──────────┘
```

**三条主线**：
1. **确定性优化主线**（第2、3、4、5、6章）：从线性规划出发，扩展到对偶、运输、多目标、整数。**考试大头，必须手算熟练。**
2. **算法进阶主线**（第7、8章）：非线性规划（K-T 条件）与动态规划（分阶段决策），理论性最强。
3. **网络与随机主线**（第9-14章）：图与网络、网络计划、排队、存储、对策、决策。**物流专业的主战场。**

## 三、学习路线建议（按你的情况定制）

### 阶段一：打地基（约 1 周）
**第2章 → 第3章**
- 第2章的单纯形法必须做到「给一个 LP 就能自己列表迭代到最优」，这是后面所有章节的工具
- 第3章吃透两件事：**对偶变换的配对规则**、**影子价格的经济含义**
- 这两章占到课程总分的 30% 以上，投入产出比最高

### 阶段二：物流核心（约 1.5 周）
**第4章 → 第9章 → 第12章 → 第10章 → 第11章**
- 第4章运输问题的「伏格尔法求初解 + 位势法检验 + 闭回路调整」是标准三段式，套路极固定
- 第9章重点：最短路（Dijkstra/Floyd）、最大流（标号法）、最大流最小割定理
- 第12章存储论公式多但结构清晰，按「允许/不允许缺货 × 瞬时/逐渐补充」四象限记忆
- 第10章 CPM 全流程 + 时差计算；第11章 M/M/1、M/M/c 公式

### 阶段三：覆盖剩余（约 1 周）
**第6章 → 第8章 → 第13章 → 第14章 → 第5章 → 第7章 → 第1章**
- 第6章匈牙利法是死套路，背下来就能拿分
- 第8章动态规划难在**建模**（定阶段、定状态、写递推式），建议集中刷 5~8 道不同类型题
- 第13、14章以理解和判断为主，计算量小
- 第5、7章按课堂要求掌握即可
- 第1章纯记忆，考前一晚看

## 六、三轮复习法（建议）

| 轮次 | 时间 | 目标 | 主要材料 |
|---|---|---|---|
| **第 1 轮：通读建框架** | 考前 2~3 周 | 搞清每章在解决什么问题、方法之间什么关系 | 本索引的「知识骨架图」+ 各章文件的一、二节 |
| **第 2 轮：套路上手** | 考前 1~2 周 | 每类题型能独立走完流程 | 各章「完整例题演算」+ `附录B` 的解题流水线 |
| **第 3 轮：刷题与纠错** | 考前 3~5 天 | 手算准确率与速度 | 各章自测题 + `附录A` 公式速查 + `附录C` 代码校验 |

**第 3 轮的关键动作**：手算 → 代码验算 → 对不上就查 `附录B` 易错点 → 重做。这样每一道错题都能转化成一条明确的"以后不犯"的规则。

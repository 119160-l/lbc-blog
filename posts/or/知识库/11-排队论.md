# 第11章 排队论

> 教材章节：第11章　｜　难度：★★★★　｜　题型：M/M/1 与 M/M/c 指标计算、Little 公式、系统最优化（**公式多，靠记+套用**）
> 智慧物流相关度 ★★★★（仓库装卸窗口、客服坐席、车辆排队、口岸通关）

---

## 一、本章定位

排队论（Queuing Theory）研究**随机到达的顾客**与**服务能力有限的服务台**之间的矛盾：服务台太多则浪费成本，太少则顾客排队等待造成损失。核心任务是**在两者之间找平衡**。

**物流场景**：仓库月台数量、分拣线数量、客服坐席数量、收费站通道数、配送车辆装卸排队。

---

## 二、排队系统的三个基本组成部分 ★★★

| 组成部分 | 内容 |
|---|---|
| **① 输入过程** | 顾客到达的规律（到达间隔时间的分布） |
| **② 排队规则** | 顾客到达后如何排队与接受服务 |
| **③ 服务机构** | 服务台的数量、服务时间的分布、服务方式 |

### 2.1 输入过程的分类

- 按**顾客源**：有限源 / 无限源
- 按**到达方式**：单个到达 / 成批到达
- 按**到达间隔分布**：定长分布 $D$、负指数分布 $M$（泊松流）、$k$ 阶爱尔朗分布 $E_k$、一般分布 $G$

### 2.2 排队规则 ★

| 规则 | 含义 |
|---|---|
| **损失制** | 顾客到达时若服务台全忙，**立即离开**（如电话占线） |
| **等待制** | 顾客到达时若服务台全忙，**排队等待** |
| **混合制** | 系统容量有限，**排满后新顾客离开**（兼有等待制与损失制） |

**等待制的服务顺序**：
- **FCFS**（先到先服务，最常见）
- **LCFS**（后到先服务，如电梯、堆栈式仓库）
- **SIRO**（随机服务）
- **PR**（优先权服务，如急诊、VIP）

### 2.3 服务机构的分类

- **服务台数**：单台 $c=1$ / 多台 $c>1$（多台又分**并联**与**串联**）
- **服务时间分布**：定长 $D$、负指数 $M$、$k$ 阶爱尔朗 $E_k$、一般 $G$
- **服务方式**：单个服务 / 成批服务

### 2.4 Kendall 记号 ★★★

用 $X/Y/Z/A/B/C$ 六个符号描述排队系统：

| 位置 | 含义 | 常见取值 |
|---|---|---|
| $X$ | 到达间隔时间的分布 | $M$（负指数/泊松）、$D$（定长）、$E_k$（$k$ 阶爱尔朗）、$G$（一般） |
| $Y$ | 服务时间的分布 | 同上 |
| $Z$ | 服务台的数目 | $1, 2, 3, \dots$ |
| $A$ | 系统容量（含正在服务的） | $\infty$ 或具体数 |
| $B$ | 顾客源数目 | $\infty$ 或具体数 |
| $C$ | 服务规则 | FCFS / LCFS / SIRO / PR |

> 通常只写前 3~5 项。例：**$M/M/1/\infty/\infty$** 就是最经典的"泊松到达、负指数服务时间、单服务台、容量无限、顾客源无限、先到先服务"。（通常简写为 $M/M/1$）

## 三、到达间隔与服务时间的分布

### 3.1 泊松流（最简单流）★★

**定义**：若顾客到达满足
$$P\{N(t) = n\} = \frac{(\lambda t)^n}{n!}\,e^{-\lambda t},\qquad n = 0,1,2,\dots$$
则称到达过程为**参数为 $\lambda$ 的泊松流**（$\lambda$ 为单位时间平均到达人数）。

**关键性质**：
1. **平稳性**：$[t, t+\Delta t]$ 内到达 $n$ 人的概率只与 $\Delta t$ 有关，与 $t$ 无关
2. **无后效性**：不相交时间区间内到达人数相互独立
3. **普通性**：充分小的时间内至多到达 1 人

**等价结论（重要）**：**泊松流的到达间隔时间服从参数为 $\lambda$ 的负指数分布**：
$$f(t) = \lambda e^{-\lambda t}\ (t \ge 0),\qquad E(T) = \frac{1}{\lambda},\qquad D(T) = \frac{1}{\lambda^2}$$

### 3.2 泊松流的可加性

若 $k$ 个独立的泊松流分别以 $\lambda_1, \lambda_2, \dots, \lambda_k$ 到达，则它们的**合成流**仍是泊松流，参数为
$$\lambda = \sum_{i=1}^{k}\lambda_i$$

### 3.3 负指数分布

$$f(t) = \mu e^{-\mu t}\ (t \ge 0),\qquad E(T) = \frac{1}{\mu},\qquad D(T) = \frac{1}{\mu^2}$$

其中 $\mu$ 为**服务率**（单位时间能服务的人数）。

**无记忆性**：$P(T > t + s \mid T > s) = P(T > t)$——"已经等了 $s$ 时间"不影响还要再等多久。这是负指数分布独有的性质，也是排队论能用马尔可夫链建模的根本原因。

### 3.4 爱尔朗分布

$k$ 阶爱尔朗分布 $E_k(t)$ 可看作 $k$ 个独立的同参数负指数分布之和：
$$E(T) = \frac{1}{\mu},\qquad D(T) = \frac{1}{k\mu^2}$$
- $k=1$ → 即负指数分布
- $k \to \infty$ → 趋近定长分布 $D$（方差为 0）

> 含义：$k$ 越大，服务时间越"稳定"（波动越小）。

## 四、单服务台负指数分布排队系统（M/M/1）★★★★

### 4.1 系统参数

设到达率 $\lambda$、服务率 $\mu$，则**服务强度（系统利用率）**：
$$\rho = \frac{\lambda}{\mu}$$

**稳定条件**：$\rho < 1$（即 $\lambda < \mu$），否则队列会无限增长。

### 4.2 核心公式 ★★★

**系统中有 $n$ 个顾客的概率**：
$$P_0 = 1 - \rho,\qquad P_n = (1-\rho)\rho^n \quad (n \ge 1)$$

**系统平均顾客数（队长）**：
$$L_s = \frac{\lambda}{\mu - \lambda} = \frac{\rho}{1-\rho}$$

**队列平均顾客数（排队等待的）**：
$$L_q = \frac{\lambda^2}{\mu(\mu - \lambda)} = \frac{\rho^2}{1-\rho}$$

**平均逗留时间（含排队 + 服务）**：
$$W_s = \frac{1}{\mu - \lambda}$$

**平均等待时间（不含服务）**：
$$W_q = \frac{\lambda}{\mu(\mu - \lambda)} = \frac{\rho}{\mu - \lambda}$$

### 4.3 Little 公式（普适，对任何排队系统都成立）★★★

$$\boxed{\ L_s = \lambda W_s,\qquad L_q = \lambda W_q\ }$$

**四个指标的关系**：
$$L_s = L_q + \rho = L_q + \frac{\lambda}{\mu},\qquad W_s = W_q + \frac{1}{\mu}$$

> **实用价值**：只要知道两个指标（通常用 Little 公式把"时间"换算成"人数"），其余全部可以推出。考试中**算错一处也能用 Little 公式救回来**。

### 4.4 其他常用概率

| 指标 | 表达式 |
|---|---|
| 系统空闲（不用排队）的概率 | $P_0 = 1-\rho$ |
| 系统中有 1 个顾客的概率 | $P_1 = (1-\rho)\rho$ |
| 顾客到达需等待（系统非空）的概率 | $1 - P_0 = \rho$ |
| 系统中至少有 $k$ 个顾客的概率 | $P(n \ge k) = \rho^k$ |
| 队长超过 $k$ 的概率 | $P(n > k) = \rho^{k+1}$ |

### 4.5 完整例题演算 ★★★

**例 11-1**　某快递驿站，顾客平均每小时到达 4 人（泊松流），服务台平均每小时服务 5 人（负指数服务时间）。求各项运行指标。

**解**：$\lambda = 4$ 人/h，$\mu = 5$ 人/h
$$\rho = \frac{\lambda}{\mu} = \frac{4}{5} = 0.8 < 1 \quad \text{（稳定）}\ ✅$$

| 指标 | 计算 | 结果 |
|---|---|---|
| 服务强度 | $\rho = 4/5$ | **0.8** |
| 系统空闲概率 | $P_0 = 1 - 0.8$ | **0.2** |
| 平均队长 | $L_s = \dfrac{4}{5-4}$ | **4 人** |
| 平均等待队长 | $L_q = \dfrac{4^2}{5 \times 1}$ | **3.2 人** |
| 平均逗留时间 | $W_s = \dfrac{1}{5-4}$ | **1 小时** |
| 平均等待时间 | $W_q = \dfrac{4}{5 \times 1}$ | **0.8 小时 = 48 分钟** |
| 需等待的概率 | $1-P_0 = 0.8$ | **0.8** |
| 系统内 ≥2 人的概率 | $\rho^2 = 0.64$ | **0.64** |

**校验 Little 公式**：$L_s = \lambda W_s = 4 \times 1 = 4$ ✅；$L_q = \lambda W_q = 4 \times 0.8 = 3.2$ ✅

**管理解读**：
- 服务台有 **80%** 的时间在忙，**20%** 空闲
- 平均有 **3.2 人**在排队等，**每人平均等 48 分钟**——这对快递驿站来说体验较差
- **改善方向**：提高服务率 $\mu$（如增加人手、优化流程）。若 $\mu$ 从 5 提高到 6：$L_q = 16/(6\times2) = 1.33$ 人，$W_q = 0.333$ h = 20 分钟，**等待时间降了 58%**——说明排队系统对服务率的**边际改善非常敏感**

## 五、系统容量有限的 M/M/1/N 模型

### 5.1 模型说明

系统最多容纳 $N$ 个顾客（含正在服务的 1 个），即**队列长度最多 $N-1$**。当系统已满（$N$ 人）时，新到达的顾客**立即离开（损失）**——这是**混合制**。

### 5.2 核心公式 ★

设 $\rho = \lambda/\mu$：

$$P_0 = \frac{1-\rho}{1-\rho^{N+1}}\quad (\rho \ne 1)$$

$$P_n = P_0\rho^n = \frac{1-\rho}{1-\rho^{N+1}}\,\rho^n \qquad (n = 0, 1, \dots, N)$$

$$L_s = \frac{\rho}{1-\rho} - \frac{(N+1)\rho^{N+1}}{1-\rho^{N+1}} \quad (\rho \ne 1)$$

> **注意**：M/M/1/N 中 $\rho$ 可以 $\ge 1$，因为系统容量有限，不会无限增长（**不需要 $\rho < 1$**）。

### 5.3 有效到达率（关键概念）★

因为系统满时顾客会离开，**真正进入系统的到达率低于 $\lambda$**：

$$\lambda_e = \lambda(1 - P_N)$$

**所有"人数—时间"关系式（Little 公式）都要用 $\lambda_e$ 而非 $\lambda$**：
$$L_s = \lambda_e W_s,\qquad L_q = \lambda_e W_q$$

> ⚠️ 这是 M/M/1/N 最容易出错的地方：**忘记把 $\lambda$ 换成 $\lambda_e$**。

### 5.4 完整例题演算 ★★★

**例 11-2**　承例 11-1，若驿站空间有限，最多只能容纳 4 位顾客（含正在服务者），超出即离开。求各项指标。

**解**：$\lambda = 4$，$\mu = 5$，$N = 4$，$\rho = 0.8$

**各状态概率**：
$$P_0 = \frac{1-0.8}{1-0.8^{5}} = \frac{0.2}{1-0.32768} = \frac{0.2}{0.67232} \approx 0.2975$$

| $n$ | $P_n = P_0 \times 0.8^n$ |
|---|---|
| 0 | **0.2975** |
| 1 | **0.2380** |
| 2 | **0.1904** |
| 3 | **0.1523** |
| 4 | **0.1219** |

（**校验**：$\sum P_n = 1.0000$ ✅）

**平均队长**：
$$L_s = \frac{0.8}{0.2} - \frac{5 \times 0.8^5}{1-0.8^5} = 4 - \frac{5 \times 0.32768}{0.67232} = 4 - 2.4369 \approx \mathbf{1.563}\ \text{人}$$

**有效到达率**：
$$\lambda_e = 4 \times (1 - 0.1219) = 4 \times 0.8781 \approx \mathbf{3.513}\ \text{人/h}$$

**平均逗留时间**（用 $\lambda_e$！）：
$$W_s = \frac{L_s}{\lambda_e} = \frac{1.563}{3.513} \approx \mathbf{0.445}\ \text{小时} \approx 26.7\ \text{分钟}$$

**平均等待队长**：
$$L_q = L_s - \rho_{\text{有效}} = 1.563 - \frac{\lambda_e}{\mu} = 1.563 - 0.703 \approx \mathbf{0.860}\ \text{人}$$

（其中"有效服务强度" $= \lambda_e/\mu = 3.513/5 = 0.703$）

**对比 M/M/1（例 11-1）**：

| 指标 | M/M/1（无限制） | M/M/1/N（N=4） |
|---|---|---|
| $L_s$ | 4 人 | **1.563 人** |
| $W_s$ | 1 小时 | **0.445 小时** |
| 顾客损失率 | 0 | **12.19%** |

**结论**：通过限制系统容量，**平均等待时间从 1 小时降到 26.7 分钟**，代价是 **12.19% 的顾客被拒之门外**。这是典型的"**用损失换体验**"——实际中需要权衡（例如快递驿站可以设置等候区座位数上限）。

## 六、多服务台负指数分布排队系统（M/M/c）★★★

### 6.1 模型说明

$c$ 个服务台**并联**，共同服务一个队列（顾客到达后哪个台空就去哪个）。到达率 $\lambda$、每台服务率 $\mu$。

**有效服务强度（每台的平均占用率）**：
$$\rho = \frac{\lambda}{c\mu}$$

**稳定条件**：$\rho < 1$（即 $c\mu > \lambda$）

### 6.2 核心公式

**系统空闲概率**：
$$P_0 = \left[\, \sum_{k=0}^{c-1}\frac{(\lambda/\mu)^k}{k!} + \frac{(\lambda/\mu)^c}{c!\,(1-\rho)} \,\right]^{-1}$$

**状态概率**（$n \le c$ 时不需要排队，$n > c$ 时需排队）：
$$P_n = \begin{cases} \dfrac{(\lambda/\mu)^n}{n!}\,P_0, & n \le c \\[6pt] \dfrac{(\lambda/\mu)^n}{c!\,c^{\,n-c}}\,P_0, & n > c \end{cases}$$

**平均等待队长**：
$$L_q = \frac{P_0\,(\lambda/\mu)^c\,\rho}{c!\,(1-\rho)^2}$$

**平均队长**：
$$L_s = L_q + \frac{\lambda}{\mu}$$

**平均等待时间与逗留时间**：
$$W_q = \frac{L_q}{\lambda},\qquad W_s = W_q + \frac{1}{\mu} = \frac{L_s}{\lambda}$$

### 6.3 完整例题演算 ★★

**例 11-3**　某仓库有 2 个装卸月台，货车按泊松流到达，平均 6 辆/小时；每个月台平均 4 辆/小时（负指数服务时间）。求各项指标。

**解**：$\lambda = 6$，$\mu = 4$，$c = 2$
$$\rho = \frac{\lambda}{c\mu} = \frac{6}{2 \times 4} = 0.75 < 1\ ✅$$

**空闲概率**（$\lambda/\mu = 1.5$）：
$$P_0 = \left[\underbrace{\left(\frac{1.5^0}{0!} + \frac{1.5^1}{1!}\right)}_{k=0,1} + \frac{1.5^2}{2!\,(1-0.75)}\right]^{-1} = \left[\,(1 + 1.5) + \frac{2.25}{0.5}\,\right]^{-1} = (2.5 + 4.5)^{-1} = \frac{1}{7} \approx \mathbf{0.1429}$$

**平均等待队长**：
$$L_q = \frac{P_0 \times 1.5^2 \times 0.75}{2! \times (1-0.75)^2} = \frac{0.1429 \times 2.25 \times 0.75}{2 \times 0.0625} = \frac{0.2411}{0.125} \approx \mathbf{1.929}\ \text{辆}$$

**平均队长**：
$$L_s = L_q + \frac{\lambda}{\mu} = 1.929 + 1.5 \approx \mathbf{3.429}\ \text{辆}$$

**平均等待时间**：
$$W_q = \frac{L_q}{\lambda} = \frac{1.929}{6} \approx \mathbf{0.321}\ \text{小时} \approx 19.3\ \text{分钟}$$

**平均逗留时间**：
$$W_s = W_q + \frac{1}{\mu} = 0.321 + 0.25 \approx \mathbf{0.571}\ \text{小时} \approx 34.3\ \text{分钟}$$

**校验**：$L_s = \lambda W_s = 6 \times 0.571 = 3.429$ ✅

**对比单台服务（$\mu = 8$，即"两台合并为一个大月台"）**：
$\rho = 6/8 = 0.75$，$L_q = 36/(8 \times 2) = 2.25$ 辆，$W_q = 2.25/6 = 0.375$ h = 22.5 分钟

> **重要结论（"多台并联优于单台大服务台"）**：虽然总服务能力相同（2×4 = 8），但**两个独立月台的等待时间（19.3 分钟）短于一个等价的大月台（22.5 分钟）**。原因是两个台可以并行服务两辆车，而单台必须串行。这就是**"两台小机器并联优于一台大机器"**这一排队论经典结论。

## 七、一般服务时间的 M/G/1 模型

### 7.1 Pollaczek-Khinchine 公式（P-K 公式）★★

设到达率 $\lambda$、平均服务率 $\mu$、服务时间的方差为 $\sigma^2$，$\rho = \lambda/\mu < 1$：

$$\boxed{\ W_q = \frac{\lambda(\sigma^2 + 1/\mu^2)}{2(1-\rho)}\ }$$

$$L_q = \lambda W_q,\qquad W_s = W_q + \frac{1}{\mu},\qquad L_s = \lambda W_s$$

> **P-K 公式的伟大之处**：它只依赖服务时间的**均值和方差**，不需要知道服务时间的具体分布形式——**"分布无关"**。这是排队论中最实用的公式之一。

### 7.2 两个特例（可用来验证记忆）

| 服务时间分布 | $\sigma^2$ | $W_q$ 结果 | 是否与 M/M/1 一致 |
|---|---|---|---|
| 负指数 $M$ | $1/\mu^2$ | $W_q = \dfrac{2\lambda/\mu^2}{2(1-\rho)} = \dfrac{\lambda}{\mu(\mu-\lambda)}$ | ✅ 完全一致 |
| 定长 $D$ | $0$ | $W_q = \dfrac{\lambda/\mu^2}{2(1-\rho)} = \dfrac{\rho}{2\mu(1-\rho)}$ | 是 M/M/1 的**一半** |

### 7.3 完整例题演算 ★★

**例 11-4**　某服务窗口，$\lambda = 4$ 人/h，$\mu = 5$ 人/h，服务时间的标准差为 **0.1 小时**（即 $\sigma^2 = 0.01$）。求各项指标。

**解**：$\rho = 0.8$，$1/\mu = 0.2$，$1/\mu^2 = 0.04$

$$W_q = \frac{\lambda(\sigma^2 + 1/\mu^2)}{2(1-\rho)} = \frac{4 \times (0.01 + 0.04)}{2 \times 0.2} = \frac{4 \times 0.05}{0.4} = \mathbf{0.5}\ \text{小时}$$

$$L_q = \lambda W_q = 4 \times 0.5 = \mathbf{2}\ \text{人}$$
$$W_s = W_q + \frac{1}{\mu} = 0.5 + 0.2 = \mathbf{0.7}\ \text{小时}$$
$$L_s = L_q + \rho = 2 + 0.8 = \mathbf{2.8}\ \text{人}$$

**与 M/M/1 对比**（例 11-1：$W_q = 0.8$ h，$L_q = 3.2$ 人）：

| | M/M/1（$\sigma^2 = 1/\mu^2 = 0.04$） | M/G/1（$\sigma^2 = 0.01$） |
|---|---|---|
| $W_q$ | 0.8 h（48 min） | **0.5 h（30 min）** |
| $L_q$ | 3.2 人 | **2 人** |

**重要结论（排队论最反直觉的洞见）**：
> **等待时间取决于服务时间的"波动"，而不只是平均速度。** 在均值相同的前提下，服务时间**越稳定（方差越小），队列越短**。本例把标准差从 0.2 小时降到 0.1 小时（均值不变），等待时间直接降了 **37.5%**。

**管理启示**：与其盲目加班提高平均速度，不如**标准化作业流程、减少服务时间的波动**（如固定打包流程、预先分拣），代价更小、效果更好。这正是物流中心推行**标准化作业（SOP）**的排队论依据。

## 八、经济分析——系统的最优化

### 8.1 费用构成

$$Z = C_s \cdot (\text{服务水平指标}) + C_w \cdot (\text{等待损失指标})$$

- **服务成本**：与服务水平（$\mu$ 或 $c$）**正相关**——服务能力越强越花钱
- **等待成本**：与等待时间/队长**正相关**——顾客等得越久损失越大

**两条曲线的交点（或总费用曲线的最低点）即最优服务水平。**

### 8.2 完整例题演算 ★★

**例 11-5**　某服务站 $\lambda = 4$ 人/h，服务率 $\mu$ 可调整。每提高 1 单位服务率需增加成本 20 元/h；每位顾客等待 1 小时造成损失 50 元/h。求最优服务率。

**解**：设总费用为 $Z(\mu)$，等待损失按平均队长计算（或用等待时间计算，结果等价）：

$$Z(\mu) = 20\mu + 50 \cdot L_s = 20\mu + \frac{50\lambda}{\mu - \lambda} = 20\mu + \frac{200}{\mu - 4}$$

**求极值**：令 $\dfrac{dZ}{d\mu} = 20 - \dfrac{200}{(\mu-4)^2} = 0$

$$(\mu-4)^2 = \frac{200}{20} = 10 \quad\Rightarrow\quad \mu^* = 4 + \sqrt{10} \approx \mathbf{7.162}\ \text{人/h}$$

**最小总费用**：
$$Z^* = 20 \times 7.1623 + \frac{200}{3.1623} \approx 143.25 + 63.25 = \mathbf{206.5}\ \text{元/h}$$

**若 $\mu$ 必须取整数**（如服务台数量只能整数）：

| $\mu$ | 服务成本 $20\mu$ | 等待损失 $200/(\mu-4)$ | 总费用 $Z$ |
|---|---|---|---|
| 6 | 120 | 100.0 | 220.0 |
| **7** | **140** | **66.7** | **206.7** ← 最优 |
| 8 | 160 | 50.0 | 210.0 |
| 9 | 180 | 40.0 | 220.0 |

$$\boxed{\mu^* = 7\ (\text{整数约束下}),\qquad Z^* = 206.7\ \text{元/h}}$$

> 💡 **注意总费用曲线的"U 形"**：$\mu$ 太小时等待损失暴涨，$\mu$ 太大时服务成本浪费。最优解就在**"最后一单位服务能力的成本 = 它带来的等待损失减少量"**那一点——这与经济学的**边际分析**完全一致。

## 九、分析排队系统的随机模拟法

当分布复杂（如 $G/G/c$）、解析公式不存在或过于复杂时，用**蒙特卡洛模拟**：

```
第1步  根据到达间隔分布生成随机到达时间序列
         （如负指数分布：t = -ln(U)/λ，U 为 (0,1) 均匀随机数）
第2步  根据服务时间分布生成每个顾客的服务时长
第3步  按排队规则推进仿真时钟，记录每位顾客的到达时刻、开始服务时刻、离开时刻
第4步  统计 Ls、Lq、Ws、Wq、服务台利用率、损失率等指标
第5步  重复多次（或加长仿真时长）以降低随机误差
```

**优点**：灵活，能处理任意分布、任意规则、复杂网络（排队网络）。
**缺点**：只给数值结果，不给解析表达式；需要足够的仿真时长以保证精度。

## 十一、本章考点与易错点

**必考**：M/M/1 全套指标、Little 公式、Kendall 记号、M/M/c 的 $L_q$、P-K 公式、系统最优化。

**易错点清单**：
1. **$\rho$ 的定义在 M/M/1 和 M/M/c 中不同**：M/M/1 中 $\rho = \lambda/\mu$（单台利用率，也是系统占用率）；M/M/c 中 $\rho = \lambda/(c\mu)$（每台的利用率）。**写错会全题崩塌**
2. **忘了验证稳定条件** $\rho < 1$（M/M/1 必须验证；M/M/1/N 因容量有限可以不满足）
3. **M/M/1/N 中用错到达率**——必须用 $\lambda_e = \lambda(1-P_N)$，不是 $\lambda$
4. Little 公式中 $L_q$ 配 $W_q$、$L_s$ 配 $W_s$，**不要交叉**（$L_q \ne \lambda W_s$）
5. **$W_s = W_q + 1/\mu$ 中的 $1/\mu$ 是平均服务时间**，不要写成 $1/\lambda$
6. M/M/c 的 $P_0$ 公式中**求和到 $c-1$**（不是到 $c$），后面单独加一项
7. P-K 公式里是 $\sigma^2 + 1/\mu^2$（服务时间方差 + 均值的平方），**不是 $\sigma^2 + 1/\mu$**
8. 时间单位要统一（$\lambda$ 用"人/小时"，服务时间也要换算成小时）
9. 系统最优化中**忘了总费用是"服务成本 + 等待成本"两项之和**，只优化其中一项
10. 把 M/M/c 的 $\rho$ 当成"系统整体利用率"来解释（实际它是**每台**的利用率；系统"有顾客需等待的概率"是另一个量，需要用 $P_{n\ge c}$ 计算）

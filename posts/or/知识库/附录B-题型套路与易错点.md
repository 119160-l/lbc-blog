## 二、分章解题套路

### 第2章 线性规划

**套路1：单纯形表迭代（最常考）**

```
① 化标准型   —— 加松弛/剩余/人工变量，min 转 max，b<0 乘 -1
② 建初始表   —— 填入 c_B、基变量、x_B，计算所有 σ_j = c_j - Σc_B·a_ij
③ 最优性判断 —— σ_j 全 ≤0？是→结束；否→继续
④ 定入基变量 —— 取 max{σ_j>0} 的列 k
⑤ 定出基变量 —— θ = min{b_i/a_ik | a_ik>0}，对应行 r
⑥ 旋转变换   —— a_rk 化 1，同列其他行化 0（高斯消元）
⑦ 回到 ③
```

**套路2：图解法**
1. 把每个约束当等式画直线（先取两个截距点）
2. 用**原点代入法**确定不等式哪一侧（$(0,0)$ 代进去成立就取含原点那侧；原点在线上则换点试）
3. 目标函数令 $z$ 为某个值画等值线，然后**平移**：max 往右上方推，min 往左下方推
4. 最优点必在顶点；若等值线与某条边界平行，则该边上两点都是最优解 ⇒ 无穷多解

**套路3：解的类型判别**（给最终单纯形表问"解的何种情况"）
- 看 $\sigma_j$ 列：全 $\le 0$ 才可能最优
- 看非基变量是否有 $\sigma_j = 0$：有 ⇒ 无穷多最优解
- 看某 $\sigma_j>0$ 列的系数：全 $\le 0$ ⇒ 无界解
- 看人工变量是否留在基中且取值 $>0$ ⇒ 无可行解

### 第3章 对偶理论

**套路1：写对偶问题**（记配对表格，逐条对照）
1. 先统一成 max（若原为 min，整体思路对偶即可，但要逐项对应）
2. 对每个**原始约束**配一个**对偶变量**，符号由约束方向定
3. 对每个**原始变量**配一个**对偶约束**，方向由变量符号定
4. 目标函数系数与右端项互换

**套路2：不求解直接算最优值**
用**强对偶定理**：若能在对偶问题中找到一可行解，其目标值即给出原问题最优值的界。若对偶可行解的值 $=$ 原问题某可行解的值 ⇒ 两者都是最优解（可宣布 $z^*$）。

**套路3：影子价格与灵敏度**
- 影子价格 = **最终单纯形表中松弛变量列的检验数**取负（$\sigma_s = -y_i$）
- 更直接：$y_i^*$ = 最终表中第 $i$ 个松弛变量对应的 $\sigma$ 的相反数
- 灵敏度区间：用**最终表中的系数矩阵**计算，$b_i$ 变化范围使所有基变量取值 $\ge 0$

### 第4章 运输问题（三段式，一定要熟练）

```
第一段：伏格尔法求初始基可行解
   ① 算每行、每列的「次小 − 最小」差值
   ② 差值最大者优先处理，在其最小运费格填 min{a_i, b_j}
   ③ 划去已满足的行或列，重复直到填满，保证基变量数 = m+n−1

第二段：位势法检验
   ① 对基变量格写 u_i + v_j = c_ij，令 u_1 = 0，解出全部位势
   ② 对非基变量格算 σ_ij = c_ij − u_i − v_j
   ③ 全部 σ_ij ≥ 0 ⇒ 最优；否则找最小 σ_ij（最负）进第三段

第三段：闭回路调整
   ① 从最负 σ 格出发画闭回路（只在基变量格转弯）
   ② 交替标 +、−，取 θ = min{负号格运量}
   ③ 加 θ 于 + 格、减 θ 于 − 格，出基一个格
   ④ 回到第二段重新检验
```

**注意**：产销不平衡时先补虚设行/列。虚设行的运费全为 0。

### 第5章 目标规划

**套路：建模**
1. 设决策变量
2. **硬约束**（必须满足的资源限制）照常写等式/不等式
3. 每个**目标**写成目标约束：$f_k(x) + d_k^- - d_k^+ = g_k$
4. 写达成函数：按题目优先级和"欠/超"要求选 $d^-$ 或 $d^+$ 或两者
5. 全部极小化

**图解法**：按优先级顺序，先只看 $P_1$ 相关约束与硬约束画可行域，找使 $P_1$ 达成的最优"区域"（可能是一条线或一个区域）；再在其中处理 $P_2$……最终得"满意解"（可能是一个区域，不是唯一点）。

### 第6章 整数规划

**套路1：匈牙利法（背下来）**

```
① 行减最小元
② 列减最小元
③ 试指派：从 0 最少的行/列开始圈 0，每行每列只能有一个圈
   → 圈数 = n 则结束
④ 作最少覆盖直线：对所有 0 元素用最少横竖线覆盖
   技巧：没圈的 0 打 √ → 同行打 √ 的行的有圈 0 所在列打 √ → 交替，最后未打 √ 的行画横线、打 √ 的列画竖线
⑤ 未覆盖元素最小值 δ：未覆盖减 δ，交叉处加 δ，其余不变
⑥ 回到 ③
```

**套路2：分支定界**
- 每层选「小数部分最接近 0.5」或「取值最大」的非整数变量分支，可减少层数
- 记住**剪枝条件**：该支 LP 最优值不优于已有整数解 ⇒ 剪掉

### 第7章 非线性规划

**套路1：K-T 条件（最常考）**

```
① 写出 f(x) 与全部 g_i(x) ≤ 0
② 枚举"起作用约束集合"（先猜哪些 g_i = 0）
   单约束题一般 2~3 种情况；双约束题枚举 4 种
③ 对每种情况：由 ∇f + Σλ_i∇g_i = 0 和 g_i = 0（起作用的）联立解出 x 与 λ
④ 校验：λ_i ≥ 0？不起作用的约束 g_i < 0 是否成立？
⑤ 通过校验的那组即为 K-T 点；若为凸规划则为全局最优
```

**套路2：凸性判断**
- 判 $f$ 的 Hesse 矩阵：正定 ⇒ 严格凸
- 判约束集：$g_i(x)$ 若为凸函数（如线性、二次正定），则可行域为凸集
- 结论：凸规划 ⇒ K-T 点就是全局最优

### 第8章 动态规划

**套路：三步建模**

```
① 定阶段 k —— 按时间/空间天然分段（如经过哪几个中间站）
② 定状态 s_k —— 「进入第 k 阶段时还剩多少资源 / 处在哪个节点」
   要求：无后效性 + 可枚举
③ 写递推方程 f_k(s_k) = opt{v_k(s_k,u_k) + f_{k+1}(s_{k+1})}
   边界：f_{n+1}(·) = 0
④ 从最后阶段往前算，每阶段对每个可能状态列表求解
⑤ 最后从 f_1(初始状态) 回溯读出最优决策序列
```

**列表法模板**（资源分配题）：

| $s$ | $u$ 的候选取值 | $v_k(s,u) + f_{k+1}(s-u)$ | $f_k(s)$ | 最优 $u_k^*$ |
|---|---|---|---|---|
| 0 | 0 | … | … | 0 |
| 1 | 0,1 | … | … | … |

### 第9章 图与网络

**套路1：最大流标号法**
```
① 给 s 标 (0, +∞)
② 反复检查：若存在弧 (i,j) 且 i 已标、j 未标、f_ij < c_ij
   → j 标 (i, min{Δ_i, c_ij − f_ij})
   若存在弧 (j,i) 且 i 已标、j 未标、f_ji > 0
   → j 标 (−i, min{Δ_i, f_ji})
③ 标到 t ⇒ 沿标号回溯得增广链，全链加 Δ_t
④ 标不到 t ⇒ 结束，此时已标号集 S 与未标号集构成最小割
```
**双重收获**：迭代结束时同时得到**最大流**和**最小割**，可互相验证（两者数值必须相等）。

**套路2：最短路 Dijkstra 表格法**

| 步骤 | 已永久标号点 | 各点 T 标号 | 新永久标号 |
|---|---|---|---|
| 1 | $v_1:P=0$ | $v_2:6,\ v_3:3,\ \dots$ | $v_3:P=3$ |
| 2 | … | … | … |

**关键**：每次只升格**T 标号最小**的点，且已永久标号的点不再更新。

### 第10章 网络计划

**套路**：
```
① 画网络图（箭线图 AOA 或节点图 AON，按教材要求）
   AOA 要正确使用虚箭线，保证逻辑关系正确、无逻辑矛盾
② 顺推算 ES、EF（起点 ES = 0；EF = ES + t；ES = max{紧前 EF}）
③ 逆推算 LF、LS（终点 LF = 工期；LF = min{紧后 LS}；LS = LF − t）
④ 算 TF = LS − ES，FF = min{紧后 ES} − EF
⑤ 找 TF = 0 的工作连成关键路线，工期 = 关键路线长度
⑥ PERT：t_e = (a+4m+b)/6，σ² = ((b−a)/6)²，关键路线累加 σ²，算 Z 查表
```

**口诀**：**顺推取大，逆推取小，时差为零是关键。**

### 第11章 排队论

**套路：先判断模型类型，再套公式**

| 题目特征 | 模型 | 用公式 |
|---|---|---|
| 单服务台、队列不限 | M/M/1 | 用 M/M/1 组公式 |
| 单服务台、**场地最多容纳 $N$ 人** | M/M/1/N | $P_0$ 带 $\rho^{N+1}$ |
| 单服务台、**顾客总数只有 $m$** | M/M/1/m | 带 $m!/(m-n)!$ |
| **$c$ 个服务台并联** | M/M/c | 用 $P_0$、$L_q$ 公式 |
| 服务时间**一般分布**（只给均值和方差） | M/G/1 | P-K 公式 |

**解题顺序**：先算 $\rho$ → 算 $P_0$ → 计算 $L_q, L_s$ → 用 Little 公式求 $W_q, W_s$ → 单位换算（时间要统一，如"小时"与"分钟"）。

**经济优化题**：列总费用函数，$c$ 从 1 枚举到几，画表比较。

### 第12章 存储论

**套路：判断四象限 → 套公式 → 算周期与年费用**

```
① 缺货是否允许？→ 决定是否乘 (C1+C2)/C2
② 补充是瞬时还是逐渐？→ 决定是否乘 P/(P−D)
③ 套 Q* 公式，再算 t* = Q*/D（或年订货次数 n* = D/Q*）
④ 总费用 C* = √(2C1C3D) × 修正因子
⑤ 若有折扣价（全量折扣）→ 分区间讨论：比较 EOQ 落点与折扣临界点
```

**报童模型**：
```
① 判断是缺货损失 C_u（少订货的代价）还是过剩损失 C_o（多订货的代价）
② 算临界比 C_u/(C_u+C_o)
③ 若是离散分布，从累积概率表找到累计概率 ≥ 临界比的最小的 Q
④ 若是连续分布，直接解 F(Q)=临界比
```

### 第13章 对策论

**套路**：
```
① 先求每行的最小值（行最小值），再取其中最大 → 下对策值 v_¯ = max min
② 先求每列的最大值，再取其中最小 → 上对策值 v̄ = min max
③ 若 v_¯ = v̄ → 有鞍点，纯策略解，结束
④ 若无鞍点：
   - 先做优超简化（删劣势行/列）
   - 若化为 2×2 → 套公式
   - 若化为 2×n 或 m×2 → 图解法
   - 否则用线性规划
```

**避坑**：优超时注意方向。**I 是 max 玩家**：行里元素越大越好，若行 A 每个元素 ≥ 行 B 对应元素，则行 B 是劣势行可删。**II 是 min 玩家**：列里元素越大对 II 越不利，若列 A 每个元素 ≥ 列 B，则列 A 是劣势列可删。

### 第14章 决策分析

**套路1：期望值法**
```
① 列损益矩阵（方案 × 状态）
② 每行乘以对应状态概率求和 → EMV
③ 选最大 EMV
```

**套路2：决策树（画树 → 从右往左算）**
```
① 画决策点（方块）→ 方案枝 → 状态点（圆圈）→ 概率枝 → 损益值
② 从最右端状态点算 EMV，写在状态点上方
③ 决策点处选最大 EMV 的方案，其余方案枝剪掉（画双斜线）
④ 若有多级决策（如"先调查再决策"），从树梢逐层往左推
```

**套路3：EVPI**
- EPPI = 每个状态下取该列最优值，再用概率加权
- EVPI = EPPI − 最优方案的 EMV

**套路4：贝叶斯**
```
① 列先验概率 P(θ_j)
② 列似然 P(B|θ_j)
③ 算联合 P(B|θ_j)P(θ_j)，求和得 P(B)
④ 后验 = 联合 / P(B)
⑤ 用后验重算 EMV，与用先验的 EMV 比较，差额即 EVSI
```

**套路5：AHP**
```
① 建层次结构
② 构造判断矩阵（逐对比较，用 1~9 标度）
③ 方根法求权重：每行元素连乘 → 开 n 次方 → 归一化
④ 算 λmax = (1/n)Σ(Aw)_i/w_i
⑤ CI = (λmax−n)/(n−1)，CR = CI/RI，CR<0.1 通过
```

## 三、易错点清单（考前必看）★★★

### 第2章

| 易错点 | 正确做法 |
|---|---|
| min 问题直接套 max 单纯形 | 必须先转 max（取负），最后结果再取负 |
| $b_i<0$ 只乘 $-1$ 忘了翻转不等号 | $\le$ 变 $\ge$，$\ge$ 变 $\le$ |
| 最小比值规则用了 $a_{ik}<0$ 的行 | 只能用 $a_{ik}>0$ 的行算比值 |
| 检验数符号方向搞反 | $\sigma_j = c_j - \sum c_{B_i}a_{ij}$，max 问题取 $\sigma_j>0$ 入基 |
| 松弛变量系数写错 | $\le$ 加 $+1$，$\ge$ 加 $-1$（剩余变量），均要入检验数计算 |
| 无界解判别看错 | 要「**该列所有** $a_{ik}\le 0$」才是无界，只要有一个正数就正常迭代 |

### 第3章

| 易错点 | 正确做法 |
|---|---|
| 对偶变量符号搞反 | 记住配对表：max 的对偶是 min，约束 $\le$ 配 $y\ge0$、$\ge$ 配 $y\le0$、$=$ 配自由 |
| 变量个数与约束个数混淆 | 原问题有 $n$ 个变量 → 对偶有 $n$ 个约束；原问题有 $m$ 个约束 → 对偶有 $m$ 个变量 |
| 影子价格符号弄反 | 影子价格 = $-\sigma$(对应松弛变量)，一般 $\ge 0$（max 问题） |
| 灵敏度只考虑一个 $b_i$ | 单一变化用最终表；多个同时变需重新求解 |

### 第4章

| 易错点 | 正确做法 |
|---|---|
| 基变量个数不足 $m+n-1$ | 必须补齐（填 0），且 0 格不能构成闭回路 |
| 伏格尔法差值算错 | 差值是「**次小 − 最小**」，不是「最大 − 最小」 |
| 位势法方程写得不对 | 只对**基变量格**写 $u_i+v_j=c_{ij}$，非基变量格不写 |
| 闭回路转向错了 | 只能在**基变量格**转弯，不能穿过非基变量格 |
| 调整量 θ 取错 | 取**所有负号格**运量的最小值，不是随便一个 |
| 产销不平衡忘了补虚设 | 补虚设行的运费全填 0（虚拟，表示无实际运输） |

### 第5章

| 易错点 | 正确做法 |
|---|---|
| 偏差变量符号用反 | $d_k^-$ 是欠（未达标）、$d_k^+$ 是超（超标） |
| 目标函数里写了决策变量 | 目标函数**只含偏差变量**，不含 $x_j$ |
| 优先级混用加减权 | 不同优先级用 $P_1 \gg P_2$；同一优先级内才用权系数 $w$ |
| 「不少于 $g_k$」写成 min $d_k^+$ | 「不少于」应 min $d_k^-$（尽量别欠） |

### 第6章

| 易错点 | 正确做法 |
|---|---|
| 匈牙利法忘了列减 | 行减后必须列减，否则试指派做不下去 |
| 覆盖线不是最少 | 覆盖线必须是**最少条数**，可用交替打 √ 方法保证 |
| 调整时符号搞错 | 未覆盖减 δ、交叉加 δ、单覆盖不变 |
| 极大化指派直接用匈牙利法 | 要先转换：$b_{ij}=M-c_{ij}$ |
| 非方阵指派问题 | 补零行/列扩展为方阵 |

### 第7章

| 易错点 | 正确做法 |
|---|---|
| 只算梯度=0 就宣布最优 | 还要二阶条件（Hesse 正定/负定）或 K-T 校验 |
| 起作用约束猜错后不校验 | 必须校验 $\lambda_i\ge0$ 与未起作用约束的可行性 |
| K-T 条件符号写错 | 标准形式是 $g_i(x)\le0$，若题目给 $\ge$，先转成 $\le$（乘 $-1$） |
| 把非凸问题的 K-T 点当全局最优 | K-T 只是必要条件；只有凸规划才是充分条件 |

### 第8章

| 易错点 | 正确做法 |
|---|---|
| 状态定义不满足无后效性 | 状态必须包含后续决策所需的全部信息 |
| 递推方程方向搞反 | 一般用**逆序**（从终点往前），边界 $f_{n+1}=0$ |
| 阶段指标与累计指标混淆 | $v_k$ 是第 $k$ 段单独的指标，$f_k$ 是从 $k$ 到结束的最优累计 |
| 忘了回溯读决策 | 表格里记下每格的最优 $u_k^*$，最后回溯 |

### 第9章

| 易错点 | 正确做法 |
|---|---|
| Dijkstra 中更新了已永久标号的点 | 永久标号的点**不再更新** |
| Dijkstra 用于负权边 | Dijkstra 要求**边权非负**，负权要用其他方法 |
| 最大流忘了后向弧 | 标号时后向弧条件是 $f_{ji}>0$，可减流 |
| 最小割算错 | 最小割 = 已标号集 $S$ 到未标号集 $\bar S$ 的**所有弧**容量之和（只算 $S\to\bar S$ 单向） |
| 最大流与最小割数值不等 | 两者必然相等，不等说明算错，用这个当自检 |
| 中国邮递员忘了奇度点 | 只有存在奇度点时才有重复边；配对取最小权匹配 |

### 第10章

| 易错点 | 正确做法 |
|---|---|
| 顺推逆推取大取小搞反 | **顺推取大**（$ES=\max$ 紧前 $EF$）、**逆推取小**（$LF=\min$ 紧后 $LS$） |
| 总时差与自由时差混淆 | $TF=LS-ES$（有"机动空间"但会影响后续）；$FF=ES_{紧后}-EF$（不影响紧后最早开始） |
| 关键路线只算长度不列工作 | 要写出关键工作序列，且必须**从起点连到终点** |
| PERT 方差累加了非关键工作 | 只累加**关键路线**上的工作方差 |
| Z 值查表方向弄反 | $Z=(T_S-T_E)/\sigma$，$P(T\le T_S)=\Phi(Z)$；若问"超过"则用 $1-\Phi(Z)$ |

### 第11章

| 易错点 | 正确做法 |
|---|---|
| 时间单位不统一 | $\lambda$（人/小时）与 $\mu$（人/小时）必须同单位；$W_q$ 算完再换算成分钟 |
| $\rho>1$ 还继续算 | $\rho\ge1$ 系统不稳定，公式无意义，需说明或增加服务台 |
| $L_s=L_q+\lambda/\mu$ 记成 $+1$ | 是 $\lambda/\mu=\rho$，等于**正在被服务**的平均人数 |
| M/M/c 的 $\rho$ 定义 | 多服务台 $\rho=\lambda/(c\mu)$（**除以 $c$**），不是 $\lambda/\mu$ |
| M/M/1/N 的 $P_0$ 公式用错 | 分母是 $1-\rho^{N+1}$（系统容量 $N$ 时共有 $N+1$ 个状态） |
| P-K 公式只适用于 M/M/1 | P-K 是 M/G/1，方差项 $\lambda^2\sigma_s^2$ 不可省 |

### 第12章

| 易错点 | 正确做法 |
|---|---|
| 修正因子用错方向 | 允许缺货乘 $\frac{C_1+C_2}{C_2}$（>1，允许缺货批量更大）；逐渐补充乘 $\frac{P}{P-D}$（>1） |
| 时间单位混乱 | $D$ 若是"年需求"，则 $C_1$ 必须是"每件每年存储费"，$t^*$ 算出来是年 |
| EOQ 忘了验算 | 最优处订货费 = 存储费，可用来快速检查 |
| 报童模型临界比倒置 | 是 $C_u/(C_u+C_o)$，分子是**缺货**损失 |
| 折扣问题直接套 EOQ | 折扣价要**分段比较**总费用，看 EOQ 在那个区间的可行性 |

### 第13章

| 易错点 | 正确做法 |
|---|---|
| 优超方向搞反 | I 是 max 玩家删**小**行；II 是 min 玩家删**大**列 |
| $2\times2$ 公式分母符号 | $\Delta=a_{11}-a_{12}-a_{21}+a_{22}$，注意中间两项都是减 |
| 混合策略概率之和不等于 1 | 一定校验 $x_1+x_2=1$、$y_1+y_2=1$ |
| 图解法取下包络还是上包络搞错 | $2\times n$ 时 I 求 max → 取各直线**下包络的最高点**；$m\times2$ 时 II 求 min → 取**上包络的最低点** |
| 支付矩阵含义理解错 | 教材默认矩阵元素是**局中人 I 的所得**（零和对策下即 II 的所失） |

### 第14章

| 易错点 | 正确做法 |
|---|---|
| 后悔值算反 | $r_{ij}=\max_i a_{ij}-a_{ij}$，即"该列最优值 − 本方案值"，非负 |
| 折中准则的 $\alpha$ 含义 | $\alpha$ 越大越乐观；$\alpha=1$ 退化为乐观准则，$\alpha=0$ 退化为悲观准则 |
| EVPI 与 EVSI 混淆 | EVPI 是**完全信息**的价值（上界）；EVSI 是**样本信息**的价值（≤ EVPI） |
| 贝叶斯分母漏项 | 分母 $\sum_k P(B\mid\theta_k)P(\theta_k)$ 要对**所有**状态求和 |
| AHP 判断矩阵不互反 | 必须满足 $a_{ij}=1/a_{ji}$、$a_{ii}=1$ |
| AHP 忘了做一致性检验 | 必须算 $CR$，$CR<0.1$ 才能用；否则重调矩阵 |
| AHP 权重没归一化 | 权重之和必须 = 1 |

## 四、通用复查清单（交卷前 3 分钟）

1. **单位**：时间、金额、数量单位是否统一？（排队论、存储论最爱考）
2. **归一化**：概率之和 = 1？权重之和 = 1？
3. **可行性**：解是否满足所有约束？非负？
4. **整数性**：整数规划题答案是否取整？指派题是否一一对应？
5. **交叉验证**：
   - 运输问题：位势法检验数是否全 $\ge 0$？
   - 最大流：$v(f)=\min C(S,\bar S)$ 是否相等？
   - 存储论：订货费 = 存储费？
   - 对偶：$c^Tx^*=y^{*T}b$？互补松弛是否满足？
   - 网络计划：关键路线上 $TF$ 是否都为 $0$？
6. **符号方向**：max 还是 min？$\le$ 还是 $\ge$？（一句话读一遍题目）
7. **答所问**：题目问的是 $W_q$ 还是 $W_s$？是 $L_q$ 还是 $L_s$？是"总费用"还是"单位时间费用"？

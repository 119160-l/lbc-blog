# 第7章 非线性规划

> 教材章节：第7章　｜　难度：★★★★　｜　题型：概念题、K-T 条件、凸规划判定、（**理论性最强的一章**）

---

## 一、本章定位

线性规划要求目标和约束都是线性的，但现实中大量问题是非线性的——**规模报酬递减、价格折扣、距离平方和、效用函数**等等。非线性规划（NLP）研究这类问题。

**与 LP 的根本差异**：LP 的最优解一定在可行域的**顶点**，所以可以只搜顶点；而 NLP 的最优解可能出现在**可行域内部或边界曲面上**，顶点搜索法失效，必须用解析方法（导数、梯度）。

---

## 二、基本概念与模型

### 2.1 一般模型

$$\min f(x) \quad \text{s.t.} \quad g_i(x) \ge 0 \ (i=1,\dots,m),\qquad h_j(x) = 0 \ (j=1,\dots,l)$$

其中 $f, g_i, h_j$ 中至少有一个是**非线性函数**。

### 2.2 局部最优与全局最优 ★

| 概念 | 定义 |
|---|---|
| **局部最优解** | 存在 $x^*$ 的某个邻域，在该邻域内的所有可行点中 $f(x^*) \le f(x)$ |
| **全局最优解** | 在整个可行域上 $f(x^*) \le f(x)$ |

> **关键事实**：**局部最优不一定是全局最优**。这是 NLP 比 LP 难的根本原因。但对于**凸规划**，局部最优就是全局最优。

### 2.3 凸集

集合 $S \subseteq \mathbb{R}^n$ 是**凸集**，若 $\forall x_1, x_2 \in S$ 及 $\forall \lambda \in [0,1]$：
$$\lambda x_1 + (1-\lambda)x_2 \in S$$

**几何含义**：集合中任意两点的连线**完全落在集合内**（没有"凹陷"）。

### 2.4 凸函数

$f$ 在凸集 $S$ 上是**凸函数**，若 $\forall x_1, x_2 \in S$、$\forall \lambda \in [0,1]$：
$$f(\lambda x_1 + (1-\lambda)x_2) \le \lambda f(x_1) + (1-\lambda)f(x_2)$$

**几何含义**：曲线上任意两点间的弦**位于曲线之上**（函数图像"向下凹"）。

**判别方法**：
- 一元函数：$f''(x) \ge 0$
- 多元函数：**Hessian 矩阵 $\nabla^2 f(x)$ 半正定**（$\forall x \in S$）
  - 严格凸：$\nabla^2 f(x)$ **正定**

### 2.5 凸规划 ★★★

若 NLP 满足：**① 目标函数 $f$ 是凸函数；② 可行域是凸集**（当 $g_i$ 是凹函数、$h_j$ 是线性函数时成立，因为凹函数 $\ge 0$ 定义的是凸集）——则称该问题为**凸规划**。

> **凸规划的核心性质**：**任何局部最优解都是全局最优解。** 这是凸规划最重要的性质，也是判断"能否用局部搜索得到全局最优"的依据。

**"凹凸性"判断的实用规则**：

| 问题类型 | 目标 $f$ | 约束 | 是否凸规划 |
|---|---|---|---|
| $\min f$，$f$ 凸，$g_i$ 凹 | 凸 | 凹 $\ge 0$ | ✅ 是 |
| $\min f$，$f$ 凸，$h_j$ 线性 | 凸 | 线性 $=0$ | ✅ 是 |
| $\max f$，$f$ 凹，$g_i$ 凹 | 凹（取负后凸） | 凹 | ✅ 是（$\max$ 凹函数等价于 $\min$ 凸函数） |
| $\min f$，$f$ **凹** | 凹 | — | ❌ 不是 |
| 含**非线性等式**约束（非线性 $h_j$） | — | — | ❌ 一般不是 |

> ⚠️ **易错**：**线性函数既是凸函数也是凹函数**。所以线性目标 + 线性约束的 LP 也是凸规划（与 LP 最优解在顶点并不矛盾）。

## 三、无约束极值问题

### 3.1 最优性条件 ★

设 $f$ 二阶连续可微。

**一阶必要条件（驻点条件）**：
$$\nabla f(x^*) = 0$$
满足此条件的点称为**驻点**（平稳点）。

**二阶充分条件**：若 $\nabla f(x^*) = 0$ 且 Hessian 矩阵 $\nabla^2 f(x^*)$ **正定**，则 $x^*$ 是**严格局部极小点**。
- $\nabla^2 f(x^*)$ 正定 → 严格局部极小
- $\nabla^2 f(x^*)$ 负定 → 严格局部极大
- **不定** → 鞍点（**不是极值点**）
- 半正定/半负定 → 需进一步判断（可能沿某方向的二阶导为 0）

### 3.2 常用求解方法

| 方法 | 思路 | 特点 |
|---|---|---|
| **梯度法（最速下降法）** | 沿负梯度方向 $-\nabla f(x_k)$ 迭代：$x_{k+1} = x_k - \lambda_k \nabla f(x_k)$ | 每步下降最快，但**靠近最优点时收敛很慢（锯齿现象）** |
| **牛顿法** | 用二阶信息，$x_{k+1} = x_k - [\nabla^2f(x_k)]^{-1}\nabla f(x_k)$ | 收敛快（二次收敛），但需求逆矩阵、对初值敏感 |
| **共轭梯度法** | 沿共轭方向搜索 | 介于梯度法与牛顿法之间，无需二阶导 |
| **变尺度法（DFP / BFGS）** | 用迭代过程构造 Hessian 的近似（拟牛顿法） | 实际中最有效的一类方法 |
| **步长 $\lambda_k$ 的确定** | 一维搜索（如黄金分割法、抛物线插值法）求 $\min_\lambda f(x_k - \lambda\nabla f)$ | 每次迭代都要做一次一维搜索 |

## 四、约束极值问题与 K-T 条件 ★★★★

### 4.1 等式约束：拉格朗日乘子法

$$\min f(x) \quad \text{s.t.}\quad h_j(x) = 0$$

构造**拉格朗日函数**：
$$L(x, \lambda) = f(x) + \sum_{j=1}^{l} \lambda_j h_j(x)$$

**必要条件**：
$$\frac{\partial L}{\partial x_i} = 0 \ (i=1,\dots,n),\qquad \frac{\partial L}{\partial \lambda_j} = h_j(x) = 0 \ (j=1,\dots,l)$$

> $\lambda_j$ 称为**拉格朗日乘子**，其绝对值表示第 $j$ 个约束的**边际影响**（约束右端项变化 1 单位引起最优值的变化）——与第3章"影子价格"思想一脉相承。

### 4.2 不等式约束：Kuhn-Tucker（K-T）条件 ★★★★

$$\min f(x) \quad \text{s.t.}\quad g_i(x) \ge 0 \ (i=1,\dots,m)$$

**K-T 条件**：若 $x^*$ 是局部最优解，且满足约束规范（Constraint Qualification），则存在乘子 $\lambda_i$ 使得

$$\boxed{\ \nabla f(x^*) - \sum_{i=1}^{m} \lambda_i \nabla g_i(x^*) = 0\ } \qquad \text{（梯度条件）}$$
$$\boxed{\ \lambda_i \cdot g_i(x^*) = 0 \ (i=1,\dots,m)\ } \qquad \text{（互补松弛条件）}$$
$$\boxed{\ \lambda_i \ge 0 \ (i=1,\dots,m)\ } \qquad \text{（乘子非负条件）}$$
$$\boxed{\ g_i(x^*) \ge 0\ } \qquad \text{（可行性条件）}$$

**K-T 条件的直观解释**：在最优解处，目标函数的负梯度 $-\nabla f$ 可以表示为**起作用约束**（$g_i(x^*) = 0$ 的那些）梯度的**非负线性组合**——即"想继续改善目标的方向，已被起作用约束挡住了"。

**互补松弛条件的含义**：**不起作用的约束（$g_i(x^*) > 0$）其乘子必为 0**——即"没绑住你的绳子，拉不动你"。

> **充分性**：若原问题是**凸规划**（$f$ 凸、$g_i$ 凹），则 K-T 条件也是**最优解的充分条件**——找到满足 K-T 条件的点，就找到了全局最优解。

### 4.3 K-T 条件的完整例题演算 ★★★

**例 7-1**　求解
$$\min f(x) = (x_1 - 2)^2 + (x_2 - 1)^2$$
$$\text{s.t.}\quad x_1 + x_2 \le 2,\qquad x_1, x_2 \ge 0$$

**第 1 步：判断凸性**

$f$ 的 Hessian：$\nabla^2 f = \begin{pmatrix} 2 & 0 \\ 0 & 2 \end{pmatrix}$ **正定** → $f$ 是严格凸函数。
约束 $2 - x_1 - x_2 \ge 0$ 是线性（凹）→ 可行域凸 → **凸规划**，K-T 条件是充要条件 ✅

**第 2 步：先试探无约束最优**

$\nabla f = (2x_1 - 4,\ 2x_2 - 2) = 0$ → $x_1 = 2,\ x_2 = 1$。
但 $x_1 + x_2 = 3 > 2$ → **约束被违反**，故约束 $x_1 + x_2 \le 2$ **起作用**（$g = 2 - x_1 - x_2 = 0$）。

**第 3 步：写出 K-T 条件**

记 $g_1 = 2 - x_1 - x_2 \ge 0$，$g_2 = x_1 \ge 0$，$g_3 = x_2 \ge 0$。
$$\nabla f - \lambda_1\nabla g_1 - \lambda_2\nabla g_2 - \lambda_3\nabla g_3 = 0$$
$$(2x_1-4,\ 2x_2-2) - \lambda_1(-1,-1) - \lambda_2(1,0) - \lambda_3(0,1) = 0$$

即
$$2x_1 - 4 + \lambda_1 - \lambda_2 = 0 \qquad (a)$$
$$2x_2 - 2 + \lambda_1 - \lambda_3 = 0 \qquad (b)$$

**第 4 步：分析起作用的约束**

已判定 $g_1$ 起作用 → $x_1 + x_2 = 2$，$\lambda_1 \ge 0$。
若 $x_1 > 0$ 且 $x_2 > 0$（内部点，$g_2, g_3$ 不起作用）→ $\lambda_2 = \lambda_3 = 0$。

代入 $(a)(b)$：
$$2x_1 - 4 + \lambda_1 = 0 \quad\Rightarrow\quad \lambda_1 = 4 - 2x_1$$
$$2x_2 - 2 + \lambda_1 = 0 \quad\Rightarrow\quad \lambda_1 = 2 - 2x_2$$

两式相减：$4 - 2x_1 - 2 + 2x_2 = 0 \Rightarrow 2x_1 - 2x_2 = 2 \Rightarrow x_1 - x_2 = 1$

联立 $x_1 + x_2 = 2$：
$$x_1 = 1.5,\qquad x_2 = 0.5$$

验证：$\lambda_1 = 4 - 2(1.5) = 1 > 0$ ✅（满足 $\lambda_1 \ge 0$）；$x_2 = 0.5 > 0$ ✅（与 $\lambda_3 = 0$ 一致）；$x_1 = 1.5 > 0$ ✅（与 $\lambda_2 = 0$ 一致）。

**第 5 步：结论**

$$\boxed{x_1^* = 1.5,\quad x_2^* = 0.5,\quad \lambda_1^* = 1,\quad f^* = (1.5-2)^2 + (0.5-1)^2 = 0.5}$$

**几何验证**：这是点 $(2,1)$ 到直线 $x_1 + x_2 = 2$ 上的**最小距离**问题。投影点计算：
$$\left(2,1\right) - \frac{(2+1)-2}{2}(1,1) = (2,1) - 0.5(1,1) = (1.5,\ 0.5)$$ ✅ 完全一致。

**乘子的经济解释**：$\lambda_1^* = 1$ 表示约束 $x_1+x_2 \le 2$ 的右端项（即 2）每增加 1 个单位，最优目标值将**减少 1**（因为这是 min 问题，约束放宽使目标可更小）。

## 五、常用约束极值求解算法

| 方法 | 思路 | 适用 |
|---|---|---|
| **拉格朗日乘子法** | 等式约束，直接构造 $L$ | 只有等式约束 |
| **罚函数法（外点法）** | 把约束的违约量以"罚项"加入目标：$\min f(x) + M\sum_i [\max(0, -g_i(x))]^2 + M\sum_j h_j^2(x)$，$M$ 很大 | 通用；从可行域**外部**逼近 |
| **障碍函数法（内点法）** | 在边界处加"障碍"，使迭代点始终停留在**可行域内部** | 只有不等式约束；迭代点始终可行 |
| **可行方向法** | 每步沿"既能使目标下降、又不破坏可行性"的方向前进 | 一般约束 |
| **二次规划** | 目标是二次函数、约束是线性的，用 K-T 条件转化为线性方程组/线性规划求解 | 目标二次 + 线性约束 |
| **序列二次规划（SQP）** | 每步用二次规划近似原问题 | 通用高效 |

### 罚函数法要点

$$\min \Phi(x, M_k) = f(x) + M_k \sum_i \left[\min(0, g_i(x))\right]^2 + M_k \sum_j h_j^2(x)$$

- $M_k$ 取一系列递增的正数（如 $1, 10, 100, \dots$）
- 当 $x$ 可行时，罚项为 0；当 $x$ 违反约束时，罚项迅速增大
- $M_k \to \infty$ 时，$\Phi$ 的极小点收敛到原问题的约束最优解
- **特点**：迭代点列从**不可行域**出发逐步逼近可行域边界（故称"外点法"）

## 六、本章自测题

1. 什么是凸集？什么是凸函数？如何用 Hessian 矩阵判断凸性？
2. 什么是凸规划？凸规划最重要的性质是什么？
3. 为什么说线性规划也是凸规划？
4. 写出无约束极值问题的一阶必要条件和二阶充分条件。
5. 什么是驻点？$\nabla f(x^*) = 0$ 且 Hessian 不定的点是什么点？
6. 写出 K-T 条件的四个组成部分，并解释互补松弛条件的含义。
7. K-T 条件是充分条件还是必要条件？什么情况下也是充分条件？
8. 用 K-T 条件求解：$\min (x_1-3)^2 + (x_2-2)^2$，s.t. $x_1 + x_2 \le 1$。

<details>
<summary>参考答案要点</summary>

1. **凸集**：集合 $S$ 中任意两点 $x_1,x_2$ 的连线全在 $S$ 内，即 $\lambda x_1+(1-\lambda)x_2 \in S$（$\forall \lambda\in[0,1]$）。**凸函数**：$f(\lambda x_1+(1-\lambda)x_2)\le\lambda f(x_1)+(1-\lambda)f(x_2)$。判断：多元函数在某点处 Hessian 矩阵 $\nabla^2 f(x)$ 半正定 ⟹ 凸函数；正定 ⟹ 严格凸函数。
2. **凸规划**：目标函数是凸函数、可行域是凸集（通常体现为 $g_i$ 是凹函数、$h_j$ 是线性函数）的非线性规划。最重要性质：**任何局部最优解都是全局最优解**。
3. 因为线性函数既是凸函数也是凹函数，线性约束定义的可行域是凸集（线性不等式 $a^Tx\le b$ 对应凸集），所以 LP 满足凸规划定义。这与"LP 最优解在顶点取得"并不矛盾——顶点搜索法的有效性是 LP 系数矩阵结构的额外性质。
4. 一阶必要条件：$\nabla f(x^*) = 0$。二阶充分条件：$\nabla^2 f(x^*)$ 正定（配合 $\nabla f(x^*)=0$）。
5. 使 $\nabla f(x^*) = 0$ 的点称为驻点（平稳点）。Hessian 不定的驻点是**鞍点**，不是极值点。
6. ① 梯度条件 $\nabla f(x^*) - \sum\lambda_i\nabla g_i(x^*) = 0$；② 互补松弛条件 $\lambda_i g_i(x^*) = 0$；③ 乘子非负 $\lambda_i \ge 0$；④ 可行性 $g_i(x^*) \ge 0$。互补松弛的含义：**约束没起作用（$g_i>0$）时其乘子必为 0**；乘子 $>0$ 时约束必取等（约束"绑紧"了最优解）。
7. K-T 条件在一般情况下是**必要条件**（需满足约束规范）；当原问题是**凸规划**时，K-T 条件同时是**充分条件**，即满足 K-T 条件的点就是全局最优解。
8. 无约束最优 $(3,2)$，$3+2=5>1$ 故约束起作用：$x_1+x_2=1$，$g = 1-x_1-x_2\ge0$。
   $\nabla f = (2x_1-6, 2x_2-4)$，K-T：$2x_1-6+\lambda_1 = 0$，$2x_2-4+\lambda_1 = 0$。
   相减：$2x_1-2x_2-2 = 0 \Rightarrow x_1-x_2 = 1$。联立 $x_1+x_2=1$ → $x_1 = 1,\ x_2 = 0$。
   则 $\lambda_1 = 6-2(1) = 4 > 0$ ✅，但 $x_2 = 0$ 触及边界，需引入 $g_3 = x_2 \ge 0$，$\lambda_3 > 0$。
   校验 $(b)$：$2(0)-4+4-\lambda_3 = 0 \Rightarrow \lambda_3 = 0$ ✅ 一致。
   **$x_1^* = 1,\ x_2^* = 0,\ \lambda_1 = 4,\ \lambda_3 = 0$，$f^* = 4+4 = 8$。**
   （几何验证：$(3,2)$ 到直线 $x_1+x_2=1$ 的投影为 $(3,2)-2(1,1)/2\cdot 2$…即 $(3,2)-2(1,1)=(1,0)$ ✅，$f=(1-3)^2+(0-2)^2 = 4+4=8$ ✅）

## 七、本章考点与易错点

**必考**：凸集/凸函数/凸规划判定、K-T 条件书写与求解、局部最优与全局最优的关系。

**易错点清单**：
1. **忘记 $\lambda_i \ge 0$** —— K-T 条件里乘子非负是必须写的
2. **互补松弛写反**：是 $\lambda_i g_i(x^*) = 0$，不是 $\lambda_i + g_i = 0$
3. K-T 条件中符号方向：$\nabla f - \sum\lambda_i\nabla g_i = 0$（**减号**，因为约束写成 $g \ge 0$ 形式）；若写成 $g \le 0$ 形式则变成 $+$ 号
4. **Hessian 正定 vs 半正定搞混**：凸函数只需**半**正定；严格凸才要正定
5. **以为驻点一定是极值点**（可能是鞍点）
6. **以为所有 K-T 点都是最优解**（一般只是必要；只有凸规划才是充分）
7. 约束 $g_i$ 的方向没统一成 $\ge 0$ 就直接套 K-T 公式
8. 求出的解要**逐条验证**：可行性、$\lambda_i \ge 0$、互补松弛是否满足——三条都要检查

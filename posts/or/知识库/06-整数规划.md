# 第6章 整数规划

> 教材章节：第6章　｜　难度：★★★　｜　题型：分支定界法、0-1 规划隐枚举、指派问题匈牙利法（**匈牙利法必考**）

---

## 一、本章定位

很多实际问题的决策变量**必须是整数**——设备的台数、人员的数量、是否投资的 0/1 选择、任务的指派。当 LP 的最优解出现小数时，简单四舍五入往往**不可行**或**不是最优**，必须用整数规划的专门方法。

### 1.1 分类

| 类型 | 说明 |
|---|---|
| **纯整数规划** | 全部变量要求取整数 |
| **混合整数规划** | 部分变量要求整数 |
| **0-1 规划** | 变量只能取 0 或 1（特殊整数规划） |

### 1.2 最重要的一条认知 ★

> **整数规划的最优解 $\ne$ 松弛问题（去掉整数要求）最优解的简单取整。**

**反例说明**：$\max z = 3x_1 + 2x_2$，$2x_1+3x_2 \le 14$，$2x_1+x_2 \le 9$，$x_1,x_2$ 为整数。
松弛问题最优解是 $(3.25,\ 2.5)$，$z = 14.75$。若直接取整：
- 四舍五入得 $(3, 3)$ → 代入约束 $2\times3 + 3\times3 = 15 > 14$，**不可行** ❌
- 向下取整得 $(3, 2)$ → 可行，$z = 13$
- 但真正的整数最优解是 $(4, 1)$ → $z = 14$ ✅ **比向下取整的 13 更好**

**结论**：取整既可能破坏可行性，也可能丢失最优性。必须用系统方法（分支定界、割平面）。

## 二、分支定界法 ★★★

### 2.1 基本思想

**"分而治之 + 定界剪枝"**：
- **分支**：松弛问题的最优解中若某变量取分数，就把它**劈成两支**（$\le \lfloor\cdot\rfloor$ 和 $\ge \lceil\cdot\rceil$），两支的并集覆盖了原问题的全部整数可行解
- **定界**：用当前找到的最好整数解作为**界**（max 问题的下界），用各子问题的 LP 最优值作为该支的**上界**
- **剪枝**：某子问题若 ① 无可行解，或 ② 其 LP 最优值**不超过**当前已知的界，则该支不可能包含更好的整数解，**直接剪掉**

### 2.2 完整例题演算 ★★★

**例 6-1**　求解
$$\max z = 3x_1 + 2x_2$$
$$2x_1 + 3x_2 \le 14,\qquad 2x_1 + x_2 \le 9,\qquad x_1, x_2 \ge 0 \text{ 且为整数}$$

**第 1 步：解松弛问题 $P_0$**

可行域顶点：$(0,0)$、$(4.5, 0)$、$(0, 14/3)$、以及两直线交点。

两直线交点：$2x_1+3x_2 = 14$ 与 $2x_1+x_2 = 9$ 相减得 $2x_2 = 5$，$x_2 = 2.5$，$x_1 = (9-2.5)/2 = 3.25$。

各顶点目标值：$z(0,0)=0$，$z(4.5,0)=13.5$，$z(0,14/3)=9.33$，$z(3.25,2.5)=14.75$。

**$P_0$ 最优解：$x_1 = 3.25,\ x_2 = 2.5,\ z_0 = 14.75$**（上界）

$x_1$、$x_2$ 都不是整数 → 需分支。

**第 2 步：分支**

选 $x_1 = 3.25$ 分支：
- **$P_1$**：$P_0$ 加约束 $x_1 \le 3$
- **$P_2$**：$P_0$ 加约束 $x_1 \ge 4$

**第 3 步：解 $P_1$（$x_1 \le 3$）**

$\max 3x_1+2x_2$ s.t. $2x_1+3x_2 \le 14$，$2x_1+x_2 \le 9$，$x_1 \le 3$，$x \ge 0$

在 $x_1 = 3$ 时，第二约束 $6 + x_2 \le 9$ 给 $x_2 \le 3$，第一约束 $6 + 3x_2 \le 14$ 给 $x_2 \le 8/3 \approx 2.667$。
取 $x_2 = 8/3$ 最大 → $z = 3\times3 + 2\times(8/3) = 9 + 5.333 = 14.333$
**$P_1$ 解：$x_1 = 3,\ x_2 = 8/3,\ z_1 = 14.333$**

$x_2$ 仍非整数 → 再分支：
- **$P_{11}$**：$x_2 \le 2$
- **$P_{12}$**：$x_2 \ge 3$

**解 $P_{11}$（$x_1 \le 3,\ x_2 \le 2$）**：$x_1=3, x_2=2$ 可行（$6+6=12\le14$ ✅，$6+2=8\le9$ ✅）→ $z = 13$。
**得到第一个整数解，$z_{11} = 13$** → 当前**下界 = 13**

**解 $P_{12}$（$x_1 \le 3,\ x_2 \ge 3$）**：$x_2 \ge 3$ 且第一约束 $2x_1 + 3x_2 \le 14 \Rightarrow x_1 \le 2.5$，与 $x_1 \le 3$ 合并 → $x_1 \le 2.5$。
最优在 $x_1 = 2.5, x_2 = 3$ → $z = 7.5 + 6 = 13.5$。
$13.5 > 13$（当前下界），**不能剪枝**，继续分支：$x_1 \le 2$ / $x_1 \ge 3$。
- $x_1 \ge 3$ 且 $x_1 \le 2.5$ → **无可行解**，剪掉 ✂️
- $x_1 \le 2$：$x_2 \ge 3$，第一约束 $4 + 3x_2 \le 14 \Rightarrow x_2 \le 10/3 \approx 3.333$ → $x_2 = 3$，$z = 6 + 6 = 12 < 13$ → **剪掉** ✂️

**第 4 步：解 $P_2$（$x_1 \ge 4$）**

$\max 3x_1+2x_2$ s.t. $2x_1+3x_2 \le 14$，$2x_1+x_2 \le 9$，$x_1 \ge 4$

$x_1 = 4$ 时：$8 + x_2 \le 9 \Rightarrow x_2 \le 1$；$8 + 3x_2 \le 14 \Rightarrow x_2 \le 2$。取 $x_2 = 1$。
$z = 12 + 2 = 14$。**$x_1 = 4, x_2 = 1$ 均为整数** ✅

**$z_2 = 14 > 13$（原下界）→ 更新下界为 14。**

**第 5 步：结论**

$$P_0 = 14.75 > P_2\text{ 的 } 14 > P_1 \text{ 及其子支的最优值}$$

所有分支已探查或剪枝完毕（$z_1 = 14.333$ 的上界仍在，但它的子支已全部剪掉或得整数解 13、12，均不超过 14）。

$$\boxed{x_1^* = 4,\quad x_2^* = 1,\quad z^* = 14}$$

**验算**：$2\times4 + 3\times1 = 11 \le 14$ ✅；$2\times4 + 1 = 9 \le 9$ ✅

**分支树回顾**：
```
                P0  x=(3.25, 2.5)  z=14.75
               ╱                        ╲
        x1≤3 ╱                            ╲ x1≥4
          P1 x=(3, 2.667) z=14.333         P2 x=(4,1) z=14  ★整数解，下界=14
         ╱            ╲
    x2≤2╱              ╲x2≥3
  P11 x=(3,2) z=13   P12 x1≤2.5,x2=3 z=13.5  (< 14 ？否，13.5<14 → 剪枝)
  ★整数解,下界=13        ╱            ╲
                  x1≤2╱                ╲x1≥3
              z=12 <13 剪枝          无可行解 剪枝
```

## 三、割平面法（Gomory）

### 3.1 基本思想

分支定界是"**分**"（把可行域劈开），割平面是"**切**"（切掉不含整数解的部分，但**不切掉任何整数可行解**）。

### 3.2 步骤

1. 解**松弛问题**。若最优解已全为整数 → 得解；否则继续
2. **从最终单纯形表中，找到取值为非整数的基变量 $x_i$** 所在的那一行：
$$x_i + \sum_{j \in N} a_{ij}' x_j = b_i'$$
其中 $b_i'$ 为非整数
3. **生成割平面约束**：把 $b_i'$ 和 $a_{ij}'$ 拆成"整数部分 + 真分数部分"
$$b_i' = \lfloor b_i' \rfloor + f_i \quad (0 < f_i < 1), \qquad a_{ij}' = \lfloor a_{ij}' \rfloor + f_{ij}$$
则割平面为
$$-\sum_{j \in N} f_{ij}\, x_j + s = -f_i \qquad (s \ge 0 \text{ 为松弛变量})$$
4. 把割平面约束**加入原最优表**（新增一行），由于右端项 $-f_i < 0$，此时需要用**对偶单纯形法**（第3章 §6）继续迭代
5. 回到第 1 步，直到最优解全为整数

> **割平面的性质**：① 切掉当前非整数最优解；② **不切掉任何整数可行解**（这是正确性的保证）；③ 每加一个割，可行域缩小一块。

### 3.3 与分支定界的比较

| | 分支定界法 | 割平面法 |
|---|---|---|
| 思路 | 把可行域**分成**多块，逐块搜索 | 用一个平面**切掉**非整数部分 |
| 优点 | 直观、易于程序化，收敛快（实际中更常用） | 思路优雅，理论上可有限步收敛 |
| 缺点 | 分支多时计算量大 | 割平面可能"切得很浅"，需要很多轮；数值稳定性差 |
| 实操 | **推荐手算 / 编程使用** | 多在理论中出现 |

## 四、0-1 型整数规划与隐枚举法

### 4.1 建模（0-1 变量的典型用法）

| 场景 | 0-1 变量的含义 |
|---|---|
| 投资选择 | $x_j = 1$ 表示投资第 $j$ 个项目，0 表示不投资 |
| 选址 | $x_j = 1$ 表示在第 $j$ 处建厂 |
| 指派 | $x_{ij} = 1$ 表示第 $i$ 人做第 $j$ 事 |
| 互斥约束 | 用 $x_1 + x_2 \le 1$ 表示两件事不能同时做 |
| 固定成本 | 用 $x_j M$ 表示"只要开工就有固定成本" |
| 逻辑关系 | $x_1 \le x_2$ 表示"选 1 必选 2" |

### 4.2 隐枚举法

**核心**：不枚举全部 $2^n$ 个组合，而是设置一个**过滤条件**，只需检查少数组合即可找到（或排除）最优解。

**步骤**：
1. 先把模型化为 $\max z = \sum c_j x_j$（$c_j \ge 0$ 更佳，否则可令 $x_j = 1-y_j$ 转换）
2. **按各变量目标系数的绝对值大小，重排变量的列出顺序**（让 $x_1$ 对应最大系数），这样从小到大地枚举时，目标值能快速变大
3. 随意取一个可行解，算出其目标值作为**初始过滤值（门槛）**
4. 按次序枚举组合，每遇到一个组合：
   - 先检查**目标函数值是否超过当前过滤值** → 不超过就直接跳过（**不必检查约束**）
   - 超过则检查约束是否满足：全满足 → 更新过滤值和最优解；有违反 → 跳过
5. 枚举完毕，最后记录的即最优解

> **关键效率来源**：**先用目标值把绝大多数组合筛掉，再检查约束**。顺序反了效率就低了。

### 4.3 完整例题演算 ★★

**例 6-2**　用隐枚举法求解
$$\max z = 3x_1 - 2x_2 + 5x_3$$
$$x_1 + 2x_2 - x_3 \le 2,\qquad x_1 + 4x_2 + x_3 \le 4,\qquad x_j \in \{0,1\}$$

**第 1 步：重排变量**。$|c|$ 从大到小为 $x_3(5),\ x_1(3),\ x_2(2)$，按 $(x_3,x_1,x_2)$ 枚举。

**第 2 步：取初始可行解**。$(x_3,x_1,x_2) = (0,0,0)$ 可行，$z = 0$。**过滤值 = 0**。

**第 3 步：枚举**

| 序 | $(x_3,x_1,x_2)$ | 目标值 | 是否 > 过滤值 | 约束检查 | 结果 |
|---|---|---|---|---|---|
| 1 | (0,0,0) | 0 | 等于，跳过 | — | — |
| 2 | (0,0,1) | $-2$ | ❌ 否 | — | 跳过 |
| 3 | (0,1,0) | $3$ | ✅ 是 | $1\le2$ ✅, $1\le4$ ✅ | **过滤值 → 3** |
| 4 | (0,1,1) | $1$ | ❌ 否 | — | 跳过 |
| 5 | (1,0,0) | $5$ | ✅ 是 | $-1\le2$ ✅, $1\le4$ ✅ | **过滤值 → 5** |
| 6 | (1,0,1) | $3$ | ❌ 否 | — | 跳过 |
| 7 | (1,1,0) | $8$ | ✅ 是 | $1-1=0\le2$ ✅, $1+1=2\le4$ ✅ | **过滤值 → 8** ★ |
| 8 | (1,1,1) | $6$ | ❌ 否 | — | 跳过 |

**最优解**：
$$\boxed{x_1^* = 1,\ x_2^* = 0,\ x_3^* = 1,\quad z^* = 8}$$

> **效率对比**：全部枚举需检查 8 个组合、每个都算约束；隐枚举只对 4 个"目标值超过过滤值"的组合检查了约束，节省一半工作量。变量数越多，效率优势越明显。

## 五、指派问题与匈牙利法 ★★★★★

### 5.1 问题的标准形式

$n$ 个人做 $n$ 件事，每人做每件事的效率（成本/时间）为 $c_{ij}$，求总成本最小的指派方案。

$$\min z = \sum_{i=1}^{n}\sum_{j=1}^{n} c_{ij}x_{ij}$$
$$\sum_{j=1}^{n} x_{ij} = 1 \ (\text{每人做一件事}),\qquad \sum_{i=1}^{n} x_{ij} = 1 \ (\text{每件事由一人做}),\qquad x_{ij} \in \{0,1\}$$

### 5.2 匈牙利法的理论依据

**关键定理**：若从系数矩阵 $(c_{ij})$ 的**某一行（或某一列）各元素分别减去一个常数 $k$**，得到新矩阵 $(c_{ij}')$，则以 $(c_{ij}')$ 为系数矩阵的指派问题与原问题**有相同的最优解**（只是最优值相差 $k$）。

> 直觉理解：每个人做任何事的成本都减了同一个数，那么"谁做哪件事"的最优搭配当然不变。

### 5.3 匈牙利法步骤 ★★★

```
第1步  变换系数矩阵：每行减去该行的最小元素 → 再每列减去该列的最小元素
         （结果矩阵中每行每列都至少有一个 0）
第2步  试指派：寻找"独立的 0 元素"
         —— 每个 0 所在的行和列都不能再有别的被圈选的 0
         做法：从含 0 最少的行（列）开始，圈出一个 0，然后划掉它所在行和列的其他 0
         若圈出的独立 0 的个数 = n  →  得最优解，结束
第3步  若独立 0 的个数 < n：作最少的直线覆盖所有的 0 元素
第4步  取未被直线覆盖的最小元素 k：
         未覆盖的行的所有元素 − k
         被覆盖的列的所有元素 + k
         （两类操作同时做，保证原来的 0 中有一些变成新的可用 0）
第5步  回到第2步，直到圈出 n 个独立 0
```

> 💡 **第3步"最少直线覆盖"的技巧**：先给**没有圈 0 的行**打 "√"；再给这些行中**被划掉的 0 所在列**打 "√"；再给这些列中**圈 0 所在的行**打 "√"……交替进行。最后**没打 "√" 的行画横线、打了 "√" 的列画竖线**，即为最少覆盖直线。

### 5.4 完整例题演算 ★★★

**例 6-3**　有 4 名工人完成 4 项任务，耗时（小时）如下，求总耗时最少的指派方案。

| | A | B | C | D |
|---|---|---|---|---|
| 甲 | 2 | 15 | 13 | 4 |
| 乙 | 10 | 4 | 14 | 15 |
| 丙 | 9 | 14 | 16 | 13 |
| 丁 | 7 | 8 | 11 | 9 |

**第 1 步：行减最小元素**

各行最小：甲 2、乙 4、丙 9、丁 7

| | A | B | C | D |
|---|---|---|---|---|
| 甲 | **0** | 13 | 11 | 2 |
| 乙 | 6 | **0** | 10 | 11 |
| 丙 | **0** | 5 | 7 | 4 |
| 丁 | **0** | 1 | 4 | 2 |

**列减最小元素**

各列最小：A 列 $0$、B 列 $0$、C 列 $4$、D 列 $2$

| | A | B | C | D |
|---|---|---|---|---|
| 甲 | **0** | 13 | 7 | **0** |
| 乙 | 6 | **0** | 6 | 9 |
| 丙 | **0** | 5 | 3 | 2 |
| 丁 | **0** | 1 | **0** | **0** |

**第 2 步：试指派**

从含 0 最少的行开始：
- **乙**行只有一个 0 → 圈定 $(乙, B)$，划去 B 列其他 0（B 列没有其他 0）
- **丙**行只有一个 0 → 圈定 $(丙, A)$，划去 A 列其他 0（甲、丁的 A 列 0 被划掉）
- **甲**行剩 $(甲,D) = 0$ → 圈定 $(甲, D)$，划去 D 列其他 0（丁的 D 列 0 被划掉）
- **丁**行剩 $(丁,C) = 0$ → 圈定 $(丁, C)$

**已圈出 4 个独立 0 = $n$** ✅ → 最优解

$$\boxed{\text{甲} \to D,\quad \text{乙} \to B,\quad \text{丙} \to A,\quad \text{丁} \to C}$$

**最少总耗时**：$c_{甲D} + c_{乙B} + c_{丙A} + c_{丁C} = 4 + 4 + 9 + 11 = \mathbf{28}$ 小时

### 5.5 变体的处理 ★

| 变体 | 处理方法 |
|---|---|
| **最大化**问题（如求最大效益） | 令 $b_{ij} = M - c_{ij}$（$M$ 为足够大的常数），转化为最小化；或直接令 $b_{ij} = \max\{c_{ij}\} - c_{ij}$ |
| **人数 ≠ 任务数**（$m < n$） | 补 $n - m$ 行虚拟的"人"，其做各任务的费用全取 **0** |
| **任务数 < 人数**（$m > n$） | 补 $m - n$ 列虚拟的"任务"，费用全取 **0** |
| **某人不能做某任务** | 该格费用取 **$M$**（充分大） |
| **求最大收益且含负值** | 用 $b_{ij} = \max\{c_{ij}\} - c_{ij}$ 变换，保证非负 |

<summary>参考答案要点</summary>

1. 因为松弛问题的最优解可能不满足整数要求，而简单取整（四舍五入或向下取整）可能导致 ① 取整后的点**违反约束**（不可行）；② 即使可行，也可能**不是整数最优解**（存在更好的整数点）。例如 $\max 3x_1+2x_2$，$2x_1+3x_2\le14$，$2x_1+x_2\le9$，松弛最优 $(3.25,2.5)$ 取整得 $(3,3)$ 不可行、$(3,2)$ 得 13，而真正整数最优 $(4,1)$ 得 14。
2. **分支**：当松弛问题最优解中某变量取分数时，加两个互斥约束（$\le \lfloor\cdot\rfloor$ 与 $\ge \lceil\cdot\rceil$）把问题劈成两个子问题。**定界**：用当前已找到的最好整数解确定一个界（max 问题为下界），用各子问题 LP 最优值作为该支的上界。**剪枝**：若某子问题无可行解，或其 LP 最优值不超过当前界，则该支不可能含有更优的整数解，停止对其继续分支。
3. 因为该子问题 LP 最优值是其所有整数可行解目标值的**上界**（max 问题），若这个上界都已经不超过当前已找到的最好整数解，则该子问题内的任何整数解都不会更好，故可剪掉。
4. ① 必须**切掉**当前松弛问题的最优（非整数）解；② 必须**不切掉任何整数可行解**。前者保证算法有效推进，后者保证不丢失最优解。
5. 因为它设置了**过滤值**（当前最好的可行目标值），枚举每个组合时**先算目标值**，若不优于过滤值就直接跳过，**根本不去检查约束**。由于目标值计算远比逐条检查约束快，且大多数组合都被目标值筛掉，总计算量大幅下降。
6. **行减最小元素**（各行最小：2、1、2）：
   $$\begin{pmatrix} 0 & 1 & 2 \\ 4 & 3 & 0 \\ 1 & 4 & 0 \end{pmatrix}$$
   **列减最小元素**（各列最小：0、1、0）：
   $$\begin{pmatrix} 0 & 0 & 2 \\ 4 & 2 & 0 \\ 1 & 3 & 0 \end{pmatrix}$$
   **试指派**：第 1 行有 2 个 0，第 2、3 行都只有第 3 列的 0 → 最多只能圈出 2 个独立 0（$< 3$），需迭代。
   **最少覆盖直线**：一条横线盖第 1 行，一条竖线盖第 3 列 → 共 2 条，覆盖全部 0。
   **未被覆盖的最小元素** $k = 1$（在第 2、3 行与第 1、2 列交叉处：$4,2,1,3$ 中最小者为 1）。
   未覆盖行（第 2、3 行）各元素 $-1$，被覆盖列（第 3 列）各元素 $+1$：
   $$\begin{pmatrix} 0 & 0 & 3 \\ 3 & 1 & 0 \\ 0 & 2 & 0 \end{pmatrix}$$
   **再次试指派**：圈 $(2,3)$，圈 $(3,1)$，圈 $(1,2)$ → **3 个独立 0** ✅

   $$\boxed{\text{甲}\to B,\quad \text{乙}\to C,\quad \text{丙}\to A,\qquad z^* = 3+1+3 = 7}$$
   （可枚举全部 6 种排列验证：$8, 9, 10, \mathbf{7}, 15, 11$，最小确为 7 ✅）
7. 引入足够大的常数 $M$，令新的成本矩阵 $b_{ij} = M - c_{ij}$（或用 $b_{ij} = \max_{i,j}\{c_{ij}\} - c_{ij}$），把最大化问题转化为最小化问题，再用匈牙利法；求得最优指派后，最优总效益为 $M\cdot n - (\text{最小总成本})$（或 $\sum\max - \min$）。
8. 把系数矩阵中 $(甲, C)$ 格的费用取为 $M$（充分大的正数，如远大于所有其他费用之和），迫使最优解中该格不被选中（$x_{甲C} = 0$）。

## 七、本章考点与易错点

**必考**：匈牙利法完整步骤、分支定界法流程、0-1 建模。

**易错点清单**：
1. **以为整数最优解 = 松弛解取整**（本章第一节的反例必须记住）
2. 分支时**变量选错**：应选最优解中**取值偏离整数最大**（或最接近 0.5）的变量分支，效率最高
3. 剪枝条件搞反：max 问题看"**小于等于下界**则剪枝"，min 问题看"**大于等于上界**则剪枝"
4. 匈牙利法只做**行减**不做**列减**（必须两步都做）
5. 匈牙利法试指派时，圈 0 后**必须同时划掉同行同列的其他 0**，否则会圈到不独立的 0
6. "最少覆盖直线"后调整时，**未覆盖的行减 $k$** 与 **被覆盖的列加 $k$** 要**同时**做；如果只做减不做加，原来的 0 会被破坏
7. 虚拟行/列的费用取 **0**（不是 $M$），因为虚拟代表"不做事/不存在"
8. 指派问题中"不能做某事"用 **$M$**，"不做也无所谓"用 **0**，两者不要混

## 三、知识库三个附录的分工

| 附录 | 解决的问题 |
|---|---|
| **A 公式总表** | 「这题该用哪个公式？」→ 14 章公式全表 + 拼音索引 + 记忆法 |
| **B 题型套路与易错点** | 「这题怎么下手 / 我总在这里错」→ 解题流水线 + 80 余条易错点 + 交卷前复查清单 |
| **C Python 求解示例** | 「我算的对不对？」→ 11 个算法模块，全部纯标准库，`Fraction` 精确计算 |

**配套代码零依赖，直接跑：**

```bash
python3 附录C-配套代码-or_tools.py
```

它会输出 11 个模块的完整演示，并内置多重交叉验证——例如运输问题会**同时**用伏格尔法和线性规划求解并比对结果，最大流会同时给出最小割验证「最大流 = 最小割」。

## 四、关于教材版权

- 官方样章（第 1 章全文）来自清华大学出版社官网，**免费、正版、可下载**
- 全书电子版目前**没有合法的 PDF 下载渠道**（文泉书局只有在线阅读，不提供原文件）
- 文件夹中的 `知识库/` 是**按教材章节体系自行整理的学习材料**，不是教材原书的扫描或复制
- 合法获取全书正文的途径见 `02-如何合法拿到全书（武科大专用操作指南）.md`

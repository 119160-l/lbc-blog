# 拉普拉斯变换入门笔记：为什么学控制要先学它

## 一个核心直觉

解微分方程很烦：要先求齐次解，再凑特解，再代初始条件。

**拉普拉斯变换干的事情，就是把"微分方程"变成"代数方程"。**

- 微分 → 乘以 `s`
- 积分 → 除以 `s`

于是时域里绕来绕去的动态过程，到了 s 域就是乘乘除除，算完再反变换回来。这就是传递函数的来源。

## 最常用的 5 个变换对

| 时域 f(t) | s 域 F(s) |
| --- | --- |
| 单位冲激 δ(t) | 1 |
| 单位阶跃 1(t) | 1/s |
| t | 1/s² |
| e^(-at) | 1/(s+a) |
| sin(ωt) | ω/(s²+ω²) |

不用死记所有表，这 5 个加上下面的性质能推出一大半。

## 三大性质

### 1. 线性性质

```
L[a·f(t) + b·g(t)] = a·F(s) + b·G(s)
```

### 2. 微分性质（最重要）

```
L[f'(t)] = s·F(s) - f(0)
```

零初始条件下就是 `s·F(s)`——这就是为什么电容、电感在 s 域里能直接写成 `1/(Cs)` 和 `Ls`。

### 3. 延迟性质

```
L[f(t-τ)·1(t-τ)] = e^(-τs)·F(s)
```

时域延迟 τ，s 域只多乘一个 `e^(-τs)`。

## 做题四步法

1. 对微分方程**两边同时做拉氏变换**（零初始条件下直接替换）
2. 整理出 **输出/输入 = X(s)/R(s)**，这就是传递函数
3. 代入输入的 s 域形式（如阶跃输入 R(s)=1/s）
4. 对结果做**部分分式分解 + 反变换**，得到时域响应

## 一个小例子

系统满足 `x'(t) + 2x(t) = r(t)`，输入单位阶跃，零初始条件：

```
sX(s) + 2X(s) = 1/s
X(s) = 1 / [s(s+2)]
     = (1/2)·(1/s) - (1/2)·(1/(s+2))   ← 部分分式分解
x(t) = (1/2)(1 - e^(-2t))
```

看，一个指数上升、最终稳定在 0.5 的响应，纯代数就算出来了。

## 易错点提醒

- ⚠️ 终值定理 `lim f(t) = lim sF(s)` 使用前必须确认**系统稳定**（极点都在 s 左半平面），否则结果是错的
- ⚠️ 别忘初始条件项 `f(0)`，只有题目说零初始条件才能省
- ⚠️ 反变换前一定先做部分分式分解，化成表上有的形式

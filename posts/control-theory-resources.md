# 自动控制原理学习资料整理（持续更新）

> 这篇文章汇总我在学《自动控制原理》过程中用过的好资源，按学习顺序排列，欢迎收藏，会持续更新。

## 一、先修数学基础

自控的拦路虎其实是数学，正式开课前建议先过一遍：

- **拉普拉斯变换**：常用变换对、线性性质、微分/积分性质、终值定理
- **复数运算**：模与幅角、共轭、极点在复平面上的位置
- **一阶/二阶常微分方程**：知道解长什么样即可，不需要刷难题

## 三、教材与习题

1. 胡寿松《自动控制原理》（第七版，科学出版社）—— 使用最广，配《习题集》
2. 卢京潮《自动控制原理》（清华大学出版社）—— 配他的课用
3. **课和书尽量用同一套**，不同教材符号体系略有差别

## 四、MATLAB 仿真（强烈建议）

光听课容易飘，自己跑一遍仿真曲线，概念立刻落地：

```matlab
% 一个二阶系统：G(s) = 1 / (s^2 + 0.4s + 1)
num = [1];
den = [1 0.4 1];
G = tf(num, den);

step(G);   % 阶跃响应：看超调量、调节时间
rlocus(G); % 根轨迹：看极点随增益怎么跑
bode(G);   % 伯德图：看频域特性
```

## 五、学习路线（章节顺序）

1. 控制系统的数学模型（微分方程、传递函数、方块图化简）
2. 时域分析法（一阶/二阶响应、稳态误差、劳斯判据）
3. 根轨迹分析法
4. 频率分析法（伯德图、奈奎斯特判据）
5. 系统校正（超前/滞后校正）

每学完一章，**至少亲手画 10 道题的根轨迹和伯德图**，手动画过和看老师画完全是两回事。

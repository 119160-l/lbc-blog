# 复变函数计算器 (Complex Calculator)

## 项目目的

本项目是第1章"复数与复平面"的实践项目，通过Python编程实现以下功能：

1. **复数四则运算**：验证复数的加减乘除运算法则
2. **极坐标与直角坐标转换**：直观理解复数的两种表示方法
3. **复数乘方和开方**：理解棣莫弗定理和单位根的概念
4. **欧拉公式验证**：数值验证 e^{iθ} = cosθ + i sinθ
5. **几何可视化**：通过图形展示复数的加法、乘法和单位根

## 使用方法

```bash
cd "第一阶段-复变函数基础/第1章-复数与复平面/5-实践项目"
python3 complex_calculator.py
```

运行后会自动生成：
- `report.txt`：详细的分析报告
- `chapter1_addition.png`：复数加法的平行四边形法则图示
- `chapter1_multiplication.png`：复数的极坐标表示（模和辐角）
- `chapter1_multiplication_result.png`：复数乘法的几何意义（模相乘、辐角相加）
- `chapter1_unit_roots.png`：5次单位根在单位圆上的分布

## 代码逻辑

- **复数运算**：使用 Python 内置的 `complex` 类型进行运算
- **坐标转换**：使用 `cmath.rect()` 和 `cmath.phase()` 实现极坐标与直角坐标互转
- **欧拉公式**：分别计算 `cmath.exp(1j*theta)` 和 `cosθ + i sinθ`，对比差值
- **可视化**：使用 `matplotlib.pyplot.quiver()` 绘制向量，`contour` 辅助理解

## 结果分析

1. 复数加法满足平行四边形法则，在几何上表现为向量加法
2. 复数乘法：模长相乘，辐角相加（z1·z2 = r1·r2 · e^{i(θ1+θ2)}）
3. 欧拉公式的数值验证表明，计算精度可达 10^{-10} 量级
4. n次单位根均匀分布在单位圆上，相邻根之间的夹角为 2π/n

# 复变函数映射探索器 (Mapping Explorer)

## 项目目的

本项目是第2章"复变函数的基本概念"的实践项目，通过可视化方式探索复变函数的映射特性。

研究以下3个复变函数：
1. **w = z²** —— 平方映射
2. **w = 1/z** —— 倒数映射（反演变换）
3. **w = e^z** —— 指数映射

## 使用方法

```bash
cd "第一阶段-复变函数基础/第2章-复变函数的基本概念/5-实践项目"
python3 mapping_explorer.py
```

运行后会自动生成：
- `report.txt`：详细的分析报告
- `chapter2_w=z2_grid.png`：z² 映射的网格对比图
- `chapter2_w=z2_3d.png`：|z²| 的三维曲面图
- `chapter2_w=1/z_grid.png`：1/z 映射的网格对比图
- `chapter2_w=1/z_3d.png`：|1/z| 的三维曲面图
- `chapter2_w=e^z_grid.png`：e^z 映射的网格对比图
- `chapter2_w=e^z_3d.png`：|e^z| 的三维曲面图

## 代码逻辑

- **网格生成**：在z平面生成垂直和水平两组网格线
- **映射计算**：将每个网格点代入复变函数，计算w平面坐标
- **对比可视化**：左右并排显示z平面网格和w平面映射结果
- **3D曲面**：绘制 |f(z)| 的三维曲面，展示函数模的分布
- **性质分析**：在多个测试点计算数值导数，分析函数性质

## 结果分析

1. **w = z²**：将直角坐标网格映射为抛物线形网格。在 z=0 处导数 f'(0)=0，该点不是保角映射。辐角加倍，模长平方。
2. **w = 1/z**：实现反演变换，将圆映射为圆（广义圆），在 z=0 处有奇点。
3. **w = e^z**：将水平线映射为射线，垂直线映射为同心圆，是典型的保角映射。|e^z| = e^x 随实部指数增长。

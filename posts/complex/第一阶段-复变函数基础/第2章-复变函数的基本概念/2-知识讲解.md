## 1. 从实函数到复变函数——自然的推广

### 回顾实函数

在高等数学中，实函数 $y = f(x)$ 将实数 $x$ 映射为实数 $y$。

$$f: \mathbb{R} \to \mathbb{R}$$

### 复变函数的推广

复变函数 $w = f(z)$ 将复数 $z$ 映射为复数 $w$。

$$f: \mathbb{C} \to \mathbb{C}$$

### 本质区别

**实函数**是一维到一维的映射（输入一个数，输出一个数），**复变函数**是二维到二维的映射。

虽然表面上看都是"一个数到另一个数"，但由于复数本身是二维的，所以复变函数本质上是：

$$(x, y) \mapsto (u(x,y), v(x,y))$$

**关键理解：复变函数是二维空间到二维空间的映射变换。**

### 从实函数到复变函数的例子

| 实函数 | 对应复变函数 | 新的可能性 |
|:------|:------------|:-----------|
| $f(x) = x^2$ | $f(z) = z^2$ | 可以取负数的平方（如 $i^2 = -1$）|
| $f(x) = e^x$ | $f(z) = e^z$ | 可以计算 $e^{i\theta}$（欧拉公式）|
| $f(x) = \sin x$ | $f(z) = \sin z$ | 可以取复数的正弦 |
| $f(x) = \ln x$ | $f(z) = \ln z$ | 可以取负数的对数（多值函数）|

## 2. 复变函数的核心思想：映射

### 映射视角

将复变函数理解为一个"变换"或"映射"是最重要的思维方式：

$$z \xrightarrow{f} w = f(z)$$

- $z$ 平面上的每个点经过映射后到达 $w$ 平面上的某个点
- $z$ 平面上的一条曲线经过映射后变成 $w$ 平面上的一条曲线
- $z$ 平面上的一个区域经过映射后变成 $w$ 平面上的一个区域

### 思考题

想象 $f(z) = z^2$ 的映射效果：

- $z$ 平面上单位圆上的点（$z = e^{i\theta}$）被映射到 $w$ 平面上的什么位置？
  - 答案：$w = e^{i2\theta}$，仍然是单位圆，但角度变为 $2$ 倍
- $z$ 平面上的射线 $\theta = \text{常数}$ 被映射到什么？
  - 答案：$w$ 平面上的射线，辐角变为 $2$ 倍

## 3. 复变函数的极限——为什么比实极限复杂得多？

### 实函数极限：只有两个方向

在实函数中，$x \to x_0$ 只有两个方向：**从左**（$x \to x_0^-$）和**从右**（$x \to x_0^+$）。

```
-----x₀-----
     →  ←
```

### 复变函数极限：无穷多个方向

在复变函数中，$z \to z_0$ 可以从**任意方向**趋近：

```
        ↑
        │   ↖
        │     ↘
        │  →  ·z₀  ←
        │     ↗
        │   ↙
        ↓
```

- 从正上方趋近
- 从正下方趋近
- 从左方趋近
- 从右方趋近
- 沿螺旋线趋近
- 沿任意曲线趋近

**所有方向的极限都必须相等，极限才存在。**

### 为什么这个区别很重要？

因为复变函数极限的"方向无关性"要求非常强，所以很多看似"合理"的函数在复变中并不可导（下一章会详细讨论）。

### 一个重要的理解

复变函数的极限实际上等价于**二元函数 $u(x,y)$ 和 $v(x,y)$ 的极限同时存在**。所以复变函数极限的问题可以转化为我们已经熟悉的二元实函数极限问题。

## 4. 连续性——从实到复的自然延伸

### 连续性的本质

$$f(z) \text{在} z_0 \text{连续} \iff \lim_{z \to z_0} f(z) = f(z_0)$$

核心思想：**当 $z$ 无限接近 $z_0$ 时，$f(z)$ 无限接近 $f(z_0)$。**

### 连续性的判定

判断 $f(z)$ 是否连续，只需要判断它的实部 $u(x,y)$ 和虚部 $v(x,y)$ 是否都连续。

这大大简化了问题——**复变函数的连续性归结为二元实函数的连续性。**

### 复变函数连续性的"好性质"

与实函数类似，连续复变函数也有：
- **有界闭区域上的连续函数必有界**
- **有界闭区域上的连续函数能取到最大值和最小值**
- 连续函数的四则运算和复合仍连续

## 5. 复变函数的可视化方法

### 困境：四维空间不可见

$f(z) = u + iv$ 需要四个维度（$x, y, u, v$），人类无法直接感知。

### 解决方案：映射法

将 $z$ 平面上的图形（网格、曲线、区域）画出来，再画出这些图形在 $w$ 平面上的像。

**这是复变函数最常用的可视化方法。**

### 例子：$f(z) = z^2$ 的映射

```
z-平面（网格）          w-平面（映射后）
┌───────┬───────┐      ┌───────┬───────┐
│       │       │      │       │       │
│   ────┼───    │  →   │  ╰─── ┼───╯  │
│       │       │      │ ╱     │     ╲ │
│   ────┼───    │      │─── ───┼─── ───│
│       │       │      │ ╲     │     ╱ │
└───────┴───────┘      └───────┴───────┘
```

### 另一种方法：三维曲面

画出 $u(x,y)$ 或 $v(x,y)$ 的三维曲面图，可以直观看到函数的变化。

## 本章小结

学习本章后，你应该能够回答以下问题：

1. **复变函数和实函数的本质区别是什么？** 复变函数是 $\mathbb{R}^2 \to \mathbb{R}^2$ 的映射
2. **复变函数如何分解？** $f(z) = u(x,y) + i\,v(x,y)$
3. **复变函数极限与实函数极限的关键区别？** 复极限要求所有趋近方向一致
4. **复变函数连续性的判定？** 等价于 $u$ 和 $v$ 都连续
5. **复变函数如何可视化？** 主要通过映射法和三维曲面法

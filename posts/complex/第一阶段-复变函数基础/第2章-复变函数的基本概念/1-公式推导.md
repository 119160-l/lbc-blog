## 1. 复变函数的定义

### 基本定义

设 $G$ 是复平面上的一个点集（通常是区域），如果对于 $G$ 中的每一个复数 $z$，按照某种对应法则，都有一个或多个确定的复数 $w$ 与之对应，则称 $w$ 是 $z$ 的**复变函数**，记作：

$$w = f(z), \quad z \in G$$

- $G$ 称为**定义域**
- $f(z)$ 的全体取值称为**值域**
- 如果每个 $z$ 对应唯一的 $w$，称为**单值函数**
- 如果每个 $z$ 对应多个 $w$，称为**多值函数**

### 复变函数的实部与虚部表示

由于 $z = x + iy$，$w = u + iv$，一个复变函数可以写成两个实变函数的组合：

$$f(z) = u(x, y) + i\,v(x, y)$$

其中 $u(x, y)$ 和 $v(x, y)$ 都是实值二元函数。

**推导：**
设 $z = x + iy$，$w = f(z) = u + iv$，则 $u$ 和 $v$ 都是 $x$ 和 $y$ 的函数，记作：

$$
\begin{cases}
u = u(x, y) = \operatorname{Re}[f(x + iy)] \\[2pt]
v = v(x, y) = \operatorname{Im}[f(x + iy)]
\end{cases}
$$

### 例子：$f(z) = z^2$ 的实部与虚部

$$
\begin{aligned}
f(z) &= (x + iy)^2 = x^2 + 2ixy + i^2 y^2 \\
     &= (x^2 - y^2) + i(2xy)
\end{aligned}
$$

因此：

$$u(x, y) = x^2 - y^2, \qquad v(x, y) = 2xy$$

## 2. 复变函数的极限

### 极限的定义

设函数 $w = f(z)$ 定义在 $z_0$ 的去心邻域内，如果存在常数 $A$，对于任意给定的 $\varepsilon > 0$，总存在 $\delta > 0$，使得当 $0 < |z - z_0| < \delta$ 时，有：

$$|f(z) - A| < \varepsilon$$

则称 $A$ 为 $f(z)$ 当 $z \to z_0$ 时的**极限**，记作：

$$\lim_{z \to z_0} f(z) = A$$

### 极限的唯一性

**定理：** 如果极限存在，则极限唯一。

**证明（反证法）：**
假设 $\lim_{z \to z_0} f(z) = A$ 且 $\lim_{z \to z_0} f(z) = B$，且 $A \neq B$。

取 $\varepsilon = \dfrac{|A - B|}{2} > 0$，则存在 $\delta_1, \delta_2 > 0$，使得：

当 $0 < |z - z_0| < \delta_1$ 时，$|f(z) - A| < \varepsilon$
当 $0 < |z - z_0| < \delta_2$ 时，$|f(z) - B| < \varepsilon$

取 $\delta = \min(\delta_1, \delta_2)$，则当 $0 < |z - z_0| < \delta$ 时，同时有：

$$
|A - B| \leq |f(z) - A| + |f(z) - B| < \varepsilon + \varepsilon = |A - B|
$$

矛盾。因此极限唯一。

### 极限与实部虚部的关系

**定理：** $\lim_{z \to z_0} f(z) = A = a + ib$ 当且仅当

$$\lim_{(x,y) \to (x_0,y_0)} u(x, y) = a, \quad \lim_{(x,y) \to (x_0,y_0)} v(x, y) = b$$

**证明：**

（$\Rightarrow$）设 $\lim_{z \to z_0} f(z) = A$，则对任意 $\varepsilon > 0$，存在 $\delta > 0$，当 $0 < |z - z_0| < \delta$ 时，$|f(z) - A| < \varepsilon$。

由于 $|u(x,y) - a| \leq |f(z) - A| < \varepsilon$，且 $|v(x,y) - b| \leq |f(z) - A| < \varepsilon$，因此：

$$\lim_{(x,y) \to (x_0,y_0)} u(x, y) = a, \quad \lim_{(x,y) \to (x_0,y_0)} v(x, y) = b$$

（$\Leftarrow$）反之，设两个实极限成立，则对任意 $\varepsilon > 0$，存在 $\delta > 0$，当 $0 < |z - z_0| < \delta$ 时：

$$|u(x,y) - a| < \frac{\varepsilon}{\sqrt{2}}, \quad |v(x,y) - b| < \frac{\varepsilon}{\sqrt{2}}$$

因此：

$$
|f(z) - A| = \sqrt{(u - a)^2 + (v - b)^2} < \sqrt{\frac{\varepsilon^2}{2} + \frac{\varepsilon^2}{2}} = \varepsilon
$$

所以 $\lim_{z \to z_0} f(z) = A$。

### 极限的四则运算法则

若 $\lim_{z \to z_0} f(z) = A$，$\lim_{z \to z_0} g(z) = B$，则：

1. $\lim_{z \to z_0} [f(z) \pm g(z)] = A \pm B$
2. $\lim_{z \to z_0} [f(z) \cdot g(z)] = A \cdot B$
3. $\lim_{z \to z_0} \dfrac{f(z)}{g(z)} = \dfrac{A}{B}$（$B \neq 0$）

**证明（以乘法为例）：**

$$
\begin{aligned}
|f(z)g(z) - AB| &= |f(z)g(z) - f(z)B + f(z)B - AB| \\
&\leq |f(z)||g(z) - B| + |B||f(z) - A|
\end{aligned}
$$

由于 $\lim_{z \to z_0} f(z) = A$，$f(z)$ 在 $z_0$ 附近有界，设 $|f(z)| \leq M$，则：

$$
|f(z)g(z) - AB| \leq M|g(z) - B| + |B||f(z) - A|
$$

当 $z \to z_0$ 时，右边趋于 $0$，因此极限为 $AB$。

### 与实函数极限的关键区别

**复变函数的极限要求 $z$ 从任意方向趋近于 $z_0$ 时极限都存在且相等。**

这意味着在复平面上，$z \to z_0$ 的路径有无穷多种（可以从上方、下方、左方、右方、沿曲线等），所有路径都必须趋向同一个值。

```
      ↑
      │  (路径1)
      │    ↖
      │      ↘
      │   (路径2) → · z₀ ← (路径3)
      │      ↗
      │    ↙
      │  (路径4)
      ↓
```

这与实函数中 $x \to x_0$ 只有左右两个方向完全不同。

## 3. 复变函数的连续性

### 连续性的定义

设 $f(z)$ 在 $z_0$ 的某邻域内有定义，如果：

$$\lim_{z \to z_0} f(z) = f(z_0)$$

则称 $f(z)$ 在 $z_0$ 处**连续**。

### 用 $\varepsilon$-$\delta$ 语言表述

对任意 $\varepsilon > 0$，存在 $\delta > 0$，使得当 $|z - z_0| < \delta$ 时，有：

$$|f(z) - f(z_0)| < \varepsilon$$

### 连续性的判定

**定理：** $f(z) = u(x,y) + i\,v(x,y)$ 在 $z_0 = x_0 + iy_0$ 处连续当且仅当 $u(x,y)$ 和 $v(x,y)$ 都在 $(x_0, y_0)$ 处连续。

**证明：** 由极限与实部虚部的关系定理直接可得。

### 连续函数的性质

**性质 1：** 若 $f(z)$ 和 $g(z)$ 在 $z_0$ 处连续，则 $f(z) \pm g(z)$，$f(z) \cdot g(z)$，$\dfrac{f(z)}{g(z)}$（$g(z_0) \neq 0$）也在 $z_0$ 处连续。

**性质 2：** 若 $f(z)$ 在 $z_0$ 处连续，$g(w)$ 在 $w_0 = f(z_0)$ 处连续，则复合函数 $g(f(z))$ 在 $z_0$ 处连续。

**性质 3：** 若 $f(z)$ 在有界闭区域 $\overline{D}$ 上连续，则 $f(z)$ 在 $\overline{D}$ 上有界，且 $|f(z)|$ 在 $\overline{D}$ 上能取到最大值和最小值。

## 4. 复变函数与实函数的关系

### 复变函数是两个实函数的组合

每个复变函数 $f(z) = u(x,y) + i\,v(x,y)$ 本质上是一个从 $\mathbb{R}^2$ 到 $\mathbb{R}^2$ 的映射：

$$(x, y) \mapsto (u(x,y), v(x,y))$$

### 映射的雅可比矩阵

将 $f$ 视为 $\mathbb{R}^2 \to \mathbb{R}^2$ 的映射，其雅可比矩阵为：

$$J_f = \begin{pmatrix}
\dfrac{\partial u}{\partial x} & \dfrac{\partial u}{\partial y} \\[6pt]
\dfrac{\partial v}{\partial x} & \dfrac{\partial v}{\partial y}
\end{pmatrix}$$

这个矩阵在后续学习解析函数（C-R方程）时非常重要。

## 5. 复变函数的可视化

### 方法一：三维图像法

一个复变函数 $w = f(z)$ 需要两个实数输入 $(x, y)$ 和两个实数输出 $(u, v)$，总共需要四维空间，无法直接可视化。

### 方法二：映射法（最常用）

将复平面上的集合（如网格、曲线、区域）映射到另一个复平面，观察形状的变化。

**例子：$f(z) = z^2$ 的映射效果**

$z$ 平面上的射线 $z = re^{i\theta}$（$\theta$ 固定，$r$ 变化）被映射为：

$$w = (re^{i\theta})^2 = r^2 e^{i2\theta}$$

即 $w$ 平面上的射线，辐角变为原来的 $2$ 倍。

$z$ 平面上的圆弧 $|z| = r$ 被映射为 $|w| = r^2$ 的圆弧。

### 方法三：将 $\operatorname{Re}(f(z))$ 或 $\operatorname{Im}(f(z))$ 作为高度画三维曲面

例如，对于 $f(z) = z^2$，可以画出 $u(x,y) = x^2 - y^2$ 的三维曲面图。

## 1. 复数项级数

### 复数项级数的定义

形如 $\displaystyle\sum_{n=1}^{\infty} a_n = a_1 + a_2 + a_3 + \cdots$ 的表达式称为复数项级数，其中 $a_n \in \mathbb{C}$。

### 收敛性

设 $S_n = \displaystyle\sum_{k=1}^n a_k$ 为部分和。如果 $\lim_{n\to\infty} S_n = S$（$S$ 为有限复数），则称级数收敛，$S$ 为级数的和。

### 收敛的充要条件

设 $a_n = \alpha_n + i\beta_n$，则 $\displaystyle\sum_{n=1}^{\infty} a_n$ 收敛当且仅当 $\displaystyle\sum_{n=1}^{\infty} \alpha_n$ 和 $\displaystyle\sum_{n=1}^{\infty} \beta_n$ 都收敛。

**证明：** 由部分和 $S_n = A_n + iB_n$，其中 $A_n = \sum_{k=1}^n \alpha_k$，$B_n = \sum_{k=1}^n \beta_k$。$S_n$ 收敛 $\iff$ $A_n$ 和 $B_n$ 都收敛。

### 绝对收敛

如果 $\displaystyle\sum_{n=1}^{\infty} |a_n|$ 收敛，则称 $\displaystyle\sum_{n=1}^{\infty} a_n$ 绝对收敛。

**定理：** 绝对收敛 $\Rightarrow$ 收敛。

**证明：** 由 $|\alpha_n| \leq |a_n|$，$|\beta_n| \leq |a_n|$，若 $\sum |a_n|$ 收敛，则 $\sum \alpha_n$ 和 $\sum \beta_n$ 绝对收敛，从而收敛，因此 $\sum a_n$ 收敛。

## 2. 幂级数

### 幂级数的定义

形如 $\displaystyle\sum_{n=0}^{\infty} c_n (z - z_0)^n = c_0 + c_1(z - z_0) + c_2(z - z_0)^2 + \cdots$ 的级数称为幂级数，其中 $c_n$ 为复常数。

### 阿贝尔定理

**定理：** 如果幂级数 $\sum_{n=0}^{\infty} c_n (z - z_0)^n$ 在 $z = z_1$（$z_1 \neq z_0$）处收敛，则它在 $|z - z_0| < |z_1 - z_0|$ 内绝对收敛且内闭一致收敛。

**证明思路：** 由收敛的必要条件，$|c_n (z_1 - z_0)^n| \to 0$，因此存在 $M > 0$ 使得 $|c_n (z_1 - z_0)^n| \leq M$。对任意 $z$ 满足 $|z - z_0| < |z_1 - z_0|$，令 $q = \frac{|z - z_0|}{|z_1 - z_0|} < 1$，则：

$$|c_n (z - z_0)^n| = |c_n (z_1 - z_0)^n| \cdot \left|\frac{z - z_0}{z_1 - z_0}\right|^n \leq M q^n$$

由于 $\sum M q^n$ 收敛，由比较判别法，原级数绝对收敛。

### 收敛半径

幂级数的收敛区域是一个圆盘 $|z - z_0| < R$，$R$ 称为**收敛半径**。

在 $|z - z_0| < R$ 内，级数绝对收敛；在 $|z - z_0| > R$ 内，级数发散。

### 收敛半径的计算

**公式 1（比值法）：** 如果 $\lim_{n\to\infty} \left|\frac{c_{n+1}}{c_n}\right|$ 存在，则：

$$R = \lim_{n\to\infty} \left|\frac{c_n}{c_{n+1}}\right|$$

**公式 2（根值法）：** $R = \frac{1}{\displaystyle\limsup_{n\to\infty} \sqrt[n]{|c_n|}}$

**证明（比值法）：** 由比值判别法，级数 $\sum c_n (z - z_0)^n$ 绝对收敛的条件为：

$$\lim_{n\to\infty} \left|\frac{c_{n+1}(z - z_0)^{n+1}}{c_n (z - z_0)^n}\right| = |z - z_0| \lim_{n\to\infty} \left|\frac{c_{n+1}}{c_n}\right| < 1$$

即 $|z - z_0| < \lim_{n\to\infty} \left|\frac{c_n}{c_{n+1}}\right| = R$。

### 幂级数的性质

**性质 1：** 幂级数在收敛圆内解析，且可以逐项求导和逐项积分：

$$\frac{d}{dz} \sum_{n=0}^{\infty} c_n (z - z_0)^n = \sum_{n=1}^{\infty} n c_n (z - z_0)^{n-1}$$

$$\int \sum_{n=0}^{\infty} c_n (z - z_0)^n \, dz = \sum_{n=0}^{\infty} \frac{c_n}{n+1} (z - z_0)^{n+1} + C$$

**性质 2：** 逐项求导和逐项积分不改变收敛半径。

## 3. 泰勒级数

### 泰勒定理

**定理：** 如果 $f(z)$ 在区域 $D$ 内解析，$z_0 \in D$，则 $f(z)$ 在 $z_0$ 的某邻域 $|z - z_0| < R$ 内可以展开为幂级数：

$$f(z) = \sum_{n=0}^{\infty} \frac{f^{(n)}(z_0)}{n!} (z - z_0)^n$$

其中 $R$ 等于从 $z_0$ 到 $D$ 的边界的最短距离。这个级数称为 $f(z)$ 在 $z_0$ 处的**泰勒级数**。

### 证明

由柯西积分公式，取 $C$ 为以 $z_0$ 为圆心、$r$ 为半径的圆周（$r < R$）：

$$f(z) = \frac{1}{2\pi i} \oint_C \frac{f(\zeta)}{\zeta - z} \, d\zeta$$

将 $\frac{1}{\zeta - z}$ 展开为几何级数：

$$\frac{1}{\zeta - z} = \frac{1}{(\zeta - z_0) - (z - z_0)} = \frac{1}{\zeta - z_0} \cdot \frac{1}{1 - \frac{z - z_0}{\zeta - z_0}} = \sum_{n=0}^{\infty} \frac{(z - z_0)^n}{(\zeta - z_0)^{n+1}}$$

代入柯西积分公式：

$$
f(z) = \frac{1}{2\pi i} \oint_C f(\zeta) \sum_{n=0}^{\infty} \frac{(z - z_0)^n}{(\zeta - z_0)^{n+1}} \, d\zeta
= \sum_{n=0}^{\infty} \left[\frac{1}{2\pi i} \oint_C \frac{f(\zeta)}{(\zeta - z_0)^{n+1}} \, d\zeta\right] (z - z_0)^n
$$

由高阶导数公式，$\frac{1}{2\pi i} \oint_C \frac{f(\zeta)}{(\zeta - z_0)^{n+1}} \, d\zeta = \frac{f^{(n)}(z_0)}{n!}$，因此：

$$f(z) = \sum_{n=0}^{\infty} \frac{f^{(n)}(z_0)}{n!} (z - z_0)^n$$

### 常见函数的泰勒展开

**$e^z$ 在 $z = 0$ 处的展开：**

由 $f^{(n)}(0) = e^0 = 1$：

$$e^z = \sum_{n=0}^{\infty} \frac{z^n}{n!} = 1 + z + \frac{z^2}{2!} + \frac{z^3}{3!} + \cdots$$

收敛半径 $R = \infty$。

**$\sin z$ 在 $z = 0$ 处的展开：**

$$\sin z = \sum_{n=0}^{\infty} \frac{(-1)^n}{(2n+1)!} z^{2n+1} = z - \frac{z^3}{3!} + \frac{z^5}{5!} - \cdots$$

收敛半径 $R = \infty$。

**$\cos z$ 在 $z = 0$ 处的展开：**

$$\cos z = \sum_{n=0}^{\infty} \frac{(-1)^n}{(2n)!} z^{2n} = 1 - \frac{z^2}{2!} + \frac{z^4}{4!} - \cdots$$

收敛半径 $R = \infty$。

**$\frac{1}{1 - z}$ 在 $z = 0$ 处的展开：**

$$\frac{1}{1 - z} = \sum_{n=0}^{\infty} z^n = 1 + z + z^2 + z^3 + \cdots$$

收敛半径 $R = 1$。

**$\ln(1 + z)$ 在 $z = 0$ 处的展开：**

$$\ln(1 + z) = \sum_{n=1}^{\infty} \frac{(-1)^{n-1}}{n} z^n = z - \frac{z^2}{2} + \frac{z^3}{3} - \frac{z^4}{4} + \cdots$$

收敛半径 $R = 1$。

## 4. 洛朗级数

### 为什么需要洛朗级数？

泰勒级数只能展开解析函数，但如果函数在 $z_0$ 处有奇点，泰勒级数就不适用了。洛朗级数允许在包含奇点的环形区域内展开。

### 洛朗定理

**定理：** 如果 $f(z)$ 在环形区域 $r < |z - z_0| < R$（$0 \leq r < R \leq \infty$）内解析，则 $f(z)$ 在该环形区域内可以展开为：

$$f(z) = \sum_{n=-\infty}^{\infty} c_n (z - z_0)^n$$

其中系数

$$c_n = \frac{1}{2\pi i} \oint_C \frac{f(\zeta)}{(\zeta - z_0)^{n+1}} \, d\zeta$$

$C$ 是环形区域内任意一条围绕 $z_0$ 的简单闭曲线。

### 洛朗级数的结构

洛朗级数由两部分组成：

$$f(z) = \underbrace{\sum_{n=0}^{\infty} c_n (z - z_0)^n}_{\text{解析部分（正则部分）}} + \underbrace{\sum_{n=1}^{\infty} c_{-n} (z - z_0)^{-n}}_{\text{主要部分（奇异部分）}}$$

- **解析部分**：在 $|z - z_0| < R$ 内收敛，是泰勒级数
- **主要部分**：在 $|z - z_0| > r$ 内收敛，反映了奇点的性质

### 例子：$f(z) = \frac{1}{z(z-1)}$ 在 $0 < |z| < 1$ 内的洛朗展开

$$
\begin{aligned}
f(z) &= \frac{1}{z(z-1)} = -\frac{1}{z} + \frac{1}{z-1} \\
&= -\frac{1}{z} - \frac{1}{1 - z} \\
&= -\frac{1}{z} - \sum_{n=0}^{\infty} z^n \\
&= -\frac{1}{z} - 1 - z - z^2 - z^3 - \cdots
\end{aligned}
$$

其中 $-\frac{1}{z}$ 是主要部分，$-1 - z - z^2 - \cdots$ 是解析部分。

### 例子：$f(z) = e^{1/z}$ 在 $0 < |z| < \infty$ 内的洛朗展开

由 $e^z$ 的泰勒展开，将 $z$ 替换为 $1/z$：

$$e^{1/z} = \sum_{n=0}^{\infty} \frac{1}{n!} z^{-n} = 1 + \frac{1}{z} + \frac{1}{2! z^2} + \frac{1}{3! z^3} + \cdots$$

这个展开有无限多项主要部分（所有负幂项），说明 $z = 0$ 是本性奇点。

## 5. 孤立奇点的分类

### 孤立奇点的定义

如果 $f(z)$ 在 $z_0$ 处不解析，但在 $z_0$ 的某去心邻域 $0 < |z - z_0| < \delta$ 内解析，则称 $z_0$ 为 $f(z)$ 的**孤立奇点**。

### 分类依据

根据洛朗展开中主要部分的特点，将孤立奇点分为三类：

| 类型 | 主要部分特征 | 极限 $\lim_{z\to z_0} f(z)$ |
|:----|:------------|:---------------------------|
| 可去奇点 | 没有主要部分（$c_{-n}=0$ 对所有 $n$） | 存在且有限 |
| 极点 | 只有有限项主要部分 | 无穷大 |
| 本性奇点 | 有无穷多项主要部分 | 不存在（也不为无穷大） |

### 可去奇点

如果 $f(z)$ 在 $z_0$ 处的洛朗展开没有负幂项：

$$f(z) = c_0 + c_1(z - z_0) + c_2(z - z_0)^2 + \cdots$$

则可补充定义 $f(z_0) = c_0$，使 $f(z)$ 在 $z_0$ 处解析。

**例子：** $f(z) = \frac{\sin z}{z}$ 在 $z = 0$ 处

$$\frac{\sin z}{z} = 1 - \frac{z^2}{3!} + \frac{z^4}{5!} - \cdots$$

没有负幂项，所以 $z = 0$ 是可去奇点。补充定义 $f(0) = 1$ 后，函数在 $z = 0$ 处解析。

### 极点

如果 $f(z)$ 在 $z_0$ 处的洛朗展开从 $-(m)$ 次方开始：

$$f(z) = \frac{c_{-m}}{(z - z_0)^m} + \frac{c_{-(m-1)}}{(z - z_0)^{m-1}} + \cdots + c_0 + c_1(z - z_0) + \cdots$$

其中 $c_{-m} \neq 0$，则称 $z_0$ 为 $f(z)$ 的 $m$**阶极点**。

当 $m = 1$ 时，称为**简单极点**。

**判定方法：** $z_0$ 是 $f(z)$ 的 $m$ 阶极点当且仅当 $\lim_{z\to z_0} (z - z_0)^m f(z)$ 存在且非零。

**例子：** $f(z) = \frac{1}{(z-1)^2(z+1)}$ 在 $z = 1$ 处是二阶极点，在 $z = -1$ 处是一阶极点（简单极点）。

### 本性奇点

如果洛朗展开有无穷多项负幂项，则 $z_0$ 是**本性奇点**。

**例子：** $f(z) = e^{1/z}$ 在 $z = 0$ 处

$$e^{1/z} = 1 + \frac{1}{z} + \frac{1}{2! z^2} + \frac{1}{3! z^3} + \cdots$$

有无穷多项负幂项，$z = 0$ 是本性奇点。

**魏尔斯特拉斯定理：** 在本性奇点的任意去心邻域内，$f(z)$ 可以无限接近任意复数（即像集在复平面上稠密）。

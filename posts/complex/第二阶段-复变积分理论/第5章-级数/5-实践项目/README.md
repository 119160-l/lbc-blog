# 级数展开逼近器 (Series Approximator)

## 项目目的

本项目通过数值计算方法，对复变函数的泰勒展开和洛朗展开进行可视化和精度分析。主要目标包括：

1. **泰勒展开逼近**：计算常用函数在展开点附近的泰勒级数逼近
2. **精度对比**：比较不同项数 (N=1,3,5,10,20) 下的逼近精度
3. **洛朗展开**：在不同环形区域对有理函数进行洛朗展开
4. **收敛性分析**：可视化收敛圆和误差随项数的变化

## 代码逻辑

### 核心函数

1. **`taylor_series_known(f, z0, N, z_vals, known_coeff_func)`**
   - 使用已知解析系数计算泰勒展开
   - 支持 e^z (1/n!)、sin(z) (交错奇阶乘)、1/(1-z) (系数全为1)

2. **`laurent_series(f, z0, inner_r, outer_r, N_neg, N_pos, z_val)`**
   - 使用数值积分计算洛朗展开系数
   - 在环形区域内对正负幂次分别积分

3. **可视化函数**
   - `plot_taylor_approximations()` — 绘制实轴上的逼近效果
   - `plot_error_vs_terms()` — 误差随项数变化
   - `plot_convergence_circles()` — 收敛圆图示

### 测试函数

- f(z) = e^z（整函数，收敛半径无穷大）
- f(z) = sin(z)（整函数，收敛半径无穷大）
- f(z) = 1/(1-z)（在 z=1 有奇点，收敛半径 R=1）
- f(z) = 1/((z-1)(z-2))（洛朗展开，验证不同环形区域）

## 结果分析

### 泰勒展开

- **整函数** (e^z, sin(z))：在任何点展开都收敛，项数越多，逼近越精确
- **有奇点函数** (1/(1-z))：收敛半径由最近的奇点决定（R=1）
- 在收敛半径内，增加项数指数级降低误差；在收敛半径外，级数发散

### 洛朗展开

- 函数 1/((z-1)(z-2)) 在 z=0 展开时，三个区域有不同的展开形式
- |z| < 1：纯泰勒级数（正幂次）
- 1 < |z| < 2：洛朗级数（含负幂次）
- |z| > 2：洛朗级数（更多负幂次项）

# 复积分计算器 (Complex Integrator)

## 项目目的

本项目通过数值计算的方法，对复变函数的积分进行可视化计算和验证。主要目标包括：

1. **数值积分实现**：使用参数化方法计算复变函数沿任意路径的积分
2. **验证柯西积分定理**：对解析函数沿闭路积分应为零
3. **验证柯西积分公式**：通过边界积分计算内部点函数值
4. **可视化分析**：绘制积分路径和结果对比图

## 使用方法

### 环境要求

- Python 3.6+

## 代码逻辑

### 核心函数

1. **`complex_integral(f, z_func, t_start, t_end, N=10000)`**
   - 通过参数化曲线计算复积分 ∫_C f(z) dz
   - 使用梯形法则进行数值积分
   - 参数 `z_func` 将参数 t 映射到复平面上的点

2. **曲线参数化**
   - `line_segment(z0, z1)` — 直线段参数化
   - `arc(center, radius, theta_start, theta_end)` — 圆弧参数化
   - `closed_circle(center, radius)` — 闭合圆参数化
   - `closed_triangle(z0, z1, z2)` — 闭合三角形参数化

3. **测试函数**
   - f(z) = z（整函数）
   - f(z) = z²（整函数）
   - f(z) = 1/z（在 z=0 有奇点）
   - f(z) = e^z（整函数）

### 验证内容

- **柯西积分定理**：计算解析函数沿闭路的积分，验证结果接近零
- **柯西积分公式**：f(a) = (1/2πi) ∮ f(z)/(z-a) dz，验证误差在 1e-10 量级

## 结果分析

### 柯西积分定理验证

对于整函数 f(z)=z, z², e^z，沿任何闭路积分结果接近 0（误差 ~1e-12），验证了柯西积分定理。

对于 f(z)=1/z，沿包围原点的闭路积分结果为 2πi（不为零），因为函数在 z=0 处有奇点。

### 柯西积分公式验证

对于 f(z)=e^z，沿 |z|=2 的积分计算 f(a) 的值，与理论值 e^a 的误差在 1e-10~1e-12 量级，验证了柯西积分公式的正确性。

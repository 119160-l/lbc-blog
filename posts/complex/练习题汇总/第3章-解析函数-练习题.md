### 基础题（1-3题）

---

**1.** 判断下列函数在何处可导、何处解析，并求出可导点的导数：

（1）$f(z) = z^2$  
（2）$f(z) = \bar{z}$  
（3）$f(z) = |z|^2$

---

**2.** 利用柯西-黎曼方程，判断下列函数是否为解析函数：

（1）$f(z) = e^x(\cos y + i\sin y)$  
（2）$f(z) = \sin x \cosh y + i\cos x \sinh y$

---

**3.** 求下列解析函数的导数（用 $z$ 表示）：

（1）$f(z) = z^3 + 2z^2 - 5z + 1$  
（2）$f(z) = \frac{1}{z^2 + 1}$  
（3）$f(z) = e^{iz}$

---

### 进阶题（4-6题）

---

**4.** 验证函数 $u(x, y) = x^3 - 3xy^2$ 是调和函数，并求其共轭调和函数 $v(x, y)$，使 $f(z) = u + iv$ 为解析函数。

---

**5.** 已知解析函数 $f(z) = u + iv$ 的虚部 $v(x, y) = e^{-x}\sin y$，求 $f(z)$。

---

**6.** 求下列各式的值：

（1）$e^{1 + i\frac{\pi}{2}}$  
（2）$\sin(i)$  
（3）$\cos\left(\frac{\pi}{2} + i\right)$

---

### 综合题（7-10题）

---

**7.** 求 $\text{Ln}(-1)$ 和 $\text{Ln}(1 + i)$ 的所有值，并写出主值。

---

**8.** 求下列各式的值：

（1）$i^i$  
（2）$(-1)^{\sqrt{2}}$  
（3）$2^{1 + i}$

---

**9.** 已知 $u(x, y) = e^x(x\cos y - y\sin y)$ 是调和函数，求其共轭调和函数 $v(x, y)$，并写出 $f(z) = u + iv$ 的表达式。

---

**10.** 设 $f(z)$ 是解析函数，且 $f(z) = u(x, y) + iv(x, y)$。

（1）证明：若 $f(z)$ 恒为常数，则 $u$ 和 $v$ 均为常数。  
（2）证明：若 $f(z)$ 是实值函数（即 $v \equiv 0$），则 $f(z)$ 为常数。  
（3）已知 $f(z)$ 满足 $f'(z) = 0$ 在整个复平面上成立，求 $f(z)$。

---

## 参考答案与解析

**1. 解：**

设 $z = x + iy$，$f(z) = u(x, y) + iv(x, y)$

（1）$f(z) = z^2 = (x + iy)^2 = x^2 - y^2 + 2ixy$

$u = x^2 - y^2$，$v = 2xy$

$\frac{\partial u}{\partial x} = 2x$，$\frac{\partial u}{\partial y} = -2y$

$\frac{\partial v}{\partial x} = 2y$，$\frac{\partial v}{\partial y} = 2x$

C-R方程：$\frac{\partial u}{\partial x} = \frac{\partial v}{\partial y}$ ⟹ $2x = 2x$ ✓

$-\frac{\partial u}{\partial y} = \frac{\partial v}{\partial x}$ ⟹ $-(-2y) = 2y$ ⟹ $2y = 2y$ ✓

C-R方程在整个复平面上成立，且偏导数均连续，所以 $f(z) = z^2$ 在整个复平面上解析。

导数：$f'(z) = 2z$

（2）$f(z) = \bar{z} = x - iy$

$u = x$，$v = -y$

$\frac{\partial u}{\partial x} = 1$，$\frac{\partial u}{\partial y} = 0$

$\frac{\partial v}{\partial x} = 0$，$\frac{\partial v}{\partial y} = -1$

C-R方程：$\frac{\partial u}{\partial x} = \frac{\partial v}{\partial y}$ ⟹ $1 = -1$ ✗

C-R方程处处不成立，所以 $f(z) = \bar{z}$ 在任何点都不可导，也不解析。

（3）$f(z) = |z|^2 = x^2 + y^2$

$u = x^2 + y^2$，$v = 0$

$\frac{\partial u}{\partial x} = 2x$，$\frac{\partial u}{\partial y} = 2y$

$\frac{\partial v}{\partial x} = 0$，$\frac{\partial v}{\partial y} = 0$

C-R方程：$\frac{\partial u}{\partial x} = \frac{\partial v}{\partial y}$ ⟹ $2x = 0$ ⟹ $x = 0$

$-\frac{\partial u}{\partial y} = \frac{\partial v}{\partial x}$ ⟹ $-2y = 0$ ⟹ $y = 0$

C-R方程仅在 $z = 0$ 处成立，所以 $f(z) = |z|^2$ 仅在 $z = 0$ 处可导，但不在任何区域中解析（解析要求在一个邻域内处处可导）。

导数：$f'(0) = \frac{\partial u}{\partial x}(0,0) + i\frac{\partial v}{\partial x}(0,0) = 0 + i \cdot 0 = 0$

> **关键点**：解析性比可导性要求更强，需要在某邻域内处处可导。

**2. 解：**

（1）$f(z) = e^x(\cos y + i\sin y) = e^x\cos y + ie^x\sin y$

$u = e^x\cos y$，$v = e^x\sin y$

$\frac{\partial u}{\partial x} = e^x\cos y$，$\frac{\partial u}{\partial y} = -e^x\sin y$

$\frac{\partial v}{\partial x} = e^x\sin y$，$\frac{\partial v}{\partial y} = e^x\cos y$

C-R方程验证：

$\frac{\partial u}{\partial x} = e^x\cos y = \frac{\partial v}{\partial y}$ ✓

$-\frac{\partial u}{\partial y} = -(-e^x\sin y) = e^x\sin y = \frac{\partial v}{\partial x}$ ✓

C-R方程在整个复平面上成立，且偏导数连续，所以 $f(z) = e^x(\cos y + i\sin y) = e^z$ 在整个复平面上解析。

（2）$f(z) = \sin x \cosh y + i\cos x \sinh y$

$u = \sin x \cosh y$，$v = \cos x \sinh y$

$\frac{\partial u}{\partial x} = \cos x \cosh y$，$\frac{\partial u}{\partial y} = \sin x \sinh y$

$\frac{\partial v}{\partial x} = -\sin x \sinh y$，$\frac{\partial v}{\partial y} = \cos x \cosh y$

C-R方程验证：

$\frac{\partial u}{\partial x} = \cos x \cosh y = \frac{\partial v}{\partial y}$ ✓

$-\frac{\partial u}{\partial y} = -\sin x \sinh y = \frac{\partial v}{\partial x}$ ✓

C-R方程在整个复平面上成立，且偏导数连续，所以 $f(z) = \sin x \cosh y + i\cos x \sinh y = \sin z$ 在整个复平面上解析。

> **关键点**：指数函数和三角函数在整个复平面上解析。

**3. 解：**

与实函数求导法则类似，直接对 $z$ 求导：

（1）$f'(z) = 3z^2 + 4z - 5$

（2）$f'(z) = -\frac{2z}{(z^2 + 1)^2}$（$z \neq \pm i$）

（3）$f'(z) = ie^{iz}$

> **关键点**：解析函数的求导法则与实函数相同。

**4. 解：**

先验证 $u$ 是调和函数（即满足拉普拉斯方程 $\nabla^2 u = 0$）：

$\frac{\partial u}{\partial x} = 3x^2 - 3y^2$，$\frac{\partial^2 u}{\partial x^2} = 6x$

$\frac{\partial u}{\partial y} = -6xy$，$\frac{\partial^2 u}{\partial y^2} = -6x$

$\nabla^2 u = \frac{\partial^2 u}{\partial x^2} + \frac{\partial^2 u}{\partial y^2} = 6x + (-6x) = 0$

所以 $u$ 是调和函数。

由C-R方程求 $v$：

$\frac{\partial v}{\partial y} = \frac{\partial u}{\partial x} = 3x^2 - 3y^2$ ⟹ $v = \int (3x^2 - 3y^2)dy = 3x^2y - y^3 + \varphi(x)$

$\frac{\partial v}{\partial x} = -\frac{\partial u}{\partial y} = 6xy$

由 $v$ 的表达式：$\frac{\partial v}{\partial x} = 6xy + \varphi'(x)$

所以 $6xy + \varphi'(x) = 6xy$ ⟹ $\varphi'(x) = 0$ ⟹ $\varphi(x) = C$（常数）

因此 $v(x, y) = 3x^2y - y^3 + C$

取 $C = 0$，得 $f(z) = x^3 - 3xy^2 + i(3x^2y - y^3)$

验证：$f(z) = z^3$（因为 $(x + iy)^3 = x^3 + 3x^2(iy) + 3x(iy)^2 + (iy)^3 = x^3 - 3xy^2 + i(3x^2y - y^3)$）

> **关键点**：利用C-R方程由实部求虚部（或反之），需通过积分和待定函数法。

**5. 解：**

由C-R方程：

$\frac{\partial v}{\partial x} = -e^{-x}\sin y$，$\frac{\partial v}{\partial y} = e^{-x}\cos y$

$\frac{\partial u}{\partial x} = \frac{\partial v}{\partial y} = e^{-x}\cos y$ ⟹ $u = \int e^{-x}\cos y \, dx = -e^{-x}\cos y + \varphi(y)$

$\frac{\partial u}{\partial y} = -\frac{\partial v}{\partial x} = e^{-x}\sin y$

由 $u$ 的表达式：$\frac{\partial u}{\partial y} = e^{-x}\sin y + \varphi'(y)$

所以 $e^{-x}\sin y + \varphi'(y) = e^{-x}\sin y$ ⟹ $\varphi'(y) = 0$ ⟹ $\varphi(y) = C$（常数）

因此 $u(x, y) = -e^{-x}\cos y + C$

$f(z) = -e^{-x}\cos y + C + ie^{-x}\sin y = e^{-x}(-\cos y + i\sin y) + C$

$= e^{-x}(-(\cos y - i\sin y)) + C = -e^{-x}e^{-iy} + C = -e^{-(x + iy)} + C = -e^{-z} + C$

取 $C = 0$，得 $f(z) = -e^{-z}$。

> **关键点**：由虚部通过C-R方程求实部，注意积分常数的处理。

**6. 解：**

（1）$e^{1 + i\frac{\pi}{2}} = e^1 \cdot e^{i\frac{\pi}{2}} = e(\cos\frac{\pi}{2} + i\sin\frac{\pi}{2}) = e(0 + i) = ei$

（2）利用 $\sin z = \frac{e^{iz} - e^{-iz}}{2i}$

$\sin(i) = \frac{e^{i \cdot i} - e^{-i \cdot i}}{2i} = \frac{e^{-1} - e^{1}}{2i} = \frac{e^{-1} - e}{2i} = \frac{e - e^{-1}}{2} \cdot i = i\sinh 1$

其中 $\sinh 1 = \frac{e - e^{-1}}{2}$

（3）利用 $\cos z = \frac{e^{iz} + e^{-iz}}{2}$

$\cos\left(\frac{\pi}{2} + i\right) = \frac{e^{i(\frac{\pi}{2} + i)} + e^{-i(\frac{\pi}{2} + i)}}{2} = \frac{e^{i\frac{\pi}{2} - 1} + e^{-i\frac{\pi}{2} + 1}}{2}$

$= \frac{e^{-1}e^{i\frac{\pi}{2}} + e^{1}e^{-i\frac{\pi}{2}}}{2} = \frac{e^{-1}i + e(-i)}{2} = \frac{i(e^{-1} - e)}{2}$

$= -i\frac{e - e^{-1}}{2} = -i\sinh 1$

> **关键点**：复指数函数和复三角函数的计算利用欧拉公式的推广。

**7. 解：**

$\text{Ln}(z) = \ln|z| + i(\arg z + 2k\pi)$，$k \in \mathbb{Z}$

主值：$\text{Log}(z) = \ln|z| + i\text{Arg}(z)$，其中 $\text{Arg}(z) \in (-\pi, \pi]$

（1）$\text{Ln}(-1)$：

$|-1| = 1$，$\arg(-1) = \pi + 2k\pi$，$k \in \mathbb{Z}$

$\text{Ln}(-1) = \ln 1 + i(\pi + 2k\pi) = i(2k + 1)\pi$，$k \in \mathbb{Z}$

主值：$\text{Log}(-1) = i\pi$（取 $k = 0$）

（2）$\text{Ln}(1 + i)$：

$|1 + i| = \sqrt{2}$，$\arg(1 + i) = \frac{\pi}{4} + 2k\pi$，$k \in \mathbb{Z}$

$\text{Ln}(1 + i) = \ln\sqrt{2} + i\left(\frac{\pi}{4} + 2k\pi\right) = \frac{1}{2}\ln 2 + i\left(\frac{\pi}{4} + 2k\pi\right)$，$k \in \mathbb{Z}$

主值：$\text{Log}(1 + i) = \frac{1}{2}\ln 2 + i\frac{\pi}{4}$

> **关键点**：复对数函数是多值函数，主值取辐角主值 $\text{Arg}(z) \in (-\pi, \pi]$。

**8. 解：**

利用 $a^b = e^{b \text{Ln} a}$ 计算多值函数。

（1）$i^i = e^{i \text{Ln} i}$

先求 $\text{Ln} i$：$|i| = 1$，$\arg i = \frac{\pi}{2} + 2k\pi$

$\text{Ln} i = \ln 1 + i\left(\frac{\pi}{2} + 2k\pi\right) = i\left(\frac{\pi}{2} + 2k\pi\right)$

$i^i = e^{i \cdot i\left(\frac{\pi}{2} + 2k\pi\right)} = e^{-\left(\frac{\pi}{2} + 2k\pi\right)} = e^{-\frac{\pi}{2}} \cdot e^{-2k\pi}$，$k \in \mathbb{Z}$

$i^i$ 是多值函数，取 $k = 0$ 得主值 $e^{-\frac{\pi}{2}}$，这是一个实数！

（2）$(-1)^{\sqrt{2}} = e^{\sqrt{2} \text{Ln}(-1)}$

$\text{Ln}(-1) = i(\pi + 2k\pi) = i(2k + 1)\pi$

$(-1)^{\sqrt{2}} = e^{\sqrt{2} \cdot i(2k + 1)\pi} = e^{i(2k + 1)\sqrt{2}\pi}$

$= \cos[(2k + 1)\sqrt{2}\pi] + i\sin[(2k + 1)\sqrt{2}\pi]$，$k \in \mathbb{Z}$

主值（$k = 0$）：$(-1)^{\sqrt{2}} = e^{i\sqrt{2}\pi} = \cos(\sqrt{2}\pi) + i\sin(\sqrt{2}\pi)$

（3）$2^{1 + i} = e^{(1 + i)\text{Ln} 2}$

$\text{Ln} 2 = \ln 2 + i(0 + 2k\pi) = \ln 2 + 2k\pi i$

$2^{1 + i} = e^{(1 + i)(\ln 2 + 2k\pi i)} = e^{\ln 2 + 2k\pi i + i\ln 2 - 2k\pi}$

$= e^{\ln 2 - 2k\pi} \cdot e^{i(\ln 2 + 2k\pi)} = 2e^{-2k\pi} \cdot e^{i\ln 2}$，$k \in \mathbb{Z}$

主值（$k = 0$）：$2^{1 + i} = 2e^{i\ln 2} = 2(\cos\ln 2 + i\sin\ln 2)$

> **关键点**：复数的复数次幂一般通过 $a^b = e^{b\text{Ln} a}$ 计算，结果为多值函数。

**9. 解：**

先验证 $u$ 是调和函数（略，已给出）。

由C-R方程：

$\frac{\partial u}{\partial x} = e^x(x\cos y - y\sin y) + e^x\cos y = e^x[(x + 1)\cos y - y\sin y]$

$\frac{\partial u}{\partial y} = e^x(-x\sin y - \sin y - y\cos y) = -e^x[(x + 1)\sin y + y\cos y]$

由 $\frac{\partial v}{\partial y} = \frac{\partial u}{\partial x}$：

$v = \int e^x[(x + 1)\cos y - y\sin y]dy$

$= e^x\left[(x + 1)\int\cos y\,dy - \int y\sin y\,dy\right]$

其中 $\int\cos y\,dy = \sin y$，$\int y\sin y\,dy = -y\cos y + \sin y$（分部积分）

$v = e^x[(x + 1)\sin y - (-y\cos y + \sin y)] + \varphi(x)$

$= e^x[(x + 1)\sin y + y\cos y - \sin y] + \varphi(x)$

$= e^x[x\sin y + y\cos y] + \varphi(x)$

由 $\frac{\partial v}{\partial x} = -\frac{\partial u}{\partial y}$：

$\frac{\partial v}{\partial x} = e^x[x\sin y + y\cos y] + e^x\sin y + \varphi'(x)$

$= e^x[(x + 1)\sin y + y\cos y] + \varphi'(x)$

$-\frac{\partial u}{\partial y} = e^x[(x + 1)\sin y + y\cos y]$

所以 $e^x[(x + 1)\sin y + y\cos y] + \varphi'(x) = e^x[(x + 1)\sin y + y\cos y]$

⟹ $\varphi'(x) = 0$ ⟹ $\varphi(x) = C$（常数）

因此 $v(x, y) = e^x(x\sin y + y\cos y) + C$

取 $C = 0$，则 $f(z) = e^x(x\cos y - y\sin y) + ie^x(x\sin y + y\cos y)$

即 $f(z) = ze^z$（验证：$ze^z = (x + iy)e^{x + iy} = (x + iy)e^x(\cos y + i\sin y) = e^x[(x\cos y - y\sin y) + i(x\sin y + y\cos y)]$）

> **关键点**：综合运用C-R方程和积分技巧，答案可验证为初等解析函数。

**10. 解：**

（1）若 $f(z)$ 恒为常数，即存在 $C \in \mathbb{C}$，使得 $f(z) = C$ 对所有 $z$ 成立。

设 $C = a + ib$（$a, b \in \mathbb{R}$），则 $u(x, y) = a$，$v(x, y) = b$，均为常数。

（2）若 $v \equiv 0$，则 $f(z) = u(x, y)$ 是实值函数。

由C-R方程：$\frac{\partial u}{\partial x} = \frac{\partial v}{\partial y} = 0$，$-\frac{\partial u}{\partial y} = \frac{\partial v}{\partial x} = 0$

所以 $\frac{\partial u}{\partial x} = \frac{\partial u}{\partial y} = 0$，即 $u$ 对 $x$ 和 $y$ 的偏导数均为 0。

因此 $u$ 为常数，$f(z)$ 为常数。

（3）$f'(z) = 0$ 表示 $f(z)$ 的导数恒为零。

由导数的定义，$f'(z) = \frac{\partial u}{\partial x} + i\frac{\partial v}{\partial x} = \frac{\partial v}{\partial y} - i\frac{\partial u}{\partial y} = 0$

所以 $\frac{\partial u}{\partial x} = \frac{\partial u}{\partial y} = \frac{\partial v}{\partial x} = \frac{\partial v}{\partial y} = 0$

因此 $u$ 和 $v$ 均为常数，$f(z)$ 为常数。

即 $f(z) = C$，其中 $C$ 为复常数。

> **关键点**：这些结论体现了解析函数的特殊性质，与实函数不同（实函数导数为零只能推出函数局部为常数，而解析函数导数为零在整个定义域内为常数）。

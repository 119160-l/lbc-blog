### 基础题（1-3题）

---

**1.** 将下列复变函数分解为实部 $u(x,y)$ 和虚部 $v(x,y)$：

（1）$f(z) = z^2$  
（2）$f(z) = \frac{1}{z}$  
（3）$f(z) = \bar{z}$

---

**2.** 求下列复变函数的定义域：

（1）$f(z) = \frac{1}{z^2 + 1}$  
（2）$f(z) = \frac{z + 1}{z^2 - 4z + 5}$  
（3）$f(z) = \frac{e^z}{z - 1}$

---

**3.** 计算下列极限：

（1）$\lim_{z \to i} \frac{z^2 + 1}{z - i}$  
（2）$\lim_{z \to 0} \frac{\bar{z}}{z}$  
（3）$\lim_{z \to 1 + i} (z^2 - 2z + 2)$

### 进阶题（4-6题）

---

**4.** 判断下列函数在指定点是否连续，并说明理由：

（1）$f(z) = \begin{cases} \frac{z^2}{|z|^2}, & z \neq 0 \\ 0, & z = 0 \end{cases}$，在 $z = 0$ 处  
（2）$f(z) = \frac{z^2 - 1}{z - 1}$，在 $z = 1$ 处

**5.** 考虑映射 $w = f(z) = z^2$。设 $z = re^{i\theta}$，$w = Re^{i\varphi}$。

（1）求 $R$ 和 $\varphi$ 与 $r$、$\theta$ 的关系。  
（2）在 $z$ 平面上，射线 $\theta = \theta_0$ 映射到 $w$ 平面上什么图形？  
（3）在 $z$ 平面上，圆周 $r = r_0$ 映射到 $w$ 平面上什么图形？  
（4）在 $z$ 平面上，第一象限（$x > 0, y > 0$）映射到 $w$ 平面上什么区域？

**6.** 考虑映射 $w = f(z) = \frac{1}{z}$（$z \neq 0$）。

（1）将 $f(z)$ 分解为实部和虚部。  
（2）在 $z$ 平面上的直线 $x = 1$ 映射到 $w$ 平面上什么图形？

## 参考答案与解析

**1. 解：**

设 $z = x + iy$，$x, y \in \mathbb{R}$。

（1）$f(z) = z^2 = (x + iy)^2 = x^2 + 2ixy + (iy)^2 = x^2 - y^2 + 2ixy$

所以 $u(x, y) = x^2 - y^2$，$v(x, y) = 2xy$

（2）$f(z) = \frac{1}{z} = \frac{1}{x + iy} = \frac{x - iy}{(x + iy)(x - iy)} = \frac{x - iy}{x^2 + y^2}$

所以 $u(x, y) = \frac{x}{x^2 + y^2}$，$v(x, y) = -\frac{y}{x^2 + y^2}$，其中 $z \neq 0$

（3）$f(z) = \bar{z} = \overline{x + iy} = x - iy$

所以 $u(x, y) = x$，$v(x, y) = -y$

**关键点**：复变函数实部虚部分离的基本方法是设 $z = x + iy$，利用代数运算分离。

---

**2. 解：**

（1）分母 $z^2 + 1 = 0$ 时函数无定义。

$z^2 + 1 = 0 \implies z^2 = -1 \implies z = \pm i$

所以定义域为 $\mathbb{C} \setminus \{i, -i\}$，即除 $i$ 和 $-i$ 外的所有复数。

（2）分母 $z^2 - 4z + 5 = 0$ 时函数无定义。

$z^2 - 4z + 5 = 0 \implies z = \frac{4 \pm \sqrt{16 - 20}}{2} = \frac{4 \pm \sqrt{-4}}{2} = \frac{4 \pm 2i}{2} = 2 \pm i$

所以定义域为 $\mathbb{C} \setminus \{2 + i, 2 - i\}$。

（3）分母 $z - 1 = 0$ 时函数无定义。

所以定义域为 $\mathbb{C} \setminus \{1\}$。

**关键点**：分母为零的点即为无定义点，需从复平面中排除。

---

**3. 解：**

（1）$\lim_{z \to i} \frac{z^2 + 1}{z - i}$

分子因式分解：$z^2 + 1 = (z - i)(z + i)$

$\lim_{z \to i} \frac{(z - i)(z + i)}{z - i} = \lim_{z \to i} (z + i) = i + i = 2i$

（2）$\lim_{z \to 0} \frac{\bar{z}}{z}$

设 $z = x + iy$，则 $\frac{\bar{z}}{z} = \frac{x - iy}{x + iy}$

沿实轴方向（$y = 0$）趋近于 0：$\lim_{x \to 0} \frac{x}{x} = 1$

沿虚轴方向（$x = 0$）趋近于 0：$\lim_{y \to 0} \frac{-iy}{iy} = -1$

两个方向的极限值不同，所以极限不存在。

（3）$\lim_{z \to 1 + i} (z^2 - 2z + 2)$

直接代入：$(1 + i)^2 - 2(1 + i) + 2 = (1 + 2i + i^2) - 2 - 2i + 2$

$= (1 + 2i - 1) - 2 - 2i + 2 = 0$

**关键点**：复变函数极限存在要求沿所有路径趋近的极限值相同。第（2）题展示了极限不存在的典型例子。

---

**4. 解：**

（1）考虑 $z \to 0$ 时的极限。

设 $z = x + iy$，则 $|z|^2 = x^2 + y^2$

$f(z) = \frac{(x + iy)^2}{x^2 + y^2} = \frac{x^2 - y^2}{x^2 + y^2} + i\frac{2xy}{x^2 + y^2}$

沿实轴（$y = 0$）趋于 0：$\lim_{x \to 0} \frac{x^2}{x^2} = 1$

沿虚轴（$x = 0$）趋于 0：$\lim_{y \to 0} \frac{-y^2}{y^2} = -1$

沿不同方向趋于 0 时极限值不同，因此 $\lim_{z \to 0} f(z)$ 不存在。

所以 $f(z)$ 在 $z = 0$ 处不连续。

（2）当 $z \neq 1$ 时，$f(z) = \frac{z^2 - 1}{z - 1} = \frac{(z - 1)(z + 1)}{z - 1} = z + 1$

$\lim_{z \to 1} f(z) = \lim_{z \to 1} (z + 1) = 2$

但 $f(1)$ 无定义，所以 $f(z)$ 在 $z = 1$ 处不连续（可去间断点）。

**关键点**：判断连续性需验证极限存在且等于函数值。

---

**5. 解：**

（1）$w = z^2 = (re^{i\theta})^2 = r^2 e^{i2\theta}$

所以 $R = r^2$，$\varphi = 2\theta$

（2）射线 $\theta = \theta_0$ 上的点满足 $z = re^{i\theta_0}$（$r > 0$），映射后：

$w = r^2 e^{i2\theta_0}$，即辐角固定为 $2\theta_0$，模长 $r^2$ 取遍所有正数。

因此射线 $\theta = \theta_0$ 映射为 $w$ 平面上的射线 $\varphi = 2\theta_0$。

（3）圆周 $r = r_0$ 上的点满足 $z = r_0 e^{i\theta}$（$\theta \in [0, 2\pi)$），映射后：

$w = r_0^2 e^{i2\theta}$，即 $R = r_0^2$ 为常数，$\varphi = 2\theta$ 取遍 $[0, 4\pi)$。

因此圆周 $r = r_0$ 映射为 $w$ 平面上的圆周 $R = r_0^2$（但沿圆周走了两圈）。

（4）第一象限：$x > 0, y > 0$，即 $r > 0$，$0 < \theta < \frac{\pi}{2}$

映射后：$R = r^2 > 0$，$\varphi = 2\theta \in (0, \pi)$

所以第一象限映射为 $w$ 平面的上半平面（$\text{Im}(w) > 0$）。

**关键点**：$w = z^2$ 将辐角放大一倍，模长平方，是典型的映射。

---

**6. 解：**

（1）由第1题知，$w = \frac{1}{z} = \frac{x}{x^2 + y^2} - i\frac{y}{x^2 + y^2}$

所以 $u(x, y) = \frac{x}{x^2 + y^2}$，$v(x, y) = -\frac{y}{x^2 + y^2}$

（2）直线 $x = 1$ 上的点满足 $z = 1 + iy$，$y \in \mathbb{R}$

$w = \frac{1}{1 + iy} = \frac{1 - iy}{1 + y^2} = \frac{1}{1 + y^2} - i\frac{y}{1 + y^2}$

所以 $u = \frac{1}{1 + y^2}$，$v = -\frac{y}{1 + y^2}$

由 $u = \frac{1}{1 + y^2}$ 得 $y^2 = \frac{1}{u} - 1$，代入 $v$ 表达式可消去 $y$。

注意到 $(u - \frac{1}{2})^2 + v^2 = \left(\frac{1}{1 + y^2} - \frac{1}{2}\right)^2 + \left(\frac{y}{1 + y^2}\right)^2$

$= \frac{(2 - (1 + y^2))^2}{4(1 + y^2)^2} + \frac{y^2}{(1 + y^2)^2} = \frac{(1 - y^2)^2}{4(1 + y^2)^2} + \frac{y^2}{(1 + y^2)^2}$

$= \frac{(1 - y^2)^2 + 4y^2}{4(1 + y^2)^2} = \frac{(1 + y^2)^2}{4(1 + y^2)^2} = \frac{1}{4}$

因此直线 $x = 1$ 映射为 $w$ 平面上的圆 $\left(u - \frac{1}{2}\right)^2 + v^2 = \left(\frac{1}{2}\right)^2$，即圆心在 $\left(\frac{1}{2}, 0\right)$、半径为 $\frac{1}{2}$ 的圆。

（3）单位圆 $|z| = 1$ 上的点满足 $z = e^{i\theta}$，$\theta \in [0, 2\pi)$

$w = \frac{1}{z} = \frac{1}{e^{i\theta}} = e^{-i\theta}$

所以单位圆映射为 $w$ 平面上的单位圆（方向相反）。

**关键点**：$w = \frac{1}{z}$ 称为反演映射，将直线映射为圆（过原点的直线映射为直线）。

**7. 解：**

设 $z = x + iy$，$f(z) = \text{Re}(z) = x$

设 $z_0 = x_0 + iy_0$ 为任意一点，则 $f(z_0) = x_0$

对于任意 $\varepsilon > 0$，取 $\delta = \varepsilon$，当 $|z - z_0| < \delta$ 时：

$|f(z) - f(z_0)| = |x - x_0| \leq \sqrt{(x - x_0)^2 + (y - y_0)^2} = |z - z_0| < \delta = \varepsilon$

因此 $f(z) = \text{Re}(z)$ 在任意点 $z_0$ 处连续，在整个复平面上连续。

**关键点**：用 $\varepsilon$-$\delta$ 定义证明连续性，利用了 $|x - x_0| \leq |z - z_0|$。

**8. 解：**

设 $z = re^{i\theta}$，$r > 0$，$\theta \in [0, 2\pi)$

$f(z) = \frac{re^{i\theta}}{r} = e^{i\theta}$

所以 $f(z)$ 的值只与辐角 $\theta$ 有关，与模长 $r$ 无关。

当 $z \to 0$ 时，无论 $r$ 多小，$f(z) = e^{i\theta}$ 的值取决于 $\theta$。

沿不同方向趋近于 0：

- 沿正实轴（$\theta = 0$）：$f(z) \to 1$
- 沿正虚轴（$\theta = \frac{\pi}{2}$）：$f(z) \to i$
- 沿负实轴（$\theta = \pi$）：$f(z) \to -1$

不同方向得到不同的极限值，因此 $\lim_{z \to 0} f(z)$ 不存在。

**关键点**：因为 $f(z) = e^{i\theta}$ 仅依赖于辐角方向。

**9. 解：**

（1）设 $z = x + iy$，$z \neq 0$

$f(z) = x + iy + \frac{1}{x + iy} = x + iy + \frac{x - iy}{x^2 + y^2}$

$= \left(x + \frac{x}{x^2 + y^2}\right) + i\left(y - \frac{y}{x^2 + y^2}\right)$

所以 $u(x, y) = x + \frac{x}{x^2 + y^2}$，$v(x, y) = y - \frac{y}{x^2 + y^2}$

（2）单位圆 $|z| = 1$ 上的点：$z = e^{i\theta} = \cos\theta + i\sin\theta$

$f(z) = e^{i\theta} + e^{-i\theta} = 2\cos\theta$

所以 $w = 2\cos\theta$ 是实数，且 $\theta \in [0, 2\pi)$ 时 $\cos\theta \in [-1, 1]$，因此 $w \in [-2, 2]$

即单位圆映射为 $w$ 平面实轴上的线段 $[-2, 2]$。

（3）圆周 $|z| = r_0$ 上的点：$z = r_0 e^{i\theta}$

$f(z) = r_0 e^{i\theta} + \frac{1}{r_0} e^{-i\theta} = \left(r_0 + \frac{1}{r_0}\right)\cos\theta + i\left(r_0 - \frac{1}{r_0}\right)\sin\theta$

所以 $u = \left(r_0 + \frac{1}{r_0}\right)\cos\theta$，$v = \left(r_0 - \frac{1}{r_0}\right)\sin\theta$

当 $r_0 \neq 1$ 时，$\frac{u^2}{\left(r_0 + \frac{1}{r_0}\right)^2} + \frac{v^2}{\left(r_0 - \frac{1}{r_0}\right)^2} = \cos^2\theta + \sin^2\theta = 1$

即圆周 $|z| = r_0$ 映射为 $w$ 平面上的椭圆，长半轴为 $r_0 + \frac{1}{r_0}$，短半轴为 $\left|r_0 - \frac{1}{r_0}\right|$。

**关键点**：这是茹科夫斯基映射的基础形式，在空气动力学中有重要应用。

**10. 解：**

（1）分母 $z - 1 - i = 0$ 时函数无定义，即 $z = 1 + i$。

所以定义域为 $\mathbb{C} \setminus \{1 + i\}$。

（2）计算分子在 $z = 1 + i$ 处的值：

$(1 + i)^2 - 2(1 + i) + 2 = (1 + 2i + i^2) - 2 - 2i + 2$

$= (1 + 2i - 1) - 2 - 2i + 2 = 2i - 2 - 2i + 2 = 0$

因此分子在 $z = 1 + i$ 处也为零，可以尝试因式分解。

验证分子是否以 $z - (1 + i)$ 为因子：

$z^2 - 2z + 2 = 0$ 的根为 $z = \frac{2 \pm \sqrt{4 - 8}}{2} = \frac{2 \pm 2i}{2} = 1 \pm i$

所以 $z^2 - 2z + 2 = (z - (1 + i))(z - (1 - i))$

因此 $\lim_{z \to 1 + i} f(z) = \lim_{z \to 1 + i} \frac{(z - (1 + i))(z - (1 - i))}{z - (1 + i)} = \lim_{z \to 1 + i} (z - (1 - i))$

$= (1 + i) - (1 - i) = 2i$

（3）可以。定义 $f(1 + i) = 2i$，则 $f(z)$ 在 $z = 1 + i$ 处连续（可去间断点被消除）。

**关键点**：分子分母同时为零时可约去公因子，这是可去间断点的特征。

### 基础题（1-3题）

---

**1.** 将下列复数分别化为三角形式和指数形式：

（1）$z_1 = 1 + i$  
（2）$z_2 = -\frac{1}{2} + \frac{\sqrt{3}}{2}i$  
（3）$z_3 = -2$

---

**2.** 设 $z_1 = 2 + 3i$，$z_2 = 1 - 2i$，计算：

（1）$z_1 + z_2$  
（2）$z_1 - z_2$  
（3）$z_1 \cdot z_2$  
（4）$\frac{z_1}{z_2}$

---

**3.** 求下列复数的共轭复数，并计算 $z \cdot \bar{z}$：

（1）$z = 3 - 4i$  
（2）$z = 5i$  
（3）$z = 2e^{i\frac{\pi}{3}}$

---

### 进阶题（4-6题）

---

**4.** 利用欧拉公式，证明：

（1）$\cos\theta = \frac{e^{i\theta} + e^{-i\theta}}{2}$  
（2）$\sin\theta = \frac{e^{i\theta} - e^{-i\theta}}{2i}$

并利用上述结果计算 $\cos^2\theta$ 的表达式。

---

**5.** 利用棣莫弗公式，计算下列各式的值：

（1）$(1 + i)^8$  
（2）$\left(\frac{1}{2} + \frac{\sqrt{3}}{2}i\right)^{12}$

---

**6.** 求下列复数的平方根：

（1）$z = 4i$  
（2）$z = -3 + 4i$

---

### 综合题（7-10题）

---

**7.** 求方程 $z^4 + 1 = 0$ 的所有根，并在复平面上标出这些根的位置。

---

**8.** 求所有 6 次单位根（即 $z^6 = 1$ 的解），并将它们表示为代数形式。

---

**9.** 已知 $z = \cos\theta + i\sin\theta$，证明：

（1）$\frac{1}{z} = \cos\theta - i\sin\theta$  
（2）$z + \frac{1}{z} = 2\cos\theta$  
（3）$z^n + \frac{1}{z^n} = 2\cos n\theta$

---

**10.** 设 $z_1, z_2, z_3$ 是单位圆上的三个复数，满足 $z_1 + z_2 + z_3 = 0$，证明这三个复数在复平面上构成等边三角形的三个顶点。

---

## 参考答案与解析

**1. 解：**

（1）对于 $z_1 = 1 + i$：

模：$r = |z_1| = \sqrt{1^2 + 1^2} = \sqrt{2}$

辐角：$\arg(z_1) = \arctan\left(\frac{1}{1}\right) = \frac{\pi}{4}$（因为实部、虚部均为正，位于第一象限）

三角形式：$z_1 = \sqrt{2}\left(\cos\frac{\pi}{4} + i\sin\frac{\pi}{4}\right)$

指数形式：$z_1 = \sqrt{2}e^{i\frac{\pi}{4}}$

（2）对于 $z_2 = -\frac{1}{2} + \frac{\sqrt{3}}{2}i$：

模：$r = \sqrt{\left(-\frac{1}{2}\right)^2 + \left(\frac{\sqrt{3}}{2}\right)^2} = \sqrt{\frac{1}{4} + \frac{3}{4}} = 1$

辐角：$\arg(z_2) = \pi - \arctan\left(\frac{\sqrt{3}/2}{1/2}\right) = \pi - \frac{\pi}{3} = \frac{2\pi}{3}$（实部为负、虚部为正，位于第二象限）

三角形式：$z_2 = \cos\frac{2\pi}{3} + i\sin\frac{2\pi}{3}$

指数形式：$z_2 = e^{i\frac{2\pi}{3}}$

（3）对于 $z_3 = -2$：

模：$r = |-2| = 2$

辐角：$\arg(z_3) = \pi$（负实轴）

三角形式：$z_3 = 2(\cos\pi + i\sin\pi)$

指数形式：$z_3 = 2e^{i\pi}$

**2. 解：**

（1）$z_1 + z_2 = (2 + 3i) + (1 - 2i) = (2 + 1) + (3 - 2)i = 3 + i$

（2）$z_1 - z_2 = (2 + 3i) - (1 - 2i) = (2 - 1) + (3 + 2)i = 1 + 5i$

（3）$z_1 \cdot z_2 = (2 + 3i)(1 - 2i) = 2 \cdot 1 + 2 \cdot (-2i) + 3i \cdot 1 + 3i \cdot (-2i)$

$= 2 - 4i + 3i - 6i^2$

$= 2 - i + 6 = 8 - i$

（4）$\frac{z_1}{z_2} = \frac{2 + 3i}{1 - 2i} = \frac{(2 + 3i)(1 + 2i)}{(1 - 2i)(1 + 2i)} = \frac{2 + 4i + 3i + 6i^2}{1 + 4}$

$= \frac{2 + 7i - 6}{5} = \frac{-4 + 7i}{5} = -\frac{4}{5} + \frac{7}{5}i$

**3. 解：**

（1）$z = 3 - 4i$，$\bar{z} = 3 + 4i$

$z \cdot \bar{z} = (3 - 4i)(3 + 4i) = 9 - 16i^2 = 9 + 16 = 25 = |z|^2$

（2）$z = 5i$，$\bar{z} = -5i$

$z \cdot \bar{z} = (5i)(-5i) = -25i^2 = 25 = |z|^2$

（3）$z = 2e^{i\frac{\pi}{3}}$，$\bar{z} = 2e^{-i\frac{\pi}{3}}$

$z \cdot \bar{z} = (2e^{i\frac{\pi}{3}})(2e^{-i\frac{\pi}{3}}) = 4e^{i0} = 4 = |z|^2$

**4. 解：**

由欧拉公式 $e^{i\theta} = \cos\theta + i\sin\theta$，可得：

$e^{-i\theta} = \cos(-\theta) + i\sin(-\theta) = \cos\theta - i\sin\theta$

（1）两式相加：

$e^{i\theta} + e^{-i\theta} = (\cos\theta + i\sin\theta) + (\cos\theta - i\sin\theta) = 2\cos\theta$

因此 $\cos\theta = \frac{e^{i\theta} + e^{-i\theta}}{2}$

（2）两式相减：

$e^{i\theta} - e^{-i\theta} = (\cos\theta + i\sin\theta) - (\cos\theta - i\sin\theta) = 2i\sin\theta$

因此 $\sin\theta = \frac{e^{i\theta} - e^{-i\theta}}{2i}$

计算 $\cos^2\theta$：

$$
\cos^2\theta = \left(\frac{e^{i\theta} + e^{-i\theta}}{2}\right)^2 = \frac{e^{i2\theta} + 2 + e^{-i2\theta}}{4} = \frac{1}{2} + \frac{e^{i2\theta} + e^{-i2\theta}}{4}
$$

又 $\frac{e^{i2\theta} + e^{-i2\theta}}{2} = \cos 2\theta$，所以：

$$
\cos^2\theta = \frac{1}{2} + \frac{\cos 2\theta}{2} = \frac{1 + \cos 2\theta}{2}
$$

这与三角恒等式一致。

**5. 解：**

棣莫弗公式：若 $z = r(\cos\theta + i\sin\theta) = re^{i\theta}$，则 $z^n = r^n(\cos n\theta + i\sin n\theta) = r^n e^{in\theta}$

（1）先将 $1 + i$ 化为指数形式：

$1 + i = \sqrt{2}e^{i\frac{\pi}{4}}$

$(1 + i)^8 = (\sqrt{2})^8 e^{i\frac{\pi}{4} \cdot 8} = 2^{4} e^{i2\pi} = 16 \cdot (\cos 2\pi + i\sin 2\pi) = 16$

（2）先将 $\frac{1}{2} + \frac{\sqrt{3}}{2}i$ 化为指数形式：

模：$r = \sqrt{\left(\frac{1}{2}\right)^2 + \left(\frac{\sqrt{3}}{2}\right)^2} = \sqrt{\frac{1}{4} + \frac{3}{4}} = 1$

辐角：$\theta = \arctan\left(\frac{\sqrt{3}/2}{1/2}\right) = \arctan\sqrt{3} = \frac{\pi}{3}$

所以 $\frac{1}{2} + \frac{\sqrt{3}}{2}i = e^{i\frac{\pi}{3}}$

$\left(\frac{1}{2} + \frac{\sqrt{3}}{2}i\right)^{12} = e^{i\frac{\pi}{3} \cdot 12} = e^{i4\pi} = \cos 4\pi + i\sin 4\pi = 1$

**6. 解：**

（1）$z = 4i$ 化为指数形式：$4i = 4e^{i\frac{\pi}{2}}$

设 $w = \sqrt{z}$，则 $w_k = \sqrt{4} \cdot e^{i\frac{\pi/2 + 2k\pi}{2}} = 2e^{i\left(\frac{\pi}{4} + k\pi\right)}$，$k = 0, 1$

$k = 0$：$w_0 = 2e^{i\frac{\pi}{4}} = 2\left(\cos\frac{\pi}{4} + i\sin\frac{\pi}{4}\right) = \sqrt{2} + \sqrt{2}i$

$k = 1$：$w_1 = 2e^{i\frac{5\pi}{4}} = 2\left(\cos\frac{5\pi}{4} + i\sin\frac{5\pi}{4}\right) = -\sqrt{2} - \sqrt{2}i$

验证：$(\sqrt{2} + \sqrt{2}i)^2 = 2 + 4i + 2i^2 = 4i$ ✓

（2）$z = -3 + 4i$

先求模和辐角：$r = \sqrt{(-3)^2 + 4^2} = 5$

$\theta = \pi - \arctan\left(\frac{4}{3}\right) = \pi - \arctan\frac{4}{3}$（位于第二象限）

设 $\theta = \pi - \alpha$，其中 $\alpha = \arctan\frac{4}{3}$

平方根：$w_k = \sqrt{5} \cdot e^{i\frac{\theta + 2k\pi}{2}}$，$k = 0, 1$

$w_0 = \sqrt{5} \cdot e^{i\frac{\theta}{2}}$，$w_1 = \sqrt{5} \cdot e^{i\left(\frac{\theta}{2} + \pi\right)} = -w_0$

实际上，我们可以用代数方法设 $(a + bi)^2 = -3 + 4i$：

$(a^2 - b^2) + 2abi = -3 + 4i$

所以 $\begin{cases} a^2 - b^2 = -3 \\ 2ab = 4 \end{cases}$

由第二式得 $b = \frac{2}{a}$，代入第一式：

$a^2 - \frac{4}{a^2} = -3 \implies a^4 + 3a^2 - 4 = 0 \implies (a^2 + 4)(a^2 - 1) = 0$

$a^2 = 1$（取正），$a = \pm 1$，$b = \frac{2}{a} = \pm 2$

所以平方根为 $1 + 2i$ 和 $-1 - 2i$

**7. 解：**

$z^4 + 1 = 0 \implies z^4 = -1 = e^{i(\pi + 2k\pi)}$，$k \in \mathbb{Z}$

$z_k = e^{i\frac{\pi + 2k\pi}{4}} = e^{i\left(\frac{\pi}{4} + \frac{k\pi}{2}\right)}$，$k = 0, 1, 2, 3$

四个根分别为：

$z_0 = e^{i\frac{\pi}{4}} = \cos\frac{\pi}{4} + i\sin\frac{\pi}{4} = \frac{\sqrt{2}}{2} + \frac{\sqrt{2}}{2}i$

$z_1 = e^{i\frac{3\pi}{4}} = \cos\frac{3\pi}{4} + i\sin\frac{3\pi}{4} = -\frac{\sqrt{2}}{2} + \frac{\sqrt{2}}{2}i$

$z_2 = e^{i\frac{5\pi}{4}} = \cos\frac{5\pi}{4} + i\sin\frac{5\pi}{4} = -\frac{\sqrt{2}}{2} - \frac{\sqrt{2}}{2}i$

$z_3 = e^{i\frac{7\pi}{4}} = \cos\frac{7\pi}{4} + i\sin\frac{7\pi}{4} = \frac{\sqrt{2}}{2} - \frac{\sqrt{2}}{2}i$

这四个根在复平面上均匀分布在单位圆上，辐角依次相差 $\frac{\pi}{2}$，构成一个正方形的四个顶点。

**8. 解：**

$z^6 = 1 = e^{i(0 + 2k\pi)} = e^{i2k\pi}$，$k = 0, 1, 2, 3, 4, 5$

$z_k = e^{i\frac{2k\pi}{6}} = e^{i\frac{k\pi}{3}}$，$k = 0, 1, 2, 3, 4, 5$

$z_0 = e^{i0} = 1$

$z_1 = e^{i\frac{\pi}{3}} = \cos\frac{\pi}{3} + i\sin\frac{\pi}{3} = \frac{1}{2} + \frac{\sqrt{3}}{2}i$

$z_2 = e^{i\frac{2\pi}{3}} = \cos\frac{2\pi}{3} + i\sin\frac{2\pi}{3} = -\frac{1}{2} + \frac{\sqrt{3}}{2}i$

$z_3 = e^{i\pi} = -1$

$z_4 = e^{i\frac{4\pi}{3}} = \cos\frac{4\pi}{3} + i\sin\frac{4\pi}{3} = -\frac{1}{2} - \frac{\sqrt{3}}{2}i$

$z_5 = e^{i\frac{5\pi}{3}} = \cos\frac{5\pi}{3} + i\sin\frac{5\pi}{3} = \frac{1}{2} - \frac{\sqrt{3}}{2}i$

这些根均匀分布在单位圆上，相邻根之间的辐角差为 $\frac{\pi}{3}$。注意 $z_1$ 和 $z_5$、$z_2$ 和 $z_4$ 互为共轭复数。

**9. 解：**

（1）由欧拉公式，$z = e^{i\theta}$，所以：

$\frac{1}{z} = e^{-i\theta} = \cos(-\theta) + i\sin(-\theta) = \cos\theta - i\sin\theta$

（2）$z + \frac{1}{z} = e^{i\theta} + e^{-i\theta} = (\cos\theta + i\sin\theta) + (\cos\theta - i\sin\theta) = 2\cos\theta$

（3）$z^n = (e^{i\theta})^n = e^{in\theta} = \cos n\theta + i\sin n\theta$（棣莫弗公式）

$\frac{1}{z^n} = e^{-in\theta} = \cos n\theta - i\sin n\theta$

所以 $z^n + \frac{1}{z^n} = (\cos n\theta + i\sin n\theta) + (\cos n\theta - i\sin n\theta) = 2\cos n\theta$

**10. 解：**

由 $z_1 + z_2 + z_3 = 0$ 得 $z_1 + z_2 = -z_3$

两边取模：$|z_1 + z_2| = |z_3| = 1$（因为 $z_3$ 在单位圆上）

又 $|z_1| = |z_2| = 1$（都在单位圆上）

设 $z_1 = e^{i\alpha}$，$z_2 = e^{i\beta}$，则：

$|z_1 + z_2|^2 = (e^{i\alpha} + e^{i\beta})(e^{-i\alpha} + e^{-i\beta}) = 2 + e^{i(\alpha - \beta)} + e^{-i(\alpha - \beta)} = 2 + 2\cos(\alpha - \beta)$

由 $|z_1 + z_2| = 1$ 得 $2 + 2\cos(\alpha - \beta) = 1$，即 $\cos(\alpha - \beta) = -\frac{1}{2}$

所以 $|\alpha - \beta| = \frac{2\pi}{3}$（或 $\frac{4\pi}{3}$，但后者等价于辐角差 $\frac{2\pi}{3}$ 的补角）

同理可得 $z_1$ 与 $z_3$、$z_2$ 与 $z_3$ 的辐角差均为 $\frac{2\pi}{3}$。

因此三个点均匀分布在单位圆上，相邻辐角差为 $\frac{2\pi}{3}$，构成等边三角形。

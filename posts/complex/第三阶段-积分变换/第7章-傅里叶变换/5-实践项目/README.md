# 信号频谱分析器 (Signal Spectrum Analyzer)

## 项目目的

本项目通过傅里叶变换的实际应用，帮助理解信号在时域和频域之间的转换关系。通过可视化方式展示典型信号的频谱特性，并演示频域滤波的基本原理。

## 使用方法

### 环境要求
- Python 3.6+
- 依赖库：numpy, matplotlib, scipy

### 安装依赖
```bash
pip install numpy matplotlib scipy
```

### 运行程序
```bash
cd "第三阶段-积分变换/第7章-傅里叶变换/5-实践项目"
python3 spectrum_analyzer.py
```

## 代码逻辑

### 1. 信号生成
- **方波信号**：周期 T=2π，幅值 1，使用 `scipy.signal.square` 生成
- **三角波信号**：使用 `scipy.signal.sawtooth` 生成
- **指数衰减正弦信号**：`e^{-t}sin(5t)`，用于演示非周期信号的频谱

### 2. 傅里叶分析
- **傅里叶级数**：通过数值积分计算方波和三角波的傅里叶系数 (a₀, aₙ, bₙ)
- **傅里叶变换**：使用 FFT (快速傅里叶变换) 计算信号的频谱
- **频谱图**：展示振幅谱，观察不同频率分量的能量分布

### 3. 信号滤波
- 在频域应用理想低通滤波器
- 通过逆 FFT 恢复时域信号
- 对比滤波前后信号的差异

## 结果分析

### 生成的可视化文件
| 文件名 | 说明 |
|--------|------|
| `fig1_square_wave_analysis.png` | 方波信号的时域波形、频谱和傅里叶级数重建 |
| `fig2_triangle_wave_analysis.png` | 三角波信号的时域波形、频谱和傅里叶级数重建 |
| `fig3_exp_decay_sine_analysis.png` | 指数衰减正弦信号的时域波形和频谱 |
| `fig4_filtering_demo.png` | 滤波演示：原始信号、加噪信号、滤波后信号对比 |
| `fig5_spectrum_comparison.png` | 三种信号的频谱对比 |

### 关键观察
1. **方波频谱**：包含基频和所有奇次谐波，幅值按 1/n 衰减，呈现离散线谱
2. **三角波频谱**：包含基频和奇次谐波，幅值按 1/n² 衰减，比方波衰减更快
3. **指数衰减信号频谱**：连续频谱，能量集中在低频区域
4. **滤波效果**：低通滤波能有效去除高频噪声，但也会使信号的陡峭边缘变得平滑
5. **傅里叶级数重建**：随着谐波数量增加，重建信号越来越接近原始信号（吉布斯现象在方波边缘处明显）

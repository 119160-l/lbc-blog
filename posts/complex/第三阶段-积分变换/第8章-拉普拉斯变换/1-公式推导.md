## 1. 拉普拉斯变换的定义

### 从傅里叶变换到拉普拉斯变换

傅里叶变换要求函数 $f(t)$ 在 $(-\infty, \infty)$ 上绝对可积，这个条件对很多函数（如 $e^{at}$、$t^n$ 等）不成立。

拉普拉斯变换的思路是：**给 $f(t)$ 乘上一个衰减因子 $e^{-\sigma t}$（$\sigma > 0$），使乘积在 $t \to \infty$ 时衰减到 $0$，然后再做傅里叶变换。**

### 定义

设 $f(t)$ 在 $t \geq 0$ 上有定义，且积分 $\int_0^\infty f(t) e^{-st} \, dt$ 在某个区域上收敛，则：

**拉普拉斯变换：**

$$\boxed{F(s) = \mathcal{L}[f(t)] = \int_0^\infty f(t) e^{-st} \, dt}$$

其中 $s = \sigma + i\omega$ 是复变量。

### 拉普拉斯逆变换

$$f(t) = \mathcal{L}^{-1}[F(s)] = \frac{1}{2\pi i} \int_{\sigma - i\infty}^{\sigma + i\infty} F(s) e^{st} \, ds$$

这个积分沿着复平面上的一条垂直线进行，称为**布罗米奇积分**。

### 拉普拉斯变换与傅里叶变换的关系

对于 $t \geq 0$ 上定义的函数 $f(t)$，令 $g(t) = f(t) e^{-\sigma t} u(t)$，则：

$$\mathcal{F}[g(t)] = \int_0^\infty f(t) e^{-\sigma t} e^{-i\omega t} dt = \int_0^\infty f(t) e^{-(\sigma + i\omega)t} dt = \mathcal{L}[f(t)]$$

即 $F(s) = \mathcal{F}[f(t) e^{-\sigma t} u(t)]$，其中 $s = \sigma + i\omega$。

## 2. 拉普拉斯变换的存在条件

### 定理

如果 $f(t)$ 满足：
1. 在 $t \geq 0$ 的任何有限区间上分段连续
2. 存在常数 $M > 0$ 和 $\sigma_0 \geq 0$，使得 $|f(t)| \leq M e^{\sigma_0 t}$（即 $f(t)$ 是指数级函数）

则 $\mathcal{L}[f(t)]$ 在 $\operatorname{Re}(s) > \sigma_0$ 上存在且解析。

### 收敛域

拉普拉斯变换的收敛域是复平面上的半平面 $\operatorname{Re}(s) > \sigma_0$，其中 $\sigma_0$ 称为**收敛横坐标**。

## 3. 拉普拉斯变换的基本性质

### 性质 1：线性性

$$\mathcal{L}[\alpha f(t) + \beta g(t)] = \alpha F(s) + \beta G(s)$$

### 性质 2：微分性质

**时域微分：** $\mathcal{L}[f'(t)] = sF(s) - f(0)$

**证明：**

$$
\begin{aligned}
\mathcal{L}[f'(t)] &= \int_0^\infty f'(t) e^{-st} dt \\
&= \left[f(t) e^{-st}\right]_0^\infty + s \int_0^\infty f(t) e^{-st} dt \quad (\text{分部积分}) \\
&= -f(0) + sF(s) \quad (\text{因为 } \operatorname{Re}(s) \text{ 足够大时 } f(t)e^{-st} \to 0)
\end{aligned}
$$

**推广：**

$$\mathcal{L}[f''(t)] = s^2 F(s) - sf(0) - f'(0)$$

$$\mathcal{L}[f^{(n)}(t)] = s^n F(s) - s^{n-1}f(0) - s^{n-2}f'(0) - \cdots - f^{(n-1)}(0)$$

**频域微分：** $\mathcal{L}[t f(t)] = -F'(s)$

**证明：** 对 $F(s) = \int_0^\infty f(t) e^{-st} dt$ 两边对 $s$ 求导：

$$F'(s) = \int_0^\infty f(t) (-t) e^{-st} dt = -\int_0^\infty t f(t) e^{-st} dt = -\mathcal{L}[t f(t)]$$

因此 $\mathcal{L}[t f(t)] = -F'(s)$。

**推广：** $\mathcal{L}[t^n f(t)] = (-1)^n F^{(n)}(s)$

### 性质 3：积分性质

$$\mathcal{L}\left[\int_0^t f(\tau) d\tau\right] = \frac{F(s)}{s}$$

**证明：**

令 $g(t) = \int_0^t f(\tau) d\tau$，则 $g'(t) = f(t)$，$g(0) = 0$。由微分性质：

$$\mathcal{L}[g'(t)] = s G(s) - g(0) = s G(s) = \mathcal{L}[f(t)] = F(s)$$

因此 $G(s) = \frac{F(s)}{s}$。

### 性质 4：位移性质

**频域位移：** $\mathcal{L}[e^{at} f(t)] = F(s - a)$

**证明：**

$$\mathcal{L}[e^{at} f(t)] = \int_0^\infty e^{at} f(t) e^{-st} dt = \int_0^\infty f(t) e^{-(s-a)t} dt = F(s - a)$$

**时域位移：** $\mathcal{L}[f(t - a) u(t - a)] = e^{-as} F(s)$，其中 $a \geq 0$

### 性质 5：延迟性质

$$\mathcal{L}[f(t - a) u(t - a)] = e^{-as} F(s), \quad a \geq 0$$

其中 $u(t)$ 是单位阶跃函数。

### 性质 6：尺度变换

$$\mathcal{L}[f(at)] = \frac{1}{a} F\left(\frac{s}{a}\right), \quad a > 0$$

### 性质 7：初值定理

$$f(0^+) = \lim_{s \to \infty} s F(s)$$

### 性质 8：终值定理

$$\lim_{t \to \infty} f(t) = \lim_{s \to 0} s F(s)$$

（要求极限存在）

## 4. 常用函数的拉普拉斯变换

### 1. 单位阶跃函数

$u(t) = \begin{cases} 1, & t \geq 0 \\ 0, & t < 0 \end{cases}$

$$\mathcal{L}[u(t)] = \int_0^\infty 1 \cdot e^{-st} dt = \left[-\frac{e^{-st}}{s}\right]_0^\infty = \frac{1}{s}, \quad \operatorname{Re}(s) > 0$$

### 2. 指数函数

$f(t) = e^{at}$

$$\mathcal{L}[e^{at}] = \int_0^\infty e^{at} e^{-st} dt = \int_0^\infty e^{-(s-a)t} dt = \frac{1}{s-a}, \quad \operatorname{Re}(s) > \operatorname{Re}(a)$$

### 3. 幂函数

$f(t) = t^n$（$n$ 为正整数）

$$\mathcal{L}[t^n] = \int_0^\infty t^n e^{-st} dt$$

令 $u = st$，则 $t = u/s$，$dt = du/s$：

$$\mathcal{L}[t^n] = \int_0^\infty \left(\frac{u}{s}\right)^n e^{-u} \frac{du}{s} = \frac{1}{s^{n+1}} \int_0^\infty u^n e^{-u} du = \frac{n!}{s^{n+1}}$$


### 4. 三角函数

$$\mathcal{L}[\sin(at)] = \frac{a}{s^2 + a^2}, \quad \mathcal{L}[\cos(at)] = \frac{s}{s^2 + a^2}$$

**推导：** 利用欧拉公式 $\sin(at) = \frac{e^{iat} - e^{-iat}}{2i}$：

$$
\begin{aligned}
\mathcal{L}[\sin(at)] &= \frac{1}{2i} \left(\frac{1}{s - ia} - \frac{1}{s + ia}\right) \\
&= \frac{1}{2i} \cdot \frac{(s + ia) - (s - ia)}{s^2 + a^2} \\
&= \frac{1}{2i} \cdot \frac{2ia}{s^2 + a^2} = \frac{a}{s^2 + a^2}
\end{aligned}
$$

### 5. 双曲函数

$$\mathcal{L}[\sinh(at)] = \frac{a}{s^2 - a^2}, \quad \mathcal{L}[\cosh(at)] = \frac{s}{s^2 - a^2}$$

### 6. $\delta$ 函数

$$\mathcal{L}[\delta(t)] = 1$$

## 5. 拉普拉斯逆变换

### 方法一：部分分式展开法

当 $F(s)$ 是有理函数时，将其分解为部分分式，然后查表求逆变换。

**步骤：**
1. 将 $F(s) = \frac{P(s)}{Q(s)}$ 分解为部分分式
2. 对每个简单分式，利用拉普拉斯变换表求逆变换
3. 利用线性性叠加

**例子：** 求 $\mathcal{L}^{-1}\left[\frac{1}{s(s+1)}\right]$

$$
\frac{1}{s(s+1)} = \frac{1}{s} - \frac{1}{s+1}
$$

$$\mathcal{L}^{-1}\left[\frac{1}{s}\right] = 1, \quad \mathcal{L}^{-1}\left[\frac{1}{s+1}\right] = e^{-t}$$

因此 $\mathcal{L}^{-1}\left[\frac{1}{s(s+1)}\right] = 1 - e^{-t}$。

### 方法二：留数法（利用复变函数）

由拉普拉斯逆变换的积分公式：

$$f(t) = \frac{1}{2\pi i} \int_{\sigma - i\infty}^{\sigma + i\infty} F(s) e^{st} \, ds = \sum \operatorname{Res}[F(s) e^{st}, s_k]$$

其中 $s_k$ 是 $F(s)$ 的所有奇点。

**例子：** 求 $\mathcal{L}^{-1}\left[\frac{1}{(s-1)(s+2)}\right]$

$F(s) e^{st} = \frac{e^{st}}{(s-1)(s+2)}$，有两个一阶极点 $s = 1$ 和 $s = -2$。

$$\operatorname{Res}[F(s)e^{st}, 1] = \lim_{s \to 1} (s-1) \frac{e^{st}}{(s-1)(s+2)} = \frac{e^{t}}{3}$$

$$\operatorname{Res}[F(s)e^{st}, -2] = \lim_{s \to -2} (s+2) \frac{e^{st}}{(s-1)(s+2)} = \frac{e^{-2t}}{-3} = -\frac{e^{-2t}}{3}$$

因此 $f(t) = \frac{e^t}{3} - \frac{e^{-2t}}{3} = \frac{e^t - e^{-2t}}{3}$。

## 6. 拉普拉斯变换的应用——解微分方程

### 基本步骤

1. 对微分方程两边取拉普拉斯变换，将微分方程转化为代数方程
2. 解代数方程，得到 $Y(s)$
3. 对 $Y(s)$ 做拉普拉斯逆变换，得到 $y(t)$

### 例子：解 $y'' + 3y' + 2y = e^{-t}$，$y(0) = 0$，$y'(0) = 1$

**步骤 1：** 取拉普拉斯变换

$$\mathcal{L}[y''] = s^2 Y(s) - s y(0) - y'(0) = s^2 Y(s) - 1$$
$$\mathcal{L}[y'] = s Y(s) - y(0) = s Y(s)$$
$$\mathcal{L}[y] = Y(s)$$
$$\mathcal{L}[e^{-t}] = \frac{1}{s+1}$$

代入：

$$(s^2 Y(s) - 1) + 3s Y(s) + 2Y(s) = \frac{1}{s+1}$$

**步骤 2：** 解出 $Y(s)$

$$(s^2 + 3s + 2) Y(s) = 1 + \frac{1}{s+1} = \frac{s+2}{s+1}$$

$$Y(s) = \frac{s+2}{(s+1)(s^2 + 3s + 2)} = \frac{s+2}{(s+1)(s+1)(s+2)} = \frac{1}{(s+1)^2}$$

**步骤 3：** 求逆变换

$$\mathcal{L}^{-1}\left[\frac{1}{(s+1)^2}\right] = t e^{-t}$$

因此 $y(t) = t e^{-t}$。

# 第12章 离散控制与数字实现——知识讲解

> **承上启下**：第8章讲了 PID，第11章讲了 LQR——但那些都是"连续公式"。现实里控制器跑在芯片上，**每 1ms、5ms、10ms 才"醒"一次**。本章解决：怎么把连续控制器变成芯片里跑的代码，以及为什么采样快慢决定成败。

---

## 一、为什么必须学"离散"？

| 连续世界（前10章） | 数字世界（本章） |
|---|---|
| 控制器是公式 | 控制器是循环里的一段代码 |
| 时间连续流动 | 时间按 $T$ 一跳一跳（采样） |
| 拉氏变换 $s$ | z 变换 $z=e^{sT}$ |
| 稳定边界：虚轴 | 稳定边界：单位圆 |

**一句话**：不会离散化，你会"设计"但不会"实现"。

---

## 二、采样与零阶保持：芯片眼里世界长什么样

- **采样**：每 $T$ 秒读一次传感器 → 芯片只认识"点"；
- **零阶保持（ZOH）**：算出的输出保持到下一拍 → 电机看到的是"阶梯电压"。

![采样与零阶保持](./figures/01_采样与零阶保持.png)

*图 12-1 连续信号、采样点、零阶保持阶梯波三者对比。*

> 生活类比：数字控制器像一个"眨眼的司机"——每 $T$ 秒睁眼看一下路况（采样），然后猛打一把方向并保持（零阶保持）。眨眼太快，像一直睁着眼；眨眼太慢，肯定出事。

**采样定理**：$f_s > 2f_{max}$。工程习惯再放宽：$f_s = 5\sim20$ 倍系统带宽。

## 三、z 变换：离散世界的"拉氏变换"

### 核心关系：$z = e^{sT}$

一条公式串起全部离散理论：

| s 平面 | z 平面 |
|---|---|
| 左半平面（稳定） | 单位圆内（稳定） |
| 虚轴（临界） | 单位圆上（临界） |
| 右半平面（发散） | 单位圆外（发散） |

![z平面单位圆判稳](./figures/02_z平面单位圆判稳.png)

*图 12-2 z 平面极点：圆内收敛、圆外发散；实部为负还会正负交替。*

**关键直觉**：$z^{-1}$ = "延迟一拍"（$z^{-1}y[k]=y[k-1]$）。**离散系统的一切"动态"，都是"延迟"的组合**——控制环就是：看现在 → 算出该干嘛 → 一拍后再干。

## 四、数字 PID：从公式到代码

### 位置式

$$
u[k] = K_p e[k] + K_i T\sum_{j=0}^{k} e[j] + \frac{K_d}{T}(e[k]-e[k-1])
$$

```python
# 伪代码（真实工程结构）
while True:                          # 控制循环
    y = read_sensor()                # 采样
    e = target - y
    integ += e * Ts                  # 积分累加
    u = Kp*e + Ki*integ + Kd*(e - e_prev)/Ts
    set_actuator(u)                  # 零阶保持输出
    e_prev = e
    sleep(Ts)                        # 等下一个采样时刻
```

### 增量式（工程首选）

$$
\Delta u[k] = K_p(e[k]-e[k-1]) + K_i T e[k] + \frac{K_d}{T}(e[k]-2e[k-1]+e[k-2])
$$

**优点**：不记历史、断电无记忆、限幅方便——无人机/机器人的位置环、速度环几乎都用增量式。

### 连续 vs 数字：差别有多大？

![连续与数字PID对比](./figures/03_连续与数字PID对比.png)

*图 12-3 采样 0.05s 时，数字 PID 与连续 PID 曲线几乎重合。*

> **时间视角**：采样快 → 数字 PID ≈ 连续 PID（曲线平滑）；采样慢 → 控制器"每拍反应太迟钝"→ 性能断崖式下降（见图 12-5）。

## 五、积分饱和：工程第一大坑

### 怎么回事？

- 执行器有极限（油门到底、电机饱和）；误差还大时，积分项**照常累积**；
- 误差反转后，累积的积分让输出**继续顶在饱和区**，系统"卡住"很久才反应过来 → 大幅超调、剧烈振荡。

![积分饱和对比](./figures/04_积分饱和对比.png)

*图 12-4 相同 PI 参数：普通 PI 超调大、收敛慢；抗积分饱和 PI 干净利落。*

### 最常用的解法：条件积分

```python
u_calc = Kp*e + Ki*integ + Kd*(e-e_prev)/Ts
u = clip(u_calc, -u_max, u_max)
if abs(u_calc) < u_max:     # 没饱和才累积积分
    integ += e * Ts
```

> **实践视角**：无人机油门、车辆油门、机械臂关节——**凡是有执行器饱和的系统，抗积分饱和是标配**。写控制代码第一件事就是加饱和保护。

## 六、采样周期选多大？（工程铁律）

| 采样周期 | 表现 |
|---|---|
| 太小（如 0.01s） | 接近连续，但占用 CPU，噪声更敏感 |
| 合适（如 0.1s） | 性能良好，成本低 |
| 太大（如 0.4s） | 性能崩溃、振荡甚至发散 |

![采样周期影响](./figures/05_采样周期影响.png)

*图 12-5 同一 PID 参数、三种采样周期。采样周期就是控制回路的"反应速度"。*

**经验值**：控制频率 ≈ 5~20 倍系统带宽；无人机内环 1~2 kHz，机器人力矩环 1 kHz，车辆 10~100 Hz。

> **补充：串级 PID 与内外环带宽分层（对应练习题 13）**——无人机姿态环常采用**串级 PID**：外环（角度环）输出角速度指令，内环（角速度环）输出力矩。内环采样频率要求更高的原因：① 内环带宽远高于外环，而 Nyquist 要求采样频率 > 2×带宽，带宽越高采样越快；② 内环是外环的"被控对象"，外环的响应速度受内环限制，内环必须"快"外环才能"快"。**串级结构的本质就是"内外环带宽分层"**——内环 1~2 kHz、外环 200~500 Hz，各环独立整定（先内环后外环）。

## 总结：知识体系图

```
数字控制（从纸面到芯片）
   │
   ├─ 采样与保持：f_s > 2f_max，ZOH
   ├─ z变换：z = e^(sT)，z^(-1)=延迟一拍
   ├─ 离散稳定：|z|<1（单位圆内）
   ├─ 数字PID：位置式 / 增量式 / 抗积分饱和
   └─ 采样周期：5~20 倍带宽，先定采样再调参
        │
        └─ 通往：第13章实物/仿真实现 · 第14章 MPC/强化学习（都是离散的）
```

### 核心脉络

1. **数字控制 = 采样 + 每拍算一次 + 保持到下一拍**；
2. **$z=e^{sT}$** 一图看懂：s 左半 ↔ 单位圆内；
3. **数字 PID**：增量式工程首选，抗饱和必做；
4. **采样周期 > 一切**：采样不对，调参白费。

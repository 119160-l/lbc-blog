# 第12章 离散控制与数字实现——公式推导

> **承上启下**：前面所有控制器都是"连续时间"的公式，但真实控制器跑在**单片机/DSP/计算机**里——按固定采样周期工作。本章把"连续"翻译成"离散"。
> 推导主线：采样与保持 → z 变换 → 脉冲传递函数 → 离散稳定性 → 数字 PID 实现 → 抗积分饱和。

---

## 1. 采样与零阶保持

### 1.1 数字控制回路的结构

```
r(t) →[A/D 采样]→ r[k] →[数字控制器]→ u[k] →[D/A 零阶保持]→ u(t) →[对象 G(s)]→ y(t)
                                                                          │
                                                                          └→[传感器]→ y[k]→→
```

- **采样**：每 $T$ 秒取一次值，$T$ 为采样周期，$f_s=1/T$ 为采样频率；
- **零阶保持（ZOH）**：把采样值保持到下个采样时刻（形成阶梯波）。

### 1.2 采样定理（Nyquist）

要无失真地从采样值恢复连续信号，须：

$$
\boxed{f_s > 2 f_{\max} \quad \Longleftrightarrow \quad T < \frac{1}{2f_{\max}}}
$$

工程上通常取采样周期 $T$ 为系统最小时间常数的 $1/5\sim1/10$，即采样频率 $f_s=1/T$ 约为系统带宽的 5~20 倍。

![采样与零阶保持](./figures/01_采样与零阶保持.png)

*图 12-1 连续信号 → 采样点 → 零阶保持阶梯波。数字控制器只能看到"每 T 秒一个点"，其余时间它"假装"信号保持不变。*

> **实践视角**：采样周期是硬件选型问题。无人机姿态环典型 250~1000 Hz，电机电流环 10~50 kHz，车辆控制 10~100 Hz——**先定采样周期，再谈控制器**。

### 1.3 零阶保持器（ZOH）的直观理解

可以把"离散系统"简单理解为：**计算机控制的系统**。因为计算机不能像模拟电路那样连续不断地处理信号，它只能每隔一小段时间（采样周期 $T$）"看"一眼数据，然后算一下，再输出一个值。而零阶保持正是工程实践中最容易踩坑的地方。

#### 什么是零阶保持器？

计算机算出一个控制量后，在下一次采样之前，这个值会**保持不变**（像台阶一样）。这种"保持上一个值不变"的行为就叫零阶保持。

#### 为什么它会引入延迟？

想象一下：你在 $t=0$ 时刻算出了控制量，但它实际上代表的是 $t=0$ 到 $t=T$ 这一整段时间的平均效果。从信息角度看，这相当于你把信号**推迟了大约 $T/2$** 才真正作用到系统上。

#### 延迟为什么致命？

在频域里，纯延迟 $e^{-sT/2}$ 会带来**相位滞后** $\phi = -\omega \cdot T/2$。

- 频率 $\omega$ 越高，滞后越严重。
- 采样周期 $T$ 越大，滞后越严重。

相位裕度被"吃掉"了 → 系统阻尼变小 → 极点向单位圆边界移动 → **$T$ 大到一定程度，极点就冲出单位圆，系统失稳！**

> 💡 **小白避坑指南**：
> 设计数字控制器时，**绝对不能**只在连续域设计好 $G(s)$ 就直接用。必须先把对象连同 ZOH 一起离散化成 $G_d(z)$，然后在 z 域设计或验证。**采样周期 $T$ 不是随便选的，选大了系统就会不稳定！**

## 2. z 变换：离散信号的"拉氏变换"

### 2.1 定义

对采样信号 $f[k]=f(kT)$：

$$
\boxed{F(z) = \mathcal{Z}\{f[k]\} = \sum_{k=0}^{\infty} f[k]\, z^{-k}}
$$

其中 $z = e^{sT}$（$T$ 为采样周期）。

计算 Z 变换的标准流程：

```
┌─────────────────────────────────────┐
│  1. 写出采样序列 f[k] 的表达式       │
│  2. 代入定义 F(z) = Σ f[k]·z⁻ᵏ     │
│  3. 化简求和（等比级数/查表/性质）    │
│  4. 整理为 z 的有理分式形式           │
│  5. 确定收敛域 ROC 并标注             │
└─────────────────────────────────────┘
```

### 2.2 与拉氏变换的对应

| 时域 $f(t)$ | $F(s)$ | 采样序列 $f[k]$ | $F(z)$ |
|---|---|---|---|
| $\delta(t)$ | 1 | $\delta[k]$ | 1 |
| $1(t)$ | $\dfrac{1}{s}$ | $1[k]$ | $\dfrac{z}{z-1}$ |
| $t$ | $\dfrac{1}{s^2}$ | $kT$ | $\dfrac{Tz}{(z-1)^2}$ |
| $e^{-at}$ | $\dfrac{1}{s+a}$ | $e^{-akT}$ | $\dfrac{z}{z-e^{-aT}}$ |

**关键思路**：分子出现 $z$，是因为"采样脉冲"本身有 $z^{-1}$ 单位延迟。**$z$ 的负幂次 = 一拍延迟**（$z^{-1}y[k]=y[k-1]$），这是离散系统"因果性"的数学表达。

### 2.3 重要性质（对比拉氏变换）

| 性质 | 拉氏（连续） | z（离散） |
|---|---|---|
| 微分/超前 | $\dot x \leftrightarrow sX(s)$ | $x[k+1]\leftrightarrow zX(z)$ |
| 延迟 | $x(t-\tau)$ | $x[k-1]\leftrightarrow z^{-1}X(z)$ |
| 终值 | $\lim_{t\to\infty}x(t)=\lim_{s\to0}sX(s)$ | $\lim_{k\to\infty}x[k]=\lim_{z\to1}(z-1)X(z)$ |

> 下面给出 z 变换的**完整性质表**（时域 ↔ Z 域对照），做题直接查：

| 性质             | 时域             | Z 域                                               | 备注                  |
| -------------- | -------------- | ------------------------------------------------- | ------------------- |
| 线性             | $af_1+bf_2$    | $aF_1+bF_2$                                       | ROC ⊇ 交集            |
| 右移 $m$         | $f[k-m]u[k-m]$ | $z^{-m}F(z)$                                      | 延迟                  |
| 左移 $m$         | $f[k+m]$       | $z^m\left[F(z)-\sum_{n=0}^{m-1}f[n]z^{-n}\right]$ | 需减初值                |
| 初值             | $f[0]$         | $\lim_{z\to\infty}F(z)$                           | 真分式                 |
| 终值             | $f[\infty]$    | $\lim_{z\to1}(z-1)F(z)$                           | 极点须在单位圆内或 $z=1$ 单极点 |
| 指数加权           | $a^k f[k]$     | $F(z/a)$                                          | ROC 缩放              |
| Z 域微分          | $k\,f[k]$      | $-z\,\dfrac{dF}{dz}$                              | 可迭代                 |
| 卷积             | $f*g$          | $F(z)G(z)$                                        | 系统分析核心              |
| 共轭对称（$f[k]$ 实） | —              | $F(z^*)=[F(z)]^*$                                 | 零极点共轭成对             |

### 2.4 Z 变换计算的标准步骤

在离散时间信号与系统分析中，**Z 变换（Z-Transform）** 是将离散时间序列从"时域"映射到"复频域（Z 域）"的核心数学工具。它类似于连续系统中的拉普拉斯变换，是分析线性时不变（LTI）系统、求解差分方程和设计数字滤波器的基础。

#### 第一步：明确序列定义与收敛域（ROC）

在进行任何计算之前，必须确认两个要素：

1. **序列表达式 $x[n]$**：明确信号的数学形式（如指数、正弦、阶跃等）。
2. **信号类型**：判断是因果序列（$n \ge 0$）、反因果序列（$n < 0$）还是双边序列。**这直接决定了收敛域（ROC）**。
   - *注意：没有 ROC 的 Z 变换是不完整的，不同的 ROC 对应完全不同的时域信号。*

#### 第二步：选择计算方法

根据序列的复杂程度，选择以下三种方法之一：

**方法 A：定义法（直接求和）**——适用于简单序列或有限长序列。

$$
X(z) = \sum_{n=-\infty}^{\infty} x[n] z^{-n}
$$

- **操作**：代入 $x[n]$，确定求和上下限，利用等比级数求和公式化简。
- **关键**：在求和过程中自然导出使级数收敛的 $|z|$ 范围，即 ROC。

**方法 B：常用变换对查表法（推荐）**——适用于典型信号。熟记或查阅以下核心变换对可大幅简化计算：

| 时域序列 $x[n]$            | Z 域 $X(z)$                                        | ROC |     |     |     |     |
| ---------------------- | ------------------------------------------------- | --- | --- | --- | --- | --- |
| $\delta[n]$（单位脉冲）      | $1$                                               | 全平面 |     |     |     |     |
| $u[n]$（单位阶跃）           | $\dfrac{z}{z-1}$                                  | $   | z   | >1$ |     |     |
| $a^n u[n]$             | $\dfrac{z}{z-a}$                                  | $   | z   | >   | a   | $   |
| $n a^n u[n]$           | $\dfrac{az}{(z-a)^2}$                             | $   | z   | >   | a   | $   |
| $\cos(\omega_0 n)u[n]$ | $\dfrac{z(z-\cos\omega_0)}{z^2-2z\cos\omega_0+1}$ | $   | z   | >1$ |     |     |

**方法 C：性质法**——利用 Z 变换的性质将复杂序列转化为简单序列的组合：

- **线性**：$ax_1[n] + bx_2[n] \leftrightarrow aX_1(z) + bX_2(z)$
- **移位性质**：$x[n-k] \leftrightarrow z^{-k}X(z)$（最常用）
- **尺度变换**：$a^n x[n] \leftrightarrow X(z/a)$
- **卷积定理**：$x[n] * h[n] \leftrightarrow X(z)H(z)$（系统分析的核心）

#### 第三步：代数化简与整理

将得到的 $X(z)$ 整理为标准有理分式形式：

$$
X(z) = \frac{b_0 z^M + b_1 z^{M-1} + \dots}{a_0 z^N + a_1 z^{N-1} + \dots}
$$

或者更常见的**零极点增益形式**：

$$
X(z) = K \cdot \frac{(z-z_1)(z-z_2)\dots}{(z-p_1)(z-p_2)\dots}
$$

- **目的**：便于后续分析系统的稳定性、频率响应及进行逆 Z 变换。

#### 第四步：确定并标注收敛域（ROC）

这是最容易被忽略但**最关键**的一步。ROC 的规则如下：

1. ROC 是 Z 平面上的环形区域，不包含任何极点。
2. **右边序列（因果）**：ROC 在最外层极点的外部（$|z| > r_{\max}$）。
3. **左边序列（反因果）**：ROC 在最内层极点的内部（$|z| < r_{\min}$）。
4. **双边序列**：ROC 为环状区域（$r_1 < |z| < r_2$）。
5. **稳定性判据**：若系统稳定，ROC 必须**包含单位圆**（$|z|=1$）。

#### 第五步：逆 Z 变换（如需返回时域）

如果题目要求从 Z 域回到时域，常用方法有：

1. **部分分式展开法**（最通用）：将 $X(z)/z$ 展开为简单分式之和，再乘以 $z$ 后查表逆变换。
2. **幂级数展开法（长除法）**：适用于求前几项数值或 FIR 系统。
3. **留数法（围线积分）**：理论严谨，适合高阶极点或复杂函数。

#### 💡 实战示例演示

**问题**：求 $x[n] = (0.5)^n u[n]$ 的 Z 变换。

1. **识别**：这是右边指数序列，对应查表法。
2. **套用公式**：令 $a=0.5$，直接得 $X(z) = \dfrac{z}{z-0.5}$。
3. **确定 ROC**：因为是 $u[n]$ 因果序列，ROC 为 $|z| > |0.5|$。
4. **结果**：$X(z) = \dfrac{z}{z-0.5}, \quad |z| > 0.5$

#### ⚠️ 常见误区提醒

- **只写表达式不写 ROC**：在考试和工程文档中，缺少 ROC 的 Z 变换答案通常被视为不完整甚至错误。
- **混淆单边与双边 Z 变换**：控制系统和数字滤波器设计通常默认使用**单边 Z 变换**（求和从 $n=0$ 开始），而信号分析可能涉及双边。务必确认上下文。
- **忘记 $z$ 的正幂形式**：部分分式展开时，建议先对 $X(z)/z$ 展开，而不是直接对 $X(z)$ 展开，这样逆变换时能直接匹配 $z/(z-a)$ 的形式，避免出错。

### 2.5 Z 变换逐步推导详解

#### 一、从物理背景出发：为什么要做 Z 变换？

连续信号 $f(t)$ 经过周期为 $T$ 的采样后，得到离散采样序列：

$$
f[k] = f(kT), \quad k = 0, 1, 2, 3, \dots
$$

我们希望在**复频域**中分析这个离散信号，就像拉普拉斯变换分析连续信号一样。Z 变换正是这个"离散版的拉普拉斯变换"。

#### 二、定义公式的逐项拆解

定义公式：

$$
F(z) = \sum_{k=0}^{\infty} f[k]\, z^{-k}
$$

逐项展开来看：

$$
F(z) = f[0]\cdot z^{0} + f[1]\cdot z^{-1} + f[2]\cdot z^{-2} + f[3]\cdot z^{-3} + \cdots
$$

**本质**：就是把每个采样值 $f[k]$ 乘以 $z^{-k}$（$z$ 的负 $k$ 次幂），然后全部加起来。

> 注意：这是**单边 Z 变换**（求和从 $k=0$ 开始），适用于因果信号或 $k<0$ 时 $f[k]=0$ 的情况。

#### 三、具体计算步骤（以实例驱动）

**例 1：阶跃序列 $f[k] = 1$（即 $f[k] = u[k]$）**

第 1 步，代入定义：

$$
F(z) = \sum_{k=0}^{\infty} 1 \cdot z^{-k} = 1 + z^{-1} + z^{-2} + z^{-3} + \cdots
$$

第 2 步，识别为等比级数：这是一个首项 $a = 1$、公比 $r = z^{-1}$ 的无穷等比级数。

第 3 步，利用等比级数求和公式：当 $|r| < 1$ 即 $|z^{-1}| < 1$ 也就是 $|z| > 1$ 时：

$$
F(z) = \frac{1}{1 - z^{-1}} = \frac{z}{z - 1}
$$

第 4 步，标注收敛域（ROC）：

$$
\boxed{F(z) = \frac{z}{z-1}, \quad |z| > 1}
$$

**例 2：指数序列 $f[k] = a^k$（$k \geq 0$）**

第 1 步，代入定义：

$$
F(z) = \sum_{k=0}^{\infty} a^k z^{-k} = \sum_{k=0}^{\infty} (az^{-1})^k
$$

第 2 步，识别等比级数：首项 $= 1$，公比 $r = az^{-1} = \dfrac{a}{z}$。

第 3 步，求和：当 $\left|\dfrac{a}{z}\right| < 1$，即 $|z| > |a|$ 时：

$$
F(z) = \frac{1}{1 - az^{-1}} = \frac{z}{z - a}
$$

第 4 步，标注 ROC：

$$
\boxed{F(z) = \frac{z}{z-a}, \quad |z| > |a|}
$$

**例 3：斜坡序列 $f[k] = kT$（$k \geq 0$）**

第 1 步，代入定义：

$$
F(z) = \sum_{k=0}^{\infty} kT \cdot z^{-k} = T \sum_{k=0}^{\infty} k \cdot z^{-k}
$$

第 2 步，利用已知结果求导法。从例 2 已知（令 $a=1$）：

$$
\sum_{k=0}^{\infty} z^{-k} = \frac{z}{z-1}
$$

对两边关于 $z$ 求导：

$$
\sum_{k=0}^{\infty} (-k) z^{-k-1} = \frac{d}{dz}\left(\frac{z}{z-1}\right) = \frac{(z-1) - z}{(z-1)^2} = \frac{-1}{(z-1)^2}
$$

两边乘以 $(-z)$：

$$
\sum_{k=0}^{\infty} k \cdot z^{-k} = \frac{z}{(z-1)^2}
$$

第 3 步，乘以系数 $T$：

$$
\boxed{F(z) = \frac{Tz}{(z-1)^2}, \quad |z| > 1}
$$

#### 四、$z = e^{sT}$ 的物理含义

这个关系是连接**连续域（s 域）**和**离散域（z 域）**的桥梁：

| 连续域 $s$ | 离散域 $z = e^{sT}$ | 含义 |
|---|---|---|
| $s = j\omega$（虚轴） | $z = e^{j\omega T}$（单位圆） | 稳定边界 |
| $\text{Re}(s) < 0$（左半平面） | $|z| < 1$（单位圆内） | 稳定区域 |
| $\text{Re}(s) > 0$（右半平面） | $|z| > 1$（单位圆外） | 不稳定区域 |
| $s = 0$（原点） | $z = 1$ | 直流/稳态 |

> 这意味着：**连续系统中"左半平面稳定"的判据，在离散系统中变成了"单位圆内稳定"。**

#### 五、总结：计算 Z 变换的标准流程

```
┌─────────────────────────────────────┐
│  1. 写出采样序列 f[k] 的表达式       │
│  2. 代入定义 F(z) = Σ f[k]·z⁻ᵏ     │
│  3. 化简求和（等比级数/查表/性质）    │
│  4. 整理为 z 的有理分式形式           │
│  5. 确定收敛域 ROC 并标注             │
└─────────────────────────────────────┘
```

核心要点：

- **$z^{-k}$ 代表延迟 $k$ 个采样周期**，所以 Z 变换本质上是"按延迟展开"
- **ROC 决定唯一性**：同一个 $F(z)$ 表达式，不同的 ROC 对应完全不同的时域信号
- **$z = e^{sT}$** 让你可以在 s 域和 z 域之间自由切换，是数字控制器设计（如双线性变换法）的理论基础

### 2.6 Z 变换性质详解

以下所有性质均基于**单边 Z 变换**定义：$F(z) = \sum_{k=0}^{\infty} f[k]\, z^{-k}$，ROC 记为 $R_f$。

#### 1. 线性性质（Linearity）

$$
\mathcal{Z}\{a\,f_1[k] + b\,f_2[k]\} = a\,F_1(z) + b\,F_2(z)
$$

- **ROC**：至少为 $R_{f_1} \cap R_{f_2}$（若零极点相消，ROC 可能扩大）
- **意义**：Z 变换是线性算子，叠加原理成立
- **示例**：$\mathcal{Z}\{3 \cdot 2^k + 5 \cdot (-1)^k\} = \frac{3z}{z-2} + \frac{5z}{z+1}$

> ⚠️ **零极点相消陷阱**：若 $aF_1(z)+bF_2(z)$ 中某个极点被分子的零点抵消，实际 ROC 会比交集更大。务必化简后重新判断。

#### 2. 移位性质（Time Shifting）⭐ 最常用

**右移（延迟）$m > 0$**：

$$
\mathcal{Z}\{f[k-m]\,u[k-m]\} = z^{-m}\,F(z)
$$

- 信号整体向右平移 $m$ 步，前面补 $m$ 个零
- **ROC**：与 $F(z)$ 相同（可能在 $z=0$ 处增加极点）

**左移（超前）$m > 0$**：

$$
\mathcal{Z}\{f[k+m]\} = z^{m}\left[F(z) - \sum_{n=0}^{m-1} f[n]\,z^{-n}\right]
$$

- 需要**减去前 $m$ 个初始值**，这是单边 Z 变换与双边的关键区别
- **物理含义**：差分方程求解时，初始条件就是通过这个公式引入的

💡 **记忆技巧**：

| 操作 | Z 域效果 | 直觉 |
|---|---|---|
| 延迟 $m$ 步 | 乘 $z^{-m}$ | $z^{-1}$ = "延迟一个采样周期" |
| 超前 $m$ 步 | 乘 $z^{m}$ 并减初值 | 提前读取未来值需补偿已丢失的历史 |

#### 3. 初值定理（Initial Value Theorem）

$$
f[0] = \lim_{z \to \infty} F(z)
$$

- **条件**：$F(z)$ 为真有理分式（分子阶数 ≤ 分母阶数）
- **用途**：不需求逆变换即可直接得到 $f[0]$
- **验证**：$F(z) = \frac{z}{z-a}$，$\lim_{z\to\infty} \frac{z}{z-a} = 1 = f[0]$ ✓

**推广：求 $f[m]$**：

$$
f[m] = \lim_{z \to \infty} z^m \left[ F(z) - \sum_{n=0}^{m-1} f[n]\,z^{-n} \right]
$$

#### 4. 终值定理（Final Value Theorem）⭐

$$
\lim_{k \to \infty} f[k] = \lim_{z \to 1} (z-1)\,F(z)
$$

- **适用条件（必须同时满足）**：
    1. $(z-1)F(z)$ 在单位圆上及外部解析（无极点）
    2. $F(z)$ 的所有极点都在单位圆内，**或者**仅在 $z=1$ 处有一个单极点
- **用途**：判断系统稳态值、稳态误差，无需逆变换
- **反例警示**：$F(z) = \frac{z}{z+1}$，极点在 $z=-1$（单位圆上），终值定理**不适用**！实际上 $f[k]=(-1)^k$ 振荡不收敛。

#### 5. 尺度变换 / 指数加权（Scaling in z-domain）

$$
\mathcal{Z}\{a^k\,f[k]\} = F\!\left(\frac{z}{a}\right)
$$

- **ROC**：变为 $|a| \cdot R_f$
- **物理含义**：时域乘以指数 $a^k$ ⟺ Z 域做尺度缩放
- **典型应用**：
    - $\mathcal{Z}\{a^k u[k]\} = U(z/a) = \frac{z/a}{z/a - 1} = \frac{z}{z-a}$
    - $\mathcal{Z}\{a^k \cos(\omega_0 k)\,u[k]\}$：将 $\cos$ 的 Z 变换中 $z$ 替换为 $z/a$

#### 6. Z 域微分（Differentiation in z-domain）

$$
\mathcal{Z}\{k\,f[k]\} = -z\,\frac{d}{dz}F(z)
$$

推广：

$$
\mathcal{Z}\{k^m\,f[k]\} = \left(-z\,\frac{d}{dz}\right)^m F(z)
$$

- **用途**：处理含 $k$、$k^2$ 等因子的序列
- **示例推导斜坡信号**：

$$
\mathcal{Z}\{k\cdot u[k]\} = -z\,\frac{d}{dz}\!\left(\frac{z}{z-1}\right) = -z \cdot \frac{-1}{(z-1)^2} = \frac{z}{(z-1)^2}
$$

#### 7. 卷积定理（Convolution Theorem）⭐⭐

$$
\mathcal{Z}\{f[k] * g[k]\} = F(z)\,G(z)
$$

其中离散卷积定义为：$(f*g)[k] = \sum_{n=0}^{k} f[n]\,g[k-n]$

- **ROC**：至少为 $R_f \cap R_g$
- **核心意义**：**时域卷积 ⟺ Z 域乘法**
    - LTI 系统输出：$y[k] = x[k] * h[k] \Rightarrow Y(z) = X(z)\,H(z)$
    - 传递函数：$H(z) = Y(z)/X(z)$
- 这是数字滤波器设计和系统分析的**理论基石**

#### 8. 复共轭性质

若 $f[k]$ 为实序列，则：

$$
F(z^*) = [F(z)]^*
$$

- **推论**：实序列的 Z 变换，其零点和极点必然**共轭成对出现**
- 工程意义：设计实系数数字滤波器时，复数极点/零点总是成对的

#### 9. Parseval 定理（能量关系）

$$
\sum_{k=0}^{\infty} |f[k]|^2 = \frac{1}{2\pi j} \oint_C F(z)\,F^*\!\left(\frac{1}{z^*}\right) z^{-1}\,dz
$$

当 ROC 包含单位圆时，简化为频域形式：

$$
\sum_{k=0}^{\infty} |f[k]|^2 = \frac{1}{2\pi} \int_{-\pi}^{\pi} |F(e^{j\omega})|^2 \, d\omega
$$

- **用途**：计算信号能量、验证滤波器增益

#### ⚠️ 使用性质的三大注意事项

1. **始终跟踪 ROC**：每次运用性质后都要重新确认 ROC，尤其是零极点相消、尺度变换时
2. **区分单边与双边**：左移性质、初值/终值定理仅适用于单边 Z 变换；双边版本形式不同
3. **终值定理先验条件**：使用前**必须先检查极点位置**，否则会得到错误的"稳态值"

掌握这些性质后，绝大多数 Z 变换问题都可以通过**查表 + 性质组合**快速求解，而无需每次都回到定义求和。

## 3. 脉冲传递函数与离散系统稳定性

### 3.1 脉冲传递函数

对线性时不变离散系统（如差分方程 $y[k]+a_1y[k-1]=b_0u[k]+b_1u[k-1]$）：

$$
G(z) = \frac{Y(z)}{U(z)}
$$

零初始条件下，输入输出 z 变换之比——和传递函数 $G(s)$ 一模一样的"离散版"。

> **小白直觉**：
> - **连续世界（s 域）**：我们用微分方程描述系统，用拉普拉斯变换得到传递函数 $G(s)$。它是连续系统的"身份证"，告诉我们输入如何变成输出。
> - **离散世界（z 域）**：计算机处理的是差分方程（比如"当前的输出 = 上一次的输出 × 0.8 + 当前的输入 × 0.2"）。我们对差分方程做 Z 变换，就得到了 **$G(z)$**。
> - $G(z)$ 就是 $G(s)$ 的"数字孪生兄弟"。只要有了 $G(z)$，我们就能像分析连续系统一样，用代数方法分析计算机控制系统的行为，而不需要去解复杂的递推数列。

### 3.2 离散稳定性的判据：单位圆

连续系统稳定 ⇔ 极点全在 s 左半平面。
由 $z=e^{sT}$ 映射：

$$
\boxed{\text{离散系统稳定} \iff \text{全部极点位于 } z \text{ 平面单位圆内 }(|z|<1)}
$$

![z平面单位圆判稳](./figures/02_z平面单位圆判稳.png)

*图 12-2 z 平面极点位置与时间行为：圆内收敛（正实根单调、负实根跳变、复根振荡），圆外发散。*

**对应关系**（由 $z=e^{sT}$）：

| s 平面 | z 平面 | 时间行为 |
|---|---|---|
| 左半平面 | 单位圆内 | 收敛 |
| 虚轴 | 单位圆上 | 等幅/临界 |
| 右半平面 | 单位圆外 | 发散 |
| 实轴负方向 | $z<0$ 区间 | 正负交替（采样抖动） |

> **时间视角**：$z$ 的实部为正 → 序列单调；实部为负 → 序列正负跳变（离散特有的"振荡"）；$|z|<1$ 才是收敛——**采样把"连续收敛"变成了"几何级数收敛"**。

#### 🤔 为什么是圆而不是线？

因为 $z$ 和 $s$ 的关系是 $z = e^{sT}$。这是一个指数映射：

- 当 $s$ 在左半平面（负实部），$e^{\text{负数}}$ 的结果一定小于 1 → 落在单位圆内。
- 当 $s$ 在虚轴上（纯虚数），$e^{j\omega T}$ 的模永远是 1 → 落在单位圆上。
- 当 $s$ 在右半平面（正实部），$e^{\text{正数}}$ 的结果一定大于 1 → 落在单位圆外。

#### ⚠️ 离散特有的"抖动"现象

注意上面对应关系表最后一行：**$z$ 为负实数时，输出会正负交替跳变**。
这在连续系统里是没有的！这是因为 $z=-a$ 对应的时间序列是 $(-a)^k$，当 $k=1,2,3...$ 时，符号会不断翻转。这就是所谓的"采样引起的振荡"，即使系统是稳定的（$|-a|<1$），输出也会像锯齿一样抖动地收敛到零。

#### 🔧 Jury 判据是什么？

- **Routh 判据**是判断连续系统极点是否在左半平面的代数工具。
- **Jury 判据**就是它的"离散版"，用来判断多项式的根是否在单位圆内。
- **小白只需要知道**：当你有一个含参数 $K$ 的特征方程，想知道 $K$ 取多少系统才稳定时，就用 Jury 判据（或者对二阶系统直接用那三个不等式）。它本质上就是在检查"根有没有跑出单位圆"。

> **补充：Jury 判据——离散版的 Routh（对应练习题 10）**——单位圆判稳只能判断"给定极点是否稳定"，要求"参数 $K$ 取何值稳定"时要用 Jury 判据。对二阶特征方程 $F(z)=z^2+a_1 z+a_0=0$，稳定充要条件为：
>
> $$
> |a_0|<1,\qquad F(1)=1+a_1+a_0>0,\qquad F(-1)=1-a_1+a_0>0
> $$
>
> 本质：稳定边界是单位圆，故令 $z=1$ 与 $z=-1$（单位圆上的实轴端点）代入求临界参数。练习题 10 中 $z^2-1.5z+K=0$：$|K|<1$；$F(1)=K-0.5>0\Rightarrow K>0.5$；$F(-1)=K+2.5>0$ 自动满足，综合得 $\boxed{0.5<K<1}$。

#### 📌 小白记忆卡片

1. **$G(z)$** = 离散系统的传递函数，由差分方程 Z 变换得来。
2. **稳定 = 极点在单位圆内**（$|z|<1$），这是由 $z=e^{sT}$ 决定的铁律。
3. **$z$ 为负** → 输出正负跳变（离散特有现象）。
4. **Jury 判据** = 离散版的 Routh，用于求稳定参数范围。
5. **ZOH 引入 ≈ $T/2$ 延迟** → 吃相位裕度 → $T$ 太大会导致失稳。
6. **永远在离散域验证稳定性**，不要相信连续域的结论直接搬到数字控制器上。

### 3.3 连续→离散：零阶保持离散化

对象 $G(s)$ 前接零阶保持后的精确离散化：

$$
\boxed{G_d(z) = (1-z^{-1})\, \mathcal{Z}\left\{\frac{G(s)}{s}\right\}}
$$

> **实践视角**：手算可用查表法；工程上直接 `control`：`Gd = ct.c2d(G, T, method='zoh')`。

> **补充：采样为什么让系统"变差"（对应练习题 14）**——零阶保持离散化会在回路中引入约半个采样周期 $T/2$ 的等效纯延迟，产生约 $\omega_c T/2$ 的相位滞后，吃掉一部分相位裕度/增益裕度。因此同一控制器，$T$ 越大，离散系统闭环极点越靠近单位圆边界，$T$ 超过某临界值后极点越出单位圆 → 失稳。这就是练习题 14 中"$T$ 增大后离散 LQR 失稳"的原因——**判断离散闭环稳定性必须用离散化后的特征值（$|z|<1$），而不能只看连续理论极点**。

### 3.4 深入推导：ZOH 离散化公式的物理含义

这个公式和它背后的物理意义确实是离散控制里**最抽象、最难直观理解**的部分之一。可以拆成两层来理解：**第一层是"这个公式到底在算什么"**，**第二层是"为什么它会引入 T/2 的延迟"**。

#### 一、公式到底在算什么？

**🎬 场景重现**：想象你有一个连续对象 $G(s)$（比如一个电机），现在你要用计算机控制它。计算机每隔 $T$ 秒输出一个数字 $u[k]$，但电机只认连续电压信号。怎么办？中间必须加一个 **DAC（数模转换器）**，而最常见的 DAC 就是**零阶保持器（ZOH）**。

ZOH 的行为非常简单粗暴：

> "我在 $kT$ 时刻收到数字 $u[k]$，然后我就把这个值**死死保持住**，一直持续到下一个采样时刻 $(k+1)T$，直到收到新的 $u[k+1]$ 才更新。"

所以，ZOH 的输出是一个**阶梯波**。

**🔍 公式拆解**：现在要找的是——**从计算机输出的数字序列 $u[k]$，到连续对象输出 $y(t)$ 的采样值 $y[k]$，这整个通道的离散传递函数是什么？**这就是 $G_d(z)$ 的定义。推导分三步：

1. **ZOH 的拉氏变换**：一个宽度为 $T$、高度为 1 的矩形脉冲，其拉氏变换是 $\frac{1-e^{-sT}}{s}$。这就是 ZOH 本身的传递函数 $H_{ZOH}(s)$。
2. **ZOH + 对象串联**：在连续域里，它们串联后的传递函数是 $H_{ZOH}(s) \cdot G(s) = \frac{1-e^{-sT}}{s} G(s)$。
3. **对这个串联系统做"阶跃响应采样"再 Z 变换**：
    - 注意到 $\frac{1}{s}$ 就是积分器，$\frac{G(s)}{s}$ 就是 $G(s)$ 的**阶跃响应**的拉氏变换。
    - 对 $\frac{G(s)}{s}$ 做 Z 变换，得到的是 $G(s)$ 阶跃响应的**采样序列**的 Z 变换。
    - 前面的 $(1-z^{-1})$ 对应时域的**差分操作**（当前值减前一个值）。因为 ZOH 输出的是阶梯波，相邻两个台阶之间的"增量"才是真正驱动系统的信息。$(1-z^{-1})$ 本质上是在把"累积的阶跃响应"还原回"脉冲响应"。

> 💡 **一句话总结公式的物理含义**：
> $G_d(z)$ = **"先算出连续对象对 ZOH 阶梯输入的响应，再在每个采样时刻取值得到的离散模型"**。
> 它是精确的，不是近似！它完全等价于"ZOH + 连续对象 + 理想采样器"这个整体。

**人话操作流程翻译**：

1. **$\frac{G(s)}{s}$ 是什么？** 在拉普拉斯变换里，除以 $s$ 等于**积分**。所以 $\frac{G(s)}{s}$ 就是连续对象 $G(s)$ 的**阶跃响应**（输入一个台阶信号，输出随时间变化的曲线）。
2. **$\mathcal{Z}\{\dots\}$ 是什么？** 把上面那个连续的阶跃响应曲线，每隔 $T$ 秒**采一个点**，变成一串数字序列，然后做 Z 变换。
3. **$(1-z^{-1})$ 是什么？** 在离散域里，$z^{-1}$ 代表"延迟一拍"。所以 $(1-z^{-1})$ 就是**"当前值减去上一拍的值"**，也就是**差分**。

> 💡 **连起来的人话翻译**：
> "先算出连续系统对台阶输入的响应，采样得到一串数，然后对这串数做差分。"

**🤔 为什么要这么折腾？** 因为**零阶保持器（ZOH）输出的就是台阶信号**！计算机每隔 $T$ 秒给出一个控制量 $u[k]$，DAC 把它保持成一个宽度为 $T$ 的台阶。这个台阶可以看作是一个正阶跃减去一个延迟了 $T$ 的负阶跃。

- 阶跃响应对应 $\mathcal{Z}\{G(s)/s\}$
- "减去延迟的负阶跃"对应乘以 $(1-z^{-1})$

所以这个公式**不是凭空捏造的数学技巧，而是精确描述了"ZOH + 连续对象"这个物理整体在采样时刻的输入输出关系**。

#### 二、为什么是 $(1-z^{-1})$：台阶分解

在离散域（z 域）里，$z^{-1}$ 是一个**延迟算子**。它的作用是：

$$
z^{-1} \cdot X(z) \quad \xleftrightarrow{\mathcal{Z}^{-1}} \quad x[k-1]
$$

也就是说，乘以 $z^{-1}$ 等于把序列**往后挪一拍**。那么 $(1-z^{-1})$ 作用于一个序列 $x[k]$ 就是：

$$
(1-z^{-1})X(z) \quad \xleftrightarrow{\mathcal{Z}^{-1}} \quad x[k] - x[k-1]
$$

> 💡 **人话**：$(1 - z^{-1})$ = **"当前值减去上一拍的值"** = **一阶后向差分**。

**为什么 ZOH 的台阶 = "正阶跃 − 延迟负阶跃"？** 假设 ZOH 在 $k=0$ 时刻收到 $u[0]=1$，然后保持到 $t=T$。这个宽度为 $T$、高度为 1 的矩形脉冲，可以分解为：

```
信号A: 在 t=0 开始的 +1 阶跃    ──────────────→ (从0到∞都是1)
信号B: 在 t=T 开始的 -1 阶跃              ─────→ (从T到∞都是-1)
                                            ↑
两者相加:                              t=T处抵消为0
       ┌──────────┐
       │          │
       │          │
───────┘          └──────────────────→
  t=0            t=T
  = 宽度为T的矩形脉冲 = ZOH的一个台阶！
```

用拉普拉斯变换写出来：

- 信号 A（正阶跃）：$\frac{1}{s}$
- 信号 B（延迟 $T$ 的负阶跃）：$-\frac{e^{-sT}}{s}$
- 两者之和：$\frac{1 - e^{-sT}}{s}$ ← **这就是 ZOH 本身的传递函数！**

**把两块拼起来**：把"ZOH 的台阶分解"和"连续对象 $G(s)$"串起来：

| 步骤 | 连续域操作 | 对应 z 域 |
|---|---|---|
| ① ZOH 输出一个台阶 | $\frac{1-e^{-sT}}{s}$ | — |
| ② 台阶经过 $G(s)$ | $\frac{1-e^{-sT}}{s} G(s)$ | — |
| ③ 拆成两项 | $\underbrace{\frac{G(s)}{s}}_{\text{正阶跃响应}} - \underbrace{\frac{G(s)}{s}e^{-sT}}_{\text{延迟}T\text{的负阶跃响应}}$ | — |
| ④ 对采样后的序列做 Z 变换 | — | $\mathcal{Z}\{\frac{G(s)}{s}\} - z^{-1}\mathcal{Z}\{\frac{G(s)}{s}\}$ |
| ⑤ 提取公因式 | — | $(1-z^{-1})\,\mathcal{Z}\{\frac{G(s)}{s}\}$ ✅ |

> 🎯 **核心洞察**：
>
> - $\mathcal{Z}\{G(s)/s\}$ 是 $G(s)$ **阶跃响应**的采样序列
> - $z^{-1}$ 代表延迟 $T$，正好对应 ZOH 台阶分解中那个"延迟了 $T$ 的负阶跃"
> - $(1-z^{-1})$ 就是把"正阶跃响应"和"延迟负阶跃响应"**相减**，还原出 ZOH 单个台阶对系统的真实作用

**🧩 终极直觉总结**——可以把整个公式想象成一个**"组装流水线"**：

1. **原料**：$G(s)$ 的阶跃响应采样值 $\mathcal{Z}\{G(s)/s\}$
2. **加工**：用 $(1-z^{-1})$ 把相邻两个阶跃响应采样值做差分
3. **成品**：得到的就是"ZOH 台阶输入下，系统在每个采样时刻的输出值"

> ⚠️ **常见误区纠正**：
> 很多人以为 $(1-z^{-1})$ 是在"去掉积分器"或者"补偿什么"。**不是的！**
> 它纯粹是因为 ZOH 的台阶可以分解为两个阶跃之差，而这两个阶跃在 z 域里就差了一个 $z^{-1}$。$(1-z^{-1})$ 是这个物理分解的**直接数学结果**，没有任何额外的"补偿"含义。

**✅ 自测题**：如果 DAC 不是零阶保持，而是**一阶保持**（线性插值，输出三角波/折线），离散化公式还会是 $(1-z^{-1})\mathcal{Z}\{G(s)/s\}$ 吗？为什么？

**答**：不会。因为一阶保持的输出不能再分解为"两个阶跃之差"，它的拉氏变换不再是 $\frac{1-e^{-sT}}{s}$，所以 z 域里也不会出现 $(1-z^{-1})$ 这个因子。公式的形式完全取决于**保持器的波形形状**。

#### 三、为什么说 ZOH 引入了 T/2 的延迟？

**角度 1：时域直觉（最容易理解）**

ZOH 在 $kT$ 时刻拿到 $u[k]$，但它代表的其实是 $[kT, (k+1)T]$ 这一整段时间的控制作用。

问自己一个问题：**这个保持住的值，在时间上"居中"在哪里？**
答案显然是这段区间的**中点**，即 $kT + T/2$。

所以，相对于"如果我能瞬间施加一个精确作用于 $kT$ 时刻的理想脉冲"，ZOH 的实际效果相当于**晚了 $T/2$** 才真正把能量"平均"送到系统里。

> 🧠 **类比**：你每 $T$ 秒给植物浇一次水，每次浇的量代表未来 $T$ 秒的需求。但水不是瞬间被吸收的，而是在整个 $T$ 内均匀渗透。从植物的感受来看，这次浇水的有效时间点大约在两次浇水的中间，而不是你倒水的那一刻。

**角度 2：频域验证（最严谨）**

ZOH 的频率响应为：

$$
H_{ZOH}(j\omega) = \frac{1-e^{-j\omega T}}{j\omega} = T \cdot e^{-j\omega T/2} \cdot \frac{\sin(\omega T/2)}{\omega T/2}
$$

看中间那个因子：**$e^{-j\omega T/2}$**！这正是**纯延迟 $T/2$** 的频率响应！后面的 sinc 项是幅值衰减，但相位部分**精确等于** $-\omega T/2$。所以在**低频段**（$\omega \ll \omega_s$，sinc ≈ 1），ZOH 的行为就**等价于一个 $T/2$ 的纯延迟**。

**角度 3：对稳定性的影响（工程后果）**

在控制系统中，相位裕度（PM）决定了稳定性。开环传递函数在穿越频率 $\omega_c$ 处的相位决定了 PM。

ZOH 带来的额外相位滞后：

$$
\Delta \phi = -\omega_c \cdot \frac{T}{2}
$$

- 原来连续系统 PM = 60°
- 加了 ZOH 后，PM' = 60° − $\omega_c T/2$（弧度转角度）
- 当 $T$ 增大 → $\Delta\phi$ 增大 → PM' 减小 → 极点靠近单位圆边界
- 当 PM' ≤ 0 → **失稳**

> ⚠️ **这就是练习题 14 的完整因果链**：
> 连续 LQR 设计时假设无延迟 → 离散实现时 ZOH 引入 $T/2$ 延迟 → 相位裕度被吃掉 → 闭环极点移出单位圆 → 系统发散。
> **解法**：要么减小 $T$，要么在离散域直接设计控制器（离散 LQR 会自动补偿这个延迟）。

### 3.5 进阶：连续 ↔ 离散桥梁的深入理解

建立直观图像之后，要把"直觉"升级为"工程能力"。深入理解离散控制系统，核心在于打通**"连续 ↔ 离散"**之间的数学桥梁，并掌握**量化误差、频率混叠、控制器实现**等连续系统中不存在的问题。

#### 一、深化 z 变换与映射关系（数学根基）

已知 $z = e^{sT}$，现在需要理解它的**多值性**和**频率折叠**。

**1. 主频带与混叠**

- s 平面上宽度为 $\omega_s = 2\pi/T$ 的水平条带，映射到整个 z 平面。
- **主频带**：$-\omega_s/2 < \omega \leq \omega_s/2$ → 对应单位圆上一圈。
- **关键推论**：如果连续信号含有高于 $\omega_s/2$ 的频率分量，采样后会**折叠**回主频带内，造成无法恢复的失真（Nyquist-Shannon 定理的工程含义）。
- **实践意义**：在 A/D 转换前必须加**抗混叠滤波器**，截止频率 < $\omega_s/2$。

**2. s 到 z 的精确对应表（建议背诵/查阅）**

| 连续极点 $s_i$ | 离散极点 $z_i = e^{s_i T}$ | 时间响应模式 |
|---|---|---|
| $0$ | $1$ | 阶跃（积分器） |
| $-\alpha$（$\alpha>0$） | $e^{-\alpha T} \in (0,1)$ | 单调指数衰减 |
| $-\alpha \pm j\omega_d$ | $e^{-\alpha T}e^{\pm j\omega_d T}$ | 衰减振荡，每步旋转 $\omega_d T$ 弧度 |
| $\pm j\omega_0$ | $e^{\pm j\omega_0 T}$ | 等幅振荡（临界稳定） |
| $\sigma > 0$ | $|z| > 1$ | 发散 |

> 💡 **深度洞察**：离散极点的**角度** $\theta = \omega_d T$ 决定了振荡频率，但注意这是**归一化频率**。同一个 $\omega_d$，当 $T$ 变大时，$\theta$ 增大，离散序列看起来"振荡更快"，但实际物理频率不变——这就是采样造成的视觉/数值假象。

## 4. 数字 PID 的实现（工程核心！）

### 4.1 位置式 PID（绝对式）

连续 PID 输出 $u(t)=K_pe(t)+K_i\int_0^t e\,d\tau+K_d\dfrac{de}{dt}$，离散化（$t=kT$，积分用矩形和、微分用一阶差分）：

$$
\boxed{u[k] = K_p e[k] + K_i T\sum_{j=0}^{k} e[j] + \frac{K_d}{T}\left(e[k]-e[k-1]\right)}
$$

**特点**：输出与历史全程有关，任何时刻知道 $\sum e[j]$ 就能算；**一断电就丢全部记忆**。

### 4.2 增量式 PID

只输出**增量** $\Delta u[k]=u[k]-u[k-1]$：

$$
\boxed{\Delta u[k] = K_p\left(e[k]-e[k-1]\right) + K_i T e[k] + \frac{K_d}{T}\left(e[k]-2e[k-1]+e[k-2]\right)}
$$

实际输出 $u[k]=u[k-1]+\Delta u[k]$。

**为什么工程偏爱增量式**：
- 执行机构（电机、舵机）接收"增量/速度指令"，天然匹配；
- 不需要记住全部积分和（无历史记忆，抗丢电）；
- 输出限幅时只需限 $\Delta u$，**天然自带一部分抗饱和效果**。

### 4.3 关键工程细节

| 问题            | 处理                                      |
| ------------- | --------------------------------------- |
| 微分放大高频噪声      | 微分项加低通滤波（$D(s)=\dfrac{K_d s}{1+T_d s}$） |
| 设定值突变引发"微分冲击" | **只对输出微分**（$y[k]-y[k-1]$），不对误差微分        |
| 积分饱和（windup）  | 条件积分 / 积分限幅 / 反算积分（见下）                  |
| 参数整定          | 先 P 后 I 后 D（第8章口诀），或 Ziegler-Nichols    |

![连续与数字PID对比](./figures/03_连续与数字PID对比.png)

*图 12-3 同一对象（$G=1/(s^2+s)$）同一组 PID 参数：采样周期 $T_s=0.05$s 时数字 PID 与连续 PID 几乎重合。采样足够快，离散化损失可忽略。*

> **时间视角**：数字 PID 就是"每 $T$ 秒看一眼误差、算一次输出、保持一拍"。快采样 ≈ 连续（平滑），慢采样 ≈ 迟钝甚至振荡（图 12-5）。

## 5. 积分饱和（Windup）与抗饱和

### 5.1 现象

执行器有物理极限（电机饱和、油门到底）。当控制量被限幅而误差仍大时，**积分项还在累积**，一旦误差反转，累积的积分让输出"卡"在饱和区下不来 → 大幅超调、长时间振荡。

### 5.2 三种抗饱和方法

**① 条件积分（最常用）**：饱和时停止积分累积：

$$
\sum e[j] \ \leftarrow\ \begin{cases} \sum e[j-1] + e[k], & |u|<u_{\max}\\ \sum e[j-1], & |u|=u_{\max} \end{cases}
$$

**② 积分限幅**：把 $\sum e[j]$ 本身限制在 $[-I_{\max}, I_{\max}]$。

**③ 反算积分（back-calculation）**：把"实际限幅输出"与"未限幅输出"之差反馈回去把积分"泄掉"：

$$
\dot I = K_i e + K_b (u_{sat}-u_{calc})
$$

![积分饱和对比](./figures/04_积分饱和对比.png)

*图 12-4 饱和限幅 $\pm0.6$ 下：普通 PI 因积分堆积出现大幅超调、长时间收不拢；抗积分饱和 PI 快速恢复。*

> **实践视角**：这是真实项目里 PID 最常见的坑——**做实物/仿真带饱和的电机、油门时，务必加抗饱和**。写无人机/车辆控制代码的第一件事。

## 6. 采样周期的选择（工程准则）

- **上限**：$T < \dfrac{1}{2f_{\max}}$（Nyquist），且通常取 $T$ 为系统最小时间常数的 $\dfrac{1}{5}\sim\dfrac{1}{10}$；
- **下限**：受计算能力与 A/D 转换时间限制；
- **经验**：控制环 $f_s \approx 5\sim20 \times$ 系统带宽；机器人关节环 1kHz 起步，无人机内环 1~2 kHz。

![采样周期影响](./figures/05_采样周期影响.png)

*图 12-5 同一 PID 参数三种采样周期：$T_s=0.01$s 接近连续；$T_s=0.1$s 明显退化；$T_s=0.4$s 振荡。采样太慢，好控制器也救不回来。*

> **实践视角**：调嵌入式代码时，先确认采样周期再调 PID——**采样周期不对，调参全白费**。用示波器/日志看实际循环频率，是工程第一课。

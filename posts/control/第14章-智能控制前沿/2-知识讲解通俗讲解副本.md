## 一、为什么需要智能控制？——因为经典控制有两个"假装"

经典控制（第 5~13 章）全程建立在一个假设上：**我有对象的数学模型**。但现实给了两记耳光：

1. **模型建不出来**：交通流、抓豆腐、大风里的无人机——物理太复杂，写不出公式。
2. **就算有模型，还有"不能"**：油门不能超 100%、不能压线——经典方法对这种**硬约束**束手无策。

于是三条出路，对应本章四大家族：

| 出路 | 代表 | 一句话 |
|---|---|---|
| 干脆不建模，用人的经验 | 模糊控制 | 老师傅会开，就把老师傅抄下来 |
| 有模型，但把"不能"写进优化 | MPC | 聪明且守规矩的规划器 |
| 没模型，让数据自己学 | 神经网络 / 强化学习 | 拟合器 / 试错学习者 |

**常见误解**：以为智能控制要"取代" PID。错——它们是**补位**：模型好用时经典控制又便宜又稳；模型不好用或有约束时才请智能方法。工程上几乎总是混着用（比如模糊 PID）。

## 二、MPC：一个"边走路边看导航"的控制器

### 画面感

把 MPC 想成**你第一次开陌生山路**：每秒钟你都在脑内模拟"接下来 3 秒几种开法分别会怎样"，选出最好的，但**手只执行这 1 秒的动作**；下一秒重新模拟。这就是"预测 + 滚动 + 只执行第一步"。

而 LQR 像**出发前算好全程的自动驾驶仪**：一次性给出一个固定反应公式 $u=-Kx$，途中不再改主意——它默认路况和车子永远符合模型，也默认方向盘能转任意角度。

### 那张三方对比表怎么记

原文给了 PID/LQR/MPC 六维对比。记法：**看多远、管不管约束、算得贵不贵** 三问。

- PID：只看现在，不管约束，几乎不算（便宜）。
- LQR：看无限远但一次性算死，不管约束，便宜。
- MPC：看 N 步、每秒重算，**管约束**，贵。

图 14-1 的画面：限幅 ±0.8 时，PID 的输出反复顶在 0.8 天花板上（积分越积越多 → 撤不下来 → 超调）；MPC 从一开始就把"最高 0.8"算进计划，曲线干净利落。**这张图就是 MPC 的卖点广告**。

### 三个高频疑问，一次讲清

**Q1：为什么只执行第一步，那后面 N-1 步不算白算了吗？**
不算。后面那些步是"陪跑的方案比较器"——正是因为模拟了后面，你才知道"现在"该怎么走。好比下棋算三步，不是为了第三步，而是为了第一步不走臭棋。而且下一秒会用**最新测量**重算，等于不断用现实纠正脑补。

**Q2：N 怎么取？**
N 要"看得见系统的主要动静"：太小 = 近视贪婪（看不到前面要刹车 → 超调）；太大 = 算得慢且远处脑补不可信。练习里把 N 从 15 改成 3 对比，就是让你亲眼看看"近视"长什么样。

**Q3：MPC 和 LQR 到底什么关系？（必考句）**
**无约束、线性、二次代价时，它俩是同一道题**：MPC 是 N 有限的版本（增益随时间变，像"快交卷时策略不同"），LQR 是 N→∞ 的极限（增益收敛成常数）。**唯一本质差别 = 约束**。MPC 火不是因为更聪明，是因为真实世界全是约束。

### Riccati 递推（概念版，公式版见公式副本 §1.2a）

MPC 每秒在解什么？解一个"从最后一步倒着推"的动态规划：先回答"最后一步该怎么走"，再倒推倒数第二步……一直推到现在。线性 + 二次 + 无约束时这个倒推有现成公式串（Riccati 递推）；加了约束现成公式作废，改成每秒数值解优化题——但"倒推"的脑回路没变。

## 三、模糊控制：驾校教练的口头禅，机器版

### 画面感

教练说："**偏得有点多**，**稍微**往右带，**别猛**。"这句话里没有数字，但你照做了。模糊控制器就是把这位教练**克隆**成四步流水线：

1. **模糊化**：数字 → 语言 + 程度。偏差 -0.3 → 「负小」0.4 分、「零」0.6 分。**关键观念**：一个数可以**同时**属于多个语言值，各带一个程度——"模糊"指的就是这个"部分属于"，不是含糊。
2. **规则库**：教练的全部口头禅，if-then 表格。
3. **推理**：一句话的"前提"有几分真，这条规则就被"点燃"几分（取最小值，木桶原理）。
4. **去模糊化（重心法）**：所有被点燃的建议**按音量加权平均**，出一个精确数字。

所以模糊控制器本质 = **一张会平滑插值的非线性查表器**，不需要任何对象模型。

### 常见误解

- "模糊 = 不精确" → 错。输入输出全是精确数字，模糊的只是中间的语言层。
- "模糊很高级/AI" → 它其实是 70 年代的老技术，胜在**直观、不要模型、好落地**（洗衣机、电饭煲里都是它）。

### 规则表里的"阻尼"（练习题 9 的考点）

规则表填不好会**来回荡**：误差还大但已经在回正时，若仍按误差大小给满输出，就会刹过头、反弹。对策：在这种格子里把输出调小——**等于给系统加阻尼**，正是 PID 里 D 项干的事。记住这句：**规则表的每一格都是控制器参数，设计规则 = 设计增益和阻尼**。

工程最常见形态：**模糊 PID**——PID 干活，模糊实时调它的三个参数。

## 四、神经网络：先别管"智能"，它就是个拟合器

### 画面感

把神经网络想成**一台可调的曲线拟合器**：你给它一堆 (输入, 输出) 数据点，它通过拧几千个旋钮（权重），让画出的曲线尽量穿过这些点。"万能逼近定理"保证：旋钮够多时，任何连续曲线都能拟合到任意精度。

结构就三层三明治：输入 →（加权求和 → tanh 压弯）→ 隐层 →（加权求和）→ 输出。
**tanh 是灵魂**：没有这个"压弯"，多少层线性叠起来都还是一层线性，只能拟合直线。

### 训练 = 三步循环（反向传播概念版）

1. **前向**：数据进去，算出一个预测。
2. **比差**：预测和目标差多少（损失 L）。
3. **反向**：把这个"差"像**漏水追责**一样从出口往回倒灌——每层按"连接强度 × 本层坡度"分摊责任，得到每个旋钮该拧多少（梯度），然后所有旋钮朝减少误差的方向拧一小步（梯度下降）。

**漏水比喻**：出水口水量不对，你沿水管往回查，每段管子按粗细和责任分摊"漏水嫌疑"，再去拧对应的阀门。链式法则 = 追责的分配律。

### 在控制里的三种用法（必背三条）

1. **系统辨识**：用数据学出对象模型 $y_{k+1}=NN(y_k,u_k)$——黑盒版传递函数。
2. **逆模型前馈**：学"想要这个输出，该给什么输入"——当前馈补偿用。
3. **RL 的脑子**：当策略网络/价值网络（第 15 章）。

**关键定位**：神经网络**本身不是控制器**，它是组件——反馈、闭环、优化这些"控制的结构"仍来自前 11 章。它只是给经典控制换了一个更强的零件。

## 五、强化学习：不让做卷子，让做实验

### 画面感

学骑自行车：没人给你公式，你**摔几次就会了**。RL 就是这个过程的数学版：智能体在环境里乱试 → 环境打分（奖励）→ 智能体慢慢记住"什么局面下干什么得分高"。

### 六个词（和控制的对照，必背）

状态 s = x（局面）；动作 a = u（干啥）；奖励 r = −代价（打分）；策略 π = 控制器（见什么干什么）；价值/Q = 这局面值多少分；ε-greedy = 先多乱试后多用经验。

### Q-learning 一句话

维护一张大表 Q(s,a) = "局面 s 出招 a、以后都好好干的总得分"。每试一次，用"新证据"修正"旧看法"：
新证据 = 到手的奖励 + 打折后的下一步最好前景。
**α** = 多信新证据；**γ** = 未来打几折（控制要长远，取接近 1）。

### 收敛保证（直觉版）

Bellman 更新像"每天把你和满分答案的距离缩小到 γ 倍"——γ<1 就必然贴上去（数学上叫压缩映射 + 不动点定理）。**所以 γ<1 不只是"打折"，它是收敛的发动机**——这是本章最爱考的"为什么"。

### 表格 → 深度 RL

状态一连续，表格格子数 $n^d$ 爆炸（维数灾难）。解法：用神经网络代替表格存 Q 值——没去过的状态也能举一反三。**用泛化代替枚举** = DQN 的全部动机。

### 本章最值钱的一句打通

**LQR = 模型已知、奖励已知、解析算出的 RL；RL = 模型未知、用数据试错的 LQR。** 你第 11 章学的 LQR，翻译一下词汇表就是 RL 的入门案例——你不是从零学 RL，你是"开卷版早就会了，现在学闭卷版"。

## 图1 MPC vs LQR vs PID：约束是分水岭

### 代码核心

```python
from scipy.optimize import minimize
import control as ct

# 对象 G(s)=1/(s^2+s)，离散化 dt=0.02
Ad = np.array([[1.0, 0.02], [0.0, 0.98]])
Bd = np.array([[0.0], [0.02]])
Q = np.diag([10.0, 1.0]);  R = np.array([[0.5]])
umax = 0.8                                     # 执行器限幅！

# LQR（状态反馈，偏差形式；对象自带积分器→无需积分增广即无静差）
K_lqr, _, _ = ct.dlqr(Ad, Bd, np.diag([10.,1.]), R)
# 偏差形式：把目标 (r,0) 当平衡点，反馈偏差而非绝对值（第11章"状态反馈+对象积分器=无静差"）

# MPC：每步向前看 N_mpc=15 步，把约束写进优化
N_mpc = 15
def u_mpc(x, e, integ, k):
    def cost(us):
        X = x.copy(); J = 0.0
        for i in range(N_mpc):
            X = Ad @ X + Bd.ravel()*us[i]
            J += (X - np.array([r,0])) @ Qc @ (X - np.array([r,0])) + R[0,0]*us[i]**2
        return J
    res = minimize(cost, np.zeros(N_mpc), method="SLSQP",
                   bounds=[(-umax,umax)]*N_mpc, options={"maxiter":30})
    return res.x[0]                            # 只执行第一步！
```

### 现象解释

| 控制器 | 输出 y 的表现 | 原因 |
|---|---|---|
| PID | 明显超调、收敛慢 | 饱和时积分继续堆积（第12章的坑） |
| LQR | 几乎无超调 | 对象自带积分器，状态反馈即可无静差跟踪，仅第1步短暂撞限幅 |
| MPC | 几乎无超调、最快收敛 | 从一开始就"知道"u 不能超 0.8，提前规划 |

![MPC_LQR_PID对比](./figures/01_MPC_LQR_PID对比.png)

*图 14-1 执行器限幅 ±0.8 时三种控制器对比：PID 反复顶在限幅上（积分堆积→超调）；LQR 无约束设计（对象自带积分器，状态反馈即可无静差跟踪，几乎无超调）；MPC 从一开始就把“不超过 0.8”算进优化，几乎无超调、且把 PID 顶限幅的时间压到零。*

## 图2 模糊控制：一张规则表 + 重心法

### 代码核心

```python
def fuzzy_controller(e, de):
    centers = np.array([-1.0, -0.5, 0.0, 0.5, 1.0])     # 5 个语言值
    def mem(x):                                          # 三角形隶属度
        return np.array([trimf(x, c-0.5, c, c+0.5) for c in centers])
    me, mde = mem(e), mem(de)
    rule = np.array([                                    # 5x5 规则表
        [0,0,0,1,2], [0,0,1,2,3], [0,1,2,3,4], [1,2,3,4,4], [2,3,4,4,4]])
    act = np.zeros(5)                                    # 聚合激活度
    for i in range(5):
        for j in range(5):
            act[rule[i,j]] = max(act[rule[i,j]], min(me[i], mde[j]))
    return (act*centers).sum() / act.sum()               # 重心法去模糊化
```

### 现象解释

- 左图"规则面"：一张三维曲面就是完整控制器——**模糊控制 = 带插值的非线性查表**；
- 右图：同样控制 $G(s)=1/(s^2+s)$，模糊控制器和 PID 表现相当——不需要模型也能控；
- 整个控制器只有一张规则表，**改规则=改控制器**，这就是"专家经验数字化"。

![模糊控制](./figures/02_模糊控制.png)

*图 14-2 左：模糊控制器的“规则面”（输入误差 e、误差变化 de → 输出 u）——它本质是一张“非线性查表控制器”；右：模糊控制对同一对象的闭环响应，与 PID 相当。*
### 思考题

2. 为什么模糊控制器本质上不需要模型？（答案：它按"误差 e、误差变化 de"查规则，不依赖对象的数学描述；规则面就是隐式的非线性控制器。）

## 图3 神经网络：手写 MLP 拟合非线性

### 代码核心

```python
# 前向：x → W1→tanh→ W2 → y
def mlp_predict(W1,b1,W2,b2,X):
    H = np.tanh(X @ W1 + b1)
    return H @ W2 + b2

# 训练循环（4000 步）
for ep in range(4000):
    pred = mlp_predict(W1,b1,W2,b2,X)
    loss = np.mean((pred - Yt)**2)
    d_pred = 2*(pred - Yt)/len(X)          # 输出误差
    dW2 = H.T @ d_pred                     # 反向：链式法则
    dH  = d_pred @ W2.T
    dW1 = X.T @ (dH * (1-H**2))            # tanh 导数
    W2 -= lr*dW2;  W1 -= lr*dW1            # 梯度下降
```

### 现象解释

- 左图：网络从带噪声数据中逼近非线性函数 $y=\sin x+0.3x\cos2x$；
- 右图：损失对数坐标单调下降——"训练"就是让损失变小；
- **整段代码不到 30 行**——深度学习框架做的也是同样的事，只是更快、更省心。

![神经网络拟合](./figures/03_神经网络拟合.png)

*图 14-3 左：手写 MLP 从带噪声数据中拟合出非线性函数（红色点是数据，蓝色曲线是网络输出）；右：训练损失单调下降。神经网络 = 可微分函数逼近器。*
### 思考题

3. 如果目标函数改成 $y=x^2$（二次），隐藏层激活换成 `relu` 而非 `tanh`，还拟合得好吗？（提示：relu 是分段线性，逼近二次需要更多层/更多神经元——体会"激活函数的表达能力"。）

## 图4 强化学习：Q-learning 学"保持倒立"

### 代码核心

```python
# 真实倒立摆（0°=竖直向上，不稳定平衡点）：θ''=(u+g·sinθ)/l
Q = np.zeros((13, 13, 2))                  # 状态(θ,ω)各13档 × 2动作
lr, gamma = 0.3, 0.95
eps = 1.0                                  # 探索率，随训练衰减
for ep in range(500):
    th = np.random.uniform(-0.25, 0.25);  om = 0.0
    for step in range(200):
        ti, oi = discretize(th), discretize(om)   # 状态离散化
        a = np.random.randint(2) if np.random.rand()<eps else np.argmax(Q[ti,oi])
        u = actions[a]                           # 动作：向左推/向右推
        om += (u + g*np.sin(th)/l)*dt            # 重力把摆推向倒下
        th += om*dt
        r = 1.0 if abs(th) < 0.3 else -1.0       # 奖励：稳住给+1，倒下给-1
        Q[ti,oi,a] += lr*(r + gamma*np.max(Q[ti2,oi2]) - Q[ti,oi,a])  # 更新！
        if abs(th) > 0.5: break
    scores.append(step)
    eps = max(eps*0.992, 0.05)                   # 探索率衰减
```

### 现象解释

- 训练曲线（红色滑动平均）从"开局就倒"上升到"稳定活满 200 步"——**策略被学出来了**；
- 蓝点是原始得分，抖动大——RL 训练天生有噪声，要看趋势；
- 全部代码没有一行"倒立摆知识"——**智能体完全靠试错 + 奖励自己学会了控制**，这就是"无模型控制"。

![强化学习训练曲线](./figures/04_强化学习训练曲线.png)

*图 14-4 Q-learning 训练倒立摆（0°=竖直向上的不稳定平衡）：横轴是训练回合，纵轴是“存活步数”。前期乱试（几分），几百回合后学会保持平衡（接近满分）。曲线上升的过程，就是“策略被学到”的过程。*

# 第14章 智能控制前沿——公式推导（通俗讲解副本）

> **这是什么**：这份"副本"是《1-公式推导.md》的**逐节翻译版**——把原文每一节的公式，翻译成大一、数学基础一般也能看懂的大白话。原文讲"是什么"，这里讲"为什么、凭什么、怎么想出来的"。
> **怎么用**：先看副本对应小节，读懂思路后，回去看原文的公式，你会发现公式不再吓人。每节末尾有"三秒自测"，能答上来就过。
>
> **数学急救包**（下面会反复用到，先花 2 分钟扫一遍）：      
> - **向量**：一列数，比如位置 + 速度写成 $x=\begin{bmatrix}位置\\速度\end{bmatrix}$。
> - **矩阵**：一个数表；**矩阵乘向量** = 对向量做一次"线性加工"（加权求和）；**转置 $A^T$** = 行列互换，把横的变竖的。
> - **$x^TQx$（二次型）**：别怕，它就是"把偏差的平方们加权求和"。$Q$ 里每个数代表"这项偏差有多重要"。比如 $x^TQx = 3\cdot位置偏差^2 + 1\cdot速度偏差^2$ 表示位置更重要。
> - **求导 = 找山坡最平的地方**。一个二次函数（抛物线）的最低点，就是导数 = 0 的地方。整个副本里"对 u 求导令为 0"= "找抛物线最低点"，就这一招。
> - **链式法则**：复合函数求导 = 一环扣一环相乘。高数里学过 $(f(g(x)))' = f'(g(x))\cdot g'(x)$，副本里所有"反向传播""倒灌"都是它。
> - **递推 / 倒着推**：从最后一步的答案往回推第一步。像规划旅行：先定"最后一天住哪"，再倒推"倒数第二天住哪"。

## §1 MPC：开车时"看三步再打方向"

### §1.1 问题设定：把"开车"写成一个数学题

**大白话**：MPC 干的事和你开车一模一样——**眼睛盯着前方 N 秒，脑子里模拟几种打方向的结果，选最好的那种，但手只执行当下这一下**；下一秒再重复。原文的公式就是把这个过程写成数学。

原文公式：$\min\limits_{u_k,\dots,u_{k+N-1}} \sum_{i=0}^{N-1}\Big( (x_{k+i}-x_{ref})^T Q (x_{k+i}-x_{ref}) + u_{k+i}^T R u_{k+i} \Big)$

**逐符号翻译**：

| 符号                          | 人话                            |
| --------------------------- | ----------------------------- |
| $x_{k+i}$                   | 未来第 $i$ 步时车子的状态（位置、速度等）       |
| $x_{ref}$                   | 你想去的目标（车道中心线）                 |
| $(x-x_{ref})^TQ(x-x_{ref})$ | "偏得有多惨"的加权平方和——偏离目标要扣分        |
| $u_{k+i}^TRu_{k+i}$         | "动作有多猛"的加权平方和——猛打方向、猛踩油门也要扣分  |
| $\sum$ 从 0 到 N-1            | 把未来 N 步的扣分**全加起来**，算总账        |
| $\min$                      | 在所有"未来 N 步的动作方案"里，挑总扣分最小的那套   |
| $u_k,\dots,u_{k+N-1}$       | 被挑的对象：一整套未来动作（注意是"一套"，不是"一个"） |

**人话版**：MPC 在问——"未来 N 步，我怎样既**贴线**（第一项小）又**动作柔和**（第二项小）？"Q、R 就是两个旋钮：Q 大 = 更在乎贴线，R 大 = 更在乎省油省动作。

**subject to（约束）——MPC 的灵魂**：

$u_{min}\le u \le u_{max}$：方向盘最多打半圈、油门最多踩到底——**执行器能力有限**。
$x$ 在安全域：不能冲出护栏。
$x_{k+N}=x_{ref}$：要求"N 步之后必须回到目标"——给优化一个"收尾"的规矩。

为什么叫灵魂？因为**真实世界全是这种"不能"**，而经典方法（LQR）假装没有它们。

**只执行第一个 $u_k^*$ + 滚动**：解出来的是一套 N 步动作，但只执行第一步。为什么？因为 N 步之后的预测是"脑补"的，不可靠；下一秒你会**重新测量、重新算**，等于计划永远只信眼前这一步。类比：导航每秒钟都在重新规划路线，而不是出发时算一次用到死。

**三秒自测**：MPC 的三要素是什么？（预测模型、代价函数、约束）为什么只执行第一步？

### §1.2 MPC 与 LQR 是"同一道题的两个版本"

先一句话回忆 LQR（第 11 章）：**模型已知时，一次性算出一个固定公式 $u=-Kx$（看到状态 x 就按公式输出 u），让总代价最小**。它聪明，但有两个"假装"：假装力气无限（不管约束）、假装可以看无限远（$N\to\infty$）。

**对照表（人话版）**：

| | LQR | MPC |
|---|---|---|
| 看多远 | 无限远，一步算死，$K$ 永远不变 | 只看 N 步，每秒重算 |
| 约束 | 不管。算出来油门 150%？真实世界帮你"截断"成 100% | 一开始就写进题目："油门不许超 100%" |
| 输出 | 一个固定公式 $u=-K_\infty x$ | 每秒现算一套动作，只用第一个 |

**关键差别只在约束**。打个比方：LQR 像纸面教练，算出"这里该猛打 720° 方向"；真实方向盘只能转 360°，被硬截断后车子就"不听使唤"（积分堆积、超调）。MPC 像老司机，**提前知道**方向盘转不到 720°，所以规划时就不会给出这种方案。

**$N\to\infty$ 那句怎么理解**：让 MPC "看的步数"越来越多，多到无限，它的解就**收敛**成 LQR 的那个固定 $K_\infty$。所以"LQR = 看得无限远的 MPC"。反过来"MPC = 近视版 + 懂规矩版的 LQR"。

### §1.2a Riccati 递推：MPC 肚子里的"倒推算法"（本章最难，慢慢读）

这一节回答：如果没有约束，MPC 那套"看 N 步求最优"能不能**直接写出答案**，不用每秒苦算？能。答案叫 Riccati 递推。读它需要三个台阶：

**台阶 1：价值函数 $V_i(x)$ = "从现在到结束的剩余最少花费"**。
类比打车：你在半路，问"从这儿到终点最少还要花多少钱"——这个"剩余最少钱数"就是价值函数。它只和"现在的位置 x"和"还剩几步 i"有关。终端时（走完了）还剩多少？就是终端代价 $x^TQ_fx$，所以 $P_N=Q_f$。

**台阶 2：Bellman 方程 = "这一步的花费 + 剩下的最少花费，一起最小化"**。
$V_i(x)=\min_u[x^TQx+u^TRu+V_{i+1}(Ax+Bu)]$
人话：现在的总花费 = 当下这一步的扣分 + 下一步开始往后的最少花费。注意 $Ax+Bu$ 就是"下一步会到的位置"。**这个方程的精髓是"把大问题拆成一步 + 一个已知的小问题"**，从最后一天倒着推，每一步都只需要解一个"一步的小优化"。

**台阶 3：猜 $V=x^TPx$，然后"求导令 0"**。
为什么敢猜二次型？因为代价是二次的（平方和）、模型是线性的，"二次"经过线性系统还是二次——形状传下去不变，只是系数矩阵 $P$ 在变。
把猜的形式代进 Bellman 方程，括号里整个就是关于 $u$ 的一个**二次函数（高维的抛物碗）**。抛物碗的最低点在哪？**求导、令导数 = 0**——就是你高中学的"顶点"，只是这里变成了矩阵写法：
$2Ru+2B^TP_{i+1}(Ax+Bu)=0$，解出 $u^*=-K_i x$，其中 $K_i=(R+B^TP_{i+1}B)^{-1}B^TP_{i+1}A$。

把 $u^*$ 代回去整理，就得到 $P_i$ 的递推公式（原文那个大框）。**使用方法**：从终点 $P_N=Q_f$ 出发，倒着算 $P_{N-1},P_{N-2},\dots,P_0$，顺手得到一串 $K_i$。MPC 每秒干的就是这个倒推，然后只用第一个 $K_0$。

**$N\to\infty$ 时**：倒推无穷多次后 $P_i$ 不再变化，停在 $P_\infty$，递推式变成等式 $P_\infty=\dots P_\infty\dots$——这就是**代数 Riccati 方程（DARE）**，解出的增益就是 LQR 的常数 $K_\infty$。
**一句记牢**：Riccati 递推 = 有限步的最优解；DARE = 无限步的极限。加了约束后这套闭式解作废（抛物碗被"切了一刀"，最低点可能切掉），才退回每秒数值求解——但"倒推"思想不变。

**三秒自测**：Bellman 方程把大问题拆成了什么？（一步代价 + 后续最优代价）为什么从最后一步往回推？

### §1.3 对比表人话版

- **约束处理**：LQR 不会，MPC 天生会 → 自动驾驶选 MPC 的原因。
- **计算量**：LQR 是一行公式（算一次用一辈子）；MPC 每秒解一个优化题 → **贵**，贵在为"懂规矩"买单。
- **LMPC/NMPC**：模型用线性的叫 LMPC，用非线性的叫 NMPC（更准但更贵）。

## §2 模糊控制：把"老师傅的口头禅"变成数学

### §2.1–2.2 四步流水线

倒车入库时教练说："**偏得有点多**了，**稍微**往右打，**别太猛**。"——"有点多/稍微/别太猛"不是数字，但你能照做。模糊控制就是把这套话翻译成机器能执行的流水线：

1. **模糊化**：把数字变成"语言值 + 程度"。$e=-0.3$ → "负小"程度 0.4、"零"程度 0.6（一个人可以同时"有点偏"又"差不多正"，这就是"模糊"）。
2. **规则库**：一堆 if-then 口头禅："如果偏得负大 且 还在往负方向跑，那么油门给负大"。
3. **推理**：每条规则被"点燃"的强度 = 前提各程度的**最小值**（木桶原理：一句话里最不虚的那部分决定整句多可信）。
4. **去模糊化（重心法）**：把几条被点燃的规则"加权平均"出一个数字：
$u=\dfrac{\sum \mu_i c_i}{\sum \mu_i}$
人话：$\mu_i$ 是第 i 条规则的"音量"，$c_i$ 是它建议的数值，**音量大的人话事**——就是加权平均，和概率论里期望的算法一个味道。

### §2.3 三个关键理解

- **模糊 ≠ 糊涂**：输入输出都是精确数字，只有中间过程用语言；它是一张"会插值的查表器"。
- **不需要模型**：规则表本身就是控制器。
- **模糊 PID**：PID 干活，模糊在旁边实时调 $K_p,K_i,K_d$ —— 工程界最常见的形态。

### §2.3a 隶属度函数：那三个形状是什么

把"程度"量出来的尺子，三种常见形状：
- **三角形**：两段直线，最好算，最常用。公式 $f(x)=\max(0,1-|x-c|/w)$ 人话：离中心 c 越远程度越低，降到 0 为止。
- **梯形**：三角形削个尖、顶上变平台 → "误差大到一定程度后，统统算负大"（饱和）。
- **高斯形**：$e^{-(x-c)^2/2\sigma^2}$ ——就是概率论里正态分布的**钟形曲线**（去掉归一化系数），光滑好求导，适合让算法自己调参数。

**两条设计军规**：① 完备性——任何输入至少有一个隶属度 > 0，否则出现"没人管"的状态，控制器当场罢工；② 交叠 0.3~0.5——相邻曲线要手拉手，输出才平滑；不拉手会跳变，拉太紧会"规则打架"。

**算一个例子**（原文）：$e=0.3$，中心 0 的"零"给程度 $1-0.3/0.5=0.4$，中心 0.5 的"正小"给 $1-0.2/0.5=0.6$。**0.3 这一个数被"软拆"成两个语言值**——这就是模糊的全部秘密。

## §3 神经网络：一台"万能拟合器"

### §3.1 为什么能用

**万能逼近定理**（记住结论即可）：只要隐层神经元够多，一层隐层的网络就能以任意精度逼近任何连续函数。意义：那些写不出公式的非线性（摩擦、饱和），**用数据拟合出来**。

### §3.2 前向传播：三层三明治

$z^{(1)}=W^{(1)}x+b^{(1)}$：第一层 = 加权求和 + 偏置（"偏置"= 门槛微调）。
$h=\tanh(z^{(1)})$：**激活函数**，把数压进 (-1,1) 的 S 形曲线。为什么必须有它？因为"线性叠线性还是线性"（矩阵乘矩阵还是矩阵），没有非线性，一万层 = 一层，什么都拟合不了。
$y=W^{(2)}h+b^{(2)}$：输出层再加工一次。

### §3.3–3.3a 反向传播：误差"倒灌"回来改参数

**目标**：知道输出错了之后，**每层的每个权重该改多少**。工具只有链式法则。

**定义误差信号** $\delta^{(l)}=\partial L/\partial z^{(l)}$：第 l 层"加工前"的数值每动一点，总损失 L 动多少——即"这一层对错误负多少责"。

三步走（背下来就懂了）：
1. **输出层**：$\delta^{(2)}=y-\hat y$ —— 责任就是"预测减目标"，误差本身。
2. **往前传一层**：$\delta^{(1)}=(\delta^{(2)}W^{(2)})\odot(1-h^2)$ —— 后面的责任 $\delta^{(2)}$ 乘上连接权重 $W^{(2)}$（责任按连接强度分摊），再乘激活函数导数 $\tanh'=1-\tanh^2=1-h^2$（这一层"坡度"越平，传下来的责任越小——平的地方改了也白改）。$\odot$ 是逐个元素相乘。
3. **权重梯度**：$\partial L/\partial W=(\delta)^T\times$ 该层输入 —— 责任 × 输入大小 = 这个权重该背的锅。

然后 $W\leftarrow W-\eta\cdot梯度$（梯度下降：朝下坡方向挪一小步，$\eta$ 是步长）。
**一句总结**：前向算输出、反向传责任、梯度下降改参数。第 15 章策略梯度、第 16 章姿态求导，全是这把刀。

### §3.4 三种用法

辨识（学对象）、逆模型前馈（学"想要什么输出该给什么输入"）、RL 的策略/价值网络（当控制器的脑子）。

**三秒自测**：为什么必须有激活函数？$\delta$ 往前传时乘的 $(1-h^2)$ 是谁的导数？

## §4 强化学习：不会做？试到会为止

### §4.1 MDP：换一套词说控制

| RL 的词 | 控制的词 | 人话 |
|---|---|---|
| 状态 s | x | 当前局面 |
| 动作 a | u | 这一步干啥 |
| 奖励 r | −代价 | 干得好的打分 |
| 策略 π | 控制器 | "见什么干什么"的规矩 |
| 价值 V | 最优代价 | 这局面值多少分 |
| 折扣 γ | （无） | 未来的分打几折 |

### §4.2 LQR = 最简单的 RL

LQR：模型和奖励都**已知** → 用动态规划**解析算出**最优策略。RL：模型**未知** → 用数据**试错试出**同一个最优策略。同一道题，一个开卷一个闭卷。

### §4.3 Q-learning：一张"经验值表"

$Q(s,a)$ = "在局面 s 出招 a，**以后都好好打**，总共能拿多少分"。更新公式：
$Q(s,a)\leftarrow Q(s,a)+\alpha\big(r+\gamma\max_{a'}Q(s',a')-Q(s,a)\big)$

**人话拆解**：括号里 = "新估计 − 旧估计"。新估计 = 马上到手的奖励 r + 打折后的"下一局面最优前景" $\gamma\max Q$。整句 = **旧看法 + 学习率 × (新证据 − 旧看法)**，和你根据新消息修正判断一模一样。
- $\alpha$ 大 → 信新消息、易震荡；$\alpha$ 小 → 稳但学得慢。
- $\gamma$ 小 → 短视（只管眼前奖励）；$\gamma\to1$ → 有远见（控制问题要稳到最后，所以取 0.99 这类）。
- **ε-greedy**：以概率 ε 乱试（探索），否则用目前认为最好的招（利用）；ε 越练越小——先广撒网，后精耕。

### §4.3a 为什么一定收敛：把"差距"越缩越小（压缩映射）

**先懂一个比喻**：假设有个操作 $\mathcal T$，每用一次，任意两张 Q 表之间的"最大差距"就缩小到原来的 $\gamma$ 倍（$\gamma<1$）。这就像"每天把你和目标的距离砍掉一成"——不管起点在哪，最后必然贴到同一个点。这个点叫**不动点** $Q^*$（$\mathcal TQ^*=Q^*$，即最优 Q 表），这个保证叫 **Banach 不动点定理**（记住名字和结论即可）。

为什么 $\mathcal T$ 会缩差距？因为 $\mathcal T$ 里唯一的"传播项"是 $\gamma\max$：两个 max 之差不超过对应点的最大差（"两个班的最高分之差，不会超过两班学生逐个配对的最大分之差"——直觉上显然），再乘 $\gamma<1$，必缩。

Q-learning 的更新 = "朝着 $\mathcal T Q$ 迈一小步 α" 的采样版。只要每个 (s,a) 被反复访问、步长 α 满足"加起来无穷、平方加起来有限"（**步子总体够远、但越来越小**，像 1, 1/2, 1/3…），就**以概率 1 收敛**到 $Q^*$。

**这就是 γ 必须 < 1 的真正原因**：它不只是"未来打折"，它是收敛的发动机。

### §4.4 维数灾难：表格装不下世界

状态连续时，把每维切 n 档，d 维就有 $n^d$ 格——4 维状态、每维 10 档就是 1 万格，还大多空空如也（没试过的格子没有经验）。DQN 的解法：**用神经网络代替表格**——相邻状态共享网络参数，没去过的状态也能"举一反三"。**用泛化代替枚举**，这就是深度强化学习的全部动机。

## §5 全景图人话版

自动驾驶 = 五层流水线：**感知**（眼睛：相机/雷达）→ **状态估计**（"我在哪"：卡尔曼滤波，第 13 章）→ **决策规划**（"怎么走"：MPC/RL，本章）→ **控制执行**（"怎么控"：PID/MPC）→ **执行器**（手脚：电机油门，它的限幅就是约束，就是 MPC 的主场）。

三种方法论一句话：PID = 不建模靠手感；LQR/MPC = 有模型靠优化；模糊/NN/RL = 没模型靠经验或数据。

## 全章一页纸总结

| 方法 | 一句话 | 需要模型吗 | 核心数学 |
|---|---|---|---|
| MPC | 看 N 步、带约束、只走第一步 | 要 | 优化 + Riccati 递推 |
| 模糊 | 老师傅口头禅数字化 | 不要 | 隶属度 + 重心法加权平均 |
| 神经网络 | 万能拟合器 | 不要（要数据） | 链式法则 + 梯度下降 |
| 强化学习 | 试错学策略 | 不要 | Q 更新 + 压缩映射收敛 |
| 打通 | LQR = 无约束无限远 MPC = 开卷版 RL | — | 同一个 Bellman |

# 第14章 智能控制前沿——项目实战

> **本文件的定位**：本章的 5 张图把手写的 MPC、模糊、神经网络、Q-learning 都跑通了，但它们的"工业形态"长什么样？本文件给你 4 个真实项目：从倒立摆上的 LQR/MPC 对决，到意大利理工的四足全身 MPC（IROS 2024 开源），再到 TUM 的实时神经 MPC（RA-L 2023），最后用 scikit-fuzzy 把模糊控制器工程化。

> **总原则不变**：青铜=跑通别人的代码，黄金=改参数做对比实验，王者=接到自己的系统上。

## 项目 A：经典复现——倒立摆上的 LQR vs MPC 正面对决

### 为什么要做

本章图1 已经对比过 MPC/LQR/PID，但那是"单输入单输出"的简化对象。**倒立摆（cart-pole）是 4 状态、欠驱动、开环不稳定的标准基准**，LQR 和 MPC 在它身上的差别会比图1 更刺眼：一旦加入"小车不能出界、力矩不能超限"两条约束，LQR 立刻露馅，MPC 依然稳。这个实验做完，"MPC 的代差是约束"这句话就刻进肌肉记忆了。

### 用哪两个开源项目

| 项目 | 内容 | 仓库 |
|---|---|---|
| LQR 倒立摆（OpenAI Gym） | 从非线性动力学线性化 → 离散化 G/H → LQR 增益，接 Gym 可视化 | `https://github.com/K1nght/LQRcontroller-InvertedPendulum-in-OpenAIGym-python` |
| MPC 倒立摆（CasADi/QP） | 线性 MPC、非线性 MPC、LQR 三者同框对比，QP 矩阵构造过程完整可读 | `https://github.com/JAParedes/MPC_for_inverted_pendulum_on_a_cart_stabilization`（Matlab + CasADi；无 Matlab 可用 Python 等价路线，见下） |

> **无 Matlab 的等价路线**：PythonRobotics 里的 `PathTracking/model_predictive_speed_and_steering_control.py` 用 CasADi（或 cvxpy）实现了一个完整的"车辆跟踪 MPC"，QP 构造、约束、滚动时域一目了然——把它当 MPC 的"Python 版教材"读。仓库：`https://github.com/AtsushiSakai/PythonRobotics`。

### 实战路线

**青铜（半天）：跑通 LQR 版**
1. `pip install numpy matplotlib gym`（新版环境可用 `gymnasium`，API 略改）；
2. 运行 LQR 脚本，观察倒立摆从 0.6 rad 初始倾角回到竖直；
3. 在代码里找到线性化点、$A,B$ 矩阵和 `dlqr`/离散 Riccati 求解——和第11章的公式逐一对上。

**黄金（1~2 天）：把"约束"加进去，看 LQR 翻车**
1. 给 LQR 闭环加一条硬规则：$|x|>2$m 就判失败。把初始倾角加大到 0.9 rad，LQR 为了救摆必然把小车推出界——**记录失败过程**；
2. 换 MPC（用 PythonRobotics 版或自己把第14章图1 的 `u_mpc` 扩成 4 状态版），把 $|x|\le2$、$|u|\le u_{max}$ 写进约束，同一初始条件再跑：**MPC 会"先往反方向挪小车再救摆"，全程不出界**；
3. **输出物**：并排两张状态轨迹图（LQR vs MPC），标出 LQR 越界的时刻。这张图能直接当面试讲解材料。

**王者：Q/R 权重扫描实验**
写个循环扫 $Q$ 矩阵里"摆角权重/位置权重"的比值（1、10、100），记录超调、收敛时间、控制能量，画成热力图——**这就是控制器选型报告的标准做法**。

### 验收标准

- 能用自己的话说出"为什么同一个系统，LQR 出界而 MPC 不出界"（关键词：约束是否在优化内）；
- 权重扫描实验至少 9 组参数、一张汇总图。

## 项目 B：工业级 MPC 求解器——acados + 四足全身控制（DWMPC）

### 为什么要做

自动驾驶和腿足机器人里，MPC 的"真身"不是 scipy 的 `minimize`，而是**专用 QP/NLP 求解器**：acados（开源、C 代码生成、毫秒级）、OSQP、CasADi。意大利理工学院动态腿足实验室（IIT DLS Lab）开源的 **DWMPC**（Distributed Whole-Body MPC，IROS 2024，作者 Amatucci、Turrisi 等）是学习"工业级 MPC 集成"的绝佳样本：C++ 核心 + acados + Python 仿真接口，控制 Aliengo 四足机器人全身。

仓库：`https://github.com/iit-DLSLab/DWMPC`。

### 实战路线

**青铜（1 天，不编译也能完成）：读架构**
1. 读 README 和论文图，回答三个问题：这个 MPC 的**决策变量**是什么（各腿地面反力？躯干加速度？）？**预测时域多长、控制频率多少**？**约束有哪些**（摩擦锥、力矩限幅、 foothold）；
2. 在源码里定位 acados 模型的导出脚本（通常在 `python/` 或 `models/` 目录下的 acados template 文件）——看"动力学方程 → acados 结构体"的翻译过程。

**黄金（半天安装 + 1~2 天实验，需 Ubuntu）**
1. 按 README 装依赖（cmake、eigen3、pybind11、acados），编译项目；
2. 安装 `gym-quadruped` 仿真环境，跑通 Aliengo 站立的 Python 示例；
3. **改代价函数权重再编译**：把"躯干高度跟踪"权重调大 5 倍，观察机器人在受扰后的恢复姿态变化——体会"MPC 调参 = 改权重"这句话在真系统上的含义。

**王者：从 acados 官方例子入门自己的 MPC**
DWMPC 太重就先退一步：acados 官方仓库（`https://github.com/acados/acados`）的 `examples/python` 里有"倒立摆 NMPC"的最小完整例子（建模 → 生成 C 代码 → Python 调用闭环），跑通它，再回头读 DWMPC，难度立刻降一档。

### 验收标准

- 能画出 DWMPC 的"状态-决策变量-约束"三件套；
- （黄金）至少一次"改权重→重编译→观察行为变化"的完整循环。

## 项目 C（前沿）：实时神经 MPC——神经网络动力学 + acados 实时求解

### 为什么要做

MPC 的软肋是"模型要准"。TUM 的 **Real-time Neural MPC**（Salzmann, Kaufmann, Scaramuzza 等，IEEE RA-L 2023；arXiv: 2203.07747）给出了答案：**用神经网络学动力学残差（气动效应、未建模项），再把它"线性化后塞进 acados"，保持毫秒级实时**。四旋翼高速机动跟踪误差显著下降。这是"第14章神经网络 + MPC"两条线的正式合流，也是学习类 MPC（learning-based MPC）的入门必读。

仓库：`https://github.com/TUM-AAS/neural-mpc`（配套 `https://github.com/TUM-AAS/ml-casadi`，后者让 PyTorch 模型能被 CasADi 求导调用）。

### 实战路线

**青铜（1 天）：读论文 + 代码结构**
1. 读论文第 III 节：神经网络动力学如何被"逐段线性化"成 MPC 可吃的形式；
2. 在仓库里找到三个文件：训练数据的采集脚本、网络训练脚本、`export` 成 acados 模型的脚本——**这条"采集→训练→导出→求解"流水线，就是所有学习类 MPC 的骨架**。

**黄金（选做，需 Ubuntu + GPU，约 2~3 天）**
1. 按 README 装 acados Python 接口 + ml-casadi；
2. 用仓库自带的数据训练一个小的残差动力学网络（MLP 即可），跑它的仿真实验，对比"纯解析模型 MPC vs 神经 MPC"的跟踪误差曲线；
3. 思考：网络给出的模型没有稳定性保证，论文里用什么手段兜底？（提示：终端约束/鲁棒管——读论文 discussion 部分）。

**王者（科研向）：把思路搬到倒立摆**
给你第14章的倒立摆人为加一个未建模项（比如 $\dot\theta$ 的非线性摩擦 $\mu\,\mathrm{sign}(\dot\theta)\dot\theta^2$），用数据学一个残差网络补偿它，再放进 MPC——**这就是"模型错了怎么办"的完整科研闭环，也是很多顶会论文的最小可复现单元**。

### 验收标准

- 能解释"神经网络塞进 MPC"的两难：表达能力 vs 实时性/稳定性，以及该论文的折中手段；
- （黄金）一张"解析 MPC vs 神经 MPC"误差对比图。

## 项目 D：模糊控制工程化——scikit-fuzzy 实现"模糊 PID"

### 为什么要做

本章图2 手写了 5×5 规则表的模糊控制器。工程上最常见的形态是**模糊 PID**：规则表根据 $e, \dot e$ 在线调整 $K_p,K_i,K_d$。Python 的 `scikit-fuzzy`（`pip install scikit-fuzzy`）是模糊控制的工业标准教学库，提供完整的"隶属度函数定义 → 规则推理 → 重心去模糊"API，且和 MATLAB Fuzzy Logic Toolbox 概念一一对应。

### 实战路线

**青铜（半天）：用 skfuzzy 重建图2**
1. 用 `skfuzzy.control.ControlSystem` 把本章图2 的 5×5 规则表重建一遍（语言值 NB/NS/ZO/PS/PB，三角形隶属度）；
2. 用 `view()` 画出规则面，和你手写的对比——验证"规则面 = 非线性查表控制器"；
3. 把它接到第14章图1 的对象 $G(s)=1/(s^2+s)$ 上跑闭环，复现"模糊 ≈ PID"的结论。

**黄金（1 天）：模糊 PID 调参器**
1. 设计两张规则表：$e,\dot e \to \Delta K_p$ 和 $e,\dot e \to \Delta K_i$（经典模板：误差大时 $K_p$ 大、$K_i$ 小防超调；误差小时反过来消静差）；
2. 把"基础 PID + 在线 $\Delta K$"接到带执行器限幅（±0.8）的对象上，和普通 PID、图2 纯模糊三者对比阶跃响应；
3. **输出物**：三曲线对比图 + 一段 200 字的结论（模糊 PID 在什么时候真正占优？——提示：对象参数漂移或限幅频繁触发时）。

**王者：规则表的"阻尼设计"实验**
按本章知识讲解"规则表怎么避免过冲回弹"一节的思路，故意构造一张"无微分作用"的规则表（e 大就满输出），观察振荡；再修正规则表消除振荡——**把"规则 = 增益与阻尼"这句话做成可视化实验**。

### 验收标准

- skfuzzy 规则面与手写版一致（同样输入下输出差 < 5%）；
- 模糊 PID 对比实验有明确的"占优区间"结论。

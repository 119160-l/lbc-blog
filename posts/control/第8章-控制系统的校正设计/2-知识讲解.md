### 承上启下

前七章全是"**分析**"——给定系统，判断它稳不稳、算超调、画根轨迹、读裕度。但工程真正要的是"**设计**"：系统不达标，怎么改？本章就是答案。**第7章打下的稳定裕度 γ、穿越频率 ωc 是设计的"刻度尺"**，本章的所有校正方法都是"把 γ、ωc 调到目标值"的操作手册。学完本章，你将从"会看病"升级为"会开药方"。

### 问题导向

带着以下问题学习本章，你会更有方向感：

1. **一个系统"太快但超调大"和"太慢但不准"，分别该用超前还是滞后校正？为什么？**
2. **超前校正提相位裕度的原理是什么？滞后校正明明"减相位"，为什么也能提裕度？**
3. **PID 的 P、I、D 三个字母，分别对应"稳、准、快"中的哪一项？**

## 一、为什么要校正？

### 为什么？

第5~7章的分析经常得出这样的结论："系统稳定，但 γ 只有 15°（太脆）""稳态误差 0.5（太大）""调节时间 10s（太慢）"。**分析发现了病，治疗就是校正。**校正的目标一句话：**把系统调到"稳、准、快"三方面都达标**。

### 怎么做？（设计总流程）

```
① 定指标：γ≥45°、σ%≤20%、ess 达标（由用户/工程要求给出）
② 定增益：先按稳态精度要求确定开环增益 K
③ 找差距：用 K 分析原系统，量出 γ0、ωc0、ess0 差多少
④ 选打法：差相位→超前；差精度→滞后；都差→超前-滞后或PID
⑤ 算参数：按公式推出校正装置参数
⑥ 验证：画校正前后 Bode 图、阶跃响应对比，达标则完成
```

### 是什么？

> **校正**：在控制系统中引入附加装置（校正装置），改变系统开环频率特性（或闭环极点的位置），使系统满足给定的性能指标。它是**"分析—设计"闭环的最后一环**。

> 类比：原系统像一辆"出厂没调好的车"——刹车太软（γ 不足）、油门太肉（ωc 太低）。校正就是"调校"：换刹车片（超前）、换变速器（滞后）、或者加电子辅助（PID）。

![校正设计全流程](./figures/04_校正设计全流程.png)

*图 8-4 校正设计六步"施工图"：定指标 → 定增益 → 找差距 → 选打法 → 算参数 → 验证。做任何校正题，都按这个顺序走；验证不达标就回到第3步迭代。*

> **时间视角**：注意指标栏里写着 $\sigma\%\le20\%$、$t_s$ 达标——**这些都是时间指标**。校正设计的终点永远是"让时间响应变好"，Bode 图只是工作台。

## 二、校正的三种"打法"

### 增益校正：最朴素的"校正"

在引入动态校正装置之前，最朴素的手段是**只调整开环增益 $K$**（如第6章"由幅值条件求 $K$"、第7章"由裕度求参数"都属于增益校正）。$K$ 变化使闭环极点沿**既定根轨迹**移动，能改超调、调裕度。但增益校正的边界在于：**它只能"沿轨迹选点"，不能改变根轨迹的形状**——若目标阻尼比射线（如 $\zeta=0.5$ 的 $60°$ 线）与根轨迹**没有交点**，无论 $K$ 取多大都达不到目标（练习题3.3 中 $G=K/[s(s+1)(s+5)]$ 正是如此，$\zeta=0.5$ 对应 $K$ 解为负值）。这时就需要**动态校正装置**——加零点（超前/PD）把根轨迹"掰"向左，或用滞后压低穿越频率——从根本上改变轨迹形状，这就是本章引入超前、滞后、PID 的原因。（对应练习题 3.3）

### 串联校正（最常用）

把校正装置 $G_c(s)$ 串在误差信号之后、被控对象之前：

```
R → (误差) → [Gc] → [G] → C
        ↑                    │
        └────── [H] ←────────┘
```

开环变 $G_c(s)G(s)$，直接"重塑"开环频率特性。**本章重点。**

### 反馈校正

用局部反馈 $H(s)$ 包围系统中"毛病最多"的环节 $G_2(s)$。根据第4章结论，当 $|G_2H|\gg1$ 时被包围部分 ≈ $1/H(s)$——**把坏环节的坏特性洗掉**，换成 $H(s)$ 的干净特性。适合被控对象本身不稳定或参数漂移大的场合。

### 复合校正（前馈）

在输入或扰动通道上"提前补偿"。优点是理论上零误差，缺点是**依赖精确模型**（要算 $1/G$）。工程上通常是"前馈+反馈"双保险。

| 打法 | 改什么 | 优点 | 缺点 |
|------|--------|------|------|
| 串联 | 开环频率特性 | 设计简单、理论成熟 | 可能放大噪声 |
| 反馈 | 局部环节特性 | 抗参数变化、抗扰动强 | 结构复杂 |
| 复合 | 前馈通道 | 精度极高、响应快 | 依赖模型精确 |

## 三、超前校正：给系统"提神"

### 为什么？

原系统"γ 太小"（太脆）或"ωc 太低"（太慢）时用超前校正。它的"药效"是**在穿越频率附近给相角"打鸡血"**——把裕度补上去，同时 ωc 右移、响应变快。

### 怎么做？（设计五步）

```
① 定K：按稳态误差要求确定开环增益
② 量γ0：画原系统 Bode 图，量出相位裕度 γ0
③ 算需补角：φm = γ目标 − γ0 + ε（ε=5°~12°，补偿ωc右移带来的新损耗）
④ 求参数：a = (1+sinφm)/(1−sinφm)；
   在原幅频曲线上找 |G(jω)| = −10lg a 的频率作为新 ωc，令 ωm=ωc，T = 1/(ωm√a)
⑤ 验证：画校正后 Bode 图，γ、Kg 达标
```

### 是什么？

> **超前校正** $G_c(s)=\dfrac{1+aTs}{1+Ts}\ (a>1)$：在 $\omega_m=1/(T\sqrt a)$ 处提供最大超前角 $\varphi_m=\arcsin\dfrac{a-1}{a+1}$，同时把该频率的幅值抬高 $10\lg a$ dB。**"用高频增益换相位"**——这也是它放大高频噪声的原因。

### 生活类比

开车过急弯（=穿越频率附近相角太负），你需要**提前打方向盘**（=相位超前）。但方向打太早太大，副驾驶会觉得"颠"（=高频噪声被放大）。所以 $a$ 一般不超过 10~20。

![校正前后阶跃响应对比](./figures/03_校正前后阶跃响应对比.png)

*图 8-3 超前校正效果：左图校正前（红）$\gamma=25.4°$、超调约 50%、振荡久；校正后（绿）$\gamma\approx43°$、超调约 30%、调节时间缩短；右图 Bode 幅频对比显示 $\omega_c$ 右移。*

> **时间视角**：看左图两条时间曲线——**校正前"冲得高、晃得久"，校正后"冲得低、收得快"**。这正是 $\gamma$ 从 25.4° 提到 43° 在时间域的"投影"：频域多补一点相位裕度，时间上就少一点振荡。

### 鲁棒性：设计对模型误差的敏感度

> **鲁棒性（Robustness）**：系统在模型不精确、参数漂移、环境变化下仍能保持规定性能的能力——"设计得好"不只是"纸面上达标"，更是"实际中扛得住误差"。

超前校正特别依赖建模精度：设计五步要"量出原系统 $\gamma_0$"、"在原幅频曲线上找 $|G(j\omega)|=-10\lg a$ 的频率"，这些数据全部来自被控对象模型 $G(s)$。模型一有误差（参数估计不准、工作点漂移、被忽略的高阶动态），量出的 $\gamma_0$ 就偏，算出的 $\varphi_m$、$\omega_m$、$T$ 也随之偏，实际 $\gamma$ 与设计值出现偏差——模型把裕度"高估"，系统就比预期"脆"。

工程对策三条：① 设计时预留裕度（$\varepsilon$ 取 $10°\sim12°$）；② 设计完成后用 $\pm20\%$ 参数摄动做仿真验证；③ 想要更强鲁棒性，改用反馈校正——局部反馈把坏环节特性"洗掉"，对参数漂移不敏感（见本章第六节）。（对应练习题 3.1）

### 跟着算一遍：超前校正数值例

拿第7章贯穿的系统 $G(s)=\dfrac{10}{s(s+1)(s+5)}$ 走一遍，你会对"超前校正"有手感。

1. **先看病人**：第7章已算出它 $\omega_c\approx1.23$、$\gamma_0\approx25°$——太脆，目标是 $\gamma\ge45°$。
2. **算缺多少角**：$45°-25°\approx20°$，但超前会让 $\omega_c$ 右移、相位又损失一点，所以多补 $10°$ 余量，$\varphi_m\approx30°$。
3. **由角定 $a$**：$a=\dfrac{1+\sin30°}{1-\sin30°}=3$。$a=3$ 意味着"用 3 倍高频增益换 $30°$ 相位"。
4. **由 $a$ 定位置**：$10\lg3\approx4.77$ dB，在幅频曲线上找到 $-4.77$ dB 处的频率 $\omega_m\approx1.67$，这就是新的穿越频率。
5. **由位置定 $T$**：$T=\dfrac{1}{\omega_m\sqrt a}\approx0.35$。
6. **拼出校正器**：$G_c(s)=\dfrac{1+1.05s}{1+0.35s}$，校正后 $\gamma\approx42°$。

**体感**：全过程就是"**量出缺口 → 用 $a$ 决定补多少 → 用 $\omega_m$ 决定补在哪 → 用 $T$ 落位**"。三个参数各司其职，不会乱。

## 四、滞后校正：给系统"压担子" 

### 为什么？

原系统"低频增益不够（精度差）"且"γ 也不足"时用滞后校正。它不像超前那样"打鸡血"，而是**"压着幅频曲线往下走"**——让穿越频率左移到相角更安全的位置，从而提 γ；同时低频增益不受影响，稳态精度保住。

### 怎么做？（设计四步）

```
① 定K：按稳态精度确定 K（高频段等效于"提升低频增益"）
② 选点：找新穿越频率 ωc_新，使该处相角 = −180°+γ目标+ε
③ 求b：b = 1/|G(jωc_新)|，使校正后幅频正好在此穿越
④ 取T：令 1/(bT) ≈ ωc_新/10（滞后转折远低于穿越频率，避免添乱），T = 10/(b·ωc_新)
   验证：γ 达标、低频增益不变
```

### 是什么？

> **滞后校正** $G_c(s)=\dfrac{1+bTs}{1+Ts}\ (b<1)$：低频段幅值 ≈0 dB（不伤精度），高频段衰减 $20\lg b$ dB（压低中频幅值 → ωc 左移 → γ 变大）。**"用带宽（速度）换稳定性和精度"**——代价是响应变慢。

### 生活类比

一个"太敏感"的学生（γ 不足）：不是让他反应更快（超前），而是**降低他的任务强度**（压幅值）——作业量减半，质量反而上去了。代价是学得慢一点。

### 超前 vs 滞后（必考对比）

| 项目 | 超前校正 | 滞后校正 |
|------|----------|----------|
| 传递函数 | $\dfrac{1+aTs}{1+Ts}$，$a>1$ | $\dfrac{1+bTs}{1+Ts}$，$b<1$ |
| 相位效果 | 加相位 | 减相位 |
| 幅值效果 | 高频增益↑ | 高频增益↓ |
| ωc | 右移（更快） | 左移（更慢） |
| γ | 直接补足 | 间接补足（左移躲开危险区） |
| 稳态精度 | 不变 | 不变（低频增益保住） |
| 副作用 | 放大高频噪声 | 响应变慢 |
| 适用 | γ不足、太慢 | 精度不够、γ严重不足 |

![超前与滞后校正Bode对比](./figures/01_超前与滞后校正Bode对比.png)

*图 8-1 超前（蓝）与滞后（红）校正的频率特性对比：超前相位为正（"加相位"），滞后相位为负但压低了高频幅值（"压幅值"）。*

> **时间视角**：超前 = "急性子"（响应更快但爱放大噪声）；滞后 = "慢性子"（更稳更准但变慢）。**同一张 Bode 图对比，读出的是两种截然不同的"时间性格"。**

### 跟着算一遍：滞后校正数值例

还是 $G(s)=\dfrac{10}{s(s+1)(s+5)}$，这次试试"慢性子"的滞后校正。

1. **定相角找位置**：目标 $\gamma=45°$，留 $5°$ 余量，新 $\omega_c$ 处相角要 $-130°$。反解相角方程得 $\omega_c\approx0.64$（比原来的 1.23 小了一半——响应会变慢，这是代价）。
2. **量幅值定 $b$**：在 $\omega_c=0.64$ 处 $|G|\approx2.60$，要把它压到 1，$b=\dfrac{1}{2.60}\approx0.385$。
3. **把转折甩远定 $T$**：$T=\dfrac{10}{b\omega_c}\approx40.5$，让滞后转折远在 $\omega_c$ 左侧，不在穿越点"添乱"。
4. **拼出校正器**：$G_c(s)=\dfrac{1+15.6s}{1+40.5s}$。

**体感对比**：超前是"往前冲"（$\omega_c$ 右移、更快），滞后是"往后撤"（$\omega_c$ 左移、更稳）。**同一个病人，两副药，效果相反**——这就是为什么要先判断"你到底想快还是想稳"。

## 五、PID：工程界最常用的控制器 

### 为什么？

上述校正都是"模拟装置"，而 PID 是**一台通用计算机就能实现的控制器**，全球 90% 以上的工业回路都在用它。它不需要精确模型——**按直觉和经验整定三个旋钮**即可，这也是它长盛不衰的原因。

### 怎么做？（三个旋钮各自的效果）

先看一张"单一参数变化"的直觉表（详细曲线见绘图章）：

| 调哪个 | 响应变快？ | 超调怎么变？ | 稳态误差？ | 副作用 |
|--------|------------|--------------|------------|--------|
| $K_p \uparrow$ | ↑ | ↑（更振） | ↓ | 过大振荡 |
| $K_i \uparrow$ | ↓ | ↑（更振） | **→0** | 积分饱和、更易失稳 |
| $K_d \uparrow$ | ↑ | **↓**（刹车） | 不变 | 放大噪声 |

**口诀：P 管"现在"（快）、I 管"过去"（准）、D 管"未来"（稳）。**

![PID三个参数的作用](./figures/02_PID三个参数的作用.png)

*图 8-2 同一对象配不同控制器的阶跃响应：纯 P（灰）快但稳态误差约 0.33；PI（红）误差归零但更振；PD（蓝）超调减小；PID（绿）取长补短，又快又准又稳。*

> **时间视角（本章点睛）**：六个字在这张图上"现身"——**P 管爬升速度（斜率）、I 管终值贴不贴目标线、D 管爬升过程刹不刹得住**。调三个旋钮，就是在同一时间曲线上分别调节这三件事。

### 是什么？

> **PID**：$G_c(s)=K_p+\dfrac{K_i}{s}+K_d s$。比例项即时纠错、积分项消除稳态误差、微分项阻尼振荡。**"三个旋钮，一套哲学：现在、过去、未来都要管到。"**

### 整定经验（Ziegler-Nichols 简版）

- 先用纯 P，增大 $K_p$ 直到系统临界振荡，记临界增益 $K_u$、临界周期 $T_u$；
- 经验公式（经典 Z-N）：$K_p=0.6K_u$，$T_i=0.5T_u$，$T_d=0.125T_u$；
- 再微调：想更稳→减 $K_p$ 或增 $T_i$；想更快→增 $K_p$ 或减 $T_i$。

### 跟着算一遍：Z–N 整定数值例

对象 $G(s)=\dfrac{1}{s(s+1)(s+5)}$，三步算出 PID 初值：

1. **找临界增益**：闭环特征方程 $s^3+6s^2+5s+K=0$，Routh 判据给出临界 $K_u=30$。
2. **找临界周期**：临界振荡 $s=\pm j\sqrt5$，$\omega_u=\sqrt5$，周期 $T_u=\dfrac{2\pi}{\sqrt5}\approx2.81$ s。
3. **套公式**：$K_p=0.6K_u=18$，$T_i=0.5T_u\approx1.41$，$T_d=0.125T_u\approx0.35$，即 $G_c(s)=18+\dfrac{12.8}{s}+6.3s$。

**体感**：Z–N 不需要模型推导、不需要画 Bode 图，只要"**把系统调到临界振荡，记两个数，套公式**"——这就是它 90% 工业回路都在用的原因。缺点是初值偏激进，后面还得手调。

## 六、反馈校正与复合校正 ：高级打法

### 反馈校正（内部洗澡）

```
R → [G1] → ┌─[G2]─┐ → C
            │  ↑    │
            └ [H] ←─┘
```

当 $|G_2(j\omega)H(j\omega)|\gg1$ 时，被包围部分 ≈ $1/H(s)$。**好处**：被控对象参数漂移、非线性都对整体影响很小——鲁棒性极强。**代价**：结构复杂、调试麻烦。

### 复合校正（前馈：先发制人）

```
R ──[Gf]─────────────┐
   ↓                  ↓
R →[G1]→[G2]→ C      （Gf 从输入直通输出）
```

- 扰动全补偿：$G_f=-1/G_1$；
- 输入全补偿：$G_f=1/G_2$。

**"预判"是它的本质**：不等误差出现就先给一个补偿信号。但 $1/G$ 要模型精确，模型一歪就失效，所以通常与反馈并用。

> **反馈的边界**：反馈只能修正"被误差信号检测到的"扰动——若扰动注入点在比较点（测量点）**之前**、尚未进入误差信号，反馈对它无能为力（反馈环对输入点之前的扰动没有抑制作用）。这正是前馈存在的理由之一：前馈不依赖误差检测，直接在扰动通道上做补偿。（对应练习题 3.2）

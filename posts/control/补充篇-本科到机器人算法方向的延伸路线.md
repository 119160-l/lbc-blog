## 三、四条主线知识地图（对应大厂岗位，按优先级排序）

```
主线1  控制深化（你最强，往上走）
  经典控制 → 现代控制(LQR) → 最优控制 → MPC → 带约束/鲁棒控制 → 学习控制(RL)
  ★ 任务：把第14章 MPC 从"2阶玩具"升级到"10阶倒立摆+约束"

主线2  状态估计（大疆SLAM的必经之路）
  卡尔曼滤波(KF) → 扩展KF(EKF)/无迹KF(UKF) → 因子图/图优化(g2o/Ceres)
       → 视觉惯性里程计(VIO) → SLAM 建图+重定位 → 语义SLAM / 3DGS
  ★ 任务：在 Python 里从零实现一个 2D 激光雷达 SLAM 最小demo

主线3  机器人学（宇树运动的底座）
  刚体/齐次变换 → 正运动学(DH参数) → 逆运动学 → 动力学(拉格朗日/牛顿-欧拉)
      → URDF建模 → 轨迹规划 → 力/阻抗控制 → 运动控制器(如MPC腿部控制器)
  ★ 任务：给倒立摆/单腿机器人写 URDF，在 PyBullet 里跑通

主线4  学习算法（具身智能/自动驾驶的"大脑"）
  手写MLP/Q-learning(第14章) → 手写DQN/PPO(第15章) → PyTorch版PPO → CNN/Transformer/Diffusion
      → 模仿学习：行为克隆(BC) → ACT / Diffusion Policy
      →（研一+）世界模型 / VLA（如 π₀、GR00T、OpenVLA）
  ★ 任务：把第15章手写 PPO 改写成 PyTorch 版并在 gymnasium 的 CartPole 上训练；再复现 Diffusion Policy 最小demo
```

**配套数学（贯穿四条主线）**：线性代数（矩阵分解、SVD）、概率论（高斯、贝叶斯）、数值优化（梯度下降→牛顿法→凸优化）——大疆岗位要求的"几何、统计、机器学习"就是这三样。

```

  · 数学三件套 + PyTorch（跟李沐《动手学深度学习》到 Transformer 为止）

  · 作品1：GitHub 放"倒立摆全栈"（仿真→物理引擎→(有硬件则真机)）

大三上~大三下（定方向+出作品）：
  · 四选一深耕：规控(MPC/路径规划) / 感知(SLAM) / 学习控制(RL) / 机器人大模型(前沿)

  · 进导师组：优先选 控制/机器人/具身智能/自动驾驶 方向的 985 课题组

  · 目标：研一结束前出 1 篇论文（IROS/ICRA 或高水平期刊），实习转正更有底气

研一~研二（深造+对接大厂）：
  · 研一：打满主线4（RL/模仿学习/世界模型），进实验室核心课题
  · 研二：暑期实习（宇树/大疆/华为车BU/蔚小理），实习转正 or 秋招
```

## 七、给本科生的三条"避坑"建议

1. **别只刷课，一定要"做出来一个东西"**：算法岗简历上"会 PyTorch"一文不值，"复现过 Diffusion Policy 并部署到机械臂"才有分量。本课程的每个"动手实践"任务就是最小单位的作品。
2. **C++ 现在就开始**：宇树/大疆几乎所有算法岗都要求 C++（真机部署、ROS2 都是 C++ 生态）。建议大三前掌握：STL、类/继承/模板、CMake 构建，能读 PyBullet/ROS 示例即可。
3. **用"控制+学习"的交叉身份定位自己**：纯 CV/纯 NLP 方向卷成红海，但"懂经典控制 + 会用 RL/模仿学习做机器人"的人才在大厂仍然稀缺——你学完本课程就已经是半个这样的人，接下来只需把另一半补上。

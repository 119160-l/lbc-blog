## 一、什么是自动控制？

### 为什么？

想象你洗衣服：手洗要一直盯着、一直搓；用洗衣机，设定好程序它就自己完成整个流程。再比如开车定速巡航：脚踩油门要一直调整（手动），开启巡航后车速自己保持（自动）。**"自动控制"就是让机器代替人，自动地完成"观察→判断→决策→执行"这一系列动作**。人类社会之所以离不开它，是因为==人反应慢、会疲劳、精度有限，而机器不会。==，懒

### 怎么做？

一个完整的控制过程，本质上是在不断重复四个动作：

```
观察（测量当前状态）→ 判断（与期望值比较）→ 决策（决定怎么调整）→ 执行（施加控制作用）
```

- **手动控制**：这四个动作全部由人完成。
- **自动控制**：用装置（传感器、控制器、执行器）代替人完成这些动作。

### 是什么？

**自动控制**：在没有人直接参与的情况下，利用控制装置使被控对象（如温度、转速、液位）自动地按预定规律运行的技术。

**几个关键术语**（全课通用）：
- **被控对象**：要被控制的设备或过程，如恒温箱、电机、锅炉。
- **被控量（输出量）** $c(t)$：对象的实际运行状态，如箱内温度。
- **给定量（输入量）** $r(t)$：我们希望被控量达到的值，如设定的25°C。
- **扰动量** $d(t)$：破坏被控量保持期望值的外部因素，如开门导致的热量散失。

> 一个类比：**空调的"设定温度"=给定量，"室内温度"=被控量，"开窗"=扰动**。自动控制要解决的问题就是：在扰动不断出现的情况下，让室内温度始终贴近设定值。

## 二、开环控制与闭环控制

### 为什么？

既然要自动控制，第一个要回答的问题是：**要不要"回头看看"输出结果？** 这一念之差，就分出了开环与闭环两种截然不同的控制方式。

### 怎么做？

**开环控制**：只按"输入指令"正向执行，**不检测输出、不回头修正**。

```
输入指令 → [控制器] → [被控对象] → 输出
（信息只走一条路，没有回头路）
```

例子：
- 洗衣机（按设定程序转，不管洗得干不干净）；
- 老式交通灯（按固定时间切换，不管路口车多车少）；
- 步进电机开环定位（按脉冲数走，走错不纠正）。

**闭环控制（反馈控制）**：把输出**检测回来与输入比较**，用差值（误差）去修正，形成闭合回路。

```
输入 → (误差) → [控制器] → [被控对象] → 输出
        ↑                               │
        └────── [测量反馈环节] ←─────────┘
（信息形成闭环，自动纠偏）
```

例子：
- 空调（检测室温，高了降温、低了升温）；
- 定速巡航（检测车速，慢了加油、快了收油）；
- 无人机悬停（检测姿态，偏了自动修正）。

### 是什么？

| 对比维度 | 开环控制 | 闭环控制 |
|----------|----------|----------|
| **结构** | 无反馈，单向 | 有反馈，闭合回路 |
| **是否检测输出** | 否 | 是 |
| **抗扰动能力** | 差（扰动直接造成偏差） | 强（扰动引起的偏差会被自动修正） |
| **精度** | 低，依赖元件精度 | 高，依赖反馈与增益 |
| **稳定性问题** | 不存在（永远"稳定"） | **可能不稳定**（反馈过头会振荡） |
| **成本/复杂度** | 低 | 高 |
| **典型例子** | 洗衣机、交通灯 | 空调、定速巡航、导弹制导 |

**关键结论**：
1. **闭环的代价是可能不稳定**——这是全课要反复解决的"稳定性"问题的根源；
2. 工程上**以闭环为主**，因为系统总会遇到扰动，开环对此无能为力；
3. 有一种折中叫"复合控制"（开环+闭环），第8章会提到。

> **前馈控制（复合控制的另一半）**：前馈控制是"开环思想"的控制方式——它不依赖输出反馈，而是**预先**根据输入（或可测扰动）的变化直接施加控制作用，与反馈通道并联构成"前馈+反馈"复合控制。为什么加了反馈还不够？因为反馈是**事后修正**：偏差 $e(t)$ 出现后控制器才动作，响应总是滞后一步；当设定值突然大幅变化（如温度设定从 25°C 突升到 40°C）或强扰动袭来时，纯反馈系统要等测温看到偏差才开始加温，明显滞后。前馈的作用是"防患于未然"：设定值一变，前馈通道立刻按对象模型算出应有的控制量并提前施加，让输出快速跟随。但前馈的代价是**依赖对被控对象的准确建模**——模型不准时前馈会"帮倒忙"产生错误补偿，所以工程上以前馈加快跟踪、以反馈消除模型误差与扰动，两者优势互补（对应练习题 3.2，第8章复合校正详述）。

![开环与闭环方框图对比](./figures/01_开环与闭环方框图对比.png)

*图 1-1 左：开环控制，信号单向流动，无反馈；右：闭环控制，输出经反馈环节绕回输入端形成闭合回路。*

> **从时间响应的角度看开环与闭环**：给系统一个阶跃输入，开环系统的输出直接取决于元件精度（偏差"赖着不走"）；闭环系统的输出会被误差信号不断修正——输出偏高就减、偏低就加，最终被"拉"向期望值。**开环是"一次性执行"，闭环是"反复纠偏"**。这条时间曲线上的差别，就是第5章将用 $c(t)$ 定量刻画的内容。

## 三、反馈原理与控制系统组成

### 为什么？

"反馈"是闭环控制的灵魂。**反馈（feedback）= 把输出信息取一部分送回输入端，参与形成控制信号**。没有反馈，闭环就不成立。理解了反馈，就理解了这门课的80%世界观。

### 怎么做？

任何反馈控制系统，都可以拆成**五大基本元件**：

```
给定量 r(t) ──►(比较元件 ⊕)──► [控制器] ──► [执行机构] ──► [被控对象] ──► 输出 c(t)
                   ▲                                            │
                   │                                            │
                   └────────── [测量元件 + 反馈环节] ◄───────────┘
```

1. **测量元件（传感器）**：检测被控量，如温度计、转速传感器、电位器。
2. **比较元件**：把给定量与反馈量相减，产生误差信号（数学上就是 $e = r - b$）。
3. **控制器（调节器）**：根据误差信号按某种规律（如PID）计算控制策略。
4. **执行机构**：把控制信号变成物理动作，如电机、阀门、加热器。
5. **被控对象**：被控制的设备，如恒温箱、电机。

### 是什么？

> **反馈控制原理**：控制系统通过"检测偏差 → 利用偏差 → 消除偏差"的机制实现自动调节。系统工作的动力来自"偏差"——偏差消失，动作停止；偏差出现，动作立刻响应。

**举个完整例子——恒温箱**（全课反复使用的经典案例）：
- 设定温度 25°C（给定量 $r$）；
- 温度计测出箱内 24.5°C（反馈量 $b$）；
- 比较元件算出偏差 $e = 25 - 24.5 = 0.5$°C；
- 控制器指挥加热器加大功率（执行）；
- 温度回升 → 偏差减小 → 加热功率回落 → 最终稳定在 25°C 附近。

![恒温箱反馈控制系统组成](./figures/02_恒温箱反馈控制系统组成.png)

*图 1-2 恒温箱闭环系统：设定温度(给定量)→比较元件→控制器→加热器(执行机构)→恒温箱(被控对象)→温度计(测量元件)→反馈。五大元件一图看清。*

> **时间视角下的闭环纠偏过程**：温度随时间的变化是**一条渐近逼近 25°C 的曲线**——先快速上升、接近目标后减速、最终停在目标值。若一开始偏差大则加热猛、升温快；偏差小则加热缓、曲线变平。**"误差大→动作大，误差小→动作小"这种随时间的自动调节，就是反馈控制的全过程。**

这就是一个**自动纠偏的闭环**。注意：系统中每个元件都在"做减法"——闭环的本质就是让系统自己找平衡点。

## 四、控制系统的方框图表示

### 为什么？

真实的系统由很多元件组成，直接画实物图既复杂又不便分析。**方框图**用图形把"信号的流动关系"抽象出来，是分析控制系统的通用语言，也是第4章结构图的基础。

### 怎么做？

方框图由四种基本元素组成：

```
信号线：────►   带箭头的线段，表示信号的传递方向
方框：  [G]     一个环节，方框内写该环节的传递函数
比较点：⊕      信号相加/相减（⊕处带−号表示相减）
引出点：●      把信号分出一路（分支）
```

### 是什么？

| 元素 | 图形 | 含义 |
|------|------|------|
| 信号线 | $R(s) \to$ | 信号（拉氏变换表示） |
| 方框 | $[G(s)]$ | 环节：输出 = 输入 × G(s) |
| 比较点 | $\oplus$ | 求代数和（输入−反馈） |
| 引出点 | $\bullet$ | 信号分支（不改变信号） |

> 方框图的本质：**它是一张"信号流动图"**，把 $e=r-b$、$c=G e$ 这些代数关系画出来。第4章我们将学习它的化简（等效变换）与信号流图（梅森公式），届时方框图会从"示意图"升级为"计算工具"。

## 五、对控制系统的基本要求：稳、准、快

### 为什么？

造一个控制系统，总得有个"好坏的标尺"。工程师评价任何控制系统，都用同一把尺子：**稳定性、准确性、快速性**，简称"稳、准、快"。

### 怎么做？

以二阶系统（第5章重点）对单位阶跃输入的典型响应曲线为例：

```
c(t)
1.0 ┤    ╭─────── 稳态值
    │   ╭╯
    │  ╭╯      ← 超调量：冲出稳态值的程度
    │ ╭╯
    │╭╯
    │╯
    ┼──────────────────────── t
    ←───上升时间──→
    ←───────调节时间 ts ──────→
```

1. **稳（稳定性）**：响应最终能收敛到稳态值，不振荡发散。**这是前提**。
2. **准（准确性）**：稳态值与期望值之差（稳态误差 $e_{ss}$）尽量小。
3. **快（快速性）**：上升时间、调节时间尽量短，响应尽量快。

### 是什么？

| 要求 | 衡量指标（本章定性，第5章定量） | 直观理解 |
|------|--------------------------------|----------|
| 稳 | 系统是否发散 | "不翻车" |
| 准 | 稳态误差 $e_{ss}$ | "不跑偏" |
| 快 | 调节时间 $t_s$、上升时间 $t_r$ | "不磨蹭" |

![反馈对扰动的抑制效果](./figures/03_反馈对扰动的抑制效果.png)

*图 1-3 阶跃扰动下开环与闭环输出的时间响应对比：开环（红线）输出被扰动"推离"期望值且不回来；闭环（蓝线）扰动造成瞬时偏差后，被反馈自动拉回。稳、准、快三要求在时间曲线上直观可见。*

> **用时间曲线读懂"稳准快"**：
> - **稳**：曲线最终是否"平"下来（收敛），如蓝线最后是一条水平线；
> - **准**：平稳后离期望虚线差多少（稳态误差 $e_{ss}$）；
> - **快**：曲线从起步到接近稳态用了多长时间（调节时间 $t_s$）。
> 第5章将用数学公式精确计算这三项——本章先看"图感"。

> **重要工程观念**：稳、准、快三者常相互制约。比如把增益调大，响应变快、稳态误差变小，但振荡加剧、甚至不稳定。**"折中"是控制工程的核心艺术**，第5章、第8章会反复体会这一点。

## 六、自动控制的工程应用与发展

### 为什么？

了解学科的应用版图，能帮你建立学习动机：这门课不是空中楼阁，它支撑着现代工业与生活的方方面面。

### 怎么做？（应用版图）

| 领域 | 典型系统 | 控制的被控量 |
|------|----------|--------------|
| 家用电器 | 空调、冰箱、热水器 | 温度 |
| 工业过程 | 锅炉、化工反应釜、精馏塔 | 温度/压力/液位/流量 |
| 运动控制 | 机床伺服、机械臂 | 位置/速度 |
| 运载工具 | 汽车ABS/巡航、高铁、电梯 | 速度/位置 |
| 航空航天 | 无人机、导弹制导、火箭姿态 | 姿态/轨迹 |
| 能源电网 | 发电机励磁、频率调节 | 电压/频率 |

### 是什么？（发展简史）

1. **经典控制理论**（本课内容）：以传递函数为基础，时域/根轨迹/频域三大方法，适用于单输入单输出的线性定常系统；
2. **现代控制理论**：状态空间法，多变量系统，最优控制/鲁棒控制（后续课程）；
3. **智能控制**：模糊控制、神经网络控制、深度学习控制的工程落地。

> 一个优秀自动化工程师的知识结构 = **扎实的经典控制理论（本课）** + 现代控制理论 + 数学工具 + 仿真技能。本课程就是这一切的起点。

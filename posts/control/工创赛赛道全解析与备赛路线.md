## 3. 逐赛道深度拆解

### 3.1 工程实践赛道 —— 主题「绿色能源」

**命题定位（官方原文）**：以绿色能源为主题，以再生能源效率为目标，践行「双碳」理念；重点考察机械、电子、计算机等**基础工程知识**与**基本实践技能**，突出「基础性」和「通用性」。

#### 赛项 A：太阳能电动车（「复刻宇宙行」）

| 项 | 官方约束 |
|---|---|
| 尺寸 | ≤200mm×250mm（宽×长），含所有软质线路 |
| 构成 | 太阳能板、充电模块、超级电容模组、语音播报模块、读卡器(13.56MHz/ISO14443A)、电能检测模块、外壳、电机及相关元器件 |
| 电机 | **只有 1 个，不能装任何传感器** |
| 转向 | **只能机械机构实现，禁止任何电控转向**；不能装任何传感器、不能无线通讯 |
| 外壳 | 完整坚固、便于拆装、不许柔性材料；镂空面积 ≤ 所在表面 30% |
| 初赛 | 自备超级电容模组；10 个标志点，总里程约 **12238mm**，限时 3 分钟，15s 内必须启动 |
| 决赛 | 组委会统一超级电容（7.94V 最大充电 / 7.4V±0.1V 输出 / 2A / 60×60×46mm）；创新实践环节**现场焊接充电模块**；拆除太阳能板稳压模块 |
| 场地 | 2000mm×6000mm 喷绘布，太空场景，16 个备选标志点（初赛走 10 个） |

#### 赛项 B：生物质能电动车（「复刻丝路行」）

- 原理：固体酒精燃烧 → 温差片模组（塞贝克效应）「热能→电能」直接转化 → 充电模块 → 超级电容 → 电机
- 初赛：**不准用超级电容**，固体酒精燃烧经温差发电直接驱动（温差片不限）
- 场地：陆上丝绸之路，31 个备选标志点，初赛 12 个、总里程约 **6321mm**

#### 评分权重（两赛项一致）

```
初赛总分 = A 任务命题文档(网评) + B 作品创意设计(现场评) + C 现场初赛
   C = C1 标记成功(30) + C2 有效运行距离(40) + C3 语音播报(30)
决赛总分 = 创新实践(A/B/C 三级) + E 充电(100) + F 现场决赛
   F = F1 标记成功(40) + F2 电量消耗(20) + F3 有效运行距离(40)
```

**反直觉点（命题解析明确标注）**：充电成绩**不是功率越大越好**，而是按「本队平均功率」在全体队伍最大/最小功率区间内的相对位置折算；电量消耗同理。这是一个**相对排名型**评分，目标是"贴着最优区间走"。

**文档 0 分红线**：文档雷同 ≥30%、出现地名/单位名/队名/人名、出现 `*` `/` `★` 等标记、未删模板蓝字 → 0 分；且**排版规范分不得高于内容质量分**。

**需要学的知识栈**

| 模块 | 具体内容 |
|---|---|
| 机械 | 轻量化结构设计、外壳 3D 打印/激光切割、纯机械转向机构（凸轮/连杆/阿克曼）、齿轮传动比计算 |
| 电力电子 | 太阳能板选型与 MPPT、**DC-DC 变换器（Buck/Boost）设计与现场焊接**、超级电容充放电特性（E=½CV²、内阻、均压） |
| 热电（生物质能） | 塞贝克效应、温差片串并联、冷端散热（水冷/翅片）、热管理 |
| 计量 | 3mΩ 采样电阻 + 隔离 ADC + 滤波放大（电能检测模块原理） |
| 嵌入式 | MCU 驱动 RFID 读卡器（RC522/SPI）、语音播报（UART）、LED 点亮逻辑、电机驱动 |
| 工具 | SolidWorks/CAD、EDA（立创 EDA/Altium）、Keil/CubeIDE |
| 文档 | 决赛场地策划、情景点权重设计、轻量化对比分析（限字数、重排版） |

> **对自动化方向的帮助**：中等偏低。唯一高价值部分是**充电模块的闭环控制与 DC-DC 拓扑**，这是电力电子/运动控制的邻域；纯机械转向是"反控制"，对控制理论无增益。

**命题定位**：紧扣「全面实施人工智能+行动」，聚焦智能制造、工业大模型、具身智能，培育「智能+制造+民生+应急」复合型人才。

#### 评分权重（三赛项一致）

```

决赛总分   = 创新实践 × 30% + 现场决赛 × 70%
决赛创新实践分 A / B / C 三级（A>B>C），C 级取消后续资格
```

**需要学的知识栈（三赛项共有主干）**

| 层 | 内容 |
|---|---|
| 机械 | SolidWorks 建模、非标件设计与 3D 打印/激光切割、底盘（麦轮/差速/阿克曼）、机械臂正逆运动学、夹爪/推铲机构 |

| 控制 | **串级 PID**（速度环+位置环）、抗积分饱和、增益调度、循迹与航向控制 —— **这里直接用到你的《自动控制原理》** |

### 3.3 虚拟仿真赛道 —— 四个赛项，四种玩法

#### 3.3.1 飞行器设计仿真（北京航空航天大学承办）

| 项 | 内容 |
|---|---|
| 任务 | 「航空救援」50% + 「协同对抗」50%，任一任务都必须完成 |
| 编制 | 3 人：1 名指挥员（全局态势视角、标记规划）+ 2 名飞行员（第一人称操控） |
| 平台 | 北航「先进飞行器设计运用平台」，官网 jointcup.buaa.edu.cn（免注册访问） |
| 硬件 | 自备，建议 i5 520M+/8GB+/3060 显卡/Win10+；实际吃显卡 |
| 计分 | 救援：`G = 100×(0.7×效率 + 0.1×成本 + 0.2×安全)`；对抗：`E = ωr·R + ωs·S + ωa·A` |
| 特点 | 系统自动取多次仿真的**最佳成绩**；无编程要求；规模参考：2025 年约 300 所高校 3000+ 支团队备赛，实际参赛 2154 支 |
| 湖北批次 | **第二轮**：校赛 2027 年 3 月线上，省赛 2027 年 4 月线上 |

**需要学的**：航空器参数体系（航程/巡航速度/最大起飞重量/伤员容量与救援时间/水源载量/取水投水时间/物资载量/购置成本）、任务规划与资源调度、态势理解、临场沟通。**知识门槛低，但"熟练度+策略+配合"决定成绩。**

#### 3.3.2 智能网联汽车设计 ★ 与自动化最对口

| 项 | 内容 |
|---|---|
| 开发 | **Python 或 C++** 自主开发决策与控制算法，按标准协议接入仿真平台 |
| 内容 | ADAS（AEB 自动紧急制动 / LKA 车道保持 / APA 自动泊车）+ 无人驾驶 |
| 场景 | **41 个场景**：静态 6 + 单一动态目标 9 + 多目标协同 12 + 极端场景 9 + 多场景串联 4 + 连续赛道（含虚实融合） |
| 平台 | SimOne（`dc.nevc.com.cn`），提供传感器 API、高精地图 API、红绿灯 API、23 自由度车辆动力学模型 |
| 评分依据 | 《北京市自动驾驶车辆测试道路管理办法》《自动驾驶车辆道路测试能力评估与方法》《智能网联汽车自动驾驶功能仿真试验方法和要求》 |

## 5. 想借这个比赛「深入自动化」——可行性诊断与最优路径

### 5.1 先泼一盆冷水（这是实话）

工创赛**不是自动化专业课的延伸考试**。它的评分 70% 落在「现场初赛/决赛」的实物运行成绩上，考的是机构设计、加工装配、电控调试、临场应变。控制理论的直接占比并不高——比如太阳能电动车赛项**明令禁止任何电控转向和传感器**，等于把控制理论排除在外。

所以如果你的目标是"借比赛把《自动控制原理》《现代控制理论》学深"，正确做法是**挑一个控制权重最高的赛项**，而不是随便报一个。

### 5.2 控制权重排序（我的判断）

### 5.3 推荐路线（按推荐度）

这是本科生最高效的路径，理由：**硕士/博士论文（[D]）有完整的技术路线、参数、图表和调试细节，等于把别人的备赛报告读一遍**；期刊论文（[J]）更前沿但碎片化；综述用来建立全貌。

| 顺序 | 库 | 目的 | 数量 |
|---|---|---|---|
| 1 | 学位论文（硕士） | 建立技术路线与工程细节 | 精读 3–5 篇 |
| 2 | 学术期刊（北大核心/CSSCI/CSCD） | 掌握主流方法与评价指标 | 泛读 10–20 篇 |
| 3 | 会议论文 | 追最新热点 | 选读 |
| 4 | 综述类文献 | 建立领域地图 | 1–2 篇 |

**筛选技巧**：结果页先按「**被引**」排序锁定奠基文献，再按「发表时间」看近 3 年进展；左侧勾选「北大核心/CSCD」；学位论文优先选近 5 年、双一流高校。

### 7.4 阅读方法：三层漏斗

1. **第一层（15 分钟/篇）**：只看标题 → 摘要 → 结论。判断"要不要读"。
2. **第二层（1 小时/篇）**：看目录 → 技术路线图 → 关键公式 → 实验/仿真结果表 → 参考文献（顺藤摸瓜找 3–5 篇）。
3. **第三层（3–5 小时/篇）**：**只对你主攻方向精读 3–5 篇**，手推关键公式、复现仿真、记下"如果我做会改哪里"。

**必须建立的文献库字段**：`问题 → 方法 → 评价指标 → 数据集/平台 → 结论 → 可复现性 → 我的改进点`。用知网研学的笔记功能或用 Markdown 建表，一篇一行，累计 30 行你就有领域地图了。

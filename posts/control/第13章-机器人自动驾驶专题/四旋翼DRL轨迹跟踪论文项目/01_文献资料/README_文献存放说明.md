# 文献资料存放说明

本目录用于存放你手动检索下载的四旋翼 DRL 轨迹跟踪相关文献（PDF 格式）。

## 子目录分类规则

| 子目录 | 放什么 |
|--------|--------|
| 综述类 | Survey / Review 类文章，用于把握全局（如 Memlikai 2026、Chan 2024 仿真器综述） |
| 混合架构类 | 经典控制器打底 + DRL 增强的方法（增益调节、残差补偿、级联、持续学习） |
| 端到端类 | 策略网络直接输出电机指令的方法（Chen 2025、Zhao 2022 等） |
| 奖励设计与训练技巧 | 奖励函数设计、课程学习、域随机化、sim-to-real 相关 |

## 文件命名规范（重要）

下载的 PDF 请统一重命名为：

```
年份_第一作者姓氏_核心方法关键词.pdf
```

示例：
- `2025_Kong_DRL调节PID增益轨迹跟踪.pdf`
- `2026_GustPilot_分层DRL抗阵风.pdf`
- `2025_Chen_端到端RL底层控制.pdf`

## 查文献入口

详细检索方法见 `02_项目文档/文献检索指南.md`，里面有推荐的检索工具、搜索关键词和必读种子文献清单。

## 进度建议

第一批先下 8-10 篇种子文献（清单见检索指南），覆盖综述、混合架构、端到端三类即可开工。后续按需补充。

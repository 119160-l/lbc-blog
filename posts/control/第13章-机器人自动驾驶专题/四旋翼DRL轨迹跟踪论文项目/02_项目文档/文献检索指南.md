# 文献检索指南

> 目标：帮你高效找到、下载、整理本课题需要的文献。
> 原则：**先英文后中文，先综述后专论，先种子后扩展**。

---

## 一、用什么工具查（全部免费或有学校渠道）

| 工具 | 网址 | 用途 | 说明 |
|------|------|------|------|
| Google Scholar | scholar.google.com | 首选检索入口 | 覆盖面最广，能看到被引数；搜中文文献也好用 |
| Semantic Scholar | semanticscholar.org | 找高影响力论文 | 有 AI 摘要，能看引用关系图谱 |
| Connected Papers | connectedpapers.com | 顺藤摸瓜找相关论文 | 输入一篇种子论文，自动生成相关论文关系图，找文献神器 |
| arXiv | arxiv.org | 最新预印本 | 计算机/机器人方向最新工作都先挂这里，免费全文 |
| IEEE Xplore | ieeexplore.ieee.org | 机器人控制权威库 | 需要学校图书馆权限下载全文 |
| 学校图书馆数据库 | 你校图书馆官网 | 下载付费文献 | 一般可访问 IEEE、Springer、Elsevier、知网 |

**下载技巧**：
1. 优先找 arXiv 版本（免费）：Google Scholar 搜到论文后，看右侧有没有 arxiv.org 链接。
2. 付费文献走学校图书馆：校园网内直接下载，或用图书馆的校外访问系统。
3. 找不到全文时，把论文题目发给我，我帮你找开放获取版本。

## 二、用什么关键词搜

**英文关键词（主力，直接复制到 Google Scholar）**：

```

quadrotor trajectory tracking reward shaping
drone simulators reinforcement learning survey
deep reinforcement learning UAV flight control survey
```

**中文关键词（补充，搜知网/万方）**：

```
四旋翼 轨迹跟踪 深度强化学习
四旋翼 强化学习 PID 混合控制
无人机 强化学习 抗扰 控制
```

**搜索组合技巧**：
- 想找最新进展：关键词后加 `2024 2025 2026`
- 想找综述：关键词后加 `survey` 或 `review`
- 想找某篇论文的所有相关论文：在 Connected Papers 里输入该论文标题

## 四、下载后的命名与存放规范

**命名格式**：`年份_第一作者姓氏_核心方法关键词.pdf`

示例：
- `2026_Memlikai_RL无人机控制综述.pdf`
- `2026_GustPilot_分层DRL抗阵风.pdf`
- `2025_Kong_DRL调节PID增益轨迹跟踪.pdf`

**存放**：按上面清单指定的子目录放入。

**每篇下完后**（可选但推荐）：在论文 PDF 同目录不用建笔记，把论文文件名发给我即可，我来精读提炼。

## 五、查文献的实用流程（每篇都这么查）

1. Google Scholar 输入论文标题或检索词
2. 看被引数和年份：被引高 + 近三年的优先
3. 点标题进详情页，找 PDF 链接（优先 arXiv，其次学校图书馆）
4. 下载 → 重命名 → 放入对应子目录
5. 顺藤摸瓜：对特别相关的论文，丢进 Connected Papers 看它引用了谁、谁引用了它，能发现漏掉的重要文献

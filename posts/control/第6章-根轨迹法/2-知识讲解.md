### 承上启下

第5章我们学会了分析"参数已定"的系统。但工程中增益 $K$ 常常是可调的——**调 $K$ 会怎么影响稳定性？调到多大开始振荡？** 第5章的 Routh 判据能求 $K$ 的范围，但只能回答"稳不稳"，看不到"极点怎么走"。本章的根轨迹法**把闭环极点随 $K$ 的移动轨迹画出来**，==既能判稳（越虚轴即失稳）==，又能估计性能（极点位置→超调量、调节时间）。它是第5章"极点决定行为"的图形化延伸，也是第7章频域法的"兄弟方法"。

## 一、为什么要根轨迹？

### 为什么？

假设系统开环 $G(s)H(s) = \dfrac{K}{s(s+1)(s+2)}$。设计者想知道：**$K$ 从 0 调到 100，系统会不会失稳？什么时候开始失稳？** 逐点试 $K$ 太蠢，Routh 判据只能给"范围"。**根轨迹一次画出"全谱"**——所有 $K$ 对应的极点位置一目了然。

### 怎么做？

```
开环传函 G₀H  → 特征方程 1 + KG₀H = 0
→ 按绘制规则画出"闭环极点随 K 的轨迹"
→ 看轨迹：在哪穿越虚轴（临界 K）？主导极点在哪（性能）？
```

### 是什么？

> **根轨迹（Root Locus）**：增益 $K$ 从 0 到 $\infty$ 变化时，闭环极点（特征方程根）在 $s$ 平面上移动的轨迹。**它把"参数的连续变化"变成"极点的连续移动"，一次画完，全部信息在手。**

> 类比：用望远镜追踪一颗变轨卫星。开环极点是"发射台"（K=0），开环零点是"目的地"（K=∞），轨迹就是卫星的航线，穿越"领空边界"（虚轴）的时刻就是临界增益。

## 二、幅值条件与相角条件：根轨迹的 DNA

### 为什么？

根轨迹的本质是解特征方程 $1+KG_0H=0$。这个复方程拆成两个实方程，就是相角条件和幅值条件——**一切绘制规则都由它们翻译而来**。

### 怎么做？

复方程 $KG_0(s)H(s) = -1$：

| 条件 | 表达式 | 作用 |
|------|--------|------|
| 相角条件 | $\angle G_0H = \pm(2k+1)180^\circ$ | **决定轨迹的形状**（点在哪） |
| 幅值条件 | $K = \dfrac{1}{\lvert G_0H \rvert}$ | **决定轨迹上的参数**（K 是多少） |

### 是什么？

> **相角条件是根轨迹的"等相角线"**：满足它的所有 $s$ 点组成根轨迹。因为它不含 $K$，所以轨迹形状与 $K$ 无关，只由开环零极点位置决定。**这就是为什么画轨迹永远只看"零极点布局"。**

> 工程直觉：一个点在"右方有奇数个零极点"的实轴区段，相角自然满足条件（右侧每个贡献 $180^\circ$）。这就是实轴区段规则的来源。

![相角条件几何示意](./figures/01_相角条件几何示意.png)

*图 6-1 相角条件的几何验证：试验点 $s=-0.5+j0.866$ 到两个开环极点的矢量角之和为 $180^\circ$，满足条件 → 该点在根轨迹上。每个这样的点都对应某一个 $K$ 下的闭环极点。*

> **时间视角**：相角条件不含 $K$，说明**根轨迹的形状由系统"出生即定"（零极点布局决定），与增益无关**；$K$ 只负责"走多远"。就像一条固定的轨道，$K$ 是油门——**踩多深，极点走多远，时间响应就变多"急"**。

## 三、绘制规则：八条"几何翻译"

### 为什么？

直接逐点解相角条件太累。**把相角条件翻译成八条几何规则**，手绘即可完成，且规则之间互相印证。

### 怎么做？是什么？

| #   | 规则                                                                                  | 一句话                    |
| --- | ----------------------------------------------------------------------------------- | ---------------------- |
| 1   | 起点=开环极点，终点=开环零点                                                                     | $K=0$ 与 $K=\infty$ 的极限 |
| 2   | 分支数 = 开环极点数 $n$                                                                     | 特征方程阶数                 |
| 3   | 关于实轴对称                                                                              | 复根成对                   |
| 4   | 实轴区段：右侧零极点数**为奇数**                                                                  | 相角条件直接翻译               |
| 5   | 渐近线：$\varphi_a=\frac{(2k+1)180^\circ}{n-m}$，交点 $\sigma_a=\frac{\sum p-\sum z}{n-m}$ | 趋向无穷远的方向               |
| 6   | 分离点：$\sum\frac{1}{d-p_i}=\sum\frac{1}{d-z_j}$                                       | 重根处                    |
| 7   | 虚轴交点：$s=j\omega$ 代入令实虚部为零                                                           | 稳定边界                   |
| 8   | 出射角/入射角                                                                             | 复极/零点处切线方向             |

### 手绘流程（固定套路）

```
① 标出开环零极点（极点 ×，零点 ○）
② 画实轴区段（规则4）
③ 算渐近线（规则5）→ 画虚线方向
④ 求分离点（规则6）
⑤ 求虚轴交点与 Kcr（规则7）
⑥ 连成光滑曲线，标几个典型 K 值（幅值条件）
```

> **检查习惯**：每次画完自查——起点终点对不对？分支数够不够？关于实轴对称吗？四问通过，图基本没问题。

![典型系统根轨迹](./figures/02_典型系统根轨迹.png)

*图 6-2 按八条规则画出的典型根轨迹：$G(s)=K/[s(s+1)(s+2)]$。三个开环极点出发，一对共轭极点随 $K$ 增大向右移动，在 $K=6$ 处穿越虚轴（橙色圈）。越过这个点，极点进入右半平面，系统失稳。*

> **时间视角**：轨迹离开实轴的那一刻，极点变成共轭复根，响应开始出现振荡；轨迹到达虚轴，振荡从"衰减"变成"等幅"（临界）；再往右，等幅变发散。**根轨迹上最右边的点，就是时间上最"失控"的系统。**

## 四、根轨迹的应用

### 为什么？

画根轨迹不是目的，**用根轨迹做工程判断**才是。

### 怎么做？是什么？

**① 判断稳定性与临界增益**

轨迹穿越虚轴 → 记下交点 $\omega$ 与 $K_{cr}$：

| $K$ 范围       | 极点位置     | 稳定性   |
| ------------ | -------- | ----- |
| $0<K<K_{cr}$ | 全部左半平面   | ✅ 稳定  |
| $K=K_{cr}$   | 虚轴上有共轭极点 | ⚠️ 临界 |
| $K>K_{cr}$   | 出现右半平面极点 | ❌ 不稳定 |

==**② 估计动态性能**==

- ==**主导极点**（离虚轴最近、贡献最大）：$t_s \approx \dfrac{3}{\zeta\omega_n} = \dfrac{3}{|\sigma_{主导}|}$；==
- ==**等阻尼比线**：$\zeta$ 常数射线（与负实轴夹角 $\beta=\arccos\zeta$）——轨迹与某条 $\zeta$ 线相交，交点处即对应超调量 $\sigma\%$；==
- ==由幅值条件算出交点处的 $K$，就知道"要这个性能，K 该取多少"。==

> ==**设计闭环**：目标阻尼比线 ∩ 根轨迹 → 得极点位置 → 反推 $K$。这就是"根轨迹法设计增益"的完整逻辑（第8章还会用）。==

![根轨迹选点与响应验证](./figures/03_根轨迹选点与响应验证.png)

*图 6-3 "选点 → 看响应"的闭环验证：左图在根轨迹上取 $K=5$ 与 $K=8$ 两个点，右图显示对应阶跃响应——$K=5$ 收敛（极点还在左半平面）、$K=8$ 发散（极点已越过虚轴）。*

> **时间视角（全章点睛）**：设计者在根轨迹上"选点"，本质是在**挑选时间响应**：想要超调小 → 选靠近实轴的共轭复根；想要快 → 选离虚轴远的点；想要绝对安全 → 选 $K<K_{cr}$。**一条轨迹 + 一组响应 = "参数 ⇄ 性能"的完整地图。**

**③ 通俗版：主导极点、等阻尼比线与设计增益（零基础）**

别怕，你觉得难，是因为课本把**“工程简化”**和**“数学推导”**混在一起讲了。我把它拆成**三块积木**，你用生活的直觉去接住它，就会发现它比前面的根轨迹绘制还简单。

首先，请你把脑海里的复平面（根轨迹图）想象成一个**“操场”**：
- **横轴（实轴）** = 系统的“**衰减速度**”（离竖轴越远，刹车越猛）。
- **竖轴（虚轴）** = 系统的“**振荡频率**”（离横轴越远，抖得越快）。

---

**第一块积木：为什么只看“主导极点”？（老大法则）**

**课本说**：离虚轴最近的那个极点叫主导极点，调节时间只由它算。
**生活直觉**：
想象三个人一起抬一口大锅（系统响应）。力气最大、但跑得最慢的人（离虚轴最近的极点，衰减最慢）决定了这锅汤什么时候能平静下来。旁边两个力气小的（离虚轴远的极点）早就把活干完了，在那闲着等你。
**结论**：把离虚轴最近的极点找出来，它的位置横坐标是 $-\sigma$。代入公式：
$$
\boxed{t_s \approx \frac{3}{\sigma}}
$$
（比如这个点在横轴 -1.5 处，那 $\sigma = 1.5$，调节时间 $t_s \approx 3 / 1.5 = 2$ 秒。**超级好记：离竖轴越近，$\sigma$ 越小，时间越长！**）

---

**第二块积木：什么是“等阻尼比线”？（超调量探测器）**

**课本说**：从原点引出一条射线，与负实轴夹角 $\beta$，这条线上的阻尼比 $\zeta$ 都相等。
**生活直觉**：
你站在操场原点，往左上方看。这根视线抬得**越高（越靠近竖轴）**，系统振荡越猛（超调大）；这根视线抬得**越低（越靠近横轴）**，系统越平稳（超调小）。
**这个夹角 $\beta$** 和阻尼比 $\zeta$ 的关系是：**$\zeta = \cos\beta$**。

- 如果你想要超调 **4.3%（最佳阻尼 $\zeta=0.707$）**，你就从原点画一条 **45°（因为 cos45°=0.707）** 的射线。
- 如果这根 45° 射线正好穿过你画的根轨迹线，那么交点处的系统特性就是 **4.3% 超调**。

**记住**：你不需要画很多线，只需要知道——**当根轨迹穿过某条射线时，那个点的超调就是射线对应的值。**

---

**第三块积木：根轨迹法“设计增益”的完整逻辑（导航仪）**

把前两块积木拼起来，就是根轨迹设计的**终极闭环比对**。你把自己想象成一个“调音师”：

1. **你拿到任务**：领导说“给我调出个 **$\zeta = 0.707$**（超调 4.3%）的系统”。
2. **你找出尺子（画线）**：你在复平面上从原点画一条 **45° 的射线**（因为 $\cos 45°=0.707$）。
3. **你看交点（定位）**：你看着射线与根轨迹相交的那个点 **A**。这时候，点 A 的横坐标决定了响应速度（用 $t_s \approx 3/|\sigma|$ 算出来）。
4. **你反推增益（拧旋钮）**：这个点 A 对应的增益 K 是多少？
   - **操作**：拿尺子量一下 **“所有极点到点 A 的距离”**，乘起来；再量 **“所有零点到点 A 的距离”**，乘起来。
   - **K = (极点到A的距离乘积) / (零点到A的距离乘积)**。
   - **结论**：你把电路里的电阻调成这个算出来的 K 值，系统的超调量恰好就是 4.3%！

---

**第四步：用“导航仪”走一遍旧例子（可视化）**

我们还是用那个老系统 $G(s) = \frac{K}{s(s+1)(s+2)}$（之前画过图的）。

**设想场景**：你想要这个系统超调量小一点（比如 $\zeta = 0.5$，即 cosβ=0.5，β=60°）。

1. 你在根轨迹图上，从原点画一条 **60° 的射线**（朝左上方）。
2. 因为我们的根轨迹在 -0.423 分离点处就分叉朝 ±60° 飞了，你会发现这条 60° 射线**正好和根轨迹的渐近线方向重合**。
3. 这意味着，在很远很远的地方，这条 60° 线才会和根轨迹相交。
4. 你用量距离的方法算出那个遥远的交点对应的 K 值，就是实现 $\zeta=0.5$ 所需的增益。

> **如果你把 K 调得比这个值小**：根轨迹还没爬到 60° 线，阻尼比更大（更平稳但更慢）。
> **如果你把 K 调得比这个值大**：根轨迹跑到 60° 线外面去了，阻尼比更小（振荡更猛，甚至不稳定）。

---

**给你的“绝对防错”与“考试心得”**

1. **调节时间只看横坐标绝对值**：就算根是复数（比如 -2 ± 3j），也只看横坐标 **2**。$t_s \approx 3/2 = 1.5$ 秒。千万不要拿斜边长去算时间！
2. **与虚轴交点是“底线”**：之前算出来的临界 K=6，就是虚轴交点。任何设计出的 K 值，**绝对不能大于临界 K**，否则根跑到右边去，系统直接爆炸（不稳定）。
3. **考试答题话术（给你抄在答题卡上）**：
   > “为使系统具有满意的动态性能，根据主导极点法，忽略非主导极点的影响。在根轨迹图上作 $\zeta = 0.707$ 的等阻尼比线，读取其与根轨迹的交点 $s_1$，由幅值条件 $K = \prod |s_1 - p_i| / \prod |s_1 - z_j|$ 求得所需增益。”

现在闭上眼睛想一遍：**画线（定性能）→ 找交点（定位）→ 算距离（反推K）**。这套逻辑不仅在自控原理里用，你未来做工程调试，脑袋里也是这套流程。是不是瞬间感觉它高大上但其实很朴素了？😊

## 五、根轨迹法与 Routh 判据的对照

### 为什么？

两种工具都在判稳、求临界增益，理解它们的联系，才真正理解稳定性。

### 怎么做？是什么？

| 对比   | Routh 判据     | 根轨迹法               |
| ---- | ------------ | ------------------ |
| 原理   | 代数：特征方程系数排表  | 几何：极点移动轨迹          |
| 回答   | 稳定？临界 K 是多少？ | 稳定？**极点怎么走、K 多大**？ |
| 额外信息 | 无            | 极点位置→动态性能估计        |
| 适用   | 快速验算、参数范围    | 设计、可视化、性能权衡        |

**同一个临界值**：对 $G(s)=\frac{K}{s(s+1)(s+2)}$——Routh 求出 $K_{cr}=6$，根轨迹上轨迹恰好在 $s=\pm j\sqrt{2}$ 处穿越虚轴且该点 $K=6$。**两种方法答案完全一致，殊途同归**（练习题2.2与本章呼应）。

> 学习金句：**Routh 给答案，根轨迹给过程。** 考试题经常"先用根轨迹画图，再用 Routh 验证临界 K"。

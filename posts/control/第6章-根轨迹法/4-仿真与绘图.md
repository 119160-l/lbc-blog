## 图1 相角条件的几何意义

### 绘图代码

```python
"""第6章图1：相角条件验证"""
import numpy as np
import matplotlib.pyplot as plt
import matplotlib.patches as mpatches

plt.rcParams['font.sans-serif'] = ['PingFang SC', 'STHeiti', 'SimHei', 'DejaVu Sans']
plt.rcParams['axes.unicode_minus'] = False

fig, ax = plt.subplots(figsize=(7.5, 7))
ax.set_xlim(-3.5, 1.5); ax.set_ylim(-2.5, 2.5)
ax.axhline(0, color='k', lw=0.8); ax.axvline(0, color='k', lw=0.8)
p1 = (0, 0); p2 = (-1, 0); s_pt = (-0.5, 0.866)

ax.plot(p1[0], p1[1], 'x', ms=14, mew=3, color='#C62828')
ax.plot(p2[0], p2[1], 'x', ms=14, mew=3, color='#C62828')
ax.plot(s_pt[0], s_pt[1], 'o', ms=9, color='#1565C0')
ax.text(p1[0]-0.2, p1[1]-0.45, '极点 p1=0', color='#C62828', fontsize=10)
ax.text(p2[0]-0.2, p2[1]-0.45, '极点 p2=-1', color='#C62828', fontsize=10)
ax.text(s_pt[0]+0.12, s_pt[1]+0.12, '试验点 s', color='#1565C0', fontsize=10)

for p, ang in [((0,0), 120), ((-1,0), 60)]:
    ax.annotate('', xy=s_pt, xytext=p, arrowprops=dict(arrowstyle='-|>', color='#333', lw=1.6))
    arc = mpatches.Arc(p, 0.7, 0.7, angle=0, theta1=0, theta2=ang, color='#2E7D32', lw=1.4)
    ax.add_patch(arc)
ax.text(-1.25, 0.55, '相角之和 = 120°+60° = 180° ✓', fontsize=11, color='#2E7D32')
ax.set_title('相角条件验证：满足 ±(2k+1)180° 的点在根轨迹上', fontsize=12)
ax.grid(alpha=0.3); ax.set_xlabel('σ'); ax.set_ylabel('jω')
fig.tight_layout()
fig.savefig('figures/01_相角条件几何示意.png', dpi=150, bbox_inches='tight', facecolor='white')
plt.close(fig)
print('图1 已生成')
```

### 运行与结果

![相角条件几何示意](./figures/01_相角条件几何示意.png)

*图1 试验点 $s=-0.5+j0.866$ 到两个极点的矢量角分别为 120° 和 60°，和为 180°，满足相角条件 → 该点在根轨迹上。*

**现象解释**：这就是根轨迹的"筛选规则"——每个满足相角条件的点都是某个 $K$ 下的闭环极点。**逐点筛选太累，所以用八条规则直接"画出"整条轨迹。**

## 图2 典型系统根轨迹

### 绘图代码

```python
"""第6章图2：G=K/[s(s+1)(s+2)] 的根轨迹"""
import numpy as np
import matplotlib.pyplot as plt
import control

plt.rcParams['font.sans-serif'] = ['PingFang SC', 'STHeiti', 'SimHei', 'DejaVu Sans']
plt.rcParams['axes.unicode_minus'] = False

s = control.TransferFunction.s
G = 1/(s*(s+1)*(s+2))
fig, ax = plt.subplots(figsize=(8, 7))
control.root_locus(G, kvect=np.linspace(0, 30, 800), plot=True, ax=ax)
ax.set_xlim(-3.5, 1.5); ax.set_ylim(-3, 3)
ax.set_title('根轨迹：G(s) = K/[s(s+1)(s+2)]（K 从 0 到 30）', fontsize=12)
ax.axhline(0, color='k', lw=0.8); ax.axvline(0, color='k', lw=0.8)
for p in [0, -1, -2]:
    ax.plot(p, 0, 'x', ms=12, mew=3, color='#C62828')
ax.plot(0, np.sqrt(2), 'o', ms=8, color='#E65100'); ax.plot(0, -np.sqrt(2), 'o', ms=8, color='#E65100')
ax.annotate('穿越虚轴 s=±j√2, K=6', xy=(0, np.sqrt(2)), xytext=(0.7, 2.2),
            arrowprops=dict(arrowstyle='->', color='#E65100'), color='#E65100', fontsize=10)
ax.text(0.15, 1.4, '右半平面\n(不稳定)', fontsize=9, color='#C62828')
ax.text(-3.3, 2.7, '左半平面(稳定)', fontsize=10, color='#2E7D32')
fig.tight_layout()
fig.savefig('figures/02_典型系统根轨迹.png', dpi=150, bbox_inches='tight', facecolor='white')
plt.close(fig)
print('图2 已生成')
```

### 运行与结果

![典型系统根轨迹](./figures/02_典型系统根轨迹.png)

*图2 三个开环极点（红色 ×）出发，K 增大后其中一对共轭极点向右移动，在 $K=6$ 处穿越虚轴进入右半平面。*

**现象解释**：红色 × 是"发射台"（$K=0$），轨迹随 $K$ 增大而移动。穿越虚轴的点 $s=\pm j\sqrt2$ 对应 $K=6$——**这正是 Routh 判据得到的临界增益**。轨迹方向清楚地解释了"为什么 $K$ 太大会失稳"：极点被"推"进了右半平面。

## 图3 根轨迹"选点"与响应验证

### 仿真代码

```python
"""第6章图3：在根轨迹上选 K，看对应的阶跃响应"""
import numpy as np
import matplotlib.pyplot as plt
import control

plt.rcParams['font.sans-serif'] = ['PingFang SC', 'STHeiti', 'SimHei', 'DejaVu Sans']
plt.rcParams['axes.unicode_minus'] = False

s = control.TransferFunction.s
G2 = 1/(s*(s+1)*(s+2))
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(13, 5.5))

control.root_locus(G2, kvect=np.linspace(0, 30, 500), plot=True, ax=ax1)
ax1.set_xlim(-3.5, 1.5); ax1.set_ylim(-3, 3)
ax1.set_title('根轨迹：选择 K=5（稳定）与 K=8（失稳）', fontsize=12)
ax1.axhline(0, color='k', lw=0.8); ax1.axvline(0, color='k', lw=0.8)
for p in [0, -1, -2]:
    ax1.plot(p, 0, 'x', ms=12, mew=3, color='#C62828')

t = np.linspace(0, 8, 800)
for Kval, color, lab in [(5, '#2E7D32', 'K=5'), (8, '#C62828', 'K=8')]:
    sys = control.feedback(Kval*G2, 1)
    T, y = control.step_response(sys, t)
    ax2.plot(T, y, lw=2.2, color=color, label=f'K = {Kval}（{"稳定" if Kval==5 else "不稳定"}）')
ax2.axhline(0.2, color='k', ls=':', lw=1)
ax2.set_xlim(0, 8); ax2.set_ylim(-0.4, 0.8)
ax2.set_xlabel('t (s)'); ax2.set_ylabel('c(t)')
ax2.set_title('对应阶跃响应：K=5 收敛，K=8 发散', fontsize=12)
ax2.legend(fontsize=10); ax2.grid(alpha=0.3)

fig.tight_layout()
fig.savefig('figures/03_根轨迹选点与响应验证.png', dpi=150, bbox_inches='tight', facecolor='white')
plt.close(fig)
print('图3 已生成')
```

### 运行与结果

![根轨迹选点与响应验证](./figures/03_根轨迹选点与响应验证.png)

*图3 左：根轨迹上 $K=5$ 的点仍在左半平面（稳定），$K=8$ 已越过虚轴（失稳）；右：对应阶跃响应，K=5 收敛、K=8 发散。*

**现象解释**：这是"根轨迹→稳定性→时域响应"的完整闭环验证：**图上一点对应一个系统，其稳定性直接反映在响应曲线上**。这就是根轨迹法最直观的工程价值——设计时"选点"就能预测系统行为。

### 附：性能指标公式与物理理解对照

| 对比维度 | 公式与代入计算 | 通俗物理理解 |
| --- | --- | --- |
| 峰值时间（到达第一个峰值的时间） | $t_p=\dfrac{\pi}{\omega_d}$；$t_p=\dfrac{\pi}{0.866}\approx3.63$ s | 虚部 $\omega_d$ 越大，系统冲击回弹速度越快，峰值来得越早 |
| 超调量（振荡剧烈程度） | $\zeta=\dfrac{\sigma}{\sqrt{\sigma^2+\omega_d^2}}=\dfrac{0.5}{1}=0.5$；$\sigma\%=e^{-\frac{\pi\zeta}{\sqrt{1-\zeta^2}}}\approx16.3\%$ | 虚部相对于实部占比越大，极点与负实轴夹角越大，阻尼比越小，超调量越大 |
| 调节时间（系统彻底稳定下来的时间） | $t_s\approx\dfrac{3}{\sigma}=\dfrac{3}{0.5}=6$ s | **仅由极点实部绝对值 $\sigma$ 决定，和虚部无关**；实部越靠左，收敛速度越快 |

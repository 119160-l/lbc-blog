# 自动控制原理——完整学习路线框架

> 本框架基于《概率论与数理统计》模板优化而来，针对自动控制原理的学科特点（动态系统、反馈思维、强逻辑链、图形化分析）做了专项调整。
> 核心主线一句话：**认识系统 → 数学建模 → 分析系统 → 设计系统**。

---

## 〇、先看学科差异：为什么自动控制原理的学法不同于概率论

| 维度       | 概率论与数理统计             | 自动控制原理                          |
| -------- | -------------------- | ------------------------------- |
| **研究对象** | 不确定的随机现象             | 确定的动态系统（输入→系统→输出）               |
| **核心思维** | 统计思维（大量样本、规律）        | **反馈思维 + 动态思维**（因果、闭环、演化）       |
| **数学工具** | 排列组合、积分、期望方差         | **拉普拉斯变换、复变函数、微分方程**            |
| **主线逻辑** | 概率→分布→期望→估计→检验（横向铺开） | **建模→分析→设计（纵向链条，环环相扣）**         |
| **分析手段** | 以计算为主                | **计算 + 画图（Bode图、Nyquist图、根轨迹）** |
| **知识结构** | 各章相对独立               | **第5/6/7章三大方法互相印证、殊途同归**        |
| **工程属性** | 偏数学、偏统计              | 偏工程，需要仿真验证、结合实际系统               |

> **学习方法的推论**：
> 1. 自动控制原理是一门**强逻辑链**课程，前面章节没学好，后面寸步难行（尤其拉普拉斯变换），所以必须**按顺序学**；
> 2. 三大分析方法（时域、根轨迹、频域）表面是三章，实际上是**同一个问题的三种视角**，学完第7章必须回头做横向对比；
> 3. 画图和仿真不是可选项——Bode图、根轨迹必须亲手画过，抽象概念必须用 MATLAB / Python 仿真看过，才算真懂。

### 全课贯穿的"两条主线"

1. **暗线——稳定性**：第5章用 Routh 判据（代数法）→ 第6章看根轨迹是否越过虚轴（几何法）→ 第7章用 Nyquist 判据（频率法）→ 第11章看 A 矩阵特征值是否全部在左半平面（状态空间法）。**同一个问题，四种解法，学一章要回看上一章是怎么做的**。
2. **明线——性能指标**：动态性能（超调量、调节时间、上升时间）、稳态性能（稳态误差），每个分析方法都在算这些指标，三种方法之间可以互相换算（如相位裕度↔超调量）；第11章的 LQR 加权矩阵 Q、R 就是性能指标的最优形式。

## 二、篇章与章节详细规划

### 第零篇 思想启蒙

#### 第1章 自动控制的基本概念
- **解决什么问题**：什么是"控制"？为什么必须有"反馈"？
- **核心内容**：开环/闭环控制、反馈原理、输入量/输出量/扰动量、控制系统组成（被控对象、测量元件、控制器、执行机构）、控制系统方框图、对控制系统的基本要求（**稳、准、快**）。
- **生活案例**：恒温箱、水位自动调节、空调温控、汽车定速巡航、倒车入库。
- **本章精髓**：建立**反馈思维**——为什么闭环能自动纠偏？这是全课的"世界观"。
- **仿真任务**：用 Python/MATLAB 画一个开环与闭环系统在扰动下的对比图，直观感受反馈的价值。

### 第一篇 数学工具

#### 第2章 拉普拉斯变换与复变函数基础
- **解决什么问题**：微分方程太难解，需要一个工具把"微积分运算"变成"代数运算"。
- **核心内容**：
  - 拉氏变换定义与收敛域；
  - 常用变换表（单位阶跃、单位斜坡、指数、正弦、冲激）；
  - **三大性质**：线性、微分定理、积分定理、终值定理；
  - 拉氏反变换（**部分分式法**）；
  - 复变函数基础（极/零点、极点分布）。
- **本章精髓**：记住"**变换 → 代数运算 → 反变换**"三步走，这是全课一切传递函数运算的基础。**卡在这里=全课卡住**，务必练熟部分分式法。
- **仿真任务**：用 Python 的 `control` 库或手算对比，验证用拉氏变换解一阶、二阶微分方程的过程。

### 第二篇 系统建模

#### 第3章 控制系统的数学模型
- **解决什么问题**：要分析系统，先得能"描述"系统。
- **核心内容**：
  - 物理系统（电路、机械、电机）列写**微分方程**的步骤；
  - **传递函数**的定义（零初始条件下输出/输入拉氏变换之比）；
  - 典型环节：比例、积分、微分、惯性、振荡、延迟；
  - 非线性系统的**线性化**（泰勒展开取一阶）。
- **本章精髓**：掌握"**物理系统 → 微分方程 → 传递函数**"这条建模链；能一眼认出系统由哪些典型环节串联组成。
- **生活案例**：RC电路、弹簧-质量-阻尼系统、直流电机调速。
- **仿真任务**：对同一物理系统，分别列微分方程、写传递函数，并用仿真验证两者等价。

#### 第4章 结构图与信号流图
- **解决什么问题**：真实系统由多个环节组成，需要系统化的图形方法来表示和化简。
- **核心内容**：
  - 结构图的组成与四种基本连接（串联、并联、反馈、引出点/比较点移动）；
  - 结构图等效化简；
  - 信号流图与梅森增益公式。
- **本章精髓**：**梅森公式是必考点**——"前向通路 × 增益 / (1 - 回路和 + 两两不相交回路和 - …)"，掌握"画信号流图→套梅森公式"的固定套路。
- **仿真任务**：对一个复杂结构图，用化简法和梅森公式分别求闭环传递函数，结果对照。

### 第三篇 系统分析（全课核心）

> 三章是并列的三大分析方法，回答同一问题：**系统稳不稳？准不准？快不快？**
> 学习节奏建议：每学完一章，回头用上一章的角度重新解释一遍结论。

#### 第5章 时域分析法
- **解决什么问题**：最直观——直接在"时间"上观察系统对典型输入的响应。
- **核心内容**：
  - 典型输入信号（阶跃、斜坡、抛物线、正弦）；
  - 一阶系统的单位阶跃响应；
  - **二阶系统**（重点）：欠阻尼/临界/过阻尼/无阻尼，动态性能指标（上升时间、峰值时间、超调量、调节时间）与阻尼比、自然频率的关系；
  - 稳定性概念与 **Routh 稳定判据**（代数法）；
  - 稳态误差分析与误差系数（位置/速度/加速度误差系数），系统型别（0型、Ⅰ型、Ⅱ型）。
- **本章精髓**：**二阶系统是本课第一个"圣地"**——所有动态性能公式从这里来；区分"稳定性（前提）""动态性能（快）""稳态性能（准）"三个层次。
- **仿真任务**：画不同阻尼比（0.2/0.5/0.707/1/1.5）下二阶系统阶跃响应对比图，直观理解超调量与阻尼比关系。

#### 第6章 根轨迹法
- **解决什么问题**：时域分析假设参数固定。当增益 K 连续变化时，系统闭环极点怎么"走"？哪里会走出稳定区？
- **核心内容**：
  - 根轨迹概念与**幅值条件、相角条件**（180°根轨迹）；
  - 绘制规则：起点终点、对称性、实轴区段、渐近线、分离点、与虚轴交点；
  - 参量根轨迹；
  - 用根轨迹分析稳定性区间与动态性能估计。
- **本章精髓**：**相角条件 = 根轨迹的本质**；绘制规则其实是"把相角条件翻译成几何规则"；学会"由 K 求极点位置、由极点位置反推 K"。
- **仿真任务**：用 `control.root_locus()` 画典型系统的根轨迹，验证手绘结果，观察 K 变大极点如何穿越虚轴。

#### 第7章 频域分析法
- **解决什么问题**：很多系统难以精确建模，但能通过实验测出频率响应；频率法还能处理时域棘手的延迟、抗干扰、噪声问题。
- **核心内容**：
  - 频率特性概念（幅频/相频）；
  - 典型环节频率特性；
  - **Bode 图**绘制（对数坐标，叠加法）；
  - Nyquist 图绘制；
  - **Nyquist 稳定判据**（围绕 (-1, j0) 点）；
  - 稳定裕度：**相位裕度 γ、幅值裕度 Kg**；
  - 频域与时域性能的换算（如由 γ 估超调量）→ **与第5章交汇**。
- **本章精髓**：Bode 图是"基本功"，必须手绘熟练；Nyquist 判据理解"开环绕 (-1,0) 圈数 → 闭环稳定性"；**学完本章做三章对比总结**。
- **仿真任务**：用 `control.bode_plot()` 和 `control.nyquist_plot()` 画系统图，标注相位裕度和幅值裕度，与解析结果对照。

### 第四篇 系统设计

#### 第8章 控制系统的校正设计
- **解决什么问题**：分析发现系统不稳/太慢/超调太大 → 设计环节（校正）来改好它。**这是控制的最终目的——"设计"**。
- **核心内容**：
  - 性能指标与校正手段的对应关系；
  - **串联超前校正**（提相位裕度、加快响应）；
  - **串联滞后校正**（降稳态误差、牺牲速度）；
  - 超前-滞后校正；
  - **PID 控制**：P（比例）/I（积分）/D（微分）各自作用与整定思想；
  - 反馈校正、复合校正（前馈）。
- **本章精髓**：每个校正方法掌握"**为什么用它 → 设计步骤 → 验证指标**"三段流程；PID 是工程应用最广的控制器，值得理解到"直觉"层面。
- **生活案例**：恒温箱的 PID 温控、无人机姿态环、汽车 ABS。
- **仿真任务**：对同一个不达标系统，分别用超前、滞后、PID 校正，画校正前后阶跃响应对比，验证指标是否达标。

### 第六篇 现代控制（状态空间法）——机器人/自动驾驶算法工程师的"必修第二课"

> 目标方向是自动化算法、机器人、具身智能、自动驾驶——这些领域里，**状态空间法是绝对主流**：LQR、卡尔曼滤波、MPC、强化学习全都建立在状态空间之上。本篇是经典控制（传递函数）通往现代算法的桥。

#### 第11章 状态空间与现代控制
- **解决什么问题**：传递函数只能描述"外部输入→输出"，看不到系统内部；且只能处理单输入单输出（SISO）。真实机器人是多输入多输出（MIMO）系统，需要能描述**内部状态**的模型。
- **核心内容**：
  - 状态空间模型：$\dot{x}=Ax+Bu,\ y=Cx+Du$；从传递函数↔状态空间互化（能控标准型、能观标准型）；
  - 状态方程求解：矩阵指数 $e^{At}$；
  - **能控性、能观性**（机器人系统设计的前置检查，否则控制器/观测器白搭）；
  - **状态反馈与极点配置**（Ackermann 公式）——根轨迹的现代推广，"把极点放到指定位置"；
  - **LQR 最优控制**：$J=\int_0^\infty(x^TQx+u^TRu)dt$，Riccati 方程——"自动算出最好的 K"；
  - **状态观测器**（Luenberger）与分离定理，衔接卡尔曼滤波；
- **与经典控制的对话**：状态反馈的极点 = 闭环传递函数极点；LQR 是"校正设计的自动化"；特征值判稳 = Routh/根轨迹的现代版。
- **实践任务**：倒立摆线性化建模 + LQR 平衡控制（这是机器人/无人机姿态控制的标准模板）；直流电机位置控制从传递函数改写成状态空间。
- **仿真环境**：Python control 库 `ct.ss()`、`ct.lqr()`、`ct.acker()`，配合 PyBullet 倒立摆。

### 第七篇 数字实现——从"纸上算"到"机器里跑"

> 所有实际控制器都是单片机/DSP/计算机里跑的**离散算法**。学完连续控制必须跨到离散，否则永远停留在纸面。

#### 第12章 离散控制与数字实现
- **解决什么问题**：控制器是数字芯片，按采样周期工作，不是连续的。
- **核心内容**：
  - 采样与零阶保持器、采样定理（工程采样周期选择）；
  - **z 变换**与脉冲传递函数（和拉氏变换一一对应的"离散版"）；
  - 离散系统稳定性：z 平面单位圆 ↔ s 平面左半平面；
  - **数字 PID 实现**：位置式/增量式、积分分离、抗积分饱和、微分滤波（完整工程代码）；
  - 采样周期对性能的影响（仿真演示）；
- **实践任务**：写一个"手写数字 PID"驱动仿真直流电机/倒立摆；比较不同采样周期下的控制品质；实现抗饱和并对比"积分饱和"现象。
- **仿真环境**：纯 Python + control 库（`c2d` 离散化、`discrete` 系统仿真）。

### 第八篇 前沿实战——机器人、自动驾驶与具身智能

> 把前面全部知识投射到真实前沿场景。目标是**能动手跑通一个完整的机器人/车辆控制任务**。

#### 第13章 机器人/自动驾驶专题与倒立摆大项目
- **解决什么问题**：把"会做题"变成"会控车、会控机器人"。
- **核心内容**：
  - 移动机器人运动学：差速车、阿克曼车模型；
  - **路径跟踪**：纯跟踪（Pure Pursuit）、Stanley、PID 航向控制（自动驾驶横向控制入门）；
  - **车辆纵向控制**：定速巡航 PI 设计、ACC 自适应巡航思想；
  - **无人机姿态控制**：串级 PID（内环角速度 + 外环角度）；
  - **倒立摆大项目**（贯穿全课收官）：建模 → 时域/根轨迹/频域分析 → 超前校正/PID → 状态反馈/LQR → PyBullet 仿真跑通 →（可选）实物；
  - **具身智能衔接**：状态估计（卡尔曼滤波）、仿真环境（PyBullet/gym）怎么用；
- **实践任务**：PyBullet 里跑差速小车沿轨迹跟踪；倒立摆从"数学上稳住"到"仿真里稳住"。

#### 第14章 智能控制前沿（算法方向拓展）
- **解决什么问题**：经典控制解决"模型已知、规律清晰"的问题；现实（自动驾驶复杂路况、机械臂抓取、无人机集群）模型难建、环境复杂——需要更智能的控制。
- **核心内容**：
  - **MPC 模型预测控制**：滚动优化 + 约束处理，自动驾驶车辆控制的主流方案（与 LQR 对比、与 PID 对比）；
  - **模糊控制**：规则式控制（倒车入库、洗衣机、自适应巡航），理解"专家经验数字化"；
  - **神经网络/自适应控制**：系统辨识、NMPC 简介；
  - **强化学习与控制的衔接**：MDP 建模、策略梯度/DQN 直觉、**LQR 就是最简单的 RL（线性二次型 + 动态规划）**——打通"控制"与"AI"的桥；
  - **自动驾驶/具身智能全景**：感知→状态估计→决策→控制，各层用什么工具；
- **实践任务**：用 Python 实现小车强化学习（gym 环境）或 PyBullet 机械臂抓取；写一个简单的 MPC 对比 LQR。
- **学习路线衔接**：本篇之后可无缝进入《机器人学》《状态估计》《深度学习》《强化学习》等进阶课程。
- **延伸路线**：对照大厂（宇树/大疆）招聘要求整理的《[补充篇-本科到机器人算法方向的延伸路线](./补充篇-本科到机器人算法方向的延伸路线.md)》，含四条主线知识地图、本科→985读研→大厂时间线、作品集三台阶与书单。

### 第九篇 强化学习实战——从 Q-learning 到 DQN/PPO（"深度强化学习算法工程师"的入门篇）
- **解决什么问题**：第14章的表格 Q-learning 只适用于离散、低维状态；真实机器人状态连续高维、动作连续——需要"深度强化学习"。
- **核心内容**：
  - **DQN**：神经网络函数逼近替代查表、经验回放、目标网络（"三大法宝"）；
  - **策略梯度**：直接输出连续动作（力矩/油门），REINFORCE 与 baseline；
  - **PPO**：重要性采样 + clip 截断代理目标——OpenAI、宇树、大疆的工业默认算法；
  - **sim-to-real**：域随机化、课程学习、分层架构（RL 大脑 + 经典控制小脑）；
  - **深化"LQR=最简单 RL"**：Riccati 解析解 vs 试错数值解；
- **实践任务**：纯 numpy 手写 DQN/PPO，在倒立摆上完成"从 20 分到 194 分"的训练；改参数实验（目标网络同步、探索衰减、PPO clip）。
- **学习路线衔接**：本章用纯 numpy 打通思想后，即可无痛切换 PyTorch + gymnasium 做标准实验，再进阶模仿学习（BC/ACT/Diffusion Policy）与世界模型/VLA。

## 三、三大分析方法横向对比（第9章专题预览）

| 对比维度 | 时域分析法（第5章） | 根轨迹法（第6章） | 频域分析法（第7章） |
|----------|---------------------|-------------------|---------------------|
| **观察角度** | 时间 t | 复平面 s（极点的走位） | 频率 ω |
| **基本工具** | 拉氏反变换、微分方程 | 幅值/相角条件 | 频率特性、Bode/Nyquist 图 |
| **稳定性判断** | Routh 判据 | 根轨迹是否越过虚轴 | Nyquist 判据 |
| **动态性能** | 直接算超调量、调节时间 | 由极点位置估计 | 由相位裕度 γ 换算 |
| **稳态性能** | 误差系数、型别 | 由增益 K 相关 | 由低频段斜率/增益 |
| **最大优势** | 直观、物理意义清晰 | 看清参数变化对极点的影响 | 抗干扰/噪声、实验建模、适用于难建模系统 |
| **最大局限** | 只能分析参数固定系统 | 绘制较繁琐 | 相对抽象 |

> **学习金句**：三条路到同一个终点，考试最爱考"用三种方法分析同一个系统"——这就是第9章综合案例的设计初衷。

### 相对概率论模板的优化点

1. **新增 `4-仿真与绘图.md`**：自动控制原理高度图形化、工程化。每章用 MATLAB / Python (`control`, `numpy`, `matplotlib`) 画核心图（阶跃响应、根轨迹、Bode 图、Nyquist 图、校正前后对比），"画过才算懂"。

### 动手实践学习法（重点！光看不练等于没学）

> 控制是"动手的学问"：**先推公式 → 再看图 → 再亲手改参数 → 再故意破坏系统 → 再连成系统**。每章末尾的"动手实践"小节和 `4-仿真与绘图.md` 就是为此设计。

| 实践层次 | 做什么 | 学到什么 |
|----------|--------|----------|
| L1 改参数 | 把仿真里的 K、ζ、T、Q/R 改大改小，看曲线怎么变 | 参数的"手感" |
| L2 破坏 | 故意把极点移到右半平面、把裕度调成负的 | 边界在哪、为什么 |
| L3 造坑 | 加扰动、加噪声、加延迟，看控制系统扛不扛得住 | 真实系统为什么难控 |
| L4 连系统 | 把各章工具连成"建模→分析→设计→验证"闭环 | 工程能力 |
| L5 真机/仿真环境 | PyBullet 里跑小车、倒立摆、机械臂 | 从数学到物理 |

## 六、易错点提前预警（贯穿全课）

| 易错点 | 正确认识 |
|--------|----------|
| 拉普拉斯变换的终值定理滥用 | 终值定理要求系统**稳定**（极点左半平面）才能用 |
| 传递函数与输入信号混淆 | 传递函数只描述系统本身，与输入无关 |
| 结构图化简顺序乱套 | 引出点/比较点移动时，同位置同时动先化简再处理 |
| 二阶系统公式套错 | 分清是欠阻尼（0<ζ<1）才有的超调量公式 |
| Routh 判据出现全零行 | 用辅助方程处理（临界稳定） |
| 根轨迹相角条件方向搞反 | 180°根轨迹相角条件：相角之和 = (2k+1)·180° |
| Bode 图叠加法丢环节 | 先画各典型环节，再叠加；注意转折频率顺序 |
| Nyquist 判据绕过 (-1,0) 计数 | 计数按**包围 -1 点的净圈数**，方向逆时针为正 |
| 相位裕度 γ 的大小判断 | γ>0 且越大越稳，但 γ 过大响应变慢，工程上通常 30°~60° |
| PID 整定无章法 | 先 P 后 I 后 D，一步步来，每次只动一个参数 |

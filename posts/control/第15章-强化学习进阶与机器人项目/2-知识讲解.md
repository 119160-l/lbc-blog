## 一、为什么从表格到神经网络？

### 1.1 表格的天花板（复习第14章）

| 维度 | 表格 Q-learning | 现实需求 |
|---|---|---|
| 状态 | 离散 13×13=169 格 | 连续：关节角、角速度、IMU、图像（$10^6$+ 维） |
| 动作 | 离散 {左推,右推} | 连续：电机力矩、油门、舵机角度 |
| 泛化 | 无：没访问过的格子永远学不到 | 必须泛化到未见状态 |

**结论：真实机器人根本没法查表。** 但 Q-learning 的"奖励驱动"思想完全正确——缺的只是把"表"升级成"能插值、能泛化的函数"，这就是**函数逼近**。

**表格还有第二道坎：分辨率。** 把连续状态切成格子，状态落在格子边缘时会被"量化"到格心——倒立摆角度范围 ±0.8 rad 只分 13 档，每档宽约 0.06 rad，这一格化误差就是**信息丢失**（控制器能分辨的精度被焊死，可能让状态"看起来"偏离平衡更远）。DQN 直接吃连续浮点状态，没有量化损失。**表格输在两点：相邻格子之间无法互相借鉴（无泛化）、单格内部被粗暴平均（量化损失）**——这正是图 15-2 中 138 分 vs 194 分差距的两个来源。（对应练习题13）

![表格RL与神经RL对比](./figures/02_表格RL与神经RL对比.png)

*图 15-2 相同倒立摆环境下的正面硬碰：Q-learning（表格 13×13）后50回合平均 138 分、约 250+ 回合才首次满分；DQN（2→16→2 网络）后50回合平均 194 分、第 77 回合就满分。唯一的变量是"状态怎么表示"——查表 vs 函数逼近。*

### 1.2 DQN 的三个法宝

**法宝一：神经网络函数逼近。** $Q(s,a;\theta)$ 是一个 2 输入、16 神经元、2 输出的 MLP（和第14章手写的 MLP 一模一样）。相邻状态输出相近的 Q 值 → **自动泛化**：学到 $(-0.2,0.5)$ 附近要往右推，$(-0.3,0.6)$ 附近也懂。

**法宝二：经验回放（Experience Replay）。** 神经网络的梯度下降假设样本**独立同分布**，但 RL 的相邻样本高度相关（连续几步动作相近）。把每一步 $(s,a,r,s')$ 存进缓冲池，训练时**随机抽样 64 条**——打散相关性，数据还能反复用（样本效率↑）。

**法宝三：目标网络（Target Network）。** 训练时"目标值 $y=r+\gamma\max Q_{\theta^-}$"如果每次都拿自己算，等于"狗追自己尾巴"——越追越乱。于是冻结一份旧参数 $\theta^-$ 当"慢腿"，每隔 10 回合才同步一次，训练瞬间稳定。

> 实测（`第15章绘图.py`，同一倒立摆环境）：Q表格 后50回合平均 138 分，DQN **后50回合平均 194 分**且**第77回合首次拿满 200 分**。连续状态输入 + 泛化，就是 DQN 全面胜出的原因。

![DQN训练曲线](./figures/01_DQN训练曲线.png)

*图 15-1 DQN 训练曲线：蓝点=每回合得分（噪声大），红线=20 回合滑动平均——RL 训练要看趋势不看单点。前 50 回合平均 20 分（开局就倒），后 50 回合平均 194 分，第 77 回合首次满分。*

## 二、从"值"到"策略"：策略梯度

### 2.1 值方法的天花板：动作必须离散

DQN 输出层给每个**离散动作**一个 Q 值（推左 3.2 / 推右 1.8）。可真实舵机要输出"连续角度 37.4°"，不可能为每个角度开一个神经元。

### 2.2 换一种问法

> 值方法问：**"在状态 s 下，哪个动作价值最高？"**
> 策略方法问：**"在状态 s 下，我该以多大概率选每个动作？"**

策略网络直接输出动作（均值 $\mu$）+ 探索噪声（$\sigma$）——**连续动作空间天然兼容**。

### 2.3 一行直觉

$$
\text{策略梯度} = \text{"这个动作比平均好多少"} \times \text{"朝哪个方向调参能多选它"}
$$

对应代码就三行：

```python
Adv = G - V.forward(S)                       # 优势：比 baseline 好多少
dOut = (Adv * (A - mu) / sigma**2)           # 梯度：动作越"正确"越推 μ 靠近它
pi.sgd(S, dOut, lr)                          # 朝梯度方向更新网络
```

![策略梯度连续控制](./figures/03_策略梯度连续控制.png)

*图 15-3 策略梯度 REINFORCE：动作不再是"推左/推右"，而是连续力矩。后50回合平均 190 分——一回合 200 步里策略每步输出不同的连续力矩，这是 DQN 做不到的（动作空间连续）。*

### 2.4 为什么能对"策略"求梯度：log 导数技巧

策略梯度定理的完整推导（公式推导 §3.2a）用到一个关键技巧：$\nabla\pi=\pi\,\nabla\log\pi$。它为什么有用？因为 $\pi$ 可能是一个很复杂的函数（神经网络），但 $\log\pi$ 把它"拆开"后，梯度变成了一个**只跟"这个动作被选中的概率往哪个方向变"有关**的简单表达式。

直觉：你想让"好动作"更常被选，就得知道"往哪个方向调参，能让这个动作的概率变大"。$\nabla\log\pi(a|s)$ 正是这个方向——**它把"调整整个策略"这个抽象目标，落到了"对每个具体动作算一个方向"**。这就是策略梯度能处理连续动作的根本原因：动作不再是一个个离散格子，而是"概率密度里的一个点"，梯度直接告诉你怎么挪它。


## 三、REINFORCE → PPO：三个版本的演进

| 算法 | 核心思想 | 优点 | 缺点 |
|---|---|---|---|
| **REINFORCE**（纯蒙特卡洛） | 一回合打完，用总回报调整策略 | 简单、无偏 | 方差大（同一策略不同回合结果差很多） |
| **+ baseline（本章实现）** | 用值网络 $V(s)$ 当"及格线"，只学"超额部分" | 方差大降 | 仍需完整回合，样本利用率低 |
| **PPO**（截断代理目标） | 同一批数据多更新几次，但 clip 限制步子 | 样本效率高、稳定 | 超参多（clip 值、epochs） |

> 类比：REINFORCE 像"考完试才改错题"（一回合才更新一次）；PPO 像"边做边改，但每次最多只改一点点，防止改过头"。

### Actor-Critic：演员和评论家的分工

上面表格里"REINFORCE → PPO"中间还隔着一个重要节点 **Actor-Critic**：把"算奖励的"和"做决策的"分成两个网络。

- **Actor（演员）**＝策略网络：上台表演，负责"在每个状态该做什么动作"；
- **Critic（评论家）**＝值网络：坐在台下，负责"刚才这步走得好不好"（实时打分）。

REINFORCE 要等整回合打完才知道输赢（演员演完整场才拿到点评）；Actor-Critic 让评论家**边看边打分**（TD 误差），演员随时调整。**"实时反馈"就是它比 REINFORCE 样本效率高的原因**——而 PPO 又在此基础上加了"步子别迈太大"的 clip，才最终登顶。


## 四、为什么 PPO 是工业界默认算法？

1. **稳**：clip 把每次更新的"油门"焊死在 ±20%，策略不会突然崩坏（第14章调 Q-learning 时 lr 一大就震荡，同样的坑 PPO 用 clip 主动规避）；
2. **样本效率高**：同一批数据用 3 个 epoch 反复学习，比 REINFORCE 省 3 倍交互；
3. **实现简单、调参少**：OpenAI 把它做成 Stable-Baselines3 默认算法，宇树（双足/四足决策）、大疆（决策规划 NN 方向）的算法岗 JD 里 RL 岗位基本都点名 PPO；
4. **兼容连续动作**：高斯策略直接输出力矩/油门。

> 实测（同环境）：PPO **第18回合就首次拿到满分 200**（爆发极早），REINFORCE 要磨到 100 回合后；两者最终都能学会，但 PPO 的"早期爆发 + clip 保护"正是它工业地位的来源。

![PPO与REINFORCE对比](./figures/04_PPO与REINFORCE对比.png)

*图 15-4 PPO vs REINFORCE：PPO 第 18 回合爆发到满分（同一批数据用 3 个 epoch，样本效率约 3 倍）；REINFORCE 后50回合平均更高（190 vs 167）但学得慢。把 lr 调大 2 倍再跑：REINFORCE 易发散，PPO 因为有 clip 依然稳——这就是"工业默认算法"的底气。*

### PPO 里的另一个隐形技巧：GAE

很多人只知道 PPO 的 clip，却不知道 PPO 论文里**优势函数用的是 GAE（广义优势估计）**。GAE 解决一个两难：用"整回合回报"当优势无偏但方差大（一局打很久、结果波动大），用"一步 TD 误差"当优势方差小但有偏（只看眼前）。

GAE 用一个参数 $\lambda$ 调和：$A^{\mathrm{GAE}}=\sum(\gamma\lambda)^k\delta_{t+k}$。$\lambda=0$ 就是"只看一步"，$\lambda=1$ 就是"看到回合结束"，工程上取 $\lambda\approx0.95$——**既看得够远（学到长期回报），又不至于被一局的运气带偏（方差可控）**。一句口诀：**clip 管"步子多大"，GAE 管"看得多远"**，两者合起来才是完整的 PPO。


## 五、RL 与 LQR/MPC：深化"LQR=最简单的强化学习"

第14章我们建立了术语映射表，本章用训练曲线把它"坐实"：

| 概念 | 经典控制 | 强化学习 |
|---|---|---|
| 目标 | 代价函数 $J=\int(x^TQx+u^TRu)dt$ | 奖励 $r=-x^TQx-u^TRu$ |
| 求解 | Riccati 方程（解析） | 试错更新（数值） |
| 适用范围 | 线性、已知模型 | 非线性、模型未知（甚至只看图片） |
| 类比 | 拿着地图规划 | 蒙着眼睛摸路 |

**一句话：LQR 是"已知模型时 RL 的解析解"，RL 是"没模型时 LQR 的数值解"。** 这正是为什么宇树的运动控制器是"底层 LQR/MPC 平滑 + 高层 RL 决策"——两条腿走路。

## 六、sim-to-real：仿真学的怎么上真机

训练在仿真里做（便宜、安全、快），部署在真机——中间隔着"仿真与现实差异（Sim2Real Gap）"。三大对策：

1. **域随机化**：每次训练随机改摩擦、质量、控制延迟，让策略学会"不管环境怎么变都稳"——相当于给策略"打过疫苗"；
2. **课程学习**：先学简单（小扰动、慢速），再逐步加压；
3. **分层架构**：RL 输出高层指令（"迈左腿"），底层由 MPC/PID 平滑执行——仿真学的"大脑" + 经典控制的"小脑"。

![RL 训练管线](./figures/05_RL训练管线全景.png)

*图 15-5 强化学习训练管线：环境（倒立摆/真机）产出交互数据 → 存入回放池 → 学习器用 batch 梯度更新策略/值网络 → 参数回流智能体 → 最终部署真机。数据在循环，参数在学习。*

- 第14章的 Q-learning 是"在线单条更新"（学一条丢一条）；
- 本章 DQN 加了**回放池**（数据复用）、PPO 加了**batch 多次更新**（样本效率）——**三者共享同一条"奖励驱动的试错"主线，这就是"强化学习"四个字的全部秘密。**

> 本章代码**全部纯 numpy 手写**（无 PyTorch/gymnasium 依赖），改参数就能做实验。

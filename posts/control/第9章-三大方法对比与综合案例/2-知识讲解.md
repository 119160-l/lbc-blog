# 第9章 三大方法对比与全流程综合案例——知识讲解

> **本章内容**
> 
> 1. 为什么要有"综合案例"：从会解题到会工程
> 2. 三大方法总对比：三副眼镜看同一台机器
> 3. 综合案例：直流电机调速系统全流程
> 4. 工程思维：验证、迭代、鲁棒性

### 承上启下

前8章把每个工具都学了一遍，但工具是"散装"的。本章把它们**焊成一条流水线**：物理建模 → 传递函数 → 时域分析 → 根轨迹分析 → 频域分析 → 发现不达标 → 校正设计 → 仿真验证。**目标只有一个：以后给你任何系统，你都能独立走完这条流水线。**

### 问题导向

带着以下问题学习本章，你会更有方向感：

1. **同一个系统，时域、根轨迹、频域三种方法给出的"稳定性结论"为什么必然一致？**
2. **综合案例中，为什么先做时域、再做根轨迹、最后频域？顺序可以换吗？**
3. **如果三种方法验证结果不一致，说明什么问题？该怎么处理？**

## 一、为什么要有"综合案例"？

### 为什么？

单章练习题是"零件"，综合案例是"整机"。**真正的工程能力 = 在合适的时间调用合适的工具**。本章用一个直流电机调速系统，逼你把所有工具用一遍——就像毕业设计/工程实训的"预演"。

### 怎么做？（全流程流水线）

```
物理建模 → 求传递函数 → 时域分析 → 根轨迹分析 → 频域分析
   → 发现不达标 → 校正设计 → 仿真验证 → （不达标则回到校正迭代）
```

### 是什么？

> **综合案例**：一个完整系统的"从零到达标"全流程。它强迫你回答三个问题：**系统是什么（建模）？系统好不好（分析）？不好怎么办（设计）？**

![全流程流水线](./figures/04_全流程流水线.png)

*图 9-4 七步流水线：物理建模 → 时域 → 根轨迹 → 频域 → 发现问题 → 校正设计 → 仿真验证。每一步对应一章工具，不达标就回到第6步迭代。*

> **时间视角**："发现问题"用的是频域语言（$\gamma<45°$），"验收达标"用的是时间语言（$\sigma\%$、$t_s$）——**设计用频域/复域工具，验收回到时间响应**，这就是工程师的工作节奏。

## 二、三大方法总对比：三副眼镜

### 为什么？

三种方法本质是**同一个系统在不同"坐标系"下的投影**。理解了这一点，你就永远不会再把它们当成三门课。

### 怎么做？是什么？（总对比表）

| 对比维度       | 时域分析法（第5章） | 根轨迹法（第6章）   | 频域分析法（第7章）        |
| ---------- | ---------- | ----------- | ----------------- |
| **观察角度**   | 时间 t       | 复平面 s（极点走位） | 频率 ω              |
| **基本工具**   | 拉氏反变换、微分方程 | 幅值/相角条件     | 频率特性、Bode/Nyquist |
| **稳定性**    | Routh 判据   | 根轨迹是否越虚轴    | Nyquist 判据 / 裕度   |
| **动态性能**   | 直接算 σ%、ts  | 极点位置估计      | γ、ωc 换算           |
| **稳态性能**   | 误差系数、型别    | 增益 K        | 低频段斜率/增益          |
| **最大优势**   | 直观、物理意义清晰  | 看清参数变化的影响   | 实验建模、抗噪声          |
| **最大局限**   | 参数固定才能算    | 绘制繁琐        | 相对抽象              |
| **"稳"的语言** | Routh 表    | 左半平面        | γ>0、Kg>0          |
| **"准"的语言** | ess、型别     | K           | 低频增益              |
| **"快"的语言** | σ%、ts      | ζ、ωn        | γ、ωc              |

### 一个灵魂类比

| 方法 | 类比 |
|------|------|
| 时域 | **录像带**：完整记录过程，最直观 |
| 根轨迹 | **导航地图**：看"极点"往哪儿走，预测未来 |
| 频域 | **体检报告**：扫一扫就知道哪里虚（γ 不够）、哪里亢（谐振峰） |

![三大方法三副眼镜](./figures/01_三大方法三副眼镜.png)

*图 9-1 三副眼镜的比喻：时域法看"响应曲线"（录像带）、根轨迹法看"极点走位"（导航地图）、频域法看"频率特性"（体检报告）。三副眼镜看同一台机器，结论必然一致。*

> **时间视角**：其中只有时域法是"直接看时间"，另外两副都是"间接预言时间"——根轨迹用极点预言响应形态，频域用裕度预言振荡收敛快慢。**戴上任何一副眼镜，最终都要回到时间曲线上兑现。**

> **学习金句**：**"稳"是底线（三者都判），"准"是低频的事（三者都看增益/型别），"快"是中频的事（三者都盯穿越/极点）。** 三副眼镜最终看到的是同一件事。

> **补充：三大方法的分析顺序可以换吗？（对应练习题 2.4）**——可以换。三大方法是**并列的三种视角**，对同一个已建模系统回答同一套问题（稳、准、快），信息等价、结论一致，所以先做时域还是先做频域，顺序不影响最终结论。唯一的例外是**校正设计**：校正装置（超前/滞后）的参数由频域量（$\gamma$、$\omega_c$）计算得出，所以必须先做频域分析测出 $\gamma_0$、$\omega_{c0}$，才能设计 $G_c(s)$；设计完再用时域验证响应。此时"频域在前、时域验证在后"是逻辑必然。

## 三、综合案例：直流电机调速系统全流程

### 3.1 建模（第3章）

**问题**：直流电机电枢控制，输入电枢电压 $u_a$，输出转速 $\omega$。

**推导**（详见 1-公式推导.md）：电路方程 + 转矩方程 → 消中间变量 → 简化得一阶模型；考虑驱动器惯性后取经典三阶：

$$
G(s)=\frac{K}{s(s+1)(s+4)}
$$

> 理解：**积分环节** = 转速是电压的"积累"（电压一直在，转速就持续涨）；**两个惯性环节** = 电枢惯性 + 机械惯性。

### 3.2 时域分析（第5章）

- **Routh 判据**：$0<K<20$（否则不稳定）；
- **稳态误差**：Ⅰ型系统，速度输入时 $e_{ss}=1/K$；
- **取 K=6**：查仿真得 σ%≈50%、ts≈5s——**超调太大、太慢**，不达标！

### 3.3 根轨迹分析（第6章）

- 渐近线：$-\frac{5}{3}$ 处、$\pm60°$；
- 分离点 $d\approx-0.47$；虚轴交点 $\pm j2$（$K=20$）；
- **根轨迹告诉我们**：K 太大（>20）极点进右半平面 → 失稳；K 太小响应慢。**可调范围就这么窄，这就是"为什么需要校正"的根轨迹视角。**

### 3.4 频域分析（第7章）

- 画 Bode 图：低频斜率 $-20$ dB/dec（Ⅰ型）、穿越频率 $\omega_c$ 处读 $\gamma$；
- **K=6 时 γ≈28°<45°**（仿真验证）——**不达标**；
- 频域还告诉我们：想提 γ 就得把 $\omega_c$ 左移或加相位 → 选**超前校正**。

![综合案例三法分析](./figures/02_综合案例三法分析.png)

*图 9-2 $K=6$ 时的三法分析：①根轨迹——极点全在左半平面（稳定）；②Bode——$\gamma\approx30°<45°$（不达标）；③阶跃响应——超调约 50%（不达标）。三法一致：稳定但"脆"且"慢"。*

> **时间视角**：右图那条"冲高又晃"的曲线，就是中图 $\gamma$ 太小在时间域的"真身"——**同一件事，频域叫"裕度不够"，时域叫"超调过大收不住"**。

### 3.5 校正设计（第8章）

设目标 $\gamma\ge45°$，超前校正：

$$
\varphi_m = 45°-28°+12° = 29°,\quad a=\frac{1+\sin29°}{1-\sin29°}\approx 3.0
$$

在原幅频上找 $-10\lg a$ 处频率定 $\omega_m$，求 $T$。校正装置：

$$
G_c(s)=\frac{1+aTs}{1+Ts}
$$

### 3.6 仿真验证（三法核对）

| 方法  | 验证内容       | 结果                     |
| --- | ---------- | ---------------------- |
| 时域  | 阶跃响应 σ%、ts | 达标（σ% 降到 30% 以下、ts 缩短） |
| 根轨迹 | 闭环极点位置     | 主导极点 ζ≈0.5、全部左半平面      |
| 频域  | γ、Kg       | γ≈43°~50°、Kg>6dB       |

> 若三法一致 → 设计可靠；若不一致 → 回查哪一步算错。**这就是工程师的自检闭环。**

![校正前后三法验证](./figures/03_校正前后三法验证.png)

*图 9-3 校正前后三法验证：左图时域——超调下降、调节时间缩短；中图根轨迹——极点左移更稳；右图频域——$\gamma$ 从 30° 提到 44°。三个独立视角同一个结论：达标。*

> **时间视角（全章点睛）**：对比图 9-2 和图 9-3 左图——**校正把"又冲又晃"变成"稳而快"**。所有频域/复域工具，最终都回到"时间曲线好不好看"这一个标准。

## 四、工程思维：验证、迭代、鲁棒性

### 为什么？

做完案例，你会发现工程设计的真实状态：**一次成功是运气，迭代才是常态**。

### 怎么做？

1. **验证永远比计算重要**：算完必须仿真/实验验证；
2. **不达标就迭代**：γ 差一点 → 加大 φm 再算一遍；超调大 → 降 K 或加 D；
3. **考虑鲁棒性**：模型参数（J、b、Ra）会漂移，设计时留足裕度（γ 留 5°~10° 余量）；
4. **噪声与饱和**：D 项和高频增益会放大噪声，控制器输出有饱和——工程细节，但决定成败。

### 是什么？

> **工程闭环 = 设计 → 验证 → 迭代 → 再验证**，直到所有指标达标且有余量。这条闭环，就是本书想让你带走的最重要的"软件"。

> **补充：反馈校正为什么能"洗掉"参数变化的影响？（对应练习题 3.1、3.3）**——局部反馈的等效传递函数为 $G_{等效}=\dfrac{G_2}{1+G_2H}$。当回路增益 $|G_2H|\gg1$ 时，$G_{等效}\approx\dfrac{1}{H}$，与被包围环节 $G_2$ 的实际参数几乎无关——这就是"用强反馈换来对模型的免疫力"（第8章结论的回顾）。因此当对象特性差、参数漂移大时，反馈校正的鲁棒性最强：只要反馈通道 $H$ 是稳定的精密元件（如测速机、传感器），整体特性就稳定可靠。代价是需要额外传感器、结构更复杂，但换来的是对模型不确定性的免疫力。

## 总结：知识体系图

```
直流电机调速系统（或其他任何系统）
   │
   ├─ 1. 物理建模 → G(s) = K/[s(s+1)(s+4)]（第3章）
   ├─ 2. 时域分析 → Routh 判稳、ess、σ%、ts（第5章）
   ├─ 3. 根轨迹分析 → 极点走位、临界K、ζ（第6章）
   ├─ 4. 频域分析 → Bode、γ、ωc（第7章）
   ├─ 5. 发现不达标（γ=28° < 45°）
   ├─ 6. 校正设计 → 超前校正 Gc(s)（第8章）
   └─ 7. 仿真验证（三法核对）→ 达标 ✓
```

### 核心脉络

1. 全流程：**建模 → 三视角分析 → 发现不达标 → 校正 → 验证**；
2. 关键思想：**三大方法殊途同归**——稳、准、快是唯一标准，三副眼镜是三个角度；
3. 工程落地：**设计完必须验证、不达标必须迭代、好设计必须留裕度**；
4. 下一章：总复习——把整本书压缩成一张"考前冲刺地图"。

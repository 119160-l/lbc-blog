### 承上启下

第3章我们学会了把单个物理对象建模成传递函数。但**真实控制系统由许多环节组成**：传感器、控制器、执行器、被控对象、反馈回路……十几个传递函数连在一起，怎么求整个系统的输入-输出关系？本章解决这个问题——用**结构图**和**信号流图**两种图形语言，把复杂系统化繁为简，求总传递函数。这是第5章分析的"弹药库"：没有总传函，后面什么都算不了。

### 问题导向

带着以下问题学习本章，你会更有方向感：

1. **为什么不能把各个环节的传递函数直接乘起来？反馈回路为什么"特殊"？**
2. **结构图化简和梅森公式，哪种更快？什么时候用哪种？**
3. **梅森公式里"回路""不接触"到底是什么？数错会怎样？**

## 一、为什么要结构图？

### 为什么？

第3章的模型是一个方框 $G(s)$。但系统通常是"多环节串联+交叉反馈"的网。**结构图就是控制系统的"电路图"**——把信号的产生、传递、反馈画成一目了然的图，既能帮助理解物理结构，又能通过规则求出总传函。

### 怎么做？

把每个环节画成方框，信号用带箭头线段连接，反馈用回路表示。这张图就是结构图（方框图）。

### 是什么？

> **结构图**：由信号线、方框、比较点、引出点组成的，表示信号流动关系的图形。**它既是一种"可视化"，也是一种"计算工具"**。

---

## 二、结构图的组成与信号流动

### 为什么？

看懂结构图=看懂系统。要理解：每个元素在图中"干什么"。

### 怎么做？是什么？

| 元素 | 图形 | 数学含义 |
|------|------|----------|
| 信号线 | $R(s) \to$ | 传递信号（拉氏变换值） |
| 方框 | $[G(s)]$ | 输出 = 输入 × G(s)（环节） |
| 比较点 | $\oplus$ | 信号代数和（$+$/$-$） |
| 引出点 | $\bullet$ | 信号分路（值不变） |

> 例子：恒温箱系统结构图就是把第1章的五元件图"填上传递函数"——比较点做减法、温控器是控制器 $G_c(s)$、加热器+箱体是被控对象 $G_p(s)$、温度计是 $H(s)$。

---

## 三、结构图等效变换

### 为什么？

系统结构五花八门，但**只由三种基本连接构成**：串联、并联、反馈。把复杂结构化简为这三种基本连接，就能套公式。

### 怎么做？（三条基本公式）

| 连接 | 化简公式 | 直觉 |
|------|----------|------|
| 串联 | $G_1 G_2$ | 信号依次经过，增益相乘 |
| 并联 | $G_1 + G_2$ | 各路分别作用，输出叠加 |
| 负反馈 | $\dfrac{G}{1+GH}$ | 闭环"吃"掉一部分信号 |

![三种基本连接等效变换](./figures/01_三种基本连接等效变换.png)

*图 4-1 三种基本连接的等效变换：串联相乘、并联相加、负反馈"除以 $1+GH$"。绿色方框就是化简后的等效环节——任何复杂系统最终都是这三种形式的嵌套。*

> **时间视角**：反馈连接不只是"多一条线"，它**改变了系统的时间行为**。以 $G=\dfrac{K}{Ts+1}$ 为例：开环时间常数是 $T$；加单位负反馈后闭环时间常数变为 $\dfrac{T}{1+K}$——**反馈越强，系统"反应越快"**。这就是"闭环优于开环"在时间域的第一证据，第8章校正还会用到。

当遇到"引出点/比较点位置不当"造成交叉时，需要**移动**它们（规则：跨过环节 $G$ 时，支路增益补乘/除 $G$），移到能化简的位置。

### 是什么？（化简策略）

```
① 先化简内部的串联、并联、反馈（由内向外）
② 处理交叉：移动比较点/引出点
③ 逐层套"串乘并加反馈除"，直到只剩一个方框
```

> **易错提醒**：移动规则容易记反。记住检验标准——**化简前后的输入输出关系必须完全一致**，做任何移动后可以随手验证。

## 四、信号流图：另一种画法

### 为什么？

结构图直观，但化简繁琐。**信号流图**是一种更"数学化"的画法：只有节点和支路，非常适合套用统一的梅森公式。

### 怎么做？

结构图 ↔ 信号流图的对应：

```
方框 [G(s)]      →  支路（带箭头线段，标 G）
比较点 ⊕         →  节点（信号相加处）
信号线           →  支路
引出点 ●         →  节点分支（输出可以分给多条支路）
```

### 是什么？

> **信号流图**：用节点表示信号、有向支路表示信号传输关系的图。支路上标注"增益"。信号沿支路方向流动，数值=节点值×支路增益。

> 一句话记忆：**结构图是"带方框的图"，信号流图是"把方框变成支路增益的图"**——信息量相同，但信号流图更适合公式化计算。

## 五、梅森增益公式：一步到位的求总传函神器

### 为什么？

化简结构图像"解九连环"，步骤多、容易错。**梅森公式直接"数"出答案**——不化简，只看图数三条清单，就能写出总传函。考试和工程都非常实用。

### 怎么做？

$$
G(s) = \frac{\sum_k P_k \Delta_k}{\Delta}
$$

```
四步流程：
① 找出所有前向通路 P_k（输入→输出，节点不重复）
② 找出所有回路 L_a（闭合路径，节点不重复）
③ 算特征式 Δ = 1 − ΣL + Σ(L_iL_j) − Σ(L_iL_jL_k) + …
    （L_iL_j 表示两两不接触回路的增益乘积）
④ 对每条前向通路 P_k 求余子式 Δ_k：
    在 Δ 中去掉所有与 P_k 接触（有公共节点）的回路项
⑤ G = Σ P_k Δ_k / Δ
```

### 是什么？（三个关键概念的可视化）

```
前向通路：从"入口"到"出口"的一条完整路线，中途节点不重复
回路：   画个圈回到起点，中途节点不重复
不接触： 两个回路没有任何公共节点（"没有交集"）
```

![信号流图与梅森公式](./figures/02_信号流图与梅森公式.png)

*图 4-2 信号流图示例：紫色箭头是前向通路（R→C 的两条路线），红色箭头是回路。先"数"前向通路、回路，再判断哪些回路互不接触，最后套公式——三步完成，全程不用化简。*

> **时间视角**：请把"回路"理解成"信息绕了一圈回到原点"。回路越多、增益越大，$\Delta=1-\sum L+\cdots$ 就越可能接近 0——**$1+GH$ 或 $\Delta$ 越接近 0，闭环极点越靠近虚轴，时间响应越容易振荡发散**。数回路时多留个心眼：你数的其实是系统的"时间命运"。

> **记忆口诀**：`前向通路分母配，回路交替加减乘`。
> - 分子：每条前向通路 × 它的余子式，全部相加；
> - 分母：1 减回路和，加两两不接触积，减三三不接触积，交替。

> **Δ 与 $1+GH$ 的关系**：梅森公式的 $\Delta = 1 - \sum L + \sum L_iL_j - \cdots$ 正是闭环特征式的**一般形式**。对最简单的单位反馈结构（单回路 $L=-GH$），$\Delta = 1 - L = 1+GH$——**Δ 就是 $1+GH$ 在多回路、多前向通路结构下的推广**。所以 $\Delta=0$ 与 $1+GH=0$ 是同一件事：它们的根都是闭环极点。这正是第6章根轨迹法的出发点——研究增益 $K$ 连续变化时 $\Delta=0$ 的根（闭环极点）如何在复平面移动（对应练习题 3.2）。

## 六、双解法对比与工程意义

### 为什么？

同一个系统，两种方法都能解。选对方法能省一半力气。

### 怎么做？是什么？

| 对比   | 结构图等效变换    | 梅森公式         |
| ---- | ---------- | ------------ |
| 本质   | 逐步化简       | 一步到位         |
| 适合   | 小型、结构清晰    | 复杂、多回路、多前向通路 |
| 出错点  | 移动规则记错     | 漏数通路/回路      |
| 速度   | 慢（步骤多）     | 快（数清楚即可）     |
| 物理直觉 | 强（每一步都看得懂） | 弱（纯公式）       |

**工程意义**：在 MATLAB/Python 中，`control.feedback()`、`series()`、`parallel()` 就是自动做"等效变换"；而实际系统（如飞机、化工过程）结构复杂，梅森公式的思想贯穿于系统辨识与回路设计。**两种方法都要会——考试喜欢"先用梅森求，再用化简验证"**。

![双解法传递函数验证](./figures/03_双解法传递函数验证.png)

*图 4-3 同一系统的两种解法（手算化简 vs 仿真库）阶跃响应完全重合。这条曲线就是一阶闭环系统 $1/(s+2)$ 的时间响应——单调上升、无超调，$t=0.5$ s 时到达 63.2%。*

> **时间视角：一张结构图 = 一条时间曲线**。本图中内环反馈把增益 $G_2=2$ "压"成 1，再与外环闭合得到 $1/(s+2)$——极点 $-2$ 在左半平面，所以响应收敛；时间常数 $0.5$ s，约 $1.5$ s 进入稳态。**化简的每一步，最终都会体现在时间曲线的形状上**——这是贯穿全课的"图 ⇄ 时间"对应思想。

## 总结：知识体系图

```
多环节系统
   │
   ├─ 结构图（方框图）：串乘 / 并加 / 反馈除 / 移动规则 → 逐步化简
   │
   └─ 信号流图：节点+支路 → 梅森公式 G = ΣP_kΔ_k / Δ → 一步到位
                        │
                        ▼
                  总传递函数 Φ(s)
                        │
              （输入→输出，全系统一张名片）
                        ▼
           第5章 时域分析、第6章 根轨迹、第7章 频域分析
```

### 核心脉络

1. 复杂系统 = 简单连接的嵌套，化简有公式（串乘并加反馈除）；
2. 关键思想：**梅森公式"数"出总传函**——前向通路、回路、不接触；
3. 下一章：拿到总传函，开始真正的"分析"——时域分析法。

> 梅森公式是"数数"的章——实践任务是**手数一遍 + 机器核对**。

1. **手算 + 符号验证**：取一个 3 回路复杂结构图，先手画信号流图、手数前向通路和回路、套梅森公式求总传函；再用 `sympy` 的符号化简或 `control` 库的 `series/parallel/feedback` 组合验证。

# 第7章 频域分析法——知识讲解

> 本章用**频率的语言**重新理解控制系统：不讨论"时间"而讨论"快慢信号"，不画"波形"而画"频率响应曲线"。
> 本章天然跟工程实践挂钩——你只要能对真实系统做扫频实验，就不需要知道它的微分方程，照样能分析稳定性、设计控制器。

---

## 1. 什么是频域分析？用一段对话理解

想象你和一位音响工程师聊天：

> 你："这个功放的频率响应怎么样？"
> 他："低频还行，中频增益 30 dB，高频从 10 kHz 开始滚降。"
> 你："相位裕度够吗？"
> 他："在穿越频率 8 kHz 处有 52°，挺稳的。"

这段对话里没有一次提到"微分方程"——工程师在**频域里工作**。**这就是频域法的核心优势：你不需要解微分方程，只需要知道系统对不同频率正弦波的"态度"。**

**三段式框架**：
- **是什么**：频域分析 = 给系统扫频，记录各频率下的幅度缩放倍数和相位滞后角度，画成 Nyquist 图/Bode 图。
- **为什么**：① 很多对象（化工、气动、生物）建模极难，但扫频实验人人能做；② 纯延迟 $e^{-\tau s}$ 在频域里干净利落；③ 噪声分析天然在频域做（高频噪声一目了然）。
- **怎么用**：扫频实验 → 画 Bode 图 → 读裕度判稳 → 裕度不够就校正（第8章）。

## 2. 从"正弦扫频"建立体感

### 2.1 给惯性环节做一次"听力测试"

拿一个一阶惯性环节 $G(s)=\dfrac{1}{s+1}$，输入纯正弦波 $r(t)=\sin(\omega t)$，稳定后看输出波形：

```text
ω=0.2 rad/s 时：输出幅值 0.98，几乎不变；相位滞后约 11°，几乎同步
ω=1 rad/s 时：输出幅值 0.707（-3 dB），相位滞后 45°，明显"慢了半拍"
ω=5 rad/s 时：输出幅值 0.196，相位滞后 79°，信号被"压扁"且严重延迟
```

**规律**：频率越高，幅值衰减越狠、相位滞后越严重。这是**所有物理系统的共性**——惯性大了跟不上快节奏。

### 2.2 为什么频域法能做实验建模？

第1章我们写微分方程：输入 → 传递函数 → 输出。现在反过来：

```text
对未知系统输入不同频率的正弦波
  → 记录各频率的稳态输出
  → 算出幅值比和相角差
  → 画 Bode 图 → 反推传递函数
```

**只要能给系统"放音乐"，就能测出它的"听力曲线"**——这就是频域法"不依赖模型"的底气，也是工业界大量使用扫频仪做系统辨识的原因。

## 3. 典型环节的频域性格——把每个零件"拟人化"

开环传函是若干个典型环节的乘积，每个环节对正弦信号的反应有鲜明的"性格"。理解这些性格，Bode 叠加法就是拼乐高。

### 3.1 比例环节 $K$：不管什么频率，一律放大/缩小 $K$ 倍

性格像**稳压电源**——不管输入频率是多少，输出恒定比例。十倍频也面不改色，Bode 图上就是一根水平线。

### 3.2 积分环节 $1/s$：越慢越放大，越快越压扁

性格像**水库**——水龙头拧开，水位慢慢累积。慢速信号（低频）给它大量时间累积，输出很大；快速信号（高频）来不及累积，输出几乎为零。

- 低频段幅值可以非常大（直流理论上无穷大，因为它一直在积）；
- 幅频斜率恒 $-20$ dB/dec：频率每涨十倍，输出就缩十倍；
- 相位恒 $-90°$：输出永远比输入慢四分之一周期。

**工程对应**：电机的位置是速度的积分——给定速度指令，位置一直在"累积"，所以低频位置响应很大，高频就来不及动。

### 3.3 惯性环节 $1/(Ts+1)$：有个"精力上限"

性格像**人的反应**——节奏慢时游刃有余，节奏快过某个点（转折频率 $1/T$）后就开始"跟不上"。

- 低于转折频率：信号太慢，系统完全跟得上 → 幅值 ≈ 1、相位 ≈ 0°；
- 到了转折频率：开始"吃力" → 幅值降到约 0.707（$-3$ dB）、相位滞后 45°；
- 远超转折频率：彻底跟不上 → 幅值每十倍频缩十倍（$-20$ dB/dec）、相位最多滞后 90°。

**工程对应**：RC 低通滤波器——高频噪声进来，直流成分顺利通过，交流成分被滤掉。

### 3.4 一阶微分环节 $\tau s+1$：提前预判

性格像**先知**——信号还没变大，它已经感知到变化趋势并提前放大。频率越高，提前量越大（相位超前，最多 $+90°$），幅值也越来越大（$+20$ dB/dec，这一点和惯性环节正好相反）。

**工程对应**：PID 里的 D 项——"看变化趋势"来提前补偿，改善瞬态性能。

### 3.5 振荡环节：有一个"最敏感的共振频率"

性格像**秋千**——在固有频率附近，越推越高（谐振峰）；远离固有频率则正常衰减。阻尼越小，共振峰越尖锐（$M_r$ 越大），对应的时间响应超调也越大。$\zeta\ge0.7$ 之后峰消失，单调衰减。

**工程对应**：汽车悬挂、建筑结构抗震——都要避开共振。

### 3.6 延迟环节 $e^{-\tau s}$：不管输入多小，就是晚到

性格像**快递**——东西不丢不烂，但就是要晚几天到。**唯一一个幅值恒为 1 但相位随频率线性增长的环节**。频率越高，延迟同样的时间就对应更大的相位滞后。

**工程对应**：网络通信延迟、管道传输延迟——没有办法补偿，只能容忍。

## 4. Bode 图：把乘法变成加法

### 4.1 为什么取对数这么牛？

系统串联时 $G=G_1 G_2$，取对数后 $20\lg|G|=20\lg|G_1|+20\lg|G_2|$——**乘法变加法**！各环节的图直接叠加，用手绘就能出图。

### 4.2 手绘 Bode 图的诀窍

记住五个字：**标 → 低 → 渐 → 修 → 雕**

1. **标**：把传函标准化（每个括号常数项=1），标出所有转折频率，从小到大排好；
2. **低**：画低频段——由积分环节次数 $\nu$ 决定斜率（0、$-20$、$-40$ dB/dec），由增益 $K$ 决定起点高度；
3. **渐**：每到转折频率改斜率：==惯性 $-20$、一阶微分 $+20$、振荡 $-40$；==
4. **修**：在转折点附近把折线修成圆角（最大修 3 dB，正好在转折点）；
5. **雕**：相频图也叠加——每个转折点对应的相角走位心里有数（惯性到转折点时 $-45°$，振荡到 $\omega_n$ 时 $-90°$），逐点连光滑曲线。

一个完整的手绘示例（配图 7-2）见公式推导 §3.3——对照着那七步走一遍，就彻底掌握了。

## 5. Nyquist 判据——三大判据的"巅峰"

### 5.1 一个悬崖边的比喻

把 Nyquist 曲线想成一条**悬崖边的散步轨迹**，$(-1,j0)$ 是悬崖：

- 散步路径如果**没包围**悬崖 → 安全（$Z=0$）
- 散步路径**顺时针绕**悬崖一圈 → 有一个闭环极点在右半平面（$Z=1$）
- 散步路径**贴着悬崖边缘走** → 临界稳定，稍一扰动就掉下去

**如果悬崖本身就在散步区域内（$P\ge1$，开环不稳定）怎么办？**
这时候规则变成：散步路径必须**逆时针**绕悬崖 $P$ 圈，"抵消"掉开环的不稳定因素，闭环才能安全。§4.4 例 2 就是这种情况——$P=1$，曲线逆时针绕一圈，闭环稳定。

### 5.2 对数判据：Bode 图上看悬崖

不想画 Nyquist 曲线也行——在 Bode 图上数相频曲==线穿过 $-180°$ 的次数，就能等价判稳。**穿越发生在 $L(\omega)>0$ dB 的频段**才计数（信号够大才算）。正穿越（向上穿）加稳定性、负穿越（向下穿）减稳定性。==

**大部分常规系统**（$P=0$）的简化判据：
- Bode 图上 $L(\omega_c)=0$ dB 时，只要相位没到 $-180°$，系统就稳定；
- **相位裕度 $\gamma$ 就是 $\omega_c$ 处相位离 $-180°$ 还有多远。**

## 6. 稳定裕度——不仅"稳不稳"，还问"有多稳"

### 6.1 双裕度缺一不可

工程要求**两个裕度同时合格**：

- **$\gamma=30°\sim60°$**：保证瞬态不剧烈振荡（太小），也不过于迟钝（太大）；
- **$K_g\ge 6$ dB（≥2 倍）**：保证增益漂移 2 倍内不失稳。

**为什么两个都要**？因为 $(-1,j0)$ 是复平面上的一个点，你需要**角度方向**和**模长方向**两个维度的安全距离。

### 6.2 典型设计场景

| 场景                        | 裕度表现        | 怎么办       |
| ------------------------- | ----------- | --------- |
| $\gamma=25°$、$K_g=9.5$ dB | 幅值安全，相位偏脆   | 加超前校正补相位  |
| $\gamma=60°$、$K_g=3$ dB   | 相位安全，增益裕度不够 | 降增益或用滞后校正 |
| $\gamma=45°$、$K_g=12$ dB  | 两者均优，设计完美   | 别动它       |

### 6.3 手把手读一次 Bode 图（考试/工程核心技能）

对着 $G(s)=\dfrac{10}{s(s+1)(s+5)}$ 的 Bode 图（图 7-2），按顺序读四个数：

```
① 找 ωc：幅频曲线与 0 dB 线的交点        → ωc ≈ 1.23
② 读 γ：在 ωc 处看相频 = -154.7°         → γ = 180°-154.7° = 25.4°
③ 找 ωg：相频曲线与 -180° 线的交点        → ωg ≈ 2.24
④ 读 Kg：在 ωg 处看幅频 = -9.5 dB         → Kg = 9.5 dB
```

**下结论**：

| 指标 | 数值 | 合格线 | 结论 |
|------|------|--------|------|
| $\gamma$ | $25.4°$ | $\ge30°$ | ❌ 相位裕度不足 |
| $K_g$ | $9.5$ dB | $\ge6$ dB | ✅ 幅值裕度合格 |

**一句话诊断**："系统能稳，但偏脆——$\gamma$ 不达标，需要超前校正"——这就是第8章要干的事。**会读图 → 会诊断 → 会开药方**，频域分析的工程链路就此打通。

## 7. 频域 ⇔ 时域：同一身体，不同体检

**核心速记**（二阶设计区 $\zeta=0.3\sim0.7$ 内有效）：ts是调节时间

$$
\boxed{\gamma(度) \approx 100\zeta,\qquad \omega_c \approx \frac{4\sim7}{t_s}}
$$

**关键对照表**：

| 你要的效果        | 时域指标目标            | 频域指标目标             |
| ------------ | ----------------- | ------------------ |
| 振荡小（超调 <20%） | $\zeta>0.45$      | $\gamma>45°$       |
| 响应快（调节时间短）   | $t_s$ 小           | $\omega_c$ 大       |
| 又快又稳（最佳折中）   | $\zeta\approx0.6$ | $\gamma\approx60°$ |
| 稳态误差小        | $K$ 大、型别高         | 低频段高（Bode 图左端抬高）   |

**跨章串联**（记这三个等式，三章打通）：

- $\gamma\approx100\zeta$ 连起了 **第5章（时域 $\sigma\%$）⇔ 第7章（频域 $\gamma$）**
- $K_g = K^*/K$ 连起了 **第6章（根轨迹临界增益）⇔ 第7章（幅值裕度）**
- $1+GH=0$ 连起了 **第4章（梅森）⇔ 第5章（Routh）⇔ 第6章（根轨迹）⇔ 第7章（Nyquist）**

### 7.1 换算实战：设计指标来回跳

**场景**：老师要求"超调量 $\le20\%$"，这是**时域**指标，怎么转成**频域**设计目标？

**第1步：由 $\sigma\%$ 反求 $\zeta$**（第5章公式 $e^{-\pi\zeta/\sqrt{1-\zeta^2}}=0.2$）：

$$
\zeta \approx 0.456
$$

**第2步：由 $\zeta$ 求 $\gamma$**（本章速算式）：

$$
\gamma \approx 100\zeta \approx 46°
$$

**结论**：把系统相位裕度做到 $\gamma\ge46°$ 就满足"超调 $\le20\%$"。**检验**：设计完成后实测 $\gamma=52°$，反推 $\zeta\approx0.52$、$\sigma\%\approx15\%$——达标 ✓。

**记忆闭环**：$\sigma\% \xrightarrow{第5章} \zeta \xrightarrow{第7章} \gamma$——两个方向都能换算，考试常在这三章之间"跳来跳去"出题。

## 8. 三大判据对比：一个系统，三面镜子

| | Routh 判据（第5章） | 根轨迹（第6章） | Nyquist 判据（第7章） |
|---|---|---|---|
| **输入** | 特征方程系数 | 开环传函 + 增益范围 | 频率响应（实验数据或开环传函） |
| **输出** | 右半平面极点数 | 极点随 $K$ 的运动轨迹 | 闭环稳定 + 稳定裕度 |
| **能否处理延迟** | ❌（超越方程） | ❌（延迟引入无穷极点） | ✅（$e^{-j\tau\omega}$ 只影响相位） |
| **能否用实验数据** | ❌（必须有系数） | ❌（必须有传函） | ✅（扫频实验直接画图） |
| **稳定裕度** | 无（只看绝对稳定） | 可看极点离虚轴距离 | 有（$\gamma$、$K_g$ 精确量化） |
| **适合做设计吗** | 不太适合 | 适合（选 $K$ 和极点位置） | 最适合（校正器直调裕度） |

## 9. 工程案例：频域法的三个实际应用

### 9.1 音响功放设计（带宽）

音频功放的 Bode 图要求在 20 Hz~20 kHz 范围内幅频平坦、相位线性。设计要点：$\omega_c$ 要设在远高于可听频带处，保证在可听区间内相移较小；同时高频要能滚降以抑制无线电干扰。

### 9.2 电机伺服系统的谐振抑制

永磁同步电机的机械谐振频率通常在几百 Hz 处，对应 Bode 图上有一个尖锐的谐振峰（$M_r$ 大）。控制器设计要在该频率处提供足够的阻尼——常见做法是加**陷波滤波器**，在谐振频率处开一个"坑"。

### 9.3 无人机姿态控制

飞控的角速度回路带宽（$\omega_c$）一般设到 50~100 Hz，相位裕度要求 $\ge45°$。带宽越高，抗阵风能力越强，但对噪声和延迟越敏感。实践中通过扫频实验测出实际机架+电机的频率特性，再据此设计 PID 参数——典型的实验频域法。

## 本章收束

**频域法给了我们一副"频率滤镜"看系统**：

- 时域看的是"跑起来表现怎么样"（$c(t)$ 曲线），
- 根轨迹看的是"参数变的时候极点怎么搬家"，
- 频域看的是"不同频率信号各被怎么对待"。

三副眼镜互补：时域直观、根轨迹指导参数设计、频域处理实验和工程最方便。第9章会把三条路摆在一起，看同一道题从不同角度怎么做。

**学完本章，你应该能**：
1. 把 $G(s)$ 换成 $G(j\omega)$，写出幅频和相频表达式；
2. 手绘 Bode 渐近线，读出 $\omega_c$ 和 $\omega_g$；
3. 用 Nyquist 曲线（或对数判据）判断闭环稳定性；
4. 计算相位裕度和幅值裕度，判断是否合格；
5. 用 $\gamma\approx100\zeta$ 和 $t_s\approx(4\sim7)/\omega_c$ 在频域和时域之间来回换算。
